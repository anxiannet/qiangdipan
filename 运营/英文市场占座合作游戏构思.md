# 英文市场占座合作游戏构思

更新时间：2026-07-06

## 文件定位

本文件记录面向新加坡本地英文市场的占座题材合作卡牌游戏构思。

本文件是独立题材与产品方向探索，不修改《夕妖：抢地盘》现行规则、卡表、胜利条件或视觉规范。

## 一、核心判断

“占座”题材更适合做成合作类卡牌桌游，而不是直接做成抢地盘式对抗游戏。

原因：现实中的纸巾占座通常不是一个人对抗全场，而是一群朋友在小贩中心分工合作：

```text
有人找座
有人排队买饭
有人买饮料
有人看包
有人处理突发状况
大家赶在午餐高峰前凑齐一桌
```

因此，本方向应围绕：

```text
合作完成一顿新加坡小贩中心午餐
```

## 二、产品概念

### 英文名候选

```text
Chope!
```

### 英文副标题

```text
A cooperative Singapore card game about saving seats before lunch rush.
```

### 中文内部名

```text
《占座！》
```

### 产品定位

```text
2–5人
15–20分钟
合作卡牌
新加坡小贩中心题材
轻策略 + 欢乐突发事件
```

---

## 三、核心故事

玩家是一群朋友，午餐时间来到小贩中心。

你们要在高峰期之前完成三件事：

```text
占到足够座位
买齐大家的食物和饮料
避免座位被别人拿走
```

如果成功，大家一起开饭。

如果失败，大家只能端着盘子到处找位。

---

## 四、核心目标

合作胜利条件：

```text
在 Lunch Rush 爆满前，成功完成一张 Meal Plan。
```

Meal Plan 是任务卡，用来定义本局需要完成的座位、食物与饮料需求。

示例：

```text
Table for 3
需要：3个座位 + 2份主食 + 1杯饮料
```

```text
Family Lunch
需要：4个座位 + 3份主食 + 2杯饮料
```

```text
Office Team Lunch
需要：5个座位 + 4份主食 + 3杯饮料
```

这样“占座”不会只是放纸巾，而是变成完整的小贩中心午餐任务。

## 五、玩家身份

每个玩家可以拥有一个角色能力，让合作分工更明确。

| 中文定位 | 英文名 | 能力方向 |
|---|---|---|
| 占座达人 | Chope Master | 更容易保护座位 |
| 排队高手 | Queue Pro | 买食物更快 |
| 饮料代表 | Kopi Runner | 拿饮料更快 |
| 社交王 | Friendly Regular | 化解冲突事件 |
| 桌位侦察员 | Table Scout | 更容易发现空桌 |
| 怕输朋友 | Kiasu Friend | 可以多做一次行动，但增加混乱 |

## 七、座位牌 Seat Cards

座位牌代表玩家找到的可用桌位 / 座位资源。

示例：

```text
Empty Seat
Corner Table
Shared Table
Near Fan
Near Bin
Reserved Looking Seat
Wet Table
```

不同座位可以有轻微差异。

示例效果：

```text
Corner Table
Counts as 2 seats if protected.
```

```text
Wet Table
Requires Tissue before it can be used.
```

---

## 八、占座牌 Chope Cards

占座牌是本游戏的核心趣味，用来保护座位或处理座位危机。

示例：

```text
Tissue Packet
Umbrella
Name Card
Water Bottle
Shopping Bag
Friend Sitting There
```

示例效果：

```text
Tissue Packet
Protect 1 seat.
```

```text
Umbrella
Protect 2 seats, but cannot be used during Heavy Rain.
```

```text
Friend Sitting There
Protect any table this round.
```

---

## 九、食物牌 Food Cards

食物牌代表玩家排队买到的主食。

示例：

```text
Chicken Rice
Laksa
Prata
Nasi Lemak
Char Kway Teow
Satay
Cai Fan
Fish Soup
```

不同食物可以有不同排队成本。

示例效果：

```text
Chicken Rice
Food. Queue: 1.
```

```text
Laksa
Food. Queue: 2. Worth 2 satisfaction.
```

## 十、饮料牌 Drink Cards

饮料牌既是任务资源，也可以提供小效果。

示例：

```text
Kopi O
Teh C
Milo Dinosaur
Sugarcane Juice
Bandung
Iced Lemon Tea
```

示例效果：

```text
Kopi O
Gain 1 extra action this round.
```

```text

Cancel Heaty Day.
```

## 十一、威胁系统：Lunch Rush Track

合作游戏需要持续压力。本题材最自然的压力来源是午餐高峰。

```text
Lunch Rush Track
```

建议轨道：

```text
0–3：还好，有空位
4–6：开始拥挤
7–9：人潮爆满
10：失败
```

失败条件：

```text
Lunch Rush 到达 10，所有空位被占满，游戏失败。
```

可选第二失败条件：

```text
座位被抢光
或 Meal Plan 到时间还没完成
```

---

## 十二、回合流程

每回合保持简单。

```text
1. 抽事件
2. 玩家轮流行动
3. 检查座位是否被保护
4. Lunch Rush 上升
5. 检查是否完成 Meal Plan
```

每个玩家每回合建议有 2 个行动点。

可选行动：

```text
Find Seat
Chope Seat
Queue for Food
Buy Drink
Protect Table
Ask to Share Table
Clean Table
Cancel Event
```

```

```

## 十四、游戏张力

玩家需要不断讨论分工：

```text
先占座，还是先买饭？
座位够了，但没人保护。
饭买好了，但桌子被别人拿走。
有人去排 Laksa，结果队伍太长。
有人守座，结果缺饮料。
```

典型合作讨论：

```text
你去买 kopi。
我去找四人桌。
他用 tissue 先保护两个座。
下回合一起买主食。
```

这类张力来自新加坡真实生活经验，适合英文本地市场传播。

## 十五、首版牌组结构建议

### 60–72张版本

合作游戏需要足够事件牌支撑变化，因此首版建议目标控制在 60–72 张。

示例结构：

```text
角色卡：6张
Meal Plan 任务卡：10张
Seat 座位卡：18张
Chope 占座卡：18张
Food 食物卡：20张
Drink 饮料卡：12张
Event 事件卡：30张
参考卡：4张
```

说明：上述为设计池规模，不一定全部进入首版基础盒。

### 56张压缩版本

如果需要小盒压缩，可考虑：

```text
角色卡：5张
Meal Plan：8张
Seat：12张
Chope：12张
Food / Drink：12张
Event：16张
参考卡：4张
```

但合作游戏过度压缩会降低事件变化和重玩性。

## 十六、核心卖点

英文一句话：

```text
Chope seats, grab food, survive lunch rush.
```

包装背面文案方向：

```text
You and your friends are hungry.
The hawker centre is packed.
Can you chope enough seats, grab everyone’s food, and sit down before the lunch rush takes over?
```

中文内部解释：

```text
一群朋友合作在新加坡小贩中心抢救午餐。
有人占座，有人排队，有人买饮料，有人处理突发事件。
在午餐高峰爆满前凑齐座位和食物，全员开饭即胜利。
```

## 十七、为什么题材成立

该题材不要求玩家代入摊主经营权，而是代入每个新加坡人都熟悉的午餐场景。

核心生活经验包括：

```text
找座位
放纸巾
排队买饭
朋友还没来
饭好了座位没了
下雨后人突然变多
午餐高峰爆满
```

这比“抢摊位”更自然，也更适合合作游戏。

## 十八、当前结论

推荐定位：

```text
Chope!
A cooperative card game about saving seats before lunch rush.
```

核心玩法一句话：

```text
Work together to reserve seats, buy food, and complete your meal before the hawker centre gets too crowded.
```

中文内部定位：

```text
新加坡小贩中心占座合作卡牌游戏。
不是抢摊位，而是合作完成一顿午餐。
```

## 十九、后续待验证问题

1. 英文名使用 `Chope!` 是否足够清晰，是否需要副标题解释。
2. 游戏是否定位 2–5 人还是 2–4 人。
3. Lunch Rush Track 的节奏是否能稳定控制在 15–20 分钟。
4. Food / Drink 是否拆成两类牌，还是合并为 Meal Cards。
5. 是否需要隐藏信息，还是完全开放合作。
6. 纸巾占座梗是否需要避免变成负面公共行为鼓励，文案应保持轻松幽默。
