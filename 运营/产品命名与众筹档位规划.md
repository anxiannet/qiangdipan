## 一、前期产品结构

前期实体产品只设置两个包装：

```text
1. 《夕妖：抢地盘》标准版
2. 《夕妖：抢地盘》扩展包一：妖王再临
```

不在首发阶段设置过多包装版本，避免众筹页面和买家理解成本过高。

---

## 二、主产品命名

### 正式对外名称

```text
《夕妖：抢地盘》标准版
```

### 命名理由

| 候选名 | 买家感受 | 判断 |
|---|---|---|
| 便携版 | 像小盒旅行装，容易显得内容少 | 不作为主版本名 |
| 基础版 | 像入门版，容易让买家觉得“不完整” | 内部规则可用，对外慎用 |
| 核心版 | 桌游语境可用，但中文买家可能觉得还缺扩展 | 可用于英文或内部说明 |
| 标准版 | 正式、完整、开盒即玩 | 对外主推 |

结论：

```text
对外主产品统一叫“标准版”。
内部规则文件可以继续使用“基础规则”“基础公共牌库”等术语。
```

---

## 三、标准版内容口径

标准版是完整可玩的主产品。

当前 V1.3 标准版内容：

```text
40张公共牌
12张地盘
2~4人
15~30分钟
完整可玩
```

对外话术：

```text
标准版已包含完整游戏体验，开盒即可游玩。
```

避免对外写法：

```text
基础版40张
```

原因：容易让买家误以为该版本是不完整的低配版。


```text

```

短话术：

```text
黑芯典藏卡｜更挺括｜更耐洗｜更有收藏质感
```

```text

```

说明：黑芯典藏卡是材质升级选项，不是第三个包装。

## 七、众筹档位建议

前期建议以清晰为主，不设置随机抽包。

推荐档位：

| 档位 | 内容 |
|---|---|
| 早鸟标准版 | 标准版，限时优惠 |
| 标准版 | 40张公共牌 + 12张地盘，完整可玩 |
| 妖王再临套装 | 标准版 + 扩展包一：妖王再临 |
| 黑芯典藏套装 | 标准版 + 妖王再临扩展包 + 黑芯典藏卡升级 |
| 收藏版 | 黑芯典藏套装 + 异画 / 闪卡 / 编号卡 / 收纳升级，具体另定 |

## 八、随机6卡包暂不进入首发

短期不建议采用：

```text
每包6卡
随机抽卡
玩家自己抽卡收集
```

原因：

```text
1. 众筹买家更希望知道自己买到什么。
2. 随机包会带来重复卡、缺关键卡和补齐成本疑虑。
3. 当前阶段优先验证玩法和实体产品，不优先进入TCG式抽卡商业模式。
4. 固定扩展包更适合桌游首发和众筹交付。
```

推荐路径：

```text
第一阶段：固定20张扩展包
第二阶段：如果形成粉丝和复购，再考虑异画小包、闪卡小包、妖怪收藏包
```
