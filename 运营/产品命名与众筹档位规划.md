## 一、前期产品结构

前期实体产品只设置两个包装：

```text
1. 《夕妖：抢地盘》标准版
```

## 二、主产品命名

### 正式对外名称

```text
《夕妖：抢地盘》标准版
```

### 命名理由

| 候选名 | 买家感受 | 判断 |
|---|---|---|
| 便携版 | 像小盒旅行装，容易显得内容少 | 不作为主版本名 |
| 基础版 | 像入门版，容易让买家觉得“不完整” | 内部规则可用，对外慎用 |
| 核心版 | 桌游语境可用，但中文买家可能觉得还缺扩展 | 可用于英文或内部说明 |
| 标准版 | 正式、完整、开盒即玩 | 对外主推 |

结论：

```text
对外主产品统一叫“标准版”。
内部规则文件可以继续使用“基础规则”“基础公共牌库”等术语，但对外不写“基础版”。
```

---

## 三、标准版内容口径

标准版是完整可玩的主产品。

当前 V1.3-卡表-004 标准版内容：

```text
42张公共牌
12张地盘
2~4人
15~30分钟
完整可玩
```

对外话术：

```text
标准版已包含完整游戏体验，开盒即可游玩。
```

避免对外写法：

```text
基础版42张
```

原因：容易让买家误以为该版本是不完整的低配版。

## 四、扩展包命名

### 第一包正式名称

```text
《夕妖：抢地盘》扩展包一：火云再起
```

短写：

```text
火云再起
```


```text

红孩儿
玉面狐狸
铁扇公主
芭蕉扇
```

说明：具体扩展包卡表维护于：

```text

```

本文件不重复维护卡牌数量与技能。

## 六、材质升级命名

### 正式名称

```text
黑芯典藏卡
```

### 不推荐名称

```text
黑芯纸升级
黑芯纸
专业黑芯牌芯
```

原因：这些名称偏工厂语言，不适合作为众筹页面卖点。

### 对外话术

完整话术：

```text
卡牌升级为黑芯典藏卡，手感更挺括，遮光性更好，更适合反复洗牌与长期收藏。
```

短话术：

```text
黑芯典藏卡｜更挺括｜更耐洗｜更有收藏质感
```

英文/徽章辅助标识：

```text
BLACK CORE
黑芯典藏卡
```

说明：黑芯典藏卡是材质升级选项，不是第三个包装。

## 七、众筹档位建议

前期建议以清晰为主，不设置随机抽包。

推荐档位：

| 档位 | 内容 |
|---|---|
| 早鸟标准版 | 标准版，限时优惠 |
| 标准版 | 42张公共牌 + 12张地盘，完整可玩 |
| 火云再起套装 | 标准版 + 扩展包一：火云再起 |
| 黑芯典藏套装 | 标准版 + 火云再起扩展包 + 黑芯典藏卡升级 |
| 收藏版 | 黑芯典藏套装 + 异画 / 闪卡 / 编号卡 / 收纳升级，具体另定 |
