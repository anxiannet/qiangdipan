## 一、众筹核心定位

众筹的核心不是“先收钱”，而是：

```text
用真实订单验证这个游戏有没有人愿意买，再决定印多少。
```

对《抢地盘》这种实体卡牌，众筹适合用于解决以下风险：

- 印刷成本风险
- 库存风险
- 市场验证风险
- 首批种子玩家获取风险

当前阶段不建议马上启动正式大众众筹。

更适合先进行：

```text
预热 + 试玩 + 小范围预售意向收集
```

## 二、为什么要众筹

### 1. 降低库存风险

如果直接印 1000 盒，假设一盒成本 30–50 元，前期可能需要压几万元库存。

众筹可以先验证：

```text
到底有多少人愿意付钱买？
```

判断方式：

| 支持人数 | 处理方式 |
|---:|---|
| 约30人 | 做小批量测试版，继续验证 |
| 约300人 | 考虑正式小批量或批量生产 |
| 支持人数不足 | 继续优化产品包装、价格、卖点或规则 |

### 2. 先验证市场

亲友说“好玩”不等于愿意掏钱。

众筹重点验证三个问题：

- 玩家看了封面和介绍，会不会心动。
- 玩家能不能接受价格。
- 玩家愿不愿意等待生产和发货。

这些反馈比空想更重要。

### 3. 提前锁定首批玩家

众筹支持者不是普通买家，他们可以成为：

- 第一批玩家
- 试玩反馈者
- 小红书 / 朋友圈传播者
- 群内种子用户
- 后续扩展包购买者

《抢地盘》是欢乐聚会卡牌游戏，第一批真实玩家非常重要。

### 4. 让产品看起来更正式

众筹页面会倒逼项目整理：

- 游戏定位
- 内容物
- 规则说明
- 卡牌展示
- 盒子展示
- 打样照片
- 价格档位
- 发货时间
- 风险说明

这个过程本身就是一次产品化。

## 三、众筹前置条件

不要现在马上开正式众筹。

正式众筹前至少需要准备以下内容。

### 1. 可试玩样品

最少要有一套实体测试卡。

样品不需要完美，但必须能拍照、能试玩、能展示：

- 盒子
- 卡牌
- 地盘
- 妖怪
- 法宝
- 桌面摆放效果

如果只有 AI 图和规则文档，信任感不足。

### 2. 清楚的卖点

《抢地盘》的基础卖点可以写为：

```text
2–4 人西游妖怪抢地盘卡牌游戏
15–30 分钟一局
轻策略，强互动，欢乐嘴炮
控制同一妖域 3 块地盘立即获胜
```

宣传重点不是讲复杂规则，而是让玩家一眼知道：

- 这是什么游戏。
- 几个人玩。
- 多久一局。
- 爽点是什么。

### 3. 成本核算

众筹前必须知道一盒大概成本。

成本项至少包括：

- 卡牌印刷
- 包装盒
- 说明卡 / 指南卡
- 塑封
- 打包材料
- 国内 / 本地邮费
- 平台手续费
- 损耗
- 补发成本

如果成本没算清，众筹成功也可能亏钱。

### 4. 打样照片

众筹页面最好不要只放效果图。

应优先放：

- 实物卡牌照片
- 手牌展示
- 桌面摆放
- 盒子照片
- 卡牌厚度
- 开盒内容物

真实感比精修图更重要。

## 五、众筹执行方式

### 第一步：小范围预热

不要一上来公开大推。

先在自有渠道测试反应：

- 微信群
- 朋友圈
- 小红书
- 桌游群
- 新加坡华人群
- 夕妖战队群
- 身边朋友试玩

目标不是马上卖很多，而是先看反应。

可用预热话术：

```text
我做了一款西游妖怪抢地盘卡牌游戏，2–4 人，15–30 分钟一局。
现在准备做首批测试版，有没有人愿意支持一盒？
```

如果没人问，说明包装、卖点、价格或展示方式需要继续调整。

### 第二步：首批测试版预售

第一轮不建议叫“大众筹”，建议叫：

```text
首批测试版预售
```

推荐第一目标：

```text
首批测试版 50 盒
```

不要一开始喊 1000 盒。

测试版可标注：

```text
首批测试版
非最终量产版
规则和美术可能后续微调
```

这样压力更小，也更真实。

## 六、推荐众筹结构

第一轮建议定位：

```text
首批测试版预售
```

### 1. 推荐目标

| 目标 | 数量 | 说明 |
|---|---:|---|
| 低目标 | 50盒 | 验证真实需求 |
| 中目标 | 100盒 | 可考虑正式小批量 |
| 高目标 | 300盒 | 才考虑更好的盒子、闪卡或工艺升级 |

### 2. 推荐承诺

可以承诺：

- 标准版一套
- 火云再起扩展包加购
- 首批编号
- 一张限定感谢卡
- 后续规则更新电子版
- 众筹支持者进入反馈群

不建议第一轮承诺：

- 大量闪卡
- 复杂周边
- 金属币
- 豪华盒
- 多语言说明书
- App
- 长期赛事

复杂承诺会显著增加履约风险。

## 七、众筹页面结构

### 1. 一句话介绍

```text
《夕妖：抢地盘》是一款西游妖怪题材的欢乐聚会卡牌游戏，2–4 人，15–30 分钟一局，派出妖怪占山为王，抢下同一妖域 3 块地盘即可获胜。
```

### 2. 为什么好玩

写三个点即可：

- 抢地盘：不是单纯打血量，而是争夺妖域。
- 欢乐互动：喊名字、收妖、吹回、抢守军。
- 上手快：一局 15–30 分钟，适合朋友聚会。

### 3. 内容物

标准版写清楚：

- 42张公共牌
- 12张地盘
- 指南卡 / 说明卡
- 包装盒

火云再起扩展包写清楚：

- 18张扩展卡
- 需搭配标准版使用

具体数量仍以 `规则/V1.3-基础卡表.md` 与 `规则/扩展包一-火云再起卡表.md` 为准。

### 4. 怎么赢

```text
控制同一妖域的 3 块地盘，立即获胜。
```

### 5. 当前进度

建议诚实写：

- 规则 V1.3 已完成。
- V1.3-卡表-004 已完成。
- 标准版42张公共牌，火云再起18张扩展牌。
- 正在进行实物打样。
- 首批为测试版 / 小批量版。

根据当前项目状态，还可补充：

- 实体测试版先做 5 套。
- 当前已有 11 个包装盒正在印刷。
- 正在优先完善双人快速局可选规则。

### 6. 风险说明

必须写清楚：

- 印刷颜色可能与屏幕略有差异。
- 不同批次卡背可能存在轻微色差，混入扩展包时建议使用不透明牌套。
- 首批测试版可能有小幅规则说明调整。
- 发货时间取决于打样和生产周期。
- 如果数量不足，将改为小批量手工整理发货。

这些说明能提升可信度。

## 九、推荐执行路径

《抢地盘》适合按以下路径推进：

1. 做 1–3 套实体测试样品。
2. 找 10–20 人试玩。
3. 拍实物照片和试玩短视频。
4. 做小红书 / 微信群预热。
5. 开首批 50 盒测试版预售。
6. 够 50 盒就印，不够就继续改。
7. 首批玩家进入反馈群。
8. 反馈稳定后，再做正式版众筹。

结合当前项目状态，本轮更具体的执行顺序为：

```text
完善双人快速局可选规则
↓
制作5套实体测试版
↓
检查11个正在印刷的包装盒实物效果
↓
组织10–20人试玩
↓
拍摄实物照片与试玩短视频
↓
小红书 / 微信群 / 私域预热
↓
首批50盒测试版预售
```

## 十、核心结论

```text
用最小风险验证《抢地盘》有没有真实买家。
```

第一轮目标不是做大，而是验证：

- 玩家是否愿意买。
- 价格是否能接受。
- 玩法是否能传播。
