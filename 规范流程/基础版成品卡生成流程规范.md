# 基础版成品卡生成流程规范

更新时间：2026-06-28

## 适用范围

本规范用于把已经通过插画风格审核的基础版插画，合成为《夕妖：抢地盘》成品卡正面。

适用对象：

- 妖怪卡基础版插画
- 法宝卡基础版插画
- 已经完成阔图、缩放、移动或裁切适配的成品卡审核稿

## 唯一来源

- 卡牌名称、类型、星级、卡面文案、审核状态：`规则/V1.2-基础卡表.md`
- 妖怪动作、表情、场景、道具、特效、安全区要求：`妖怪志/卡名/卡名.md`
- 法宝动作、特效、安全区要求：`法宝志/卡名.md`
- UI 与安全区规则：`规范流程/UI规范.md`
- 视觉总方向：`规范流程/视觉总规范.md`

不得从历史批量合成 JSON 反推技能文案；卡面文案以当前基础卡表为准。

## 资产分层

- 试玩版成品卡：`卡牌成品/正面/试玩版/`
- 基础版成品卡：`卡牌成品/正面/基础版/`
- 成品合成定稿资源：`资源/`
- 妖怪基础版插画：`妖怪志/卡名/插画/基础版/`
- 妖怪基础版审核与迭代记录：随插画保存在同一目录

基础版不得覆盖试玩版，也不得覆盖旧的 `卡牌成品/正面/xiyao_qiangdipan_card_front_*.png`。

## 单卡生成流程

1. 读取 `规则/V1.2-基础卡表.md`，确认卡牌处于已审核状态，且不是待设计。
2. 读取对应 `妖怪志` 或 `法宝志`，确认插画动作、表情、道具、特效和安全区要求。
3. 选择已经通过风格与亮度审核的基础版插画。
4. 若主体贴边或不利于入框，先做阔图，保留原图不覆盖。
5. 使用成品卡脚本或同等 Pillow 合成流程生成单张成品卡。
6. 输出到 `卡牌成品/正面/基础版/卡名_基础版_版本_card_front.png`。
7. 审核成品卡：
   - 脸部不得被 UI 遮挡。
   - 主动作不得被名称牌、星级或底部技能栏遮挡。
   - 关键道具不得被遮挡。
   - 技能文案必须与 `规则/V1.2-基础卡表.md` 一致。
   - 小图可读，适合实体卡印刷。
8. 将成品卡路径、审核结论和问题点写回对应插画迭代记录。
9. 将通过的成品卡登记到 `程序数据/卡牌成品/基础版成品数据.json`。

## 资源归档规则

通过审核并会继续复用的 UI、插画和合成参数必须归档到对应长期目录：

- UI 定稿：`资源/UI/`
- 插画定稿：`资源/插画/`
- 审核通过成片：`资源/审核定稿/`
- 单卡版式数据：`程序数据/合成程序/`

`output/final/` 只保留临时审核输出，不作为长期资源来源；通过审核后应同步到正式正面目录和资源目录。

## 适配原则

- 插画风格、亮度、角色表情和技能表达已经通过时，优先通过阔图、缩放、移动和裁切适配 UI。
- 不因单纯安全区位置问题反复重生成插画。
- 生成阔图时保持主体居中，主体约占有效安全画布宽度 68%、高度 58%，四周保留后期可调整空间。
- 成品卡合成时可以让非关键背景被名称牌或边框遮挡，但不得遮挡脸部、主动作、关键道具和技能结果。
