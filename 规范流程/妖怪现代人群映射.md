# 妖怪现代人群映射规范

## 文件定位

本文件用于统一《夕妖：抢地盘》基础版妖怪卡的现代社会人群映射、情绪、动作、表情与卡面台词方向。

本文件不修改规则，不维护第二份卡表，不改变任何技能效果、星级、数量或阵营归属。

插画原则：

- 妖怪插画负责增加代入感、人物感、社会观察和欢乐感。
- 技能区负责解释规则，插画不负责画卡牌规则教学图。
- 每个妖怪应对应一种现代社会中的人群、性格或处境。
- 角色设计优先表现“像这种人”，再表现“像这个妖怪”。
- 台词可以上卡面，但必须服务角色气质，不替代技能文案。
- 下列字段颗粒度应同步进各妖怪志：现代人群映射、代表群体、情绪关键词、动作设计、表情设计、台词方向、视觉禁忌。

## 一、1星有名小妖

### 小钻风

- 现代人群映射：基层摸鱼巡逻员 / 被领导派出来走流程的人。
- 代表群体：被安排做巡查、打卡、跑流程，但实际边走边混时间的小基层。
- 情绪关键词：轻松、摸鱼、惬意、应付差事、吊儿郎当。
- 动作设计：扛破旗、拎铜锣，松松垮垮走山路，边走边唱，像出来游山玩水。
- 表情设计：半眯眼、笑嘻嘻、得意又懒散，像“出来晃一圈就算交差”。
- 台词方向：大王派我来巡山……
- 视觉禁忌：不要画成认真军队巡逻，不要画成战斗冲锋，不要放卡牌教学元素。

### 有来有去

- 现代人群映射：跑腿快递员 / 办公室传文件的人 / 来回送件的小职员。
- 代表群体：夹在两边之间来回奔波、送完一件又接下一件、永远在路上的底层跑腿人。
- 情绪关键词：忙乱、赔笑、急匆匆、好脾气、滑稽、社畜式熟练。
- 动作设计：一手递新信，一手拎旧包袱，脚下烟尘和往返残影，像刚到又马上要走。
- 表情设计：嘴巴张大、眼睛瞪圆、笑得有点夸张，既热情又疲惫。
- 台词方向：来了来了，又走了！
- 视觉禁忌：不要画成火云洞小妖；不要画成只送不回；不要放卡牌、牌堆、抽弃箭头。

### 精细鬼

- 现代人群映射：小会计 / 库管 / 抠门财务 / 精打细算的账房人。
- 代表群体：天天查账、盘库存、算成本、抠细节的小管理者。
- 情绪关键词：精明、抠门、小得意、谨慎、算盘打得响。
- 动作设计：扒着账本、拨算盘、数货架和竹篮，钥匙串挂在腰间。
- 表情设计：眯眼、嘴角上扬，像“我早就算清楚了”。
- 台词方向：俺也去算一算。
- 视觉禁忌：不要画成妖王点将，不要画成偷听，不要放卡牌排序教学元素。

### 伶俐虫

- 现代人群映射：八卦消息灵通者 / 偷听墙角的人 / 群聊情报员。
- 代表群体：消息特别灵、会套话、爱打听、到处听口风的小人物。
- 情绪关键词：机灵、讨巧、憋笑、得意、偷偷摸摸。
- 动作设计：躲帘幕后或墙角，用竹筒偷听，手里夹小纸条，身体贴墙侧倾。
- 表情设计：眼睛发亮、嘴角忍笑，像“我听见了”。
- 台词方向：俺也去听听口风。
- 视觉禁忌：不要画成昆虫；不要展示完整手牌或规则信息；不要画成强偷牌角色。

### 急如火

- 现代人群映射：急性子传话人 / 催回复的人 / 群里疯狂 @ 人的人。
- 代表群体：传话很急、催人很快、等别人回应等不住的小职员。
- 情绪关键词：急、慌、催促、火急火燎、好笑。
- 动作设计：双手拢嘴大喊，身体前倾，脚下烟尘，像话还没说完人已经冲到门口。
- 表情设计：眼睛瞪大、嘴巴夸张张开，像“你快答应我啊”。
- 台词方向：喂！叫你呢！
- 视觉禁忌：不要画成紫金红葫芦收妖；不要画成攻击；不要放抽牌图示。

### 快如风

- 现代人群映射：风一样的外勤 / 跑单骑手 / 刚说完就消失的人。
- 代表群体：动作很快、信息传得快、顺手把现场搅乱的小跑腿。
- 情绪关键词：机灵、得意、捣乱、飞快、轻飘。
- 动作设计：低伏掠过山路，衣角、头巾和尾羽被风拉长，路牌和草叶被轻轻带动。
- 表情设计：回头一笑，像“我刚从你面前嗖一下过去”。
- 台词方向：风过山头喽！
- 视觉禁忌：不要画成大风暴，不要像黄风怪或芭蕉扇，不要放牌序箭头。

## 二、2星精英头目

### 云里雾

- 现代人群映射：把现场搞模糊的人 / 会议里制造不确定性的中层。
- 代表群体：不直接反对，但一开口就把原本清楚的安排重新变得不确定的人。
- 情绪关键词：淡定、神秘、得意、装糊涂。
- 动作设计：抬手放出厚云，遮住山路、山头标记和刚看清的方向。
- 表情设计：微笑、半闭眼，像“现在谁也看不清了”。
- 台词方向：山头看不清了。
- 视觉禁忌：不要画公共牌库、妖怪牌或法宝牌乱序；不要画成攻击。

### 雾里云

- 现代人群映射：打乱排班 / 打乱资源计划的人。
- 代表群体：别人刚排好资源顺序，他一伸手全部重新混成一团。
- 情绪关键词：狡黠、轻飘、恶作剧、让人猜错。
- 动作设计：双手搅动雾气，让公共资源牌影、法宝影和妖怪影混入雾中。
- 表情设计：坏笑、轻松，像“你刚排好的没有了”。
- 台词方向：牌都看不清了。
- 视觉禁忌：不要表现山路地盘被遮；不要画成云里雾。

## 三、3星普通妖王 / 洞主

### 金角大王

- 现代人群映射：资源调度主管 / 项目排期负责人 / 选址拍板的人。
- 代表群体：掌握地盘信息，喜欢先看一眼再决定放哪里的人。
- 情绪关键词：精明、掌控、算计、稳。
- 动作设计：拿令牌或山图，俯视地形，像在调山点地。
- 表情设计：皱眉思考、眼神笃定，像“这块地我来安排”。
- 台词方向：这山头，归我排。
- 视觉禁忌：不要画成法宝葫芦主视觉，不要变成银角的公共牌排序。

### 银角大王

- 现代人群映射：仓库排货主管 / 资源排序员 / 会提前摆好三步的人。
- 代表群体：不一定抢在前面，但会把资源顺序提前整理好的人。
- 情绪关键词：精打细算、得意、谨慎、有条理。
- 动作设计：面对一排资源光影或宝物清单，手指轻轻调整顺序。
- 表情设计：眯眼、笑得笃定，像“我早就排好了”。
- 台词方向：这三样，先后有数。
- 视觉禁忌：不要表现地盘山图；不要和金角调山混淆。

### 白骨精

- 现代人群映射：屡败屡来的人 / 被打散又换个马甲回来的人。
- 代表群体：失败一次不消失，换个身份、换个说法、重新回到局里的人。
- 情绪关键词：不服、狡黠、冷幽默、死不认输。
- 动作设计：身体一半碎成骨片和幻影，一半还在优雅挥手退场。
- 表情设计：冷笑、得意，像“我还会回来”。
- 台词方向：白骨不散。
- 视觉禁忌：不要召唤骷髅军团，不要画成攻击清场，不要血腥恐怖。

### 玉面狐狸

- 现代人群映射：会借关系的人 / 靠后台撑场面的人。
- 代表群体：自己不硬拼，但懂得借强者名头、靠关系稳住局面的人。
- 情绪关键词：从容、柔媚、会算计、借势。
- 动作设计：站在洞府或地盘边界，手持令牌，身后有牛魔王影子或牛首战旗虚影。
- 表情设计：笑而不露、眼神自信，像“我背后有人”。
- 台词方向：我请得动他。
- 视觉禁忌：不要画成铁扇公主挥扇；不要让牛魔王实体抢主角。

### 金鼻白毛老鼠精

- 现代人群映射：挖人高手 / 悄悄把基层员工挖走的人。
- 代表群体：不正面冲突，专门把别人手下的小角色悄悄带走的人。
- 情绪关键词：偷笑、得手、灵巧、狡黠。
- 动作设计：从洞口探出，拉绳子或牵小包袱，把一个1星小妖往自己地盘方向带。
- 表情设计：回头偷笑，像“人我先带走了”。
- 台词方向：小的，跟我走。
- 视觉禁忌：不要吞食、不要杀伤、不要法宝收妖。

### 黄袍怪

- 现代人群映射：强势挖角者 / 把人直接带进自己手里的人。
- 代表群体：靠身份、威压和手段，把基层角色收编到自己手上的人。
- 情绪关键词：强势、霸道、冷硬、掌控。
- 动作设计：披黄袍伸手一抓，小妖被卷入袖中或被护卫带走。
- 表情设计：冷眼、不屑，像“这个人我要了”。
- 台词方向：跟我回去。
- 视觉禁忌：不要画成老鼠精偷人；不要表现地盘驻守。

### 铁扇公主

- 现代人群映射：有边界感的强势管理者 / 一句话把人请出去的人。
- 代表群体：不吵不闹，但能优雅而强硬地把越界的人推回去的人。
- 情绪关键词：冷静、强势、优雅、边界感。
- 动作设计：侧身挥扇，一条单体风线把一个守军吹退。
- 表情设计：眼神平静但不可商量，像“请你回去”。
- 台词方向：回去。
- 视觉禁忌：不要画成芭蕉扇法宝主视觉；不要大范围清场。

## 四、4星强妖王

### 红孩儿

- 现代人群映射：情绪爆发的熊孩子 / 有资源撑腰的小霸王。
- 代表群体：年轻、任性、爆发力强，一上头就把场面烧乱的人。
- 情绪关键词：嚣张、暴躁、得意、无法无天。
- 动作设计：叉腰喷火或踩火轮，火焰扫过一群低星小妖。
- 表情设计：坏笑、挑衅，像“你们都别想站住”。
- 台词方向：烧起来喽！
- 视觉禁忌：不要画成成熟魔王；不要血腥焚烧。

### 黄风怪

- 现代人群映射：把团队吹散的人 / 一阵风让别人站不住的人。
- 代表群体：不一定正面打赢，但一出手就把原本的阵型和秩序吹乱的人。
- 情绪关键词：怪笑、得意、扰乱、阴风阵阵。
- 动作设计：鼓腮或挥动风袋，黄风卷起两个守军往回飞。
- 表情设计：眯眼坏笑，像“站不稳了吧”。
- 台词方向：风一起，都回去。
- 视觉禁忌：不要画成快如风小范围轻风；不要画成芭蕉扇。

### 青狮精

- 现代人群映射：强势拍板的硬派领导 / 一声吼压住场面的人。
- 代表群体：不讲太多话，靠气场和威压直接清掉一个阻碍的人。
- 情绪关键词：霸气、威严、直接、压迫感。
- 动作设计：巨爪拍下或狮吼震退一个守军，主动作集中在单体目标。
- 表情设计：怒目、沉稳，不癫狂，像“我说了算”。
- 台词方向：退下。
- 视觉禁忌：不要画成清全场；不要失去欢乐桌游的夸张感。

## 五、5星顶级妖王

### 牛魔王

- 现代人群映射：江湖大哥 / 能调动一群人的总负责人。
- 代表群体：一出面就能继续叫人、继续推进、让局面不停往前滚的大人物。
- 情绪关键词：豪横、讲义气、压场、号令群妖。
- 动作设计：坐镇山寨或宴席，举杯一挥手，身后小妖和妖王接连响应。
- 表情设计：豪爽大笑，像“兄弟们，接着上”。
- 台词方向：再来一个！
- 视觉禁忌：不要画成单纯肌肉怪；不要和青牛精混淆。

### 大鹏精

- 现代人群映射：极速扩张者 / 一看准机会就直接抢市场的人。
- 代表群体：速度极快、判断果断、机会一出现就马上扑上去的人。
- 情绪关键词：锐利、果断、狂傲、压迫。
- 动作设计：展翼从高空俯冲，直指远处地盘核心。
- 表情设计：眼神锐利，像“机会是我的”。
- 台词方向：这地，我先到。
- 视觉禁忌：不要画成普通飞鸟；不要画成全屏灾难风暴。
