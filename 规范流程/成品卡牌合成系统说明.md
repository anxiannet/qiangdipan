# 《夕妖：抢地盘》成品卡牌合成系统说明

本文原来自 `归档/卡牌成品清理_20260628/README.md`，用于记录历史成品卡牌合成系统的目录结构、脚本入口与资源来源。

该系统用于将纯插画资产与统一 UI 卡框合成为完整卡牌正面，并生成统一卡背。

## 目录

- `正面/`：完整卡牌正面 PNG。
- `正面/试玩版/`：历史试玩版成品卡归档。
- `正面/基础版/`：基础版成品卡归档，不覆盖试玩版或旧正面图。
- `背面/`：统一卡背 PNG。
- `资源/`：成品合成使用的定稿 UI、插画与审核定稿图。
- `程序数据/`：合成脚本、历史批量数据、导出报告与合成参数。
- `模板/`：UI模板规范与模板预览。
- `程序数据/合成程序/卡牌合成第2版.py`：当前唯一 Python + Pillow 合成脚本。
- `程序数据/合成程序/fabao_zijin_honghulu_layout.json`：法宝卡定稿布局参数。
- `规范流程/基础版成品卡生成流程规范.md`：基础版单卡成品生成与审核流程。

## 使用

在仓库根目录运行：

```bash
python3 程序数据/合成程序/卡牌合成第2版.py
```

脚本的长期输入来源：

- `资源/`
- `视觉/批量生成/插画资产/`（历史兼容兜底）
- 当前规则、卡表与成品数据应以 `规则/V1.2-基础卡表.md` 为唯一来源。

输出：

- `归档/卡牌成品清理_20260628/正面/`
- `归档/卡牌成品清理_20260628/背面/`
- `归档/卡牌成品清理_20260628/模板/card_front_template_preview.png`
- 临时导出文件按需生成，不作为长期保留数据。

## 规则边界

本系统只做卡牌视觉合成，不修改规则、星级、数量或技能。

基础版成品卡的技能短文案来自：

`规则/V1.2-基础卡表.md`

说明：

- 过期的 `card_data.json` 与 `generation_report.json` 不长期保留；如后续需要，应从当前基础卡表与成品目录重新生成。
- 基础版妖怪插画与审核记录维护在 `妖怪志/卡名/插画/基础版/`。
- 基础版成品卡生成流程见 `规范流程/基础版成品卡生成流程规范.md`。
