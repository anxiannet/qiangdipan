# 《夕妖：抢地盘》技能图标规范

## 文件定位

本文件用于维护《夕妖：抢地盘》当前基础版卡面技能图标的统一视觉规范。

本文件只维护视觉表现与 UI 辅助信息，不定义、不修改、不扩展游戏规则。

规则、卡牌数量、星级、类型、卡面技能文案唯一来源：

```text
规则/V1.2-基础卡表.md
```

通用 UI 规范来源：

```text
规范流程/UI规范.md
```

插画审核流程来源：

```text
规范流程/插画审核流程.md
```

---

## 一、当前决定

从青狮精最终成品卡确认后，当前基础版有技能的卡牌统一采用：

```text
技能图标 + 技能文字
```

技能图标用于辅助玩家快速识别当前卡牌的主要技能类型。

适用范围：

- 当前基础版所有有技能的妖怪卡。
- 当前基础版所有有技能的法宝卡。

不适用范围：

- 地盘卡当前无技能，不配置技能图标。
- 指南卡、包装说明、规则文档不因技能图标改变规则写法。

---

## 二、信息边界

技能图标只作为视觉辅助。

技能图标不得：

- 替代技能文字。
- 新增规则含义。
- 改写技能效果。
- 暗示卡面没有写出的额外目标、额外数量或额外行动。
- 因图标表现导致玩家误解星级、数量、阵营或胜利条件。

玩家结算时仍以卡面技能文字为唯一规则依据。

---

## 三、统一表现要求

技能图标应统一具备：

- 3D 立体感。
- 高识别度轮廓。
- 商品级精修质感。
- 与卡框、星级、名称栏属于同一视觉体系。
- 缩小到实体卡尺寸后仍能一眼识别主动作。

技能图标应避免：

- 纯扁平测试图标。
- 与卡框风格不一致的现代 UI 图标。
- 复杂到小图不可读。
- 每张卡自由漂移成不同美术风格。
- 抢过技能文字或主体插画。

---

## 四、位置原则

技能图标位于底部技能区左侧。

要求：

- 必须位于安全区内。
- 不得压住技能文字。
- 不得压住边框主体结构。
- 与技能文字之间保留清晰间距。
- 图标大小应在全套卡牌中统一，不因单卡插画构图随意变化。

说明：

具体坐标与尺寸以后续 `规范流程/UI规范.md` 的统一模板为准。若模板更新，本文件只同步图标原则，不单独维护第二份坐标体系。

---

## 五、单卡图标数量

每张卡默认只使用 1 个主技能图标。

若技能包含多个动作，图标优先表达“玩家最先记住的核心动作”。

图标不负责完整表达所有规则细节，完整规则仍由技能文字承担。

## 七、青狮精图标锚点

青狮精最终成品卡已启用技能图标，并作为当前技能图标风格锚点之一。

青狮精图标方向：

```text
青狮兽口 / 狮吼 / 利爪压制
```

表达目标：

- 表现“消灭”类技能。
- 强调青狮精对 3 星或以下守军的单体压制。
- 不表现为可处理 4 星或 5 星目标。
- 不表现血腥结果。

---

## 八、审核标准

技能图标审核时必须检查：

1. 是否存在技能图标。
2. 是否与该卡技能核心动作一致。
3. 是否与卡面文字规则冲突。
4. 是否误导目标星级、目标数量或作用范围。
5. 是否与青狮精锚点的 3D 商品级风格一致。
6. 是否保持欢乐聚会卡牌的轻松互动感。
7. 是否不血腥、不恐怖、不压过技能文字。
8. 缩小后是否仍能识别。

---

## 九、维护原则

1. 本文件只维护技能图标视觉规范。
2. 不维护第二份技能表。
3. 不维护第二份卡牌数量、星级或类型数据。
4. 若技能文案调整，先更新 `规则/V1.2-基础卡表.md` 与对应单卡志，再同步图标方向。
5. 若 UI 坐标调整，以 `规范流程/UI规范.md` 为准。
