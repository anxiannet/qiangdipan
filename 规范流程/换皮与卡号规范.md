# 《夕妖：抢地盘》换皮与卡号规范

适用规则版本：V1.3  
更新时间：2026-07-14

## 一、文件定位

本文件是不同主题皮肤、国际化换皮、卡号前缀、卡面版本识别及后台关联关系的唯一来源。

本文件只规定换皮和版本管理，不修改核心规则、胜利条件、卡牌数量、星级、技能效果或结算顺序。

标准版具体卡牌名称、数量、星级、类型与卡面文案仍以：

```text
规则/V1.3-基础卡表.md
```

为唯一来源。

---

## 二、换皮原则

换皮是对同一套游戏机制进行世界观、命名、插画、语言和视觉表现的替换。

必须遵守：

1. 不修改核心胜利条件。
2. 不修改标准版及扩展包已确定的卡牌数量。
3. 不修改星级、技能对象、技能强度和结算顺序。
4. 不创建平行规则体系。
5. 不在换皮文件中重复维护第二份规则卡表。
6. 每张换皮卡在后台关联原机制卡，但关联信息不显示在卡面上。
7. 换皮版继续兼容原规则测试结果和扩展结构。

---

## 三、卡号定义

卡号是具体卡面版本的唯一识别号，同时承担卡面版本号功能。

### 3.1 卡面完全相同

卡面完全相同的复制卡共用同一卡号。

“卡面完全相同”表示以下内容全部一致：

- 皮肤
- 语言
- 卡名
- 插画
- 星级
- 类型
- 技能文案
- 图标
- 边框
- 版式
- 卡背所属体系
- 其他实际印刷内容

只增加印刷数量、不改变卡面内容时，不分配新卡号。

### 3.2 卡面发生变化

以下任一内容变化时，必须分配新卡号：

- 插画
- 卡名
- 中文、英文或其他语言卡面文案
- 星级或类型
- 图标、边框或版式
- 皮肤
- 语言版本
- 其他实际印刷内容

旧卡号永久保留，不得覆盖、复用或重新分配给其他卡面。

---

## 四、皮肤前缀

每套独立皮肤使用独立卡号前缀。

当前西游妖怪版：

```text
QDP-001
```

通用英文奇幻换皮暂定产品名：

```text
Realm Ruckus
```

建议前缀：

```text
RRK-001
```

不同皮肤分别维护独立流水号，不要求延续其他皮肤编号。

产品名和前缀正式启用前，应确认英文名称、商标可用性和包装名称；正式投入文件或印刷后，不得随意更换。

---

## 五、卡面显示规则

实体卡面只显示本皮肤卡号，例如：

```text
RRK-001
```

以下内容不显示在卡面上：

- 原版卡号
- 来源卡名
- 机制身份编号
- 技能效果编号
- 对应皮肤卡号
- 插画版本内部编号
- 文案版本内部编号
- 数据库关联字段

---

## 六、后台关联规则

跨皮肤关联只在后台、制作清单或资产数据库中维护。

推荐字段：

```text
mechanic_id
skin_id
card_code
source_card_code
rules_effect_id
art_version
text_version
language
status
```

| 字段 | 用途 |
|---|---|
| mechanic_id | 标识同一规则机制卡，不随皮肤变化 |
| skin_id | 标识所属皮肤 |
| card_code | 实际印在卡面上的卡号 |
| source_card_code | 来源或主要对应卡号 |
| rules_effect_id | 关联同一技能机制 |
| art_version | 插画资产版本 |
| text_version | 卡面文案版本 |
| language | 卡面语言 |
| status | 当前、停用、历史或测试状态 |

示例：

```text
mechanic_id: MONSTER-001
skin_id: realm-ruckus
card_code: RRK-001
source_card_code: QDP-001
rules_effect_id: EFFECT-RETURN-OWN-DEFENDER
art_version: ART-01
text_version: TEXT-01
language: en
status: active
```

后台关联用于追溯与资产管理，不构成第二份规则卡表。

## 八、视觉方向

通用英文换皮采用欢乐、厚重、收藏级的卡通奇幻风格：

- 夸张体型和高识别度轮廓
- 怪物古怪但不恐怖
- 战斗有冲击力但不血腥
- 四个区域具有明确色彩和场景区分
- 保持妖怪卡、法宝卡与横版地盘卡的现有尺寸和框架结构
- 不使用百科卡、Word表格、测试版UI或页游风格

换皮视觉只能表现现有规则，不得通过插画或UI新增规则含义。

## 九、执行流程

1. 确认目标市场、产品名和皮肤前缀。
2. 锁定原规则版本和卡表版本。
3. 建立后台机制映射，不写入卡面。
4. 完成角色、地盘和法宝命名映射。
5. 审核英文语境、文化理解和商标风险。
6. 完成插画与卡面文案。
7. 对每个唯一卡面分配新卡号。
8. 卡面完全相同的复制卡共用卡号。
9. 任何卡面内容变化均分配新卡号。
10. 完成规则一致性、成品卡和印刷审核。

## 十、当前决定

```text
不同皮肤使用不同卡号前缀。
卡号即具体卡面版本号。
卡面完全相同的复制卡共用卡号。
插画、文案、名称、语言、版式或其他卡面内容变化时必须换卡号。
跨皮肤关联只在后台记录，不显示在卡面上。
通用英文奇幻换皮暂定名为 Realm Ruckus，建议前缀 RRK。
```
