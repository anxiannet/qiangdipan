# 规范流程目录

本目录集中维护《夕妖：抢地盘》的规范、约束、制作流程和 AI 协作流程。

## 文件清单

| 文件 | 用途 |
|---|---|
| `V1.1-角色与法宝设计规范.md` | 角色、法宝、技能与基础设计边界 |
| `视觉总规范.md` | 视觉方向、统一标准、禁止项与检查原则 |
| `UI规范.md` | UI、卡牌框架、卡背、图标与透明资产规范 |
| `生成提示词规范.md` | AI 生成图提示词结构、固定格式与禁止项 |
| `AI工作流.md` | AI 参与视觉制作时的工作流程 |
| `基础版成品卡生成流程规范.md` | 基础版成品卡合成、审核、归档流程 |
| `成品卡审核流程.md` | 成品卡从插画审核到合成审核的顺序、返工边界与记录标准 |
| `卡牌UI模板规范.md` | 成品卡 UI 模板、尺寸、安全区和显示禁项 |
| `成品卡牌合成系统说明.md` | 历史合成系统的目录、资源和使用说明 |

## 使用原则

- 规范文件决定“必须遵守什么”。
- 流程文件决定“按什么顺序执行”。
- 插画设计、卡表、规则正文不得反向修改规范。
- 如规范与其他文档冲突，以本目录文件为优先来源。
