# 《夕妖：抢地盘》视觉总规范

## 文件定位

本文件是《抢地盘》视觉系统的最高规范入口，只维护视觉边界、统一标准、禁止项与检查原则。

本文件不写具体单卡插画方案。

具体单卡视觉设计维护于：

```text
妖怪志/卡名/卡名.md
法宝志/法宝名/法宝名.md
```

UI、卡牌框架、卡背与透明资产规范维护于：

```text
规范流程/UI规范.md
```

插画生成、审核、迭代流程维护于：

```text
规范流程/插画审核流程.md
```

---

## 一、视觉边界

视觉设计不得修改：

- 游戏规则
- 卡牌数值
- 卡牌数量
- 技能效果
- 世界观人物事实
- 阵营设定事实

规则、卡表、技能文案以以下文件为准：

```text
规则/当前规则.md
规则/V1.2-基础卡表.md
```

说明：`规则/V1.2-卡面技能文案.md` 已合并入 `规则/V1.2-基础卡表.md`，不再作为独立来源。

---

## 二、产品视觉定位

《抢地盘》是：

```text
西游妖怪题材欢乐聚会卡牌游戏
```

核心视觉气质：

- 西游妖怪
- 抢地盘
- 山头势力感
- 欢乐聚会卡牌
- 轻松竞争感
- 高识别度
- 手机端小图可读
- 实体卡牌可印刷

《抢地盘》不是：

- 战棋游戏
- 兵棋游戏
- 硬核战争模拟游戏
- 严肃黑暗史诗游戏
- TCG / CCG 重竞技卡牌

视觉应服务“抢、偷、换、坑、翻盘、搞事”的欢乐混战体验。

---

## 三、统一风格要求

所有视觉资产必须像同一款游戏：

- 妖怪卡
- 法宝卡
- 地盘卡
- UI
- 图标
- 卡背
- 包装
- 宣传图

允许参考方向：

- 动画电影级 3D 角色质感
- 西游妖怪气质
- 收藏级手办感
- 明确动作和表情
- 聚会桌游的快速阅读性

禁止不同资产使用完全不同美术体系。

---

## 四、信息可读性原则

所有卡牌视觉必须优先保证：

1. 玩家能识别卡牌类型。
2. 玩家能识别角色或法宝主体。
3. 玩家能识别星级或阵营信息。
4. 玩家能在手机小图中读懂主要信息。
5. 实体印刷后关键文字不被裁切或压暗。

装饰不能压过信息。

---

## 五、玩法表达原则

视觉必须让玩家一眼感到这是“妖怪抢地盘”。

优先表达：

- 争夺
- 抢占
- 守山
- 攻山
- 群妖出动
- 山头势力
- 洞府与领地
- 欢乐混战

避免表达成：

- 孤独英雄展示
- 纯风景壁纸
- 严肃战争推演
- 黑暗压迫叙事
- 玄幻小说封面

---

## 六、技能-视觉一致性规则

妖怪卡与法宝卡的视觉设计，必须服务当前已确定技能。

每张卡牌的插画至少应与该技能的以下内容保持一致：

1. **动作一致**
   - 角色主动作必须能直接表现技能核心行为。
   - 例如：查看、巡山、探话、喊名、吹回、偷取、吞吃、调度、控场等。

2. **表情一致**
   - 角色表情必须与技能气质一致。
   - 探查类应偏机警、狡黠、专注。
   - 喊名类应偏催促、引诱、得意、期待回应。
   - 偷取类应偏鬼祟、得手感。
   - 吹飞类应偏发力、压迫感。
   - 吞吃类应偏凶猛、贪婪。

3. **场景一致**
   - 背景与环境应支持技能发生逻辑。
   - 巡山应有山路、岗哨或路径分叉。
   - 传话应有应声对象或传令场景。
   - 调山点地应有地形图、沙盘、地盘标记。
   - 盘库点将应有卷轴、名册、排布感。

4. **道具 / 特效一致**
   - 插画中的道具、法宝、特效，必须与当前技能来源一致。
   - 已移除的技能元素，不得继续保留在视觉中。
   - 例如：金角大王当前技能不是紫金红葫芦，则插画中不得让其手持葫芦。

5. **构图重点一致**
   - 玩家第一眼应能看出这张牌“在做什么”。
   - 不允许仅有站姿展示，而没有技能行为表达。

### 技能变更后的同步更新要求

若技能发生调整，必须同步检查并更新以下内容：

- 妖怪志 / 法宝志中的“视觉形象设计”。
- 妖怪志 / 法宝志中的“视觉差异要求”。
- 插画需求描述 / 出图提示词。
- 如已有成品图，需标注：视觉已同步、视觉待重画、视觉与技能不一致。

禁止出现“技能已改，但视觉仍表现旧技能”的情况。

## 七、插画视觉安全区规则

妖怪卡与法宝卡插画必须预留卡面 UI 遮挡区。生成插画时，不得将主体关键视觉信息放入以下区域：

- 左上星数区
- 右侧竖向名称栏
- 底部名称 / 技能文案栏
- 顶部中心徽记区
- 四角大型装饰压边区

主体插画必须遵循以下要求：

1. 角色脸部必须处于安全区内，保持完整清晰。
2. 技能核心动作必须处于安全区内，不得被星数区、名称栏或底栏遮挡。
3. 技能关键道具必须处于安全区内，不得被 UI 主栏压住。
4. 技能结果表现应位于中下区域，但不得落入底部文案栏。
5. 边缘区域主要承担背景、氛围、装饰性延展，不承担主叙事。

### 默认构图建议

- 头脸：中上区域
- 主体躯干：中部
- 主动作 / 关键道具：中部偏左或偏中
- 次要目标 / 技能结果：中下区域，但高于底栏

### 生成阶段留白规则

生成妖怪卡、法宝卡插画时，必须在提示词阶段直接要求主体四周保留充足留白。

目的：

- 让后续卡面合成时可以通过放大、缩小、平移、裁切适配 UI 安全区。
- 避免角色脸部、手部主动作、关键道具或技能结果在原始生成图中贴边。
- 避免为了适配星数区、名称栏、底部文案栏而反复重生成整张插画。

要求：

1. 原始插画不得把主体画满全画布。
2. 角色 / 法宝主体外侧必须保留可调整空间，四周留白以背景、烟尘、山势、云雾、光效等非关键信息填充。
3. 脸部、主动作、关键道具、技能结果不得贴近画面边缘。
4. 生成提示词只描述主体安全区比例与四周留白比例，不把右侧名称栏、左上星数区、底部文案栏等 UI 位置写成固定构图要求；未来 UI 位置可能调整，原始插画应保持可复用。
5. 主体应默认居中放置在安全构图框内，四周留白尽量均衡，留白用背景、烟尘、山势、云雾、光效等非关键信息填充。
6. 若插画本体的风格、亮度、技能表达已经合格，但安全区位置不理想，优先通过放大、缩小、平移、裁切进行适配；只有本体不合格时才重新生成。

### 危险遮挡区说明

1. **左上星数区**
   - 不放脸、眼睛、头冠、手部主动作。
   - 可允许背景、耳朵、披风边缘轻微经过，但不得影响识别。

2. **右侧竖向名称栏**
   - 不放脸、胸口主视觉、关键道具、关键动作。
   - 右侧手臂若是核心动作，也不得被压住。

3. **底部文案栏**
   - 不放被偷目标、被吸目标、被吹飞目标、脚下关键互动结果。
   - 可放地面、碎石、财宝、余焰等次要环境。

4. **顶部中心徽记区**
   - 不要让头顶主装饰、王冠尖端、法宝顶端正撞该区域。

5. **四角装饰压边区**
   - 四角不放关键叙事信息。

## 八、妖怪拟人化与台词表现规则

《夕妖：抢地盘》的妖怪视觉应强调拟人化、戏剧化与角色感。

西游记本身具有“写妖喻人”的表达传统，因此妖怪不应只表现为怪物形象，还应表现出明确的人味、情绪、性格与行为目的。

视觉设计要求：

1. 妖怪主体必须生动，有明显动作、姿态和表情。
2. 妖怪应具有清晰个性，如狡黠、得意、机灵、贪心、慌张、爱表现、会演等。
3. 视觉应增强玩家带入感，使玩家感觉角色“像在说话”“像在演戏”。
4. 角色性格优先于通用怪物感，同类小妖也应有各自行为气质。

### 台词文字使用规则

插画中允许加入简短台词、唱词、喊话或自言自语文字，用于增强角色表现力与西游味。

要求如下：

1. 台词以短句为主，建议 6~14 个字。
2. 台词只承担风味表达，不承担规则说明。
3. 台词内容必须与当前技能和角色行为一致。
4. 台词不得遮挡主体脸部、核心动作、关键道具。
5. 台词不得进入左上星数区、右侧名称栏、底部技能文案栏等 UI 危险区。
6. 台词风格应自然、口语化、有角色味，避免过度现代化或说明书式表达。

### 台词示例

| 卡牌 | 候选台词方向 |
|---|---|
| 小钻风 | “大王派我来巡山——” |
| 急如火 | “快快回话！”、“哎！叫你呢！” |
| 精细鬼 | “俺也去算一算。”、“这个得细看。” |
| 伶俐虫 | “俺也去听听口风。”、“藏着什么呢？” |
| 紫金红葫芦 | “我叫你一声——”、“你敢答应吗？” |

## 九、风格禁止项

禁止作为最终美术语言：

- 写实暗黑风
- 黑神话 Boss 写实风
- 炉石厚涂直接仿制风
- 魔兽兵团直接仿制风
- 原神二次元风
- 国漫修仙风
- 纯水墨国风
- 页游传奇风
- 低龄儿童 Q 版
- 现代机甲风
- 赛博朋克风
- 玄幻小说封面风
- 单纯概念原画风

这些只能作为局部灵感参考，不能成为《抢地盘》的统一美术语言。

## 十、规范与单卡设计关系

规范文件负责回答：

```text
必须遵守什么
禁止做什么
信息放在哪里
尺寸与边界是什么
```

单卡志负责回答：

```text
画面怎么设计
角色怎么表现
动作和表情怎么做
每个法宝或地盘的视觉关键词是什么
```

单卡设计必须符合本规范，不得反向修改规范。

---

## 十一、统一检查标准

每生成一张新图，都必须检查：

1. 放进同一副牌里，是否像同一个游戏？
2. 是否一眼看出“抢地盘”？
3. 角色、法宝或地盘主体是否清楚？
4. 表情、动作、轮廓是否小图可读？
5. 是否偏离成暗黑、写实、二次元、厚涂或玄幻封面？
6. 是否符合 `规范流程/UI规范.md` 的卡牌尺寸与信息层级？
7. 插画主体、脸部、主动作、关键道具是否避开左上星数区、右侧名称栏、底部文案栏？
8. 角色动作、表情、场景、道具、特效是否与当前技能一致？
9. 若加入台词，台词是否短、自然、有角色味，并且避开 UI 安全区？

不满足时，应重新生成、重绘或调整提示词。
