视觉设计不得修改：

- 卡牌数值

- 世界观人物事实

```text

```

说明：`规则/V1.2-卡面技能文案.md` 已合并入 `规则/V1.2-基础卡表.md`，不再作为独立来源。

## 二、产品视觉定位

《抢地盘》是：

```text
西游妖怪题材欢乐聚会卡牌游戏
```

核心视觉气质：

- 西游妖怪
- 抢地盘
- 山头势力感
- 欢乐聚会卡牌
- 轻松竞争感
- 高识别度
- 手机端小图可读
- 实体卡牌可印刷
- 商品级 / 收藏级
- 3D 立体感

《抢地盘》不是：

- 战棋游戏
- 兵棋游戏
- 硬核战争模拟游戏
- 严肃黑暗史诗游戏
- TCG / CCG 重竞技卡牌

视觉应服务“抢、偷、换、坑、翻盘、搞事”的欢乐混战体验。

## 三、当前整套视觉锚点

当前整套卡牌视觉锚点为：

```text
青狮精最终成品卡
```

该锚点用于统一后续以下资产的成品气质与产品化方向：

- 妖怪卡
- 法宝卡
- 地盘卡
- 指南卡
- 卡背
- 包装
- 宣传图
- UI 图标

### 锚点核心特征

- 更强的 3D 立体感。
- 商品级 / 收藏级厚重感。
- 适合欢乐聚会卡牌的明快互动感。
- 非血腥，但要有明确的技能动作与结果表达。
- 主体表情更夸张、可读，便于制造桌面笑点。
- 主体与目标之间应有明确互动，不做单纯站姿展示。
- 整体氛围可热闹、明亮、带轻戏剧感，不做黑暗压抑史诗风。

### 后续卡牌统一要求

后续妖怪卡、法宝卡在生成或绘制时，应优先对齐以下锚点特征：

1. 主体必须具有强动作。
2. 主体必须具有明确表情或明确情绪。
3. 技能目标或结果必须一眼可见。
4. 要有聚会卡牌的轻松竞争感与戏剧感。
5. 不允许血腥、残肢、恐怖惊悚化处理。
6. 不允许回退到“严肃战争史诗插画”或“纯角色海报”方向。

### 背景文字处理原则

背景中的旗帜、牌匾、门楼等可以辅助世界观氛围，但不得抢过卡名栏、星级、技能区的信息焦点。

如背景文字与卡名重复，应优先弱化背景文字，而不是强化背景信息。

## 四、统一风格要求

所有视觉资产必须像同一款游戏：

- 妖怪卡
- 法宝卡
- 地盘卡
- 指南卡
- UI
- 技能图标
- 卡背
- 包装
- 宣传图

允许参考方向：

- 动画电影级 3D 角色质感
- 西游妖怪气质
- 收藏级手办感
- 明确动作和表情
- 聚会桌游的快速阅读性

禁止不同资产使用完全不同美术体系。

---

## 五、信息可读性原则

所有卡牌视觉必须优先保证：

1. 玩家能识别卡牌类型。
2. 玩家能识别角色、法宝、地盘或指南卡主题。
3. 玩家能识别星级、卡名、技能文字或指南标题。
4. 玩家能在手机小图中读懂主要信息。
5. 实体印刷后关键文字不被裁切或压暗。

装饰不能压过信息。

---

## 六、玩法表达原则

视觉必须让玩家一眼感到这是“妖怪抢地盘”。

优先表达：

- 争夺
- 抢占
- 守山
- 抢地盘
- 群妖出动
- 山头势力
- 洞府与领地
- 欢乐混战

避免表达成：

- 孤独英雄展示
- 纯风景壁纸
- 严肃战争推演
- 黑暗压迫叙事
- 玄幻小说封面

---

## 七、技能图标统一原则

当前基础版所有有技能的妖怪卡、法宝卡，统一采用：

```text
技能图标 + 技能文字
```

技能图标只作为视觉辅助。

技能图标不得：

- 替代技能文字。
- 新增规则含义。
- 改写技能效果。
- 暗示卡面没有写出的额外目标、额外数量或额外行动。
- 因图标表现导致玩家误解星级、数量、阵营或胜利条件。

玩家结算时仍以卡面技能文字为唯一规则依据。

地盘卡当前无技能，不配置技能图标。

指南卡用于规则提示，不因技能图标制度而变成技能表；指南卡可以使用功能图标辅助阅读，但不得维护第二份技能规则。

技能图标具体规范来源：

```text
规范流程/技能图标规范.md
```

## 八、技能-视觉一致性规则

妖怪卡与法宝卡的视觉设计，必须服务当前已确定技能。

每张卡牌的插画至少应与该技能的以下内容保持一致：

1. **动作一致**
   - 角色或法宝主动作必须能直接表现技能核心行为。
   - 例如：查看、巡山、探话、喊名、吹回、偷取、吞吃、调度、控场、取消、收走等。

2. **表情 / 气质一致**
   - 角色表情或法宝气质必须与技能气质一致。
   - 探查类应偏机警、狡黠、专注。
   - 喊名类应偏催促、引诱、得意、期待回应。
   - 偷取类应偏鬼祟、得手感。
   - 吹飞类应偏发力、压迫感。
   - 吞吃类应偏凶猛、贪婪。
   - 法宝类应突出功能识别，不应画成无关装饰物。

3. **场景一致**
   - 背景与环境应支持技能发生逻辑。
   - 巡山应有山路、岗哨或路径分叉。
   - 传话应有应声对象或传令场景。
   - 调山点地应有地形图、沙盘、地盘标记。
   - 盘库点将应有卷轴、名册、排布感。

4. **道具 / 特效一致**
   - 插画中的道具、法宝、特效，必须与当前技能来源一致。
   - 已移除的技能元素，不得继续保留在视觉中。
   - 例如：金角大王当前技能不是紫金红葫芦，则插画中不得让其手持葫芦。

5. **构图重点一致**
   - 玩家第一眼应能看出这张牌“在做什么”。
   - 不允许仅有站姿展示，而没有技能行为表达。

### 技能变更后的同步更新要求

若技能发生调整，必须同步检查并更新以下内容：

- 妖怪志 / 法宝志中的“视觉形象设计”。
- 妖怪志 / 法宝志中的“视觉差异要求”。
- 技能图标方向。
- 插画需求描述 / 出图提示词。
- 如已有成品图，需标注：视觉已同步、视觉待重画、视觉与技能不一致。

禁止出现“技能已改，但视觉仍表现旧技能”的情况。

## 九、指南卡视觉原则

指南卡属于实体牌组的一部分，应与妖怪卡、法宝卡、地盘卡属于同一视觉体系。

指南卡视觉目标：

- 快速教学。
- 小图可读。
- 实体印刷清晰。
- 让玩家一眼知道这不是游戏牌，而是规则提示牌。
- 与整套卡牌保持 3D 商品级、欢乐聚会、西游山头势力感。

指南卡可以使用：

- 功能图标。
- 流程箭头。
- 小型地盘 / 手牌 / 守军示意图。
- 轻量装饰边框。
- 与卡背、卡框同体系的纹理。

指南卡不得：

- 维护第二份基础卡表。
- 维护完整技能表。
- 改写规则。
- 用过度复杂插画压过文字。
- 画成说明书截图、Word 表格或测试版 UI。

指南卡正文来源仍为：

```text
规则/指南卡.md
```

## 十、插画视觉安全区规则

妖怪卡与法宝卡插画必须预留卡面 UI 遮挡区。生成插画时，不得将主体关键视觉信息放入以下区域：

- 左上星数区
- 右侧竖向名称栏
- 底部名称 / 技能文案栏
- 顶部中心徽记区
- 四角大型装饰压边区

主体插画必须遵循以下要求：

1. 角色脸部或法宝主体必须处于安全区内，保持完整清晰。
2. 技能核心动作必须处于安全区内，不得被星数区、名称栏或底栏遮挡。
3. 技能关键道具必须处于安全区内，不得被 UI 主栏压住。
4. 技能结果表现应位于中下区域，但不得落入底部文案栏。
5. 边缘区域主要承担背景、氛围、装饰性延展，不承担主叙事。

### 默认构图建议

- 头脸 / 法宝主体：中上区域
- 主体躯干 / 法宝体量：中部
- 主动作 / 关键道具：中部偏左或偏中
- 次要目标 / 技能结果：中下区域，但高于底栏

### 生成阶段留白规则

生成妖怪卡、法宝卡插画时，必须在提示词阶段直接要求主体四周保留充足留白。

目的：

- 让后续卡面合成时可以通过放大、缩小、平移、裁切适配 UI 安全区。
- 避免角色脸部、手部主动作、关键道具或技能结果在原始生成图中贴边。
- 避免为了适配星数区、名称栏、底部文案栏而反复重生成整张插画。

要求：

1. 原始插画不得把主体画满全画布。
2. 角色 / 法宝主体外侧必须保留可调整空间，四周留白以背景、烟尘、山势、云雾、光效等非关键信息填充。
3. 脸部、主动作、关键道具、技能结果不得贴近画面边缘。
4. 生成提示词只描述主体安全区比例与四周留白比例，不把右侧名称栏、左上星数区、底部文案栏等 UI 位置写成固定构图要求；未来 UI 位置可能调整，原始插画应保持可复用。
5. 主体应默认居中放置在安全构图框内，四周留白尽量均衡，留白用背景、烟尘、山势、云雾、光效等非关键信息填充。
6. 若插画本体的风格、亮度、技能表达已经合格，但安全区位置不理想，优先通过放大、缩小、平移、裁切进行适配；只有本体不合格时才重新生成。

### 全部妖怪插图统一成图硬性要求

本节适用于全部妖怪卡插图，包括 1 星有名小妖、2 星精英头目、3 星普通妖王 / 洞主、4 星强妖王与 5 星顶级妖王。

1. **主体比例**
   - 妖怪主体不得过大，不得占满整张画面。
   - 妖怪主体建议控制在画面高度的 45%～60%。
   - 5 星顶级妖王可以更有压迫感，但仍必须保留卡框、星级、名称栏、台词与技能区排版空间。
   - 任何星级都不得让脸部、手部主动作、关键道具或技能结果贴边。

2. **构图位置**
   - 妖怪主体优先放在中部、中下部，或中部轻微偏左 / 偏右。
   - 原始插图必须保留足够天空、山路、洞府、云雾、烟尘或环境背景作为可裁切空间。
   - 上方、四周、底部必须有可用于卡面合成的安全留白。
   - 角色可以有夸张动作，但动作延展不得把关键叙事推到画面边缘。

3. **扩图优先**
   - 如果角色气质、动作、表情与画风已经合格，但主体过大或排版空间不足，应优先扩图、缩小主体、平移构图，而不是推翻角色方向重新设计。
   - 扩图后的版本应作为后续卡面合成优先版本。
   - 单卡妖怪志中若记录候选图状态，应同步标注“已完成扩图方向修正”或“主体过大，需扩图”。

4. **插图职责**
   - 妖怪插图只负责角色代入感、人物感、社会观察、动作表情和欢乐气氛。
   - 插图不负责解释卡牌规则，不负责代替技能文案，不负责展示技能结算流程。
   - 技能解释统一由技能文字与技能图标承担。

5. **说明文字禁令**
   - 插图不得出现说明框、信息栏、设定板、教学标签、现代人群映射文字、代表群体文字、情绪关键词文字或规则讲解文字。
   - 插图不得出现“新信 / 旧信 / 来 / 去 / 置顶 / 置底 / 抽牌 / 弃牌”等解释性标注。
   - 插图不得出现牌堆、牌序箭头、抽弃箭头、手牌展示图、公共牌库示意、地盘牌库示意等规则教学元素。
   - 如需表现归属，优先使用无字视觉元素，如洞门造型、旗帜纹样、山势、岩壁、营寨结构、器物和色彩，不使用大块牌匾文字硬解释地点。

6. **台词气泡**
   - 台词可以保留，但只能承担角色风味，不承担规则说明。
   - 台词气泡必须小于主体视觉层级，不得抢过脸部、主动作、星级区、名称栏或技能区。
   - 台词气泡应位于上方安全留白区；如安全区不足，应优先缩小、移动或取消气泡。

7. **成图一票否决项**
   - 主体过大导致无法排版。
   - 关键动作、脸部或道具落入 UI 危险区。
   - 画面出现底部说明栏、信息卡片、教学框、设定板或规则解释区。
   - 画面文字多到抢过卡名、星级、技能区。
   - 背景用大块文字说明地点、规则或角色设定。
   - 角色原型与对应妖怪志不符，或与其他妖怪重复到难以区分。

### 危险遮挡区说明

1. **左上星数区**
   - 不放脸、眼睛、头冠、手部主动作、法宝主体核心结构。
   - 可允许背景、耳朵、披风边缘、光效轻微经过，但不得影响识别。

2. **右侧竖向名称栏**
   - 不放脸、胸口主视觉、关键道具、关键动作。
   - 右侧手臂若是核心动作，也不得被压住。

3. **底部文案栏**
   - 不放被偷目标、被吸目标、被吹飞目标、脚下关键互动结果。
   - 可放地面、碎石、财宝、余焰等次要环境。

4. **顶部中心徽记区**
   - 不要让头顶主装饰、王冠尖端、法宝顶端正撞该区域。

5. **四角装饰压边区**
   - 四角不放关键叙事信息。

## 十一、妖怪拟人化与台词表现规则

《夕妖：抢地盘》的妖怪视觉应强调拟人化、戏剧化与角色感。

西游记本身具有“写妖喻人”的表达传统，因此妖怪不应只表现为怪物形象，还应表现出明确的人味、情绪、性格与行为目的。

视觉设计要求：

1. 妖怪主体必须生动，有明显动作、姿态和表情。
2. 妖怪应具有清晰个性，如狡黠、得意、机灵、贪心、慌张、爱表现、会演等。
3. 视觉应增强玩家带入感，使玩家感觉角色“像在说话”“像在演戏”。
4. 角色性格优先于通用怪物感，同类小妖也应有各自行为气质。

### 妖怪化形规则

妖怪志中记录的动物原型或产品化原型，默认是“化形来源”，不是最终成图必须呈现的动物本体。

执行要求：

1. 妖怪卡主体默认应表现为已经变成人形、能穿衣、能使用道具、能做社会化动作的妖怪角色。
2. 动物原型只用于提取少量可识别特征，例如耳朵、眼神、鼻尖、胡须、尾巴、毛色、爪形、行动气质或体态倾向。
3. 不得把妖怪直接画成动物本身、宠物形态、四足动物、自然纪录片动物或吉祥物玩偶。
4. 1 星小妖可以更矮小、夸张、滑稽，但仍应是“人形小妖”，不是动物本体。
5. 3 星及以上妖王可以保留更强动物性或法相感，但仍必须具有人格、表情、动作目的与社会角色感。
6. 若单卡妖怪志明确要求“动物本体”或“非人形法相”，才可突破本规则；否则统一按人形化妖怪处理。

审核时若出现“原型动物正确，但没有化成人形”的情况，应判定为形象不合格，要求按人形小妖或人形妖王方向重做。

### 台词文字使用规则

插画中允许加入简短台词、唱词、喊话或自言自语文字，用于增强角色表现力与西游味。

要求如下：

1. 台词以短句为主，建议 6~14 个字。
2. 台词只承担风味表达，不承担规则说明。
3. 台词内容必须与当前技能和角色行为一致。
4. 台词不得遮挡主体脸部、核心动作、关键道具。
5. 台词不得进入左上星数区、右侧名称栏、底部技能文案栏等 UI 危险区。
6. 台词风格应自然、口语化、有角色味，避免过度现代化或说明书式表达。

### 台词示例

| 卡牌 | 候选台词方向 |
|---|---|
| 小钻风 | “大王派我来巡山——” |
| 急如火 | “快快回话！”、“哎！叫你呢！” |
| 精细鬼 | “俺也去算一算。”、“这个得细看。” |
| 伶俐虫 | “俺也去听听口风。”、“藏着什么呢？” |
| 紫金红葫芦 | “我叫你一声——”、“你敢答应吗？” |

## 十二、法宝卡视觉原则

法宝卡必须与妖怪卡同属一个产品体系，但主体应明显区别于角色卡。

法宝卡重点：

- 法宝主体突出。
- 法宝功能一眼可读。
- 技能图标与技能文字统一配置。
- 插画中可加入被影响目标，但不能让目标抢过法宝主体。
- 不得把法宝画成普通装饰物或背景道具。

法宝卡必须遵循对应 `法宝志/法宝名/法宝名.md` 的具体视觉设计。

法宝图标方向必须与 `规范流程/技能图标规范.md` 一致。

## 十四、规范与单卡设计关系

规范文件负责回答：

```text
必须遵守什么
禁止做什么
信息放在哪里
尺寸与边界是什么
```

单卡志负责回答：

```text
画面怎么设计
角色、法宝、地盘或指南卡怎么表现
动作和表情怎么做
每个法宝或地盘的视觉关键词是什么
```

单卡设计必须符合本规范，不得反向修改规范。

## 十五、统一检查标准

每生成一张新图，都必须检查：

1. 放进同一副牌里，是否像同一个游戏？
2. 是否一眼看出“抢地盘”？
3. 角色、法宝、地盘或指南卡主题是否清楚？
4. 表情、动作、轮廓是否小图可读？
5. 是否偏离成暗黑、写实、二次元、厚涂或玄幻封面？
6. 是否符合 `规范流程/UI规范.md` 的卡牌尺寸与信息层级？
7. 插画主体、脸部、主动作、关键道具是否避开左上星数区、右侧名称栏、底部文案栏？
8. 角色动作、表情、场景、道具、特效是否与当前技能一致？
9. 若加入台词，台词是否短、自然、有角色味，并且避开 UI 安全区？
10. 有技能卡牌是否配置技能图标？
11. 技能图标是否只表达视觉辅助，不替代技能文字、不新增规则？
12. 指南卡是否清楚承担教学功能，而不是变成第二份规则书或技能表？
13. 妖怪主体是否过大，是否保留足够扩图后排版空间？
14. 插图是否出现说明框、信息栏、设定板、教学标签或规则解释区？
15. 背景是否使用大块文字硬解释地点、规则或角色设定？
16. 妖怪是否完成化形：动物原型是否只作为特征来源，而不是画成动物本体、宠物或四足动物？

不满足时，应重新生成、重绘、扩图、缩小主体、平移构图或调整提示词。
