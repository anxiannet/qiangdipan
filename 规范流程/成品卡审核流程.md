# 《夕妖：抢地盘》成品卡审核流程

## 文件定位

本文件用于维护基础版成品卡的审核顺序、返工边界与记录标准。

成品卡指：

```text
插画 + UI + 名称 + 星级 + 技能文案
```

本文件不替代单卡视觉设计、基础卡表或 UI 规范。

唯一来源：

```text
规则/V1.2-基础卡表.md
妖怪志/卡名/卡名.md
法宝志/法宝名/法宝名.md
规范流程/基础版成品卡生成流程规范.md
规范流程/视觉总规范.md
规范流程/UI规范.md
```

---

## 一、成品卡审核顺序

每张成品卡必须按以下顺序审核，不能跳步，不能把后一步的问题提前当成前一步问题处理。

1. 先审核插画视觉风格。
2. 再审核插画内容是否与技能匹配。
3. 再审核插画是否有充分留白空间。
4. 最后合成成品卡并做综合审核。

任何一步不通过，立即停在该步骤返工；未通过前不得进入下一步。

---

## 二、步骤 1：插画视觉风格审核

目标：判断插画本体是不是可用的基础版正式美术。

通过标准：

- 风格符合当前项目的商品级卡牌美术方向。
- 角色或法宝有独立形象、特色、记忆点。
- 妖怪之间不能看起来像同一套五官、耳朵、身形或动作换皮。
- 画面亮度、对比度、质感适合实体卡印刷。
- 不出现错误文字、水印、现代物件、错阵营元素。
- 不把角色画成与单卡志相反的定位。

不通过时：

- 必须重新生成或重做插画。
- 保留旧图和审核记录。
- 不进入技能匹配审核。

通过后：

- 进入步骤 2。
- 后续除非发现步骤 1 漏审问题，不得因为留白或合成安全区问题重新绘图。

---

## 三、步骤 2：插画内容与技能匹配审核

目标：判断插画是否表达了卡面技能和世界观定位。

通过标准：

- 插画动作、道具、场景、表情与 `规则/V1.2-基础卡表.md` 的卡面文案一致。
- 技能结果能从画面里看出来，或至少不误导成另一个技能。
- 不表现规则没有的效果。
- 不因为好看而改变技能方向。
- 单卡志中的视觉设计与当前技能一致。

不通过时：

- 必须重新生成或重做插画。
- 保留旧图和审核记录。
- 不进入留白审核。

通过后：

- 进入步骤 3。
- 步骤 1、2 都通过后，不得再因为安全区、星级、名称栏、技能栏遮挡问题重新绘图；只允许通过模型阔图、缩放、移动、裁切解决。

---

## 四、步骤 3：留白空间审核

目标：判断已经通过风格和技能的插画，是否有足够空间供卡面 UI 合成。

通过标准：

- 星级区有足够负空间。
- 名称栏区不压住脸部、主动作、关键道具或技能结果。
- 底部技能栏不压住技能结果的核心信息。
- 未来 5 星预留危险区不得压住脸部或表情。
- 主体视觉区、脸部安全区、主动作区、技能结果区都能成立。

不通过时：

- 如果步骤 1、2 已通过，不重新绘图。
- 必须优先使用模型阔图、缩放、移动、裁切解决。
- 阔图必须使用模型生成，不使用本地拼接、拉伸、模糊补边作为最终插画。
- 阔图不得改变已经通过的角色身份、造型、技能动作和关键道具。
- 阔图后必须重新审核留白空间。

通过后：

- 进入步骤 4。

---

## 五、步骤 4：合成后综合审核

目标：审核最终成品卡是否能作为实体卡使用。

通过标准：

- 插画风格仍然统一。
- 技能文案与 `规则/V1.2-基础卡表.md` 完全一致。
- 星级清晰；星星只按自身边界描边或投影，不加突兀方框或黑圈背景。
- 名称栏清晰，不遮挡核心信息。
- 底部技能栏文字可读，标点视觉底部对齐。
- 脸部不进入 5 星预留危险区。
- 主动作、关键道具、技能结果没有被 UI 遮挡。
- 小图缩略状态可读。
- 适合实体卡印刷。

不通过时：

- 如果问题来自 UI、裁切、留白、安全区，回到步骤 3，只做模型阔图、缩放、移动、裁切或合成参数调整。
- 如果合成后才发现步骤 1 或步骤 2 的漏审问题，必须明确记录为“前置审核漏审”，再回到对应步骤重做插画。
- 每一版成品卡和审核记录都必须保留。

---

## 六、审核记录模板

每张成品卡必须记录以下内容：

```text
卡名：
审核版本：
使用插画：

步骤1 插画视觉风格：通过 / 不通过
问题说明：
处理动作：重新绘图 / 进入下一步

步骤2 技能匹配：通过 / 不通过
问题说明：
处理动作：重新绘图 / 进入下一步

步骤3 留白空间：通过 / 不通过
问题说明：
处理动作：模型阔图 / 缩放 / 移动 / 裁切 / 进入下一步

步骤4 合成综合审核：通过 / 不通过
问题说明：
处理动作：通过 / 回到步骤3 / 回到步骤1或2并记录前置漏审

最终结论：通过 / 待用户审核 / 需人工复审
```

---

## 七、返工边界

- 步骤 1、2 任一步不通过：重做插画。
- 步骤 1、2 都通过，步骤 3 不通过：不重做插画，只做模型阔图、缩放、移动、裁切。
- 步骤 4 不通过：先判断问题来源；安全区和 UI 问题回步骤 3，不得直接重画。
- 本地拼接、拉伸、模糊补边只能用于临时分析，不能作为最终阔图。
- 用户明确指定某版插画时，必须优先使用该版，并只在安全区不足时做模型阔图。
