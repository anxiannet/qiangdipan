# 《夕妖：抢地盘》

西游妖怪题材欢乐聚会卡牌游戏。

2~4 人｜15~30 分钟｜轻策略｜轻 TRPG 代入｜实体印刷优先

## 当前定位

本仓库是《夕妖：抢地盘》的独立项目库，用于集中维护规则、卡表、技能文案、视觉规范、UI 资产、AI 工作流与成品卡牌资料。

## 当前版本

规则版本：V1.2

核心胜利条件：控制同一阵营 3 块地盘，立即获胜
