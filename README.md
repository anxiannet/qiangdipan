# 《夕妖：抢地盘》

西游妖怪题材欢乐聚会卡牌游戏。

2~4 人｜15~30 分钟｜轻策略｜轻 TRPG 代入｜实体印刷优先

## 当前定位

本仓库是《夕妖：抢地盘》的独立项目库，用于集中维护规则、卡表、技能文案、视觉规范、UI 资产、插画设计、AI 工作流与成品卡牌资料。

## 当前版本

规则版本：V1.2

核心胜利条件：控制同一阵营 3 块地盘，立即获胜

## 视觉维护原则

规范与插画设计分开维护。

规范文件负责：

```text
必须遵守什么
禁止做什么
信息放在哪里
尺寸与边界是什么
```

插画设计文件负责：

```text
画面怎么设计
角色怎么表现
动作和表情怎么做
法宝和地盘的视觉关键词是什么
```

插画设计必须符合规范要求。
