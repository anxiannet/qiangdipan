# 《夕妖：抢地盘》包装盒文案

## 文件定位

本文件用于维护《夕妖：抢地盘》实体包装盒对外展示文案。

用途：

- 包装盒正面 / 背面 / 侧边排版
- 产品展示图
- 电商详情页首屏信息
- 宣传物料中的简版产品介绍

本文件不维护完整规则，不替代：

```text
规则/当前规则.md
规则/指南卡.md
规则/V1.2-基础卡表.md
卡牌成品/印刷说明.md
```

卡牌数量、卡牌类型、卡面技能与审核状态仍以 `规则/V1.2-基础卡表.md` 为准。

印刷尺寸、出血、安全区、卡背与交付文件要求仍以 `卡牌成品/印刷说明.md` 为准。

## 三、盒背信息结构

推荐盒背只保留以下信息层级：

1. 游戏名称与一句话定位。
2. 核心卖点。
3. 氛围介绍。
4. 核心目标。
5. 卡牌展示。
6. 内容物。
7. 年龄、人数、时长、版权、条码等出版信息。

不建议放：

- 完整回合流程。
- 完整战斗结算。
- 完整胜负判定顺序。
- 详细卡牌技能。
- 第二份卡表。
- 未确定的条码、厂商、年龄分级或生产信息。

## 八、内容物文案

标准写法：

```text
内容物
58张妖怪与法宝牌
12张地盘牌
2张双面指南卡
```

如需标注总数：

```text
共72张实体卡
含70张游戏牌与2张指南卡
```

不建议在盒背拆成“妖怪牌54张、法宝牌4张”，除非排版空间足够。

若需要更完整版本，可写：

```text
内容物
54张妖怪牌
4张法宝牌
12张地盘牌
2张双面指南卡
共72张实体卡
```

## 十二、盒背生成图审核规则

生成或排版盒背时，必须检查：

1. 内容物数量是否正确。
2. 是否误写旧规则“1星无技能 / 2星无技能”。
3. 是否误写旧术语“攻山”。
4. 是否误写“基础版不包含4星、5星”。
5. 是否放入过多指南卡级别规则。
6. 是否生成虚构条码、厂商、年龄、认证标识。
7. 是否出现第二份卡表或第二份技能表。

盒背图若出现以上问题，不可作为定稿，只能作为美术氛围参考。
