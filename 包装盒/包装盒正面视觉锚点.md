本文件只维护包装盒正面的视觉方向、构图气质、商品感标准与审核要点。

卡牌数量

地盘列表
卡表数据

## 一、当前决定

当前确认一张“群妖冲山头、木牌金字标题”的包装盒正面图作为包装盒正面视觉锚点。

锚点用途：

```text
包装盒正面构图参考
包装盒正面气质参考
包装盒正面标题层级参考
包装盒宣传图方向参考
```

该锚点不替代：

```text
规范流程/视觉锚点-青狮精.md
```

说明：

- 青狮精最终成品卡仍是整套妖怪卡、法宝卡成品卡的视觉锚点。
- 本文件仅确认包装盒正面视觉锚点。
- 包装正面可以比单卡画面更强调整体产品感、群妖场景和购买识别。

---

## 二、锚点核心特征

包装盒正面锚点确立以下方向：

```text
明亮天空
山头目标
洞府 / 山寨 / 城楼
群妖从下方向山头冲锋
中部木牌承载主标题
金色厚重标题字
四周商品级边框
欢乐、热闹、轻竞争
```

核心视觉感受：

```text
不是严肃大战
不是黑暗史诗
不是单个角色海报
不是规则说明图
而是“群妖一起冲去抢地盘”的欢乐聚会卡牌包装
```

---

## 三、推荐包装正面结构

测试版双插盒正面建议采用以下结构：

```text
顶部：
山头、洞府、旗帜、蓝天白云

中部：
夕妖：抢地盘
金色大标题 + 木牌底

中下：
西游妖怪题材欢乐聚会卡牌游戏

底部：
2~4人｜15~30分钟

画面主体：
群妖从画面下方向山头冲锋，表现“抢地盘”
```

若正面空间不足，可采用优先级：

```text
1. 夕妖：抢地盘
2. 群妖冲山头主视觉
3. 2~4人｜15~30分钟
4. 西游妖怪题材欢乐聚会卡牌游戏
```

---

## 四、标题处理要求

包装盒正面必须清楚出现完整产品名：

```text
夕妖：抢地盘
```

可采用以下排版：

```text
夕妖
抢地盘
```

或：

```text
夕妖：抢地盘
```

当前锚点图中“抢地盘”金色大字方向可保留，但正式印刷前应由设计师重排标题文字。

要求：

1. 不直接依赖 AI 生成文字作为最终 Logo。
2. 字形必须准确，不能缺笔、错字、变形到影响识别。
3. 主标题必须比背景旗帜文字更醒目。
4. 木牌底、金色字、厚重阴影可以作为风格延续。

---

## 五、包装正面必须保留的信息

正式包装正面建议包含：

```text
夕妖：抢地盘
西游妖怪题材欢乐聚会卡牌游戏
2~4人｜15~30分钟
```

测试版如空间紧张，也不得完全省略产品名。

人数与时长可放在底部信息条：

```text
2~4人｜15~30分钟
```

---

## 六、角色与场景要求

包装正面应优先表现：

```text
群妖冲锋
抢山头
抢旗帜
冲向洞府
抢占领地
热闹搞事
轻松竞争
```

角色表现要求：

1. 角色可以夸张、可爱、滑稽，但不能低幼玩具化。
2. 表情要有戏，有抢地盘的兴奋、得意、慌张、冲劲。
3. 角色数量可以多于单卡插画，但核心人物不要过密。
4. 远景小妖用于气氛，不能压过主标题和主视觉。
5. 不表现血腥、恐怖、残酷战斗结果。

场景要求：

1. 山头 / 洞府 / 妖寨必须一眼可见。
2. 路径方向最好从画面下方通向上方目标，形成“冲上去抢”的动势。
3. 蓝天白云、明亮环境可以保留，增强欢乐聚会感。
4. 背景旗帜可用于氛围，但不得形成第二套地盘或妖域设定。

---

## 七、背景文字与旗帜限制

背景旗帜、牌匾、门楼可以辅助氛围，但必须遵守：

1. 不得抢过主标题。
2. 不得生成错误产品名。
3. 不得暗示当前规则不存在的妖域体系。
4. 不得让玩家误以为包装正面旗帜文字就是基础版四大妖域或全部地盘列表。
5. 背景文字应尽量少而清楚。

当前基础版核心妖域、地盘等信息，以规则与基础卡表为准。

若不确定某个地点是否属于当前基础版，包装正面优先使用无字旗帜、妖怪图腾、颜色区分或抽象纹样。

---

## 八、与上一版史诗大战方向的区别

包装正面锚点应避免回到上一版“多势力史诗大战海报”方向。

保留：

```text
商品级
厚重标题
山头争夺
西游妖怪
多角色热闹感
```

降低：

```text
过多势力文字
过密小兵
黑暗压迫感
史诗战争感
复杂到小盒无法阅读的背景细节
```

增强：

```text
欢乐冲锋
抢旗动作
群妖搞事
明快色彩
一眼读懂“抢地盘”
```

## 九、适配测试版双插盒正面

测试版双插盒正面尺寸：

```text
68 × 93 mm
```

展开图含出血画布与尺寸详见：

```text
包装盒/测试版双插盒展开图尺寸.md
```

正面设计时必须注意：

1. 主标题必须在小尺寸下清楚可读。
2. 副标题不得过小。
3. 底部人数时长必须放入安全区。
4. 小妖和背景建筑不能过密，否则印刷后会糊成噪点。
5. 重要人物、标题、信息条必须避开裁切风险。
6. 最终 clean 图不得带安全线、裁切线、标注文字。

## 十、审核清单

包装盒正面审核时，必须检查：

```text
产品名是否完整准确：夕妖：抢地盘
副标题是否准确：西游妖怪题材欢乐聚会卡牌游戏
人数时长是否准确：2~4人｜15~30分钟
是否有明确山头 / 洞府 / 地盘目标
是否表现群妖争抢而不是单人站姿
是否保留欢乐聚会感
是否避免严肃黑暗史诗化
是否避免背景文字误导规则
是否适配 68 × 93 mm 小盒正面
是否具有商品级 / 收藏级质感
是否没有虚构条码、厂商、年龄、认证标识
```

审核结论建议使用：

```text
包装正面锚点一致性：合格 / 不合格
产品名准确性：合格 / 不合格
信息层级：合格 / 不合格
规则边界：合格 / 不合格
小尺寸可读性：合格 / 不合格
是否可进入排版定稿：是 / 否
问题说明：
```

## 十一、维护原则

1. 本文件只维护包装盒正面视觉锚点。
2. 本文件不维护第二份规则、卡表、技能或地盘列表。
3. 若包装文案调整，先更新 `包装盒/包装盒文案.md`。
4. 若包装盒尺寸调整，先更新 `规范流程/包装盒尺寸规范.md` 或 `包装盒/测试版双插盒展开图尺寸.md`。
5. 若后续出现更高优先级包装正面锚点，应在本文件中记录替换原因。
