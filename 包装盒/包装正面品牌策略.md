## 一、品牌与产品层级

当前正式层级：

```text
主品牌：夕妖
具体产品：抢地盘
正式产品名：《夕妖：抢地盘》标准版
品类说明：西游妖怪欢乐聚会卡牌
```

“夕妖”的含义：

```text
昔日妖王
黄昏群妖
```

包装正面优先建立“夕妖”品牌认知；“抢地盘”是具体产品与玩法名称，不作为正面最大标题。

## 二、货架目标

标准版是小型便携卡盒，可能与 UNO、扑克牌、狼人杀及其他小盒聚会游戏并排陈列。

包装正面的第一任务不是完整解释玩法，而是：

```text
让顾客在2至3秒内注意到产品
↓
通过齐天大圣识别西游题材
↓
拿起包装
↓
再由背面了解《抢地盘》的玩法与内容
```

核心判断：

```text
没有注意，就没有拿起包装。
没有拿起包装，就没有了解规则和试玩的机会。
```

## 三、齐天大圣的使用原则

### 3.1 正面定位

齐天大圣作为标准版正面唯一主视觉，负责借用《西游记》的自然认知与货架吸引力。

齐天大圣可以占正面约70%至80%。

### 3.2 时间阶段

画面表现为大闹天宫之后的齐天大圣形象。

当前形象要求：

- 无紧箍或金箍。
- 明确为齐天大圣，而不是取经时期的孙行者。
- 有金箍棒、金甲、红披风、火眼金睛等经典识别元素。
- 桀骜、自信、聪明、有压迫感，但不应魔化或恐怖化。
- 不照搬任何现代影视、动画或电子游戏中的特定造型。

### 3.3 与标准版牌库的关系

包装正面使用齐天大圣，不代表标准版牌库必须加入孙悟空卡。

标准版卡牌名称、数量与类型仍以：

```text

```

为唯一来源。

## 四、正面信息层级

由强到弱：

```text
1. 齐天大圣主视觉
2. 主品牌“夕妖”
3. 品类说明“西游妖怪欢乐卡牌”
4. 2~4人｜15~30分钟
```

“抢地盘”处理方式：

- 不作为正面最大标题。
- 可在正面底部以很小的版本名出现，也可移至盒顶、侧面与背面。
- 背面必须清晰出现完整产品名《夕妖：抢地盘》。

### 正面推荐文字

```text
夕妖
西游妖怪欢乐卡牌
2~4人｜15~30分钟
```

正面禁止堆叠：

- 大段背景故事。
- 多个妖怪群像。
- 大量玩法卖点。
- 三个以上信息徽章。
- 与齐天大圣竞争视觉焦点的五指山或天宫场景。

## 五、构图比例

推荐竖版正面比例：

```text
顶部至中部约75%：齐天大圣近景插画
中下部约18%：夕妖品牌字
底部约7%：品类、人数字段与时长
```

构图要求：

- 大圣面部位于画面上半部黄金视觉区。
- 眼睛在缩小至真实包装尺寸后仍清晰可见。
- 金箍棒形成稳定斜向引导线，但不得遮挡脸部与品牌字。
- 手部不能过大，避免侵占品牌字区域。
- 下方必须预留整洁、低细节的文字安全区。
- 画面不能依赖细碎背景；缩小后仍应保持清楚。

## 六、色彩与风格

主色：

```text
暗红
古金
深黑
少量夕阳橙
```

风格目标：

- 商品级、收藏级、厚重、有立体感。
- 高识别度的大型角色近景。
- 有《魔兽兵团》《皇室战争》《炉石佣兵》式的夸张体积感与清晰轮廓。
- 保留欢乐聚会游戏的可亲近感，避免完全变成严肃动作游戏海报。

避免：

- 过度写实到类似真人影视剧照。
- 借鉴或复制特定商业作品中的孙悟空造型。
- 大量火焰、末日废墟与血腥战场氛围。
- 百科卡、测试版UI、页游式堆字。

## 七、完整包装盒正面生成提示词

### 中文主提示词

```text
为实体卡牌游戏《夕妖：抢地盘》设计一张竖版小型卡盒正面，真实印刷包装比例，正面平视展开图，不显示侧面，不做三维盒子透视，不生成背面。

画面核心是大闹天宫之后的齐天大圣孙悟空单人近景，占画面约75%。他没有紧箍或金箍，火眼金睛明亮，猴王面容英武、桀骜、自信、聪明，嘴角带一点轻微戏谑感，不恐怖、不魔化。身穿原创的暗金色云纹锁子甲和红色披风，造型具有中国古典西游识别度，但不能复制任何影视、动画或电子游戏中的具体孙悟空设计。

金箍棒从画面左下或侧后方斜向上延伸，棒身识别清楚，两端有金色箍纹，但不能挡住孙悟空的脸。人物手部适当缩小，不占据下方文字区域。背景简洁，以深黑、暗红、古金和夕阳橙的祥云、微光和少量天宫余韵构成，不出现群妖，不出现复杂战斗，不突出五指山，不堆叠大量元素。

整体风格为商品级、收藏级、厚重立体的高品质3D卡通幻想插画，参考高识别度竞技手游角色宣传图的体积感，但保持原创中国西游美术，不要写实电影剧照感，不要黑暗恐怖，不要像任何现有商业游戏角色。

下方预留约25%的干净暗色文字安全区。文字层级：最大品牌字为“夕妖”，使用厚重、清晰、易读的原创金色中文品牌字，融入夕阳、妖纹或兽瞳意象，但不要破碎难认；其下小字为“西游妖怪欢乐卡牌”；最底部仅保留“2~4人｜15~30分钟”。不要把“抢地盘”作为正面最大标题，可在最底部以极小版本名“抢地盘”出现，或完全不显示。

包装正面的首要目标是在与UNO等小盒聚会卡牌并排陈列时，依靠齐天大圣的面部、火眼金睛、红金配色和“夕妖”品牌字，在2至3秒内吸引顾客注意。构图简洁，远看醒目，缩小到约63×88毫米后仍能清楚识别人物与“夕妖”两个字。

印刷设计要求：四周保留3毫米出血安全空间，关键脸部、金箍棒和文字远离裁切线，底部文字清晰，无乱码，无错误汉字，无英文，无多余徽章，无水印，无假Logo。
```

## 八、生成与排版执行原则

推荐执行流程：

```text
1. 优先生成无文字主插画。
2. 人工审核大圣造型、无紧箍、手部比例、金箍棒与底部留白。
3. 使用正式“夕妖”品牌字资产进行人工排版。
4. 再加入品类说明与人数时长。
5. 按真实盒面尺寸缩小检查货架识别。
6. 最后进入刀模与印刷文件。
```

不建议依赖图像生成模型直接生成最终中文品牌字。正式印刷版本必须使用可控的独立文字与Logo资产，避免错字、乱码和字形不一致。

## 九、验收标准

缩小至真实卡盒尺寸后，应满足：

- 2至3秒内识别为西游题材。
- 第一眼看到齐天大圣面部，而不是复杂背景。
- 第二眼能清楚读出“夕妖”。
- 不会误认为是影视光盘、动作游戏或单纯收藏卡。
- 正面没有信息拥挤。
- 与UNO等高饱和包装并排时仍有明显红金黑视觉区隔。
- 包装背面负责完整解释《抢地盘》的名称、故事、玩法与内容物。
