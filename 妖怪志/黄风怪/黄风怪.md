# 黄风怪

## 基础信息

| 项目 | 内容 |
|---|---|
| 世界观档位 | 2 档 |
| 星级 | 3 星 |
| 战力 | 3 |
| 类型 | 强妖王 / 强神通者 |
| 来源/归属 | 黄风岭 |
| 技能状态 | 已审核 |

## 背景

黄风怪是 2 档强神通者，核心记忆点是三昧神风。

## 小传

黄风怪应有明确的风系压制感。当前技能用“吹回同一地盘中的2个2星守军”表现三昧神风能吹散中坚守军，但不直接复制芭蕉扇的整地盘清场。

## 候选技能详细描述

规则效果：

```text
选择 1 块地盘，将其中最多 2 个 2 星以下守军吹回拥有者手牌。
```

卡面文案：

```text
吹回1块地盘中的2个2星守军。
```

说明：卡面描述表示最高能力。按“吹回”总规则，实际结算时可以自动降级，选择更少数量或更低星级的守军，但不能超过同一块地盘、最多 2 个、最高 2 星这些上限。

## 设计理由

代入感来自三昧神风吹散中坚守军。旧版只吹回 1 个 1 星守军，作为 3 星强妖王明显偏弱；新版能吹回最多 2 个 2 星以下守军，形成和铁扇公主、芭蕉扇之间的清晰梯度。

## 强度分析

| 项目 | 评价 |
|---|---|
| 主要作用对象 | 同一地盘中的 2 星以下守军 |
| 受影响战力 | 1~4 |
| 牌区去向 | 回到拥有者手牌 |
| 是否直接改变资源 | 否，守军回到拥有者手牌 |
| 是否影响地盘控制 | 可能间接影响 |
| 是否突破行动节奏 | 否 |
| 技能强度评分 | 76 |
| 世界观符合度评分 | 100 / 100 |
| 技能评级 | A- |

评分理由：该技能最高可吹回 4 星战力，强于铁扇公主的单体任意吹回，也高于红孩儿和青狮精的部分低星清除灵活度；但目标回到拥有者手牌，不进入弃牌堆，且不能处理 3 星守军，因此低于芭蕉扇的整地盘吹回。

## 与其他妖怪的关系

- 与虎先锋、黄风大圣构成黄风岭体系。
- 与铁扇公主、芭蕉扇形成吹回梯度。
- 与红孩儿形成差异：红孩儿消灭 1 星铺场，黄风怪吹回中低星守军但不弃牌。

## 羁绊

候选羁绊方向：三昧神风、黄风岭、风沙扰阵。

当前羁绊未定稿。

## 互动

玩家会感受到风吹回手的干扰。对手可以保留被吹回的守军，但关键地盘会被暂时打散，容易制造抢地盘窗口。

## 连锁

- 若吹回最后守军，可能导致该地盘失去全部守军，并按地盘回流处理。
- 不能吹回 3 星守军。
- 最高能力为同一地盘中 2 个 2 星守军；实际结算可以自动降级。

## 视觉形象设计

- 黄风、沙暴、披风、旋风眼。
- 应有强神通者气势，不要画成普通小妖。
- 风沙要清楚区分于芭蕉扇的大范围扇风。
- 画面重点是三昧神风吹散中坚守军，而不是整地盘法宝级风暴。
