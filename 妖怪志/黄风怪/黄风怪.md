# 黄风怪

## 基础信息

| 项目 | 内容 |
|---|---|
| 世界观档位 | 2 档 |
| 星级 | 3 星 |
| 战力 | 3 |
| 类型 | 强妖王 / 强神通者 |
| 来源/归属 | 黄风岭 |
| 技能状态 | 待审核 |

## 背景

黄风怪是 2 档强神通者，核心记忆点是三昧神风。

## 小传

黄风怪应该有明确的风系压制感。当前候选技能较弱，只吹回 1 星守军，虽然世界观方向正确，但作为 3 星强妖王需要重审强度。

## 候选技能详细描述

候选规则效果：

```text
选择 1 块地盘，将其中 1 只 1 星守军吹回拥有者手牌。
```

卡面候选文案：

```text
吹回1只1星守军，回到拥有者手牌。
```

## 设计理由

代入感来自神风吹退。当前版本是低配风系技能，用于保持基础版稳定。

## 强度分析

| 项目 | 评价 |
|---|---|
| 主要作用对象 | 1 星守军 |
| 受影响战力 | 1 |
| 牌区去向 | 回到拥有者手牌 |
| 技能强度评分 | 40 |
| 世界观符合度评分 | 100 / 100 |
| 技能评级 | B |

评分理由：神风味道非常强，但只影响 1 星单体，规则强度明显偏低。作为 3 星候选技能应优先重审。

## 与其他妖怪的关系

- 与虎先锋、黄风大圣构成黄风岭体系。
- 可与风系回手技能形成梯度。

## 羁绊

候选羁绊方向：三昧神风、黄风岭、风沙扰阵。

## 互动

玩家会感受到风吹回手的干扰，但当前爽感不足。

## 连锁

若吹回最后 1 只守军，可能间接导致地盘无主，但发生条件较窄。

## 视觉形象设计

- 黄风、沙暴、披风、旋风眼。
- 应有强神通者气势，不要画成普通小妖。
- 风沙要清楚区分于芭蕉扇的大范围扇风。
