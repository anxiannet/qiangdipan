# 九灵元圣

## 基础信息

| 项目 | 内容 |
|---|---|
| 世界观档位 | 1 档 |
| 星级 | 3 星 |
| 战力 | 3 |
| 类型 | 顶级妖王 |
| 来源/归属 | 竹节山 / 九曲盘桓洞 |
| 技能状态 | 待审核 |

## 背景

九灵元圣是 1 档顶级妖王，适合表现统御、守势、九头压阵、稳固地盘。

## 小传

九灵元圣不一定要做爆发技能，更适合成为让己方关键地盘变得更难攻破的统御型大妖。

## 候选技能详细描述

候选规则效果：

```text
选择 1 块己方地盘，该地盘驻军上限 +1。
```

卡面候选文案：

```text
选择1块己方地盘，驻军上限+1。
```

## 设计理由

代入感来自九灵元圣的统御与守势。增加驻军上限能表现“这块地盘被大妖坐镇，能容纳更多妖众”。

## 强度分析

| 项目 | 评价 |
|---|---|
| 主要作用对象 | 己方地盘 |
| 受影响战力 | 潜在 +1~3 |
| 持续时间 | 持续到地盘失控或后续规则另行说明 |
| 技能强度评分 | 76 |
| 世界观符合度评分 | 84 / 100 |
| 技能评级 | A- |

评分理由：不是立即清场，但会持续强化关键地盘。作为 1 档顶级妖王，世界观表现可以继续加强。

## 与其他妖怪的关系

- 可与任意高战力守军形成防守核心。
- 与芭蕉扇存在强对比：一个加固地盘，一个清空地盘。

## 羁绊

候选羁绊方向：九头坐镇、万妖归阵、九曲盘桓洞守势。

## 互动

玩家会围绕被强化地盘展开争夺，形成明显目标。

## 连锁

若地盘上限提高，芭蕉扇等整地盘效果的实际影响战力可能超过 9 星，评分时需额外计算。

## 视觉形象设计

- 多头狮形、厚重王者感、稳坐山门。
- 色调金黄厚重，强调统御而非速度。
- 3 星顶级妖王气势必须明显。
