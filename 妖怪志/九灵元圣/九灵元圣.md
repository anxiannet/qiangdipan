# 九灵元圣

## 基础信息

| 项目 | 内容 |
|---|---|
| 世界观档位 | 1 档 |
| 星级 | 3 星 |
| 战力 | 3 |
| 类型 | 顶级妖王 |
| 来源/归属 | 竹节山 / 九曲盘桓洞 |
| 技能状态 | 已审核 |

## 背景

九灵元圣是 1 档顶级妖王，适合表现统御、守势、九头压阵、稳固地盘。

## 小传

九灵元圣不一定要做爆发技能，更适合成为让己方关键地盘变得更难攻破的统御型大妖。

## 技能详细描述

规则效果：

```text
九灵元圣驻守的地盘，驻军上限 +1。
```

卡面文案：

```text
此地盘驻军上限+1。
```

说明：这里的“此地盘”指九灵元圣当前驻守的地盘。该效果由九灵元圣本体作为标记，不需要额外计数器。

## 设计理由

代入感来自九灵元圣的统御与守势。增加驻军上限能表现“这块地盘被大妖坐镇，能容纳更多妖众”。

## 审核结论

已审核，修改后通过。

审核理由：

- 原“选择1块己方地盘，驻军上限+1”容易形成长期标记，不符合基础版尽量不使用长期计数器的边界。
- 改为“此地盘驻军上限+1”后，九灵元圣本体就是规则标记。
- 只要九灵元圣在该地盘，效果清楚存在；九灵元圣离开后，地盘自然不再获得额外上限。
- 该效果不直接清场、不直接夺地，但能制造防守核心，符合顶级老妖坐镇感。

## 与其他妖怪的关系

- 可与任意高战力守军形成防守核心。
- 与芭蕉扇存在强对比：一个加固地盘，一个清空地盘。
- 与大鹏精、牛魔王同为 1 档顶级妖王，但方向不同：九灵偏守，大鹏偏攻，牛魔王偏铺场。

## 羁绊

候选羁绊方向：九头坐镇、万妖归阵、九曲盘桓洞守势。

当前羁绊未定稿。

## 互动

玩家会围绕九灵元圣坐镇的地盘展开争夺，形成明显目标。对手可以通过吹回、收走、消灭等方式让九灵元圣离开，从而解除上限加成。

## 连锁

- 若九灵元圣离开该地盘，该地盘驻军上限恢复为基础上限。
- 因九灵元圣自身也离开地盘，通常不会产生额外超上限处理。
- 若未来出现特殊情况下地盘超过当前上限，默认不能继续增援，直到该地盘守军数量低于上限。

## 视觉形象设计

- 多头狮形、厚重王者感、稳坐山门。
- 色调金黄厚重，强调统御而非速度。
- 画面应体现“坐镇地盘、群妖归阵”，而不是单体冲锋。
- 3 星顶级妖王气势必须明显。
