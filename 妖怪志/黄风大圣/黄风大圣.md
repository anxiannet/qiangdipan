# 黄风大圣

## 基础信息

| 项目 | 内容 |
|---|---|
| 世界观档位 | 2 档 |
| 星级 | 3 星 |
| 战力 | 3 |
| 类型 | 强妖王 / 强神通者 |
| 来源/归属 | 黄风岭 |
| 技能状态 | 移出基础版 |

## 背景

黄风大圣是黄风岭体系的强化风系角色，当前与黄风怪存在重复风险。

## 小传

V1.2 基础版已保留黄风怪作为黄风岭 3 星风系代表，黄风大圣移出基础版，作为后续扩展、异名、异画或强化版本候选。

## 候选技能详细描述

旧候选规则效果：

```text
选择 1 块地盘，将其中 1 个 2 星以下守军吹回拥有者手牌。
```

旧卡面候选文案：

```text
吹回1个2星以下守军。
```

当前处理：

```text
不进入 V1.2 基础牌库。
```

## 设计理由

黄风大圣与黄风怪同属风系吹回方向。基础版牌位有限，当前保留黄风怪的“三昧神风”技能作为风系代表，避免两个 3 星角色在基础版中功能重复。

## 强度分析

| 项目 | 评价 |
|---|---|
| 主要作用对象 | 2 星以下守军 |
| 受影响战力 | 1~2 |
| 牌区去向 | 回到拥有者手牌 |
| 技能强度评分 | 58 |
| 世界观符合度评分 | 100 / 100 |
| 技能评级 | B+ |

评分理由：旧候选技能不能处理 3 星，且回手保留资源。作为 3 星候选技能偏保守，并与黄风怪新版吹回技能发生功能重叠，因此移出基础版。

## 与其他妖怪的关系

- 与黄风怪、虎先锋同属黄风岭体系。
- 后续扩展中可作为黄风怪的异名、强化版或事件牌方向。

## 羁绊

候选羁绊方向：黄风岭大圣、神风升级、风沙压阵。

## 互动

基础版暂不使用，避免玩家同时遇到两个相近风系 3 星技能。

## 连锁

如后续重做，应避免只是比黄风怪数值略强，最好形成独立玩法记忆点。

## 视觉形象设计

- 比黄风怪更强烈的风沙法相。
- 可以更庄重、更大圣感，但仍需区分于大鹏精和芭蕉扇。
