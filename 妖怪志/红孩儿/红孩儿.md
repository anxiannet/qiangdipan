# 红孩儿

## 基础信息

| 项目 | 内容 |
|---|---|
| 世界观档位 | 2 档 |
| 星级 | 3 星 |
| 战力 | 3 |
| 类型 | 强妖王 / 强神通者 |
| 来源/归属 | 号山 / 火云洞 |
| 技能状态 | 已审核 |

## 背景

红孩儿是 2 档强神通者，核心记忆点是三昧真火与火云洞压迫感。

## 小传

红孩儿应该有明显的火系清场感，但基础版需要控制强度，避免直接成为芭蕉扇级整地盘压制。

当前红孩儿技能作为 V1.2 基础版 3 星妖怪技能锚点：3 星守军本体保留战力 3，同时技能最多可额外消灭 3 星战力的 1 星守军，但目标限制明确，不处理 2 星或 3 星守军。

## 候选技能详细描述

规则效果：

```text
选择 1 块地盘，消灭其中所有 1 星守军。
```

卡面文案：

```text
烧掉1块地盘中的所有1星守军。
```

## 设计理由

代入感来自三昧真火。限制为只烧 1 星守军，使技能有火烧群小妖的爽感，但不会直接处理 2 星、3 星。

作为 3 星技能锚点，红孩儿用于衡量基础版 3 星技能的合理强度：高于普通单体处理，低于芭蕉扇等法宝级整地盘重置。

## 强度分析

| 项目 | 评价 |
|---|---|
| 主要作用对象 | 一块地盘内所有 1 星守军 |
| 动作 | 消灭 |
| 受影响战力 | 0~3 |
| 牌区去向 | 弃牌堆 |
| 是否直接改变资源 | 是，对手守军进入弃牌堆 |
| 是否影响地盘控制 | 可能间接影响 |
| 是否突破行动节奏 | 否 |
| 技能强度评分 | 74 |
| 世界观符合度评分 | 100 / 100 |
| 技能评级 | A |
| 3 星技能锚点 | 是 |

评分理由：最多消灭 3 星战力，且只限 1 星守军，低于芭蕉扇最高吹回 9 星战力的 100 分锚点。红孩儿本体仍作为 3 星守军正常上场，技能作为 3 星妖怪强技能参照点，用于衡量其他 3 星技能是否偏弱或偏强。

## 与其他妖怪的关系

- 与牛魔王、铁扇公主、有来有去、急如火、快如风构成火云体系。
- 可克制依赖 1 星铺场的玩家。
- 与青狮精形成对比：红孩儿清一块地盘内所有 1 星守军，青狮精可以吃最多 2 个 1 星守军或 1 个 2 星守军。

## 羁绊

候选羁绊方向：火云洞、三昧真火、烧小妖。

当前羁绊未定稿。

## 互动

玩家会主动避开把太多 1 星堆在同一地盘，形成有趣威慑。

## 连锁

可能烧掉最后若干 1 星守军，间接导致地盘无主；但不应自动按芭蕉扇级强度计算。

## 视觉形象设计

- 少年妖王，火焰、火尖枪意象可抽象化处理，重点是三昧真火。
- 火云洞、红色火焰、嚣张表情。
- 3 星强神通者，应有高亮度火焰视觉焦点。
- 视觉重点是火烧一群低星小妖，不是单体秒杀 3 星首领。
