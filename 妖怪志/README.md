# 妖怪志

## 文件定位

本目录用于维护《夕妖：抢地盘》基础版每个妖怪的详细设计资料。

基础卡表只保留索引用信息：

- 卡牌名称
- 数量
- 世界观档位
- 星级
- 战力
- 类型
- 卡面文案
- 技能强度评分
- 世界观符合度评分
- 技能评级
- 审核状态
- 妖怪志链接

以下详细内容统一维护在本目录对应妖怪文件夹中：

- 背景
- 小传
- 候选技能详细描述
- 设计理由
- 强度分析
- 与其他妖怪的关系
- 羁绊
- 互动
- 连锁
- 视觉形象设计
- 插画与迭代记录

## 维护原则

1. 每个妖怪一个文件夹，文件夹内保留同名妖怪文档。
2. 妖怪插画、基础版迭代记录和审核图放入该妖怪文件夹下的 `插画/` 目录。
3. 不在基础卡表写长篇技能解释。
4. 不在视觉文件重复维护规则。
5. 若技能调整，先修改对应妖怪志，再同步基础卡表中的卡面文案、评分、评级与审核状态。
6. 法宝暂不纳入妖怪志，继续维护于 `法宝志/`。
