# 黄袍怪

## 基础信息

| 项目 | 内容 |
|---|---|
| 世界观档位 | 3 档 |
| 星级 | 2 星 |
| 战力 | 2 |
| 类型 | 普通妖王 |
| 来源/归属 | 宝象国 / 波月洞 |
| 技能状态 | 待审核 |

## 背景

黄袍怪是波月洞妖王，适合表现强行掳走、带回洞府、形成手牌资源的技能。

## 小传

黄袍怪的技能不应是大范围清场，而应是明确的“掳走一个目标”。

## 候选技能详细描述

候选规则效果：

```text
选择 1 块地盘，获得其中 1 只 1 星守军，将其加入你的手牌。
```

卡面候选文案：

```text
掳走1只1星守军，加入你的手牌。
```

## 设计理由

代入感来自“掳走”。加入手牌比加入地盘弱一些，但更像把人带回洞府。

## 强度分析

| 项目 | 评价 |
|---|---|
| 主要作用对象 | 1 星守军 / 玩家手牌 |
| 受影响战力 | 1 |
| 牌区去向 | 加入你的手牌 |
| 技能强度评分 | 55 |
| 世界观符合度评分 | 86 / 100 |
| 技能评级 | B+ |

评分理由：形成资源差，但不会立即增加地盘守军。作为 2 星技能可测试。

## 与其他妖怪的关系

- 与白骨精、金鼻白毛老鼠精同属 3 档普通妖王层级。
- 与“偷取 / 掳走”类技能形成对比。

## 羁绊

候选羁绊方向：波月洞掳人、宝象国事件、洞主夺人。

## 互动

玩家能清楚理解“我的小妖被掳走了”，互动感强。

## 连锁

可能移走最后 1 只 1 星守军，间接导致地盘无主。

## 视觉形象设计

- 黄袍、洞主、阴郁妖王气质。
- 画面可表现伸手抓走小妖或带回洞府。
- 2 星妖王，不宜画成顶级神魔压迫。
