# 牛魔王

## 基础信息

| 项目 | 内容 |
|---|---|
| 世界观档位 | 1 档 |
| 星级 | 3 星 |
| 战力 | 3 |
| 类型 | 顶级妖王 |
| 来源/归属 | 积雷山 / 翠云山 / 火云体系 |
| 技能状态 | 已审核 |

## 背景

牛魔王是 1 档顶级妖王，当前基础版最高牌面之一。

## 小传

牛魔王的核心不是单体小动作，而是号令群妖、统御山头、带动火云体系出兵。

## 技能详细描述

规则效果：

```text
你可以立即再打出 1 张妖怪牌。
```

卡面文案：

```text
立即再打出1张妖怪牌。
```

## 设计理由

代入感来自“号令群妖”。该技能让牛魔王出场后带出另一个妖怪，体现大妖王带队压场。

## 审核结论

已审核，保留。

审核理由：

- 代入感强，能体现顶级妖王号令群妖。
- 操作简单，玩家一眼能懂。
- 强度明确突破铺场节奏，但不直接抢地盘，不直接清除守军，不直接改胜利条件。
- 与大鹏精形成差异：牛魔王强化招兵节奏，大鹏精强化攻山节奏。

## 强度分析

| 项目 | 评价 |
|---|---|
| 主要作用对象 | 玩家手牌 / 行动节奏 |
| 受影响战力 | 通常 1~3 |
| 是否突破节奏 | 是，额外打出妖怪 |
| 技能强度评分 | 68 |
| 世界观符合度评分 | 100 / 100 |
| 技能评级 | A- |

评分理由：额外打出妖怪有明确铺场收益，但不直接抢地盘，也不凭空生成资源。作为 1 档顶级妖王，牌面由“高战力 + 额外出兵节奏”共同体现。

## 与其他妖怪的关系

- 与铁扇公主、红孩儿、玉面狐狸构成火云 / 积雷山关系网。
- 可与有来有去、急如火、快如风等 1 星小妖产生出场连锁。
- 与大鹏精同为 1 档顶级妖王，但一个偏招兵，一个偏攻山。

## 羁绊

候选羁绊方向：号令群妖、火云一家、积雷山大王。

当前羁绊未定稿。

## 互动

玩家会期待牛魔王带出另一张妖怪制造节奏爆发。该技能适合形成“牛魔王一来，群妖跟上”的桌面记忆点。

## 连锁

可能配合 1 星、2 星出场技能产生连锁，后续测试关注是否会导致一回合展开过快。

## 视觉形象设计

- 顶级妖王体量，牛首图腾、战旗、厚重盔甲。
- 画面应有统御群妖的压迫感。
- 可表现身后群妖响应号令，但主体必须仍是牛魔王。
- 3 星牌面必须明显高于普通洞主。
