## 当前归属说明

铁扇公主不属于V1.3标准版牌库，当前进入《火云再起》扩展包候选。

她与芭蕉扇、牛魔王、玉面狐狸、红孩儿共同构成火云 / 芭蕉洞关系网。

## 当前技能

规则效果：

```text
弃1张手牌，选择任意1个守军，将其吹回拥有者手牌。
```

卡面文案：

```text
弃1张牌，吹回任意1个守军。
```

## 执行说明

- 必须先从手牌中弃掉1张牌，才能发动吹回效果。
- 弃掉的牌进入弃牌堆。
- 铁扇公主本身已经打出，不可作为这次技能的弃牌费用。
- 可以选择任意星级的1个守军。
- 被吹回的守军回到其拥有者手牌。
- 吹回不是消灭，不进入弃牌堆。
- 若没有其他手牌可以弃，技能不能发动。
- 若吹回某块地盘的最后1个守军，该地盘可能变为无主。

## 设计理由

铁扇公主保持4星与任意单体吹回定位，但增加弃1张手牌的发动条件。己方守军召回机制已独立交由标准版蜘蛛精承担，不在铁扇公主上维护第二套效果。

## 强度分析

| 项目 | 评价 |
|---|---|
| 主要作用对象 | 任意1个守军 |
| 影响星数 | 1～5星 |
| 发动代价 | 弃1张手牌 |
| 牌区去向 | 目标回到拥有者手牌；费用牌进入弃牌堆 |
| 是否直接消灭资源 | 否 |
| 是否可能使地盘无主 | 是，最多影响1块地盘 |
| 当前状态 | 待复测 |

## 与其他妖怪的关系

- 与牛魔王、红孩儿、玉面狐狸属于火云 / 积雷山关系网。
- 与法宝芭蕉扇强关联，但铁扇公主只处理单体，芭蕉扇处理整块地盘。
- 与白象精同为4星单体吹回：白象精不需要弃牌但受3星或以下限制；铁扇公主需要弃1张牌，但可处理任意星级。
- 与蜘蛛精区分：蜘蛛精只召回自己的守军；铁扇公主用于处理任意玩家的单个守军。

## 视觉要求

- 主体定位：4星强洞主，使用4星强化边框。
- 人物主体优先，不能画成法宝卡。
- 核心动作：朝单个目标挥扇。
- 特效只表现单体风线，不表现整块地盘风暴。
- 不需要在插画中表现弃牌动作，弃牌条件由技能文案表达。
- 禁止表现同时吹回多个守军。
