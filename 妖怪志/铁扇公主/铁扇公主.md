# 铁扇公主

## 基础信息

| 项目 | 内容 |
|---|---|
| 世界观档位 | 3 档 |
| 星级 | 2 星 |
| 战力 | 2 |
| 类型 | 洞主 |
| 来源/归属 | 芭蕉洞 |
| 技能状态 | 已审核 |

## 背景

铁扇公主当前按 3 档洞主处理，为 2 星。她的牌面与芭蕉扇关系极强，但法宝芭蕉扇单独承担整地盘吹回锚点。

## 小传

铁扇公主应体现“会扇风、能把守军吹回去”，但不能直接复制法宝芭蕉扇的整地盘压制。

## 技能详细描述

规则效果：

```text
选择任意1个守军，将其吹回拥有者手牌。
```

卡面文案：

```text
吹回任意1个守军。
```

说明：吹回的含义由总规则定义，卡面不重复写“回到拥有者手牌”。

## 设计理由

该效果把芭蕉扇的“大范围吹回”压缩为单体吹回，既保留代入感，又避免 2 星角色过强。

| 技能强度评分 | 64 |
| 世界观符合度评分 | 84 / 100 |

评分理由：可处理 3 星守军但不消灭，资源仍回到拥有者手牌。作为 2 星技能偏强，但角色与芭蕉扇关系强，且只处理单体，因此保留。

## 与其他妖怪的关系

- 与牛魔王、红孩儿、玉面狐狸属于火云 / 积雷山关系网。
- 与法宝芭蕉扇强关联，但必须区分角色技能与法宝效果。
- 与黄风怪形成梯度：铁扇公主单体任意吹回，黄风怪吹回同一地盘多个中低星守军。

候选羁绊方向：芭蕉洞、火云家族、借扇生风。

## 互动

单体吹回清楚易懂，适合制造“关键守军被吹走”的桌面瞬间。

## 连锁

- 若吹回最后 1 个守军，可能导致地盘失去全部守军，并按地盘回流处理。
- 可选择任意星级的 1 个守军。

## 视觉形象设计

- 主体轮廓：成熟人形洞主，华丽衣袖，扇姿轮廓优雅，角色本体是主角。
- 核心动作：朝单个目标挥扇，表现单体吹回。
- 核心表情：冷艳、强势、克制，有洞主贵气和掌控感。
- 核心场景：芭蕉洞、火云边界、洞府前。
- 关键道具：小型扇影、衣袖、芭蕉洞装饰；扇子可出现，但不能压过角色。
- 关键特效：单体风线、被吹回的单个守军后退轨迹。
- 候选台词：“回去。”

## 视觉差异要求

- 必须一眼看出：单体吹回，角色技能。
- 与芭蕉扇区分：铁扇公主是人物卡，法宝芭蕉扇才是巨扇主体和整地盘风暴。
- 与黄风怪区分：铁扇公主是优雅挥扇处理单体，黄风怪是妖怪神通、黄沙风暴、吹散多个中坚守军。
- 与玉面狐狸区分：铁扇公主是冷艳洞主单体挥扇，不是狐妖借牛魔王之势守地盘。
- 禁止撞点：不能画成整地盘风暴；不能让扇子本体压过角色；不能像法宝卡；不能与玉面狐狸同样狐媚姿态；不能画成牛魔王关系牌。

## 视觉安全区要求

铁扇公主的脸部、挥扇手势、单体风线必须处于中部安全区。被吹回的目标可以位于中下区域，但不得压住底部文案栏。
