## 背景

白骨精是白骨岭代表妖怪，当前按 3 档普通妖王 / 山主处理，为 2 星。

## 小传

白骨精核心不是正面战力，而是变化、伪装、白骨不散、死而复现。相比单纯查看手牌，她更适合通过“被消灭后不进弃牌堆”来表现三打三变、死后又回来的角色记忆点。

## 技能详细描述

规则效果：

```text
白骨精被消灭时，不进入弃牌堆，放回公共牌库并重洗。
```

卡面文案：

```text
被消灭时，放回公共牌库并重洗。
```

## 设计理由

白骨精最有记忆点的不是偷看，而是三次变化、被打倒后仍以另一种形式回来。

## 强度分析

| 项目 | 评价 |
|---|---|
| 主要作用对象 | 自身 / 公共牌库 |
| 动作 | 被消灭时回公共牌库并重洗 |
| 受影响战力 | 0 |
| 是否直接改变资源 | 否 |
| 是否影响地盘控制 | 否 |
| 是否突破行动节奏 | 否 |
| 技能强度评分 | 0 |
| 世界观符合度评分 | 100 / 100 |
| 技能评级 | A |

评分理由：该效果不能让当前玩家获得任何确定收益，不能回手、不能复活、不能立刻上场，也不能保证未来由自己抽到；因此作为“对玩家无增益但有强代入感”的 0 分锚点技能。

## 与其他妖怪的关系

- 与白骨妖域地盘天然绑定。
- 与红孩儿、青狮精等消灭类效果形成差异：白骨精被消灭后会回到公共牌库。
- 与精细鬼、银角大王等公共牌库技能有弱联动。

## 羁绊

候选羁绊方向：白骨不散、三打白骨、死而复现、白骨岭山主。

当前羁绊未定稿。

## 互动

对手消灭白骨精时，会产生“她没有真的没了”的桌面反馈。白骨精未来可能再次出现，但不保证由原玩家获得。

## 连锁

- 被消灭时进入公共牌库并重洗，不进入弃牌堆。
- 不阻止白骨精被吹回手牌、绑走、收走等非消灭效果。

## 视觉同步状态

- 当前状态：已同步当前技能
- 同步依据：基础卡表当前卡面文案为“被消灭时，放回公共牌库并重洗。”

## 视觉形象设计

- 白骨、人形伪装、骨影或三重幻影。
- 表情应有“倒下但还会回来”的诡异感，不做血腥恐怖。
- 场景可为白骨岭、荒坡、骨影重组、牌库漩涡。
- 禁止画成单纯攻击型妖王；不要表现为主动复活到自己地盘。
