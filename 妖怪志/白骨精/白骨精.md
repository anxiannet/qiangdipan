## 背景

白骨精是白骨岭代表妖怪，当前按 3 档普通妖王 / 山主处理，为 3 星。

## 小传

白骨精核心不是正面硬碰，而是变化、伪装、白骨不散、死而复现。相比单纯查看手牌，她更适合通过“被消灭后不进弃牌堆”来表现三打三变、死后又回来的角色记忆点。

## 技能详细描述

规则效果：

```text
白骨精被消灭时，不进入弃牌堆，放回公共牌库并重洗。
```

卡面文案：

```text
被消灭时，放回公共牌库并重洗。
```

说明：该效果只在“被消灭”时触发。被吹回、被收走、加入手牌等非消灭效果，不触发该效果。

## 设计理由

白骨精最有记忆点的不是偷看，而是三次变化、被打倒后仍以另一种形式回来。技能不提供确定收益，但保留强代入感。

## 强度分析

| 项目 | 评价 |
|---|---|
| 主要作用对象 | 自身 / 公共牌库 |
| 动作 | 被消灭时回公共牌库并重洗 |
| 影响星数 | 0 |
| 是否直接改变资源 | 否 |
| 是否影响地盘控制 | 否 |
| 是否突破行动节奏 | 否 |
| 技能强度评分 | 0 |
| 世界观符合度评分 | 100 / 100 |
| 技能评级 | A |

评分理由：该效果不能让当前玩家获得任何确定收益，不能回手、不能复活、不能立刻上场，也不能保证未来由自己抽到；因此作为“对玩家无增益但有强代入感”的 0 分锚点技能。

## 与其他妖怪的关系

- 与白骨妖域地盘天然绑定。
- 与红孩儿、青狮精等消灭类效果形成差异：白骨精被消灭后会回到公共牌库。
- 与精细鬼、银角大王等公共牌库技能有弱联动。

## 羁绊

候选羁绊方向：白骨不散、三打白骨、死而复现、白骨岭山主。

当前羁绊未定稿。

## 互动

对手消灭白骨精时，会产生“她没有真的没了”的桌面反馈。白骨精未来可能再次出现，但不保证由原玩家获得。

## 连锁

- 被消灭时进入公共牌库并重洗，不进入弃牌堆。
- 不阻止白骨精被吹回手牌、绑走、收走等非消灭效果。
- 战斗中若白骨精受到伤害达到自身星数并被击败，按“被消灭”触发本效果。

## 视觉形象设计

- 主体定位：3星普通妖王 / 山主，白骨岭代表，诡异但不血腥。
- 主体轮廓：白骨、人形伪装、骨影或三重幻影，轮廓应优雅、阴冷、可识别。
- 核心动作：被打散的骨影重新卷入公共牌库旋涡，或白骨身影化作牌影重回牌堆。
- 核心表情：冷笑、从容、像“我还会回来”，不做恐怖受害表现。
- 核心场景：白骨岭、荒坡、骨影重组、公共牌库旋涡。
- 关键道具：骨影、白骨面具、破碎伪装、牌库旋涡。
- 关键特效：骨片化作牌影、公共牌库重洗光环、三重残影。
- 候选台词：“白骨不散。”
- 禁止元素：不要表现为主动复活到自己地盘；不要画成血腥恐怖；不要表现为攻击型妖王清场。

## 视觉差异要求

- 与青狮精区分：白骨精是被消灭后回公共牌库，青狮精是主动消灭守军。
- 与雾里云区分：白骨精回公共牌库是自身效果，不是重洗公共牌库的控牌技能。
- 与白骨地盘区分：白骨精是角色主体，不是纯白骨风景。

## 视觉安全区要求

白骨精脸部、三重残影和回牌库动作必须在中部安全区。牌库旋涡可位于中下区域但高于底部文案栏，不得被左上星数区或右侧名称栏遮挡。
