# 玉面狐狸

## 基础信息

| 项目 | 内容 |

| 世界观档位 | 3 档 |
| 星级 | 2 星 |

| 来源/归属 | 积雷山 / 摩云洞 |
| 技能状态 | 已审核 |

## 背景

玉面狐狸与牛魔王关系密切，适合做关系型、依附型、借势型技能。

## 小传

她不是顶级战斗妖王，牌面重点应是关系、洞府、狐媚、借牛魔王之势守地盘。

## 候选技能详细描述

规则效果：

```text
若场上有牛魔王，你可以选择 1 块你的地盘；直到你的下回合开始，牛魔王也视为驻守该地盘。
```

卡面文案：

```text
让牛魔王驻守你的地盘1回合。
```

说明：卡面文案为简洁表达；完整规则含义是牛魔王临时视为驻守你选择的 1 块己方地盘，持续到你的下回合开始。

## 设计理由

代入感来自玉面狐狸与牛魔王的关系。技能不是自己变强，而是借牛魔王的牌面防守。

## 强度分析

| 项目 | 评价 |
|---|---|
| 主要作用对象 | 己方地盘 / 牛魔王 |
| 受影响战力 | 约 3 |
| 前置条件 | 场上有牛魔王 |
| 技能强度评分 | 42 |
| 世界观符合度评分 | 80 / 100 |
| 技能评级 | B- |

评分理由：有防守价值，但条件较窄。降为 2 星后更符合关系型角色定位，但需要测试是否太依赖牛魔王。

## 与其他妖怪的关系

- 与牛魔王强关系。
- 与火云体系可产生家庭 / 洞府方向互动。

## 羁绊

候选羁绊方向：借牛魔王之势、摩云洞守势、狐媚借势。

当前羁绊未定稿。

## 互动

适合制造“牛魔王到底算不算在这里守着”的桌面讨论，但规则表达必须清楚。

## 连锁

可防止己方关键地盘被打空，不直接触发地盘回流。

## 视觉形象设计

- 妖狐洞主，华丽但不压过铁扇公主和牛魔王。
- 摩云洞、狐尾、珠饰、柔和但危险的表情。
