# 青狮精

## 基础信息

| 项目 | 内容 |
|---|---|
| 世界观档位 | 2 档 |
| 星级 | 3 星 |
| 战力 | 3 |
| 类型 | 强妖王 |
| 来源/归属 | 狮驼岭 |
| 技能状态 | 待审核 |

## 背景

青狮精是狮驼岭大妖，当前暂按 2 档强妖王处理，为 3 星。

## 小传

青狮精的核心味道是吞食、压制、狮驼岭大妖牌面。候选技能用“吃掉”表现这一点。

## 候选技能详细描述

候选规则效果：

```text
选择 1 块地盘，消灭其中 1 只 2 星以下守军。
```

卡面候选文案：

```text
吃掉1只2星以下守军。
```

## 设计理由

代入感来自吞食与压制。限制为 2 星以下，避免无条件吞掉 3 星顶级妖王。

## 强度分析

| 项目 | 评价 |
|---|---|
| 主要作用对象 | 2 星以下守军 |
| 受影响战力 | 1~2 |
| 牌区去向 | 弃牌堆 |
| 技能强度评分 | 62 |
| 世界观符合度评分 | 100 / 100 |
| 技能评级 | A- |

评分理由：能消灭 2 星以下守军，不能处理 3 星。世界观味道强，但作为 3 星候选技能强度中等。

## 与其他妖怪的关系

- 与大鹏精、小钻风同属狮驼体系。
- 可作为狮驼岭正面压制代表。

## 羁绊

候选羁绊方向：狮驼大妖、吞食小妖、强妖压阵。

## 互动

“吃掉”非常清楚，玩家容易记住，也有桌面笑点。

## 连锁

消灭最后守军时可能导致地盘无主；但不能处理 3 星，强度边界清楚。

## 视觉形象设计

- 巨大青狮妖王，厚重、凶猛、狮驼岭气质。
- 画面可表现张口吞食，但不做血腥表现。
- 3 星强妖王，应有压迫感但低于 1 档顶级妖王。
