# 青狮精

## 基础信息

| 项目 | 内容 |
|---|---|
| 世界观档位 | 2 档 |
| 星级 | 3 星 |
| 战力 | 3 |
| 类型 | 强妖王 |
| 来源/归属 | 狮驼岭 |
| 技能状态 | 已审核 |

## 背景

青狮精是狮驼岭大妖，当前暂按 2 档强妖王处理，为 3 星。

## 小传

青狮精的核心味道是吞食、压制、狮驼岭大妖牌面。当前技能用“吃掉”表现这一点，但不直接吞掉 3 星首领，避免与法宝级硬解混淆。

## 候选技能详细描述

候选规则效果：

```text
选择 1 块地盘，消灭其中最多 2 个 1 星守军，或消灭其中 1 个 2 星守军。
```

卡面候选文案：

```text
吞食小妖，吃掉最多2个1星守军，或1个2星守军。
```

## 设计理由

优先级 1：代入感来自吞食与压制。青狮精作为狮驼岭强妖王，应有明显“张口吞食、压住低星守军”的牌面。

优先级 2：好玩有趣。玩家可以选择吃掉 1 个 2 星守军，也可以选择同一地盘最多 2 个 1 星守军，形成目标选择。

优先级 3：强度补足。旧版“吃掉 1 个 2 星以下守军”在 3 星技能中偏弱；新版保留不能处理 3 星的边界，同时提高处理 1 星铺场的上限。

## 强度分析

| 项目 | 评价 |
|---|---|
| 主要作用对象 | 1 星守军 / 2 星守军 |
| 动作 | 消灭最多 2 个 1 星守军，或消灭 1 个 2 星守军 |
| 受影响战力 | 1~2 |
| 牌区去向 | 弃牌堆 |
| 是否直接改变资源 | 是，对手守军进入弃牌堆 |
| 是否影响地盘控制 | 可能间接影响 |
| 是否突破行动节奏 | 否 |
| 技能强度评分 | 70 |
| 世界观符合度评分 | 100 / 100 |
| 技能评级 | A- |

评分理由：新版青狮精仍不能直接处理 3 星守军，因此低于“消灭 1 个任意守军”的 80 分锚点；但它可以在处理 1 星铺场时一次吃掉最多 2 个 1 星守军，明显强于旧版单体 2 星以下处理，因此由 62 上调为 70。

## 与其他妖怪的关系

- 与大鹏精、小钻风同属狮驼体系。
- 可作为狮驼岭正面压制代表。
- 与红孩儿形成区分：红孩儿是 3 星技能锚点，专门清 1 块地盘内所有 1 星守军；青狮精在 1 星与 2 星之间做选择，能处理 2 星，但不能整地盘清空 1 星。

## 羁绊

候选羁绊方向：狮驼大妖、吞食小妖、强妖压阵。

当前羁绊未定稿。

## 互动

“吃掉”非常清楚，玩家容易记住，也有桌面笑点。新版会让对手更谨慎地把多个 1 星守军堆在同一地盘，同时也保留青狮精对 2 星守军的压制能力。

## 连锁

- 消灭最后守军时可能导致地盘无主。
- 不能处理 3 星守军，强度边界清楚。
- 若选择吃 1 星守军，最多只能选择同一块地盘中的 2 个 1 星守军。

## 视觉形象设计

- 巨大青狮妖王，厚重、凶猛、狮驼岭气质。
- 画面可表现张口吞食多个低星小妖或压制一个精英守军，但不做血腥表现。
- 3 星强妖王，应有压迫感但低于 1 档顶级妖王。
- 视觉重点是“吞食低星 / 中星守军”，不是法宝级秒杀 3 星首领。
