## 当前技能

规则效果：

```text
选择你控制的1块地盘，将辟火罩放在该地盘旁。该地盘及其中守军持续免疫其他玩家的一切攻击和效果，直到辟火罩被金刚琢取消，或该地盘变为无主。
```

卡面文案：

```text
保护1块地盘。
```

## 执行说明

- 打出时选择自己控制的1块地盘。
- 将辟火罩放在该地盘旁，表示持续生效。
- 受保护地盘不能被其他玩家发动抢地盘。
- 其他玩家的妖怪技能和法宝效果不能选择或影响该地盘。
- 其他玩家不能选择、消灭、吹回、收走、召回、交换、移动或临时控制该地盘中的守军。
- 其他玩家不能通过范围效果间接影响该地盘及其中守军。
- 保护不会因回合结束而消失。
- 使用者自己的效果仍可影响该地盘及其中守军。
- 金刚琢可以在辟火罩生效期间取消辟火罩。
- 辟火罩被金刚琢取消后，辟火罩与金刚琢均进入弃牌堆。
- 若受保护地盘变为无主，辟火罩立即失效并进入弃牌堆。
- 辟火罩只保护指定的1块地盘，不保护使用者控制的其他地盘。

## “保护”的正式含义

“保护1块地盘”表示：

```text
该地盘及其中守军免疫其他玩家的一切攻击、妖怪技能和法宝效果。
```

保护范围包括：

- 抢地盘攻击
- 单体妖怪技能
- 多目标妖怪技能
- 单体法宝效果
- 范围法宝效果
- 消灭
- 吹回
- 收走
- 移动
- 控制权变化

保护不包括：

- 使用者主动召回或移动自己的守军
- 使用者自己的卡牌效果
- 地盘已经没有守军后触发的无主回流
- 金刚琢对辟火罩本身的取消

## 设计理由

卡面只保留最短文案“保护1块地盘。”，详细防护范围由本文件统一解释。

辟火罩属于持续放置型唯一法宝。全面免疫能够使其真正形成一块稳定堡垒，同时保留金刚琢这一明确破解方式。

## 强度分析

| 项目 | 评价 |
|---|---|
| 保护对象 | 指定的1块地盘及其中守军 |
| 持续时间 | 直到被金刚琢取消或地盘变为无主 |
| 防护范围 | 其他玩家的一切攻击、妖怪技能与法宝效果 |
| 是否直接增加资源 | 否 |
| 是否可被反制 | 是，金刚琢可取消 |
| 当前状态 | 已确认，待实体试玩验证强度 |

## 与其他卡牌的关系

- 金刚琢是辟火罩的明确破解手段。
- 幌金绳、紫金红葫芦、芭蕉扇及妖怪处理技能不能影响受保护地盘中的守军。
- 黄风怪等多目标技能不能选择受保护地盘中的守军作为目标。
- 红孩儿等范围技能不能影响受保护地盘。
- 辟火罩不保护其他地盘，也不取消已经完成结算的效果。

## 视觉要求

- 核心画面：护罩完整覆盖单独1块地盘及其中守军。
- 外部攻击、风、火焰、绳索或法宝光效全部被挡在罩外。
- 插画和图标不得表现同时保护多块地盘。
- 卡牌在桌面上需要能清楚放置于受保护地盘旁。
