## 当前技能

规则效果：

```text
选择你控制的1块地盘，将辟火罩放在该地盘旁。该地盘及其中守军持续免疫其他玩家的一切攻击和效果，直到辟火罩被金刚琢取消，或该地盘变为无主。
```

卡面文案：

```text
保护1块地盘。
```

## 执行说明

- 打出时选择自己控制的1块地盘。
- 将辟火罩放在该地盘旁，表示持续生效。
- 受保护地盘不能被其他玩家发动抢地盘。
- 其他玩家的妖怪技能和法宝效果不能选择、消灭、吹回、收走或移动该地盘中的守军。
- 保护不会因回合结束而消失。
- 金刚琢可以在辟火罩生效期间取消辟火罩。
- 辟火罩被金刚琢取消后，辟火罩与金刚琢均进入弃牌堆。
- 若受保护地盘变为无主，辟火罩立即失效并进入弃牌堆。
- 辟火罩只保护指定的1块地盘，不保护使用者控制的其他地盘。

## 设计理由

卡面只保留最短文案“保护1块地盘。”，持续时间、防护范围、金刚琢破解和无主失效等细节统一由规则说明承担，避免卡面文字过长。

## 强度分析

| 项目 | 评价 |
|---|---|
| 保护对象 | 指定的1块地盘及其中守军 |
| 持续时间 | 直到被金刚琢取消或地盘变为无主 |
| 防护范围 | 抢地盘、妖怪技能、法宝效果 |
| 是否直接增加资源 | 否 |
| 是否可被反制 | 是，金刚琢可取消 |
| 当前状态 | 待复测 |

## 与其他卡牌的关系

- 金刚琢可以在辟火罩生效期间将其破解。
- 辟火罩生效期间，幌金绳、紫金红葫芦及妖怪处理技能不能影响受保护地盘中的守军。
- 辟火罩不保护其他地盘，也不取消已经完成结算的效果。

## 视觉要求

- 核心画面：护罩覆盖单独1块地盘及其中守军。
- 外部攻击、风、火焰或法宝光效被挡在罩外。
- 插画和图标不得表现同时保护多块地盘。
- 卡牌在桌面上需要能清楚放置于受保护地盘旁。
