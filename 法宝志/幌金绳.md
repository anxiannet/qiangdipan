# 幌金绳

## 基础信息

| 项目 | 内容 |
|---|---|
| 类型 | 法宝 |
| 数量 | 1 |
| 核心功能 | 抓 |
| 技能状态 | 已审核 |

## 背景

幌金绳是平顶山莲花洞体系代表法宝之一，核心印象是直接绑住目标、强行收走。

## 小传

幌金绳不需要喊名、不需要对方答应。它与紫金红葫芦形成对比：紫金红葫芦更有桌面互动和名场面，幌金绳则是更稳定、更强的单体抓取法宝。

## 技能详细描述

规则效果：

```text
选择 1 个守军，将其加入你的手牌。
```

卡面文案：

```text
选择1个守军，加入你的手牌。
```

说明：被幌金绳抓走的守军离开原地盘，进入使用者手牌。该守军不是被消灭，不进入弃牌堆。

## 设计理由

优先级 1：代入感来自“绳子直接绑走”。

优先级 2：好玩有趣。它能制造关键守军被强行带走的强记忆点。

优先级 3：强度与平衡性。它可以处理任意星级守军，并把目标加入你的手牌，资源差很大，因此必须作为高强度法宝处理。

## 审核结论

已审核，保留。

审核理由：

- 与原著法宝定位贴合。
- 与紫金红葫芦形成清晰梯度：葫芦需要对方答应，幌金绳不需要。
- 与芭蕉扇形成差异：幌金绳是单体高质量夺取，芭蕉扇是整地盘回手。
- 强度高，但数量只有 1 张，且可被金刚琢反制。

## 强度分析

| 项目 | 评价 |
|---|---|
| 主要作用对象 | 任意 1 个守军 |
| 受影响战力 | 1~3 |
| 牌区去向 | 加入你的手牌 |
| 是否直接改变资源 | 是 |
| 是否影响地盘控制 | 可能间接影响 |
| 是否突破行动节奏 | 否 |
| 技能强度评分 | 92 |
| 世界观符合度评分 | 100 / 100 |
| 技能评级 | A |

评分理由：可处理 3 星守军，并把目标加入你的手牌，资源差高于“消灭1个任意守军”的 80 分锚点；但它只处理单体，不如芭蕉扇整地盘影响范围大，因此低于 100 分锚点。

## 与其他卡牌的关系

- 强于紫金红葫芦的稳定性，但缺少喊名答应的互动乐趣。
- 可被金刚琢取消。
- 与金角大王、银角大王、紫金红葫芦同属莲花洞 / 平顶山法宝体系。

## 羁绊

候选羁绊方向：莲花洞五宝、金银兄弟、绑妖收阵。

当前羁绊未定稿。

## 互动

幌金绳适合制造“关键守军被绑走”的桌面冲突。对手会更重视金刚琢，或者避免把唯一关键守军单独留在地盘上。

## 连锁

- 若目标是某块地盘最后 1 个守军，该地盘可能因失去全部守军而触发地盘回流。
- 被幌金绳抓走的守军不是被消灭，不触发“被消灭时”效果。
- 抓走到手牌后，该牌之后可按正常招兵规则重新打出。

## 视觉形象设计

- 金色绳索应是绝对视觉中心。
- 画面表现绳索缠住守军、拖向使用者手中。
- 特效要像法宝束缚，不要画成普通鞭子攻击。
- 目标守军可以有挣扎感，但不要表现血腥伤害。
