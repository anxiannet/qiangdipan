## 背景

紫金红葫芦是平顶山莲花洞体系代表法宝，核心名场面是“我叫你一声，你敢答应吗”。

在《夕妖：抢地盘》标准版中，紫金红葫芦不是稳定去除牌，而是承担喊名应声体系的强互动法宝。

## 当前技能

规则效果：

```text
喊一名玩家名字；对方答应后，收走其1个守军到你的手牌。
```

卡面文案：

```text
喊一名玩家名字；对方答应后，收走其1个守军到你的手牌。
```

## 执行说明

- 使用者必须先喊一名其他玩家的名字或该局约定使用的称呼。
- 只有该玩家明确答应后，才可以选择并收走其控制的1个守军。
- 被点名玩家不答应时，不选择守军，本法宝没有规则收益。
- 只能选择被点名玩家控制的守军。
- 被收走的守军加入使用者手牌。
- 收走不是消灭，不触发“被消灭时”效果。
- 若目标是某块地盘最后1个守军，该地盘变为无主并按地盘回流规则处理。
- 紫金红葫芦可以被金刚琢取消。
- 辟火罩保护的地盘及其中守军不能成为紫金红葫芦的目标。

## 设计决定

紫金红葫芦与幌金绳不追求相同稳定性或相同强度。

正式定位：

```text
紫金红葫芦：高趣味、低稳定的互动法宝。
幌金绳：低条件、高稳定的强制抓取法宝。
```

接受紫金红葫芦在纯规则强度上明显弱于幌金绳。该差异是有意设计，不视为待修复的平衡错误。

## 设计理由

- 代入感极强，保留原著“喊名应声”的名场面。
- 能制造真实桌面互动、误答和笑点。
- 成功时收益接近幌金绳，但对方可以拒绝，因此稳定性显著更低。
- 强度差异换取独特互动体验，符合欢乐聚会卡牌定位。

## 强度分析

| 项目 | 评价 |
|---|---|
| 主要作用对象 | 被点名玩家及其1个守军 |
| 成功条件 | 对方明确答应 |
| 动作 | 收走守军到使用者手牌 |
| 失败结果 | 无收益 |
| 是否直接改变资源 | 成功时是 |
| 是否影响地盘控制 | 成功时可能间接影响 |
| 稳定性 | 低 |
| 趣味性 | 高 |
| 当前状态 | 已确认保留 |

## 与其他卡牌的关系

- 与幌金绳形成“趣味互动／稳定控制”的明确对比。
- 与急如火、快如风共享“喊人并等待回应”的桌面流程。
- 可被金刚琢取消。
- 不能影响辟火罩保护中的守军。

## 视觉要求

- 葫芦本体必须是绝对视觉中心。
- 明确表现喊名、等待回应和答应后吸走守军的过程。
- 不得画成无条件直接收走守军。
- 不得弱化“对方答应后才生效”的戏剧感。
