# 紫金红葫芦

## 基础信息

| 项目 | 内容 |
|---|---|
| 类型 | 法宝 |
| 数量 | 1 |
| 核心功能 | 收 |
| 技能状态 | 已审核 |

## 背景

紫金红葫芦是平顶山莲花洞体系代表法宝，核心名场面是“我叫你一声，你敢答应吗”。

## 小传

紫金红葫芦不应只是普通的去除牌。它的规则文本需要保留“叫玩家名字、对方答应”的仪式感，让玩家在实体桌面上产生明确的西游名场面代入。

## 技能详细描述

规则效果：

```text
喊出一个玩家的名字。该玩家答应后，你可以收走其1个守军，加入你的手牌。
```

卡面文案：

```text
叫名收妖，喊一名玩家名字；对方答应后，收走其1个守军到你的手牌。
```

## 设计理由

优先级 1：代入感极强。“喊玩家名字，对方答应”比喊守军名称更接近原著名场面，也更适合实体桌面互动。

优先级 2：好玩有趣。使用者需要真的喊玩家名字，对方答应后才结算，能自然形成“我叫你一声你敢答应吗”的欢乐互动。

优先级 3：强度清晰。规则效果从“弃掉1个守军”升级为“收走1个守军到你的手牌”，产生明确资源差；但它仍然是单体处理，不清空整块地盘。

## 强度分析

| 项目 | 评价 |
|---|---|
| 主要作用对象 | 一名玩家 / 该玩家的1个守军 |
| 动作 | 对方答应后，收走1个守军到你的手牌 |
| 受影响战力 | 1~3 |
| 是否直接改变资源 | 是，对手失去1个守军，你获得1张牌 |
| 是否影响地盘控制 | 可能间接影响 |
| 是否突破行动节奏 | 否 |
| 技能强度评分 | 92 |
| 世界观符合度评分 | 100 / 100 |
| 技能评级 | A |

评分理由：紫金红葫芦可以在对方答应后收走其1个守军并加入你的手牌，形成“对手失去场上战力 + 你获得手牌资源”的双向资源差。强度与幌金绳同级，但紫金红葫芦额外保留叫名答应的仪式条件，因此当前按 92 处理。

## 与其他卡牌的关系

- 与金角大王、银角大王、精细鬼、伶俐虫属于莲花洞体系。
- 与幌金绳形成同级对比：紫金红葫芦通过叫名答应收走守军到手牌，幌金绳直接绑走守军到手牌。
- 与芭蕉扇形成对比：紫金红葫芦是单体夺取，芭蕉扇是整地盘吹回。
- 与金刚琢形成对比：紫金红葫芦处理守军，金刚琢处理法宝效果。

## 互动

- 使用时需要喊出一个玩家的名字，增强桌面仪式感。
- 该玩家答应后，使用者可以收走该玩家的1个守军到自己的手牌。
- 若后续测试发现玩家故意不答应导致卡牌失效，应在规则中补充“被点名玩家必须回应”的桌面约定。

## 连锁

- 若目标是某块地盘最后1个守军，该地盘可能因失去全部守军而触发地盘回流。
- 收走到手牌属于离场并改变牌区，不触发“被消灭时”效果，除非后续规则另行定义。

## 视觉形象设计

- 法宝主体应是紫红色葫芦，带金色纹饰、老君法宝质感。
- 葫芦口可以有吸入旋涡、金色符文、名字声浪或妖气被吸入的效果。
- 画面重点是“叫名答应后被收走”，不是普通爆炸或直接攻击。
- 不要把金角大王画成手持葫芦；当前角色设定中，金角大王技能是调山点地，紫金红葫芦由法宝卡单独承担。
