# 紫金红葫芦

## 基础信息

| 项目 | 内容 |
|---|---|
| 类型 | 法宝 |
| 数量 | 1 |
| 核心功能 | 收 |
| 技能状态 | 已审核 |

## 背景

紫金红葫芦是平顶山莲花洞体系代表法宝，核心名场面是“叫你一声你敢答应吗”。

## 小传

紫金红葫芦不应只是普通的去除牌。它的规则文本需要保留“叫名”的仪式感，让玩家在实体桌面上产生明确的西游名场面代入。

## 技能详细描述

规则效果：

```text
选择 1 个守军，喊出其名称，然后将其收走并弃掉。
```

卡面文案：

```text
叫名收妖，喊出1个守军名称，收走并弃掉。
```

## 设计理由

优先级 1：代入感极强。“喊出名称”是紫金红葫芦区别于普通消灭法宝的核心仪式。

优先级 2：好玩有趣。实体桌面上玩家需要把目标名字喊出来，会自然形成“我叫你一声你敢答应吗”的互动感。

优先级 3：强度清晰。规则效果仍然是单体收走并弃掉，不加入自己手牌，不清空整块地盘，低于芭蕉扇和幌金绳的资源收益。

## 强度分析

| 项目 | 评价 |
|---|---|
| 主要作用对象 | 1 个守军 |
| 动作 | 收走并弃掉 |
| 受影响战力 | 1~3 |
| 是否直接改变资源 | 是，对手失去 1 个守军 |
| 是否影响地盘控制 | 可能间接影响 |
| 是否突破行动节奏 | 否 |
| 技能强度评分 | 82 |
| 世界观符合度评分 | 100 / 100 |
| 技能评级 | A |

评分理由：紫金红葫芦可以处理任意 1 个守军，并将其弃掉。它能处理 3 星守军，形成明确场面收益；但不会把目标加入自己手牌，也不会直接清空整块地盘，因此低于幌金绳与芭蕉扇。

## 与其他卡牌的关系

- 与金角大王、银角大王、精细鬼、伶俐虫属于莲花洞体系。
- 与幌金绳形成对比：紫金红葫芦是收走并弃掉，幌金绳是绑走并加入你的手牌。
- 与芭蕉扇形成对比：紫金红葫芦是单体处理，芭蕉扇是整地盘吹回。
- 与金刚琢形成对比：紫金红葫芦处理守军，金刚琢处理法宝效果。

## 互动

- 使用时需要喊出目标守军名称，增强桌面仪式感。
- 被喊名的守军会被收走并弃掉。
- 若后续测试觉得口头仪式过长，可保留“叫名收妖”作为技能名，规则正文简化为“收走1个守军，并弃掉”。

## 连锁

- 若目标是某块地盘最后 1 个守军，该地盘可能因失去全部守军而触发地盘回流。
- 收走并弃掉属于离场处理，不触发“被消灭时”效果，除非后续规则另行定义。

## 视觉形象设计

- 法宝主体应是紫红色葫芦，带金色纹饰、老君法宝质感。
- 葫芦口可以有吸入旋涡、金色符文、名字声浪或妖气被吸入的效果。
- 画面重点是“叫名后被收走”，不是普通爆炸或直接攻击。
- 不要把金角大王画成手持葫芦；当前角色设定中，金角大王技能是调山点地，紫金红葫芦由法宝卡单独承担。
