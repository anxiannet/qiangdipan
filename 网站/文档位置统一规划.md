# 《夕妖：抢地盘》页面资料位置统一规划

## 文件定位

本文件用于统一规划项目资料在仓库中的归属位置，以及这些资料在网站具体页面中的展示位置。

本文件只规划仓库来源、页面归属、展示路径和读取边界。

本文件不迁移文件，不改写规则，不新增卡牌，不维护第二份卡表。

---

## 一、核心原则

```text
1. 仓库文件按生产用途归位。
2. 网站页面按业务模块归位。
3. 不建立前台 /docs。
4. 不建立前台 /library。
5. 不单独建立前端 Markdown 内容文件夹。
6. 不把资料堆成文件列表。
7. 卡牌资料进入 /cards。
8. 规则资料进入 /rules。
9. 美术资料进入 /art。
10. 印刷生产资料进入 /print。
11. 众筹运营资料进入 /crowdfunding。
12. 网站开发资料进入 /devlog/website。
13. 展示不等于成为唯一来源。
```

---

## 二、页面资料归位总表

```text
/cards          卡牌图鉴、单卡卡志、备选卡表、卡牌调整历史

```

## 十一、当前结论

网站内容不做单独资料中心。

所有资料分散进入对应业务页面：

```text
卡牌进 /cards
规则进 /rules
技能进 /rules
美术进 /art
印刷进 /print
众筹运营进 /crowdfunding
网站开发进 /devlog
```

前端不建立 `/docs`、不建立 `/library`、不建立 Markdown 内容文件夹。
