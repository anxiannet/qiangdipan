# 《夕妖：抢地盘》官网 UI 组件规范

## 文件定位

本文件用于把官网视觉锚点图转化为可执行的 UI 组件规范。

本文件只规定官网 UI 的视觉组件、尺寸、状态、响应式规则和禁止自由发挥项。

本文件不修改规则，不新增卡牌，不维护第二份卡表，不替代现有规则文件。

关联文件：

```text
网站/正式官网首页设计稿.md
网站/完整网站架构规划.md
网站/网站技术栈方案.md
网站/网站部署状态.md
网站/网站目录位置约定.md
规范流程/视觉总规范.md
规范流程/UI规范.md
卡牌成品/印刷说明.md
```

当前官网风格：

```text
明亮蓝金西游妖怪桌游官网风
```

角色风格：

```text
非Q版东方神话动画电影风妖怪角色
```

正式网站地址：

```text
https://qdp.weijie.sg
```

## 一、总原则

官网 UI 只服务三个目标：

```text
1. 展示实体卡牌产品。
2. 解释当前玩法与进度。
3. 承接试玩与众筹预热。
```

官网 UI 不是游戏战斗界面，不是后台，不是商城，不是充值页。

页面必须遵守：

```text
移动端优先
真实印刷资源优先
蓝金西游桌游风
非Q版动画电影风角色
不新增规则
不新增卡牌数据
```

---

## 二、设计锚点说明

当前 UI 精灵图可作为以下内容的视觉锚点：

```text
1. 蓝金主色体系。
2. 金属描边与中式云纹角花。
3. 红色主按钮与蓝色次按钮。
4. 深蓝纹理面板。
5. 金边标题条。
6. 信息卡、统计卡、进度条、标签条。
7. 移动端长页模块结构。
```

该精灵图不能作为：

```text
1. 最终卡牌内容来源。
2. 最终规则内容来源。
3. 最终角色设定来源。
4. 第二套卡牌数据库。
5. 可自由改文案的依据。
```

正式卡牌、包装、印刷成果必须来自：

```text
web/public/assets/print/v1/manifest.json
web/public/assets/print/v1/cards/
web/public/assets/print/v1/box/
web/public/assets/print/v1/docs/
```

## 四、字号 Token

移动端基准宽度：`390px`。

```text
品牌 Logo 字号：24px ~ 28px
Hero 主标题：34px ~ 40px
一级区块标题：26px ~ 30px
二级标题：20px ~ 22px
卡片标题：17px ~ 19px
正文：15px ~ 16px
辅助说明：13px ~ 14px
小标签：12px ~ 13px
按钮文字：16px ~ 18px
```

桌面端可放大，但不得改变层级关系。

```text
桌面 Hero 主标题不超过 72px。
桌面区块标题不超过 42px。
正文不低于 16px。
```

## 六、圆角、边框、阴影

```text
大面板圆角：24px
普通卡片圆角：18px
小标签圆角：999px
按钮圆角：14px 或 999px
边框厚度：1px ~ 2px
主视觉金边：2px ~ 3px
```

阴影：

```text
面板阴影：深色投影，不使用浅灰投影。
按钮阴影：轻微下压 + 金色内发光。
卡牌展示阴影：深色厚投影，突出实体卡牌感。
```

禁止：

```text
纯平无边框
玻璃拟态毛玻璃
大面积霓虹发光
现代网页阴影卡片
```

## 七、导航组件

### 1. 移动端导航

结构：

```text
左：品牌 Logo
右：菜单按钮
```

菜单按钮：

```text
方形或圆角方形
深蓝底
金色描边
三横线图标
最小点击区域：44px × 44px
```

移动端首屏不展示完整横向导航。

### 2. 桌面端导航

结构：

```text
左：品牌 Logo
中：导航项
右：立即试玩按钮
```

导航项：

```text
首页 / 卡牌 / 规则 / 试玩 / 印刷成果 / 众筹预热
```

导航项不能新增商城、会员、充值、排行榜。

## 八、按钮组件

### 1. 主按钮

用途：

```text
查看第一版印刷成果
关注试玩进度
```

样式：

```text
背景：红旗朱砂 #B93525 或主按钮暗红 #8F241B
文字：亮金高光或正文米白
边框：妖火金 2px
高度：48px
圆角：14px 或 999px
```

状态：

```text
默认：红底金边。
按下：整体下沉 1px，亮度降低 8%。
悬停：金边轻微发光，仅桌面端。
禁用：透明度 50%，不发光。
加载：文字右侧可出现小型金色旋转点。
```

### 2. 次按钮

用途：

```text
了解怎么玩
查看众筹预热
查看资源清单
```

样式：

```text
背景：面板蓝 #12345A
文字：亮金高光或正文米白
边框：妖火金 2px
高度：48px
圆角：14px 或 999px
```

### 3. 禁止按钮风格

```text
现代纯蓝 SaaS 按钮
灰色 Bootstrap 按钮
白底黑字按钮
霓虹发光按钮
扁平无边框按钮
```

## 十、卖点卡组件

用途：

```text
西游妖怪题材
轻策略，强互动
实体卡牌优先
```

移动端：

```text
纵向排列
一行一张卡
卡片内可有一个图标 + 标题 + 两行正文
正文不超过 2 行
```

桌面端：

```text
三列排列
高度保持一致
```

样式：

```text
深蓝面板
金边
左侧圆形金边图标
标题金色
正文米白
```

禁止把卖点卡做成白底普通卡片。

## 十一、印刷成果组件

用途：展示第一版真实印刷资源。

资源来源：

```text
/assets/print/v1/manifest.json
```

移动端布局：

```text
1. 一个大图预览。
2. 一个资源统计卡。
3. 横向滑动缩略图。
4. 查看资源清单按钮。
```

桌面端布局：

```text
左侧大图预览。
右侧资源统计卡。
下方缩略图列表。
```

统计文案：

```text
卡牌资源：42 个
包装资源：4 个
文档资源：3 个
其他资源：0 个
合计：49 个
```

后续资源数量变化时，应以 manifest 自动统计为准。

禁止：

```text
使用虚构卡牌图。
使用随机外部图。
重绘卡牌内容。
替换真实印刷资源。
```

## 十二、玩法步骤组件

固定标题：

```text
怎么玩？一句话：抢下同一妖域的 3 块地盘
```

固定三步：

```text
1. 派妖怪
2. 抢地盘
3. 成妖王
```

固定规则表达：

```text
控制同一妖域 3 块地盘，立即获胜。
```

移动端：

```text
三张步骤卡纵向排列。
步骤数字使用金边圆章。
步骤之间可用小箭头，但不能挤压文字。
```

桌面端：

```text
三张步骤卡横向排列。
中间使用金色箭头连接。
```

禁止出现：

```text
胜利点
积分最高者获胜
累计积分称霸
占最多地盘获胜
```

## 十三、卡牌类型组件

固定四类：

```text
妖怪牌 54 张
法宝牌 4 张
地盘牌 12 张
指南卡 2 张双面指南卡
```

移动端：

```text
两列或单列。
每项包含图片/图标 + 类型 + 数量 + 一句说明。
```

桌面端：

```text
四列排列。
```

数据来源参考：

```text
卡牌成品/印刷说明.md
规则/V1.2-基础卡表.md
```

禁止新增类别、删减类别、改变数量。

## 十七、角色与主视觉

角色风格必须是：

```text
非Q版东方神话动画电影风妖怪角色
```

主视觉可包含：

```text
山寨
山门
妖旗
蓝天云雾
山路
动画电影风妖怪角色
真实印刷卡牌
包装盒
```

主视觉不能：

```text
使用Q版二头身角色
使用幼态萌系角色
使用真人写实CG角色
使用恐怖怪物
使用不在项目内的主角作为核心卡牌
让角色压过真实卡牌产品
```

原则：

```text
角色负责氛围。
真实卡牌和包装负责产品证明。
```

## 十八、响应式规则

### 1. 移动端优先

```text
390px 宽度下必须完整可读。
首屏不依赖横向滚动。
正文不小于 15px。
按钮不低于 48px。
卡牌展示图不被压到不可辨认。
```

### 2. 桌面端展开

```text
桌面端只做横向展开。
不改变区块顺序。
不新增大段文案。
不新增新功能入口。
Hero 可左右分栏。
印刷成果可左右分栏。
卖点卡、卡牌类型可多列。
```

## 二十、开发验收视觉清单

完成后需要检查：

```text
1. 移动端 390px 下首屏可读。
2. 页面整体为明亮蓝金西游桌游风。
3. 妖怪角色不是Q版。
4. 主按钮为红色金边，次按钮为蓝色金边。
5. 面板为深蓝纹理感，不能白底。
6. 页面出现第一版印刷成果。
7. 印刷成果来自 manifest.json。
8. 未出现虚构卡牌数值。
9. 未出现“胜利点”“积分最高者获胜”。
10. 未新增规则或卡牌数据。
11. 页面不像后台、SaaS、暗黑网游或页游充值页。
12. 桌面端只横向展开，不改变移动端信息顺序。
```

## 二十一、当前结论

官网 UI 组件规范已确定为：

```text
移动端优先
明亮蓝金西游桌游风
金边 UI
红色主按钮 / 蓝色次按钮
深蓝纹理面板
非Q版东方神话动画电影风角色
真实印刷资源优先
```

后续首页实现必须按照本规范还原，不再由实现阶段决定视觉方向。
