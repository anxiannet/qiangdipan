# 《夕妖：抢地盘》官网 UI 组件规范

## 文件定位

本文件用于把官网视觉锚点图转化为可执行的 UI 组件规范。

本文件只规定官网 UI 的视觉组件、尺寸、状态、响应式规则和禁止自由发挥项。

本文件不修改规则，不新增卡牌，不维护第二份卡表，不替代现有规则文件。

关联文件：

```text
网站/正式官网首页设计稿.md
网站/正式官网首页内容设计.md
网站/官网视觉美术风格设计.md
网站/完整网站架构规划.md
网站/网站技术栈方案.md
网站/网站部署状态.md
网站/网站目录位置约定.md
规范流程/视觉总规范.md
规范流程/UI规范.md
```

说明：`卡牌成品/印刷说明.md` 仅供生产交付使用，不作为官网 UI 组件规范来源，不进入官网设计读取范围。

当前官网风格：

```text
明亮蓝金西游妖怪桌游官网风
```

角色风格：

```text
非Q版东方神话动画电影风妖怪角色
```

正式网站地址：

```text
https://qdp.weijie.sg
```

## 一、总原则

官网 UI 只服务三个目标：

```text
1. 展示实体卡牌产品。
2. 解释当前玩法与进度。
3. 承接试玩与众筹预热。
```

官网 UI 不是游戏战斗界面，不是后台，不是商城，不是充值页。

页面必须遵守：

```text
移动端优先
真实印刷资源优先
蓝金西游桌游风
非Q版动画电影风角色
不新增规则
不新增卡牌数据
```

## 四、圆角、边框、阴影

```text
大面板圆角：24px

小标签圆角：999px
按钮圆角：14px 或 999px
边框厚度：1px ~ 2px
主视觉金边：2px ~ 3px
```

阴影：

```text
面板阴影：深色投影，不使用浅灰投影。
按钮阴影：轻微下压 + 金色内发光。
卡牌展示阴影：深色厚投影，突出实体卡牌感。
```

## 五、组件规范

### 1. 导航组件

移动端：

```text
左：品牌 Logo
右：菜单按钮
菜单按钮最小点击区域：44px × 44px
```

桌面端：

```text
左：品牌 Logo
中：导航项
右：立即试玩按钮
```

导航项固定：

```text
首页 / 卡牌 / 规则 / 试玩 / 印刷成果 / 众筹预热
```

### 2. 按钮组件

主按钮：

```text
用途：查看第一版印刷成果 / 关注试玩进度
背景：红旗朱砂 #B93525 或主按钮暗红 #8F241B
文字：亮金高光或正文米白
边框：妖火金 2px
高度：48px
圆角：14px 或 999px
```

次按钮：

```text
用途：了解怎么玩 / 查看众筹预热 / 查看资源清单
背景：面板蓝 #12345A
文字：亮金高光或正文米白
边框：妖火金 2px
高度：48px
圆角：14px 或 999px
```

状态：

```text
默认：清晰高对比。
按下：整体下沉 1px，亮度降低 8%。
悬停：金边轻微发光，仅桌面端。
禁用：透明度 50%，不发光。
加载：文字右侧可出现小型金色旋转点。
```

### 3. 标题条组件

用于：

```text
第一版印刷成果
怎么玩？
一盒里有什么？
当前进度
```

样式：

```text
深蓝底纹
金色描边
左右小型云纹或金色分隔符
标题为金色
移动端高度：40px ~ 52px
桌面端高度：48px ~ 60px
```

### 4. 卖点卡组件

移动端：纵向排列，一行一张卡。
桌面端：三列排列，高度保持一致。

样式：

```text
深蓝面板
金边
左侧圆形金边图标
标题金色
正文米白
```

### 5. 印刷成果组件

资源来源：

```text
/assets/print/v1/manifest.json
```

移动端布局：

```text
一个大图预览
一个资源统计卡
横向滑动缩略图
查看资源清单按钮
```

桌面端布局：

```text
左侧大图预览
右侧资源统计卡
下方缩略图列表
```

### 6. 玩法步骤组件

固定标题：

```text
怎么玩？一句话：抢下同一妖域的 3 块地盘
```

固定三步：

```text
1. 派妖怪
2. 抢地盘
3. 成妖王
```

固定规则表达：

```text
控制同一妖域 3 块地盘，立即获胜。
```

移动端：三张步骤卡纵向排列。
桌面端：三张步骤卡横向排列，中间用金色箭头连接。

### 7. 卡牌类型组件

固定四类：

```text
妖怪牌 54 张
法宝牌 4 张
地盘牌 12 张
指南卡 2 张双面指南卡
```

移动端：两列或单列。
桌面端：四列排列。

### 8. 当前进度组件

固定进度项：

```text
规则 V1.2 已整理
第一版印刷文件已准备
包装盒测试推进中
网站 qdp.weijie.sg 已部署
PixiJS 8 游戏客户端规划中
众筹预热与试玩反馈准备中
```

状态类型：

```text
已完成
进行中
准备中
```

移动端不要做复杂任务看板。

### 9. CTA 组件

固定标题：

```text
想先试一局？
```

按钮：

```text
关注试玩进度
查看众筹预热
```

当前不应让访问者误以为完整线上游戏已经开放。

## 六、角色与主视觉

角色风格必须是：

```text
非Q版东方神话动画电影风妖怪角色
```

主视觉可包含：

```text
山寨
山门
妖旗
蓝天云雾
山路
动画电影风妖怪角色
真实印刷卡牌
包装盒
```

原则：

```text
角色负责氛围。
真实卡牌和包装负责产品证明。
```

## 七、响应式规则

移动端优先：

```text
390px 宽度下必须完整可读。
首屏不依赖横向滚动。
正文不小于 15px。
按钮不低于 48px。
卡牌展示图不被压到不可辨认。
```

桌面端展开：

```text
桌面端只做横向展开。
不改变区块顺序。
不新增大段文案。
不新增新功能入口。
Hero 可左右分栏。
印刷成果可左右分栏。
卖点卡、卡牌类型可多列。
```

## 八、禁止自由发挥清单

禁止改风格：

```text
暗黑网游风
SaaS 白底官网
科技蓝紫风
Q版儿童风
日式二次元卡牌风
写实恐怖怪物风
页游充值风
后台管理风
```

禁止改颜色体系：

```text
不得大面积白色。
不得荧光绿。
不得赛博紫。
不得现代纯蓝按钮。
不得灰白卡片。
不得玻璃拟态。
```

禁止改角色风格：

```text
不得二头身。
不得大头小身。
不得萌宠小妖。
不得儿童绘本角色。
不得真人写实CG。
不得恐怖怪物。
不得血腥暗黑。
```

禁止改规则文案：

```text
积分最高者获胜
胜利点
占领最多地盘获胜
7星
6星
攻击力/生命值新体系
新卡名
新法宝
新阵营
```

固定玩法表达：

```text
派妖怪
抢地盘
控制同一妖域 3 块地盘，立即获胜
```

## 九、视觉验收清单

完成后需要检查：

```text
1. 移动端 390px 下首屏可读。
2. 页面整体为明亮蓝金西游桌游风。
3. 妖怪角色不是Q版。
4. 主按钮为红色金边，次按钮为蓝色金边。
5. 面板为深蓝纹理感，不能白底。
6. 页面出现第一版印刷成果。
7. 印刷成果来自 manifest.json。
8. 未出现虚构卡牌数值。
9. 未出现“胜利点”“积分最高者获胜”。
10. 未新增规则或卡牌数据。
11. 页面不像后台、SaaS、暗黑网游或页游充值页。
12. 桌面端只横向展开，不改变移动端信息顺序。
```

## 十、当前结论

官网 UI 组件规范已确定为：

```text
移动端优先
明亮蓝金西游桌游风
金边 UI
红色主按钮 / 蓝色次按钮
深蓝纹理面板
非Q版东方神话动画电影风角色
真实印刷资源优先
```

后续首页实现必须按照本规范还原，不再由实现阶段决定视觉方向。
