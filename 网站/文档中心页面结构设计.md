# 《夕妖：抢地盘》资料馆页面结构设计

## 文件定位

本文件只设计网站“资料馆”的页面结构、页面分类、路由层级、浏览方式和读取边界。

说明：本文件名称可继续保留为内部规划文件；但网站前台、导航、页面标题、按钮和用户可见文案中，不使用“文档中心”“文档页”“文档详情”等说法。

用户看到的是：

```text
资料馆
规则资料
卡牌档案
技能评级
美术档案
印刷成果
历史记录
未来计划
备选方案
运营记录
网站开发
```

用户不需要知道这些页面背后来自 Markdown 文件。

---

## 一、总体原则

```text
1. 所有项目资料都要做成可浏览页面。
2. 不是把文件堆成列表，而是按用户理解路径组织。
3. 用户看的是页面、资料、档案、历史、计划，不看“文档”字样。
4. 页面之间必须有导航、面包屑、相关页面、上一篇/下一篇。
5. 用户读完当前规则后，应能直接进入规则历史、技能评级、基础卡表、未来计划。
6. 展示不等于作为唯一来源。
7. 源文件、派生展示、历史记录、生产交付、备选方案仍在内部打标签。
8. 页面不得反向改写规则源文件、基础卡表或技能表。
```

## 二、用户可见入口

主入口：

```text
/library
资料馆
```

一级分类：

```text
/library/rules        规则资料
/library/cards        卡牌档案
/library/skills       技能评级
/library/art          美术档案
/library/print        印刷成果
/library/history      历史记录
/library/plans        未来计划
/library/backup       备选方案
/library/operations   运营记录
/library/web          网站开发
```

详情页：

```text
/library/:category/:slug
```

内部可以继续从仓库 Markdown 文件生成页面，但前台不显示“文档详情”。

## 三、资料馆首页结构

```text
LibraryHomePage
├── LibraryHero
├── ReadingPathSection
├── LibrarySearchBar
├── LibraryCategoryGrid
├── FeaturedPagesSection
├── RecentUpdatesSection
└── FullIndexSection
```

### 1. LibraryHero

结构：

```text
标题：资料馆
说明：查看规则、卡牌、美术、历史、计划与项目进展
主要入口按钮
```

### 2. ReadingPathSection

推荐阅读路径：

```text
新玩家入门
深入规则设计
卡牌与妖怪设定
美术与插画过程
项目进展与未来计划
```

### 3. LibraryCategoryGrid

分类卡：

```text
规则资料
卡牌档案
技能评级

印刷成果
历史记录
未来计划
备选方案

```

### 4. RecentUpdatesSection

展示最近更新页面。

说明：最近更新不改变资料来源优先级。

```text
LibraryCategoryPage

├── RecommendedPath
├── CurrentPagesSection
```

## 五、单页阅读结构

```text
LibraryArticlePage
├── SiteHeader
├── Breadcrumbs
├── ArticleShell
│   ├── LeftSectionNav
│   ├── ArticleMain
│   └── RightOnThisPage
├── RelatedPagesBlock
├── HistoryAndPlanBlock
├── PrevNextNav
└── SiteFooter
```

### 1. Breadcrumbs

示例：

```text
首页 / 资料馆 / 规则资料 / 当前规则
```

### 2. LeftSectionNav

展示同分类页面导航。

示例：规则资料左侧导航：

```text
规则资料
├── 当前规则
├── 基础卡表
├── 技能汇总
├── 技能评分标准
├── 规则变化历史
└── 双人对战计划
```

### 3. ArticleMain

展示正文内容。

说明：

```text
正文来自仓库文件。
页面负责排版、目录、跳转和关联，不在组件里手写第二份正文。
```

### 4. RightOnThisPage

页内目录：

```text
本页内容
当前章节
快速跳转
```

### 5. RelatedPagesBlock

相关页面：

```text
相关规则
相关历史
相关计划
相关卡牌
相关技能
相关美术记录
```

### 6. PrevNextNav

```text
上一篇
下一篇
返回分类首页
```

## 六、页面关联规则

### 1. 当前规则页面

必须关联：

```text
基础卡表
技能汇总
技能评分标准
规则变化历史
双人对战计划
玩家手册
指南卡
```

说明：玩家手册和指南卡可以作为“玩家版阅读”展示，但标记为派生展示，不作为规则来源。

### 2. 基础卡表页面

必须关联：

```text
卡牌图鉴
单卡卡志
卡牌调整历史
技能汇总
备选卡表
```

### 3. 技能评分标准页面

必须关联：

```text
技能汇总
基础卡表
技能改变历史
相关卡牌
双人对战计划
```

### 4. 单卡卡志页面

必须关联：

```text
基础卡表
相关技能评级
相关卡牌
该卡插画迭代历史
该卡规则调整历史
同阵营或同类型卡牌
```

### 5. 美术规范页面

必须关联：

```text
插画审核流程
成品卡审核流程
插画迭代历史
单卡卡志
官网视觉风格
```

### 6. 历史记录页面

必须反向关联当前有效页面。

示例：

```text
规则变化历史 -> 当前规则
技能改变历史 -> 技能汇总 / 技能评分标准
插画迭代历史 -> 美术规范 / 单卡卡志
```

## 十、当前结论

资料馆是用户可浏览的正式页面系统，不是文件堆放区。

用户路径示例：

```text
首页
→ 规则资料
→ 当前规则
→ 规则变化历史
→ 技能评分标准
→ 相关卡牌
→ 单卡卡志
→ 插画迭代历史
```

页面必须提供连续导航，让用户自然从一个页面进入下一个相关页面。
