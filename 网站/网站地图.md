# 《夕妖：抢地盘》网站地图

## 文件定位

本文件用于统一记录《夕妖：抢地盘》网站的信息架构、页面路由、页面用途、阶段范围和文档展示路径。

本文件只定义网站地图，不填充页面正文，不修改规则，不新增卡牌，不维护第二份卡表。

正式网站：

```text
https://qdp.weijie.sg
```

工程目录：

```text
web/
```

## 十三、当前结论

网站地图已经统一为：

```text
官网展示
卡牌图鉴
规则中心
试玩入口
印刷成果
文档中心
众筹预热
开发日志
后续玩家中心
```

其中 `/docs` 是所有项目文档的统一展示入口。

所有文档都可以进入网站，但必须带文档状态标签，防止派生展示、历史记录、生产交付和备选方案反向覆盖当前源文件。
