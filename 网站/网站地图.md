# 《夕妖：抢地盘》网站地图

## 文件定位

本文件用于统一记录《夕妖：抢地盘》网站的信息架构、页面路由、页面用途和阶段范围。

本文件只定义网站地图，不填充页面正文，不修改规则，不新增卡牌，不维护第二份卡表。

正式网站：

```text
https://qdp.weijie.sg
```

工程目录：

```text
web/
```

---

## 一、前台信息架构原则

网站前台没有“文档中心”概念，也不单独建立资料仓库式入口。

所有资料都分散到具体业务页面中：

```text
卡牌资料放在卡牌页面。
规则资料放在规则页面。
技能评级放在规则 / 技能页面。
插画历史放在美术页面。
印刷生产说明放在印刷成果页面。
未来计划放在对应模块的计划页或开发记录中。
备选卡表放在卡牌页面的备选方案区。
网站开发资料放在开发记录或网站开发页。
```

前台禁止出现：

```text
文档中心
文档详情
文档列表
/docs
/library
Markdown 文件
文件夹浏览
```

前台可以出现：

```text
规则
卡牌
技能评级
美术档案
印刷成果
历史记录
未来计划
备选方案
开发记录
继续阅读
相关页面
```

## 十四、当前结论

网站地图统一为分散页面体系：

```text
卡牌资料在 /cards
规则资料在 /rules
技能评级在 /rules/skills 与 /rules/skill-rating
美术与插画在 /art
印刷生产在 /print
众筹运营在 /crowdfunding
开发与历史记录在 /devlog 或对应模块 history 页面
```

不建立 `/docs`，不建立 `/library`，不建立前端 Markdown 内容文件夹。

所有内容都应成为具体业务页面的一部分，并通过相关页面、历史记录和继续阅读形成浏览路径。
