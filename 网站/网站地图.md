# 《夕妖：抢地盘》网站地图

## 文件定位

本文件用于统一记录《夕妖：抢地盘》网站的信息架构、页面路由、页面用途、阶段范围和资料馆展示路径。

本文件只定义网站地图，不填充页面正文，不修改规则，不新增卡牌，不维护第二份卡表。

正式网站：

```text
https://qdp.weijie.sg
```

工程目录：

```text
web/
```

---

## 一、前台命名原则

用户看到的是页面，不是文件管理器。

前台导航、页面标题、按钮和面包屑中，不使用：

```text
文档中心
文档详情
文档列表
Markdown 文件
```

统一使用：

```text
资料馆
规则资料
卡牌档案
技能评级
美术档案
历史记录
未来计划
备选方案
印刷成果
开发记录
相关页面
继续阅读
```

内部仓库仍可以保留“文档”类文件名，前台不暴露工程感。

## 十四、当前结论

网站地图已经统一为：

```text
官网展示
卡牌图鉴
规则中心
试玩入口
印刷成果
资料馆
众筹预热
开发记录
后续玩家中心
```

其中 `/library` 是所有项目资料的用户可见入口。

所有资料都可以进入网站，但必须带状态标签，防止玩家版说明、历史记录、生产说明和备选方案反向覆盖当前源文件。
