# 《夕妖：抢地盘》官网页面结构设计

## 文件定位

本文件只设计网站页面结构、路由层级、页面骨架和模块位置。

本文件暂不填充具体文案、卡牌内容、规则说明、视觉美术细节或 UI 组件样式。

内容文案来源另见：

```text
网站/正式官网首页内容设计.md
```

视觉美术来源另见：

```text
网站/官网视觉美术风格设计.md
网站/官网UI组件规范.md
```

技术栈来源另见：

```text
网站/网站技术栈方案.md
```

本文件不修改规则，不新增卡牌，不维护第二份卡表，不读取派生展示文件作为唯一来源。

---

## 一、结构设计原则

```text
1. 先确定页面骨架，再填充内容。
2. 官网层与游戏层分开。
3. 移动端优先，桌面端只横向展开。
4. 首页负责建立第一印象，不承载全部信息。
5. 图鉴、规则、试玩、众筹、开发日志各自独立。
6. 不新增当前阶段不需要的商业模块。
7. 不在结构文档里写具体规则解释。
8. 不在结构文档里写具体卡牌数据。
```

---

## 二、网站总层级

网站分为两层：

```text
官网层
游戏层
```

### 1. 官网层

用于：

```text
产品展示
卡牌图鉴
规则入口
印刷成果展示
试玩入口
众筹预热
开发日志
```

### 2. 游戏层

用于：

```text
游戏大厅
规则教学
人机练习
双人对战
4人抢地盘
本地热座
后续联网房间
```

官网层可以像网站。

游戏层必须像卡牌游戏客户端，不能像普通网页。

## 五、全站公共结构

```text

├── PageMain

```

### 1. SiteHeader

结构：

```text
品牌区
导航区
CTA 区
移动端菜单区
```

### 2. PageMain

结构由不同页面决定。

### 3. SiteFooter

```text
品牌信息
项目状态
```

## 十四、移动端页面结构

移动端页面统一结构：

```text
MobilePage
├── MobileHeader
├── MainContentSingleColumn
├── StickyBottomCta，可选
└── MobileFooter
```

移动端规则：

```text
1. 所有页面单列优先。
2. 首屏只保留一个主任务。
3. 横向滚动只用于缩略图、卡牌列表或标签栏。
4. 不在移动端展示复杂多栏结构。
5. 游戏层移动端进入全屏客户端外壳。
```

---

## 十五、桌面端页面结构

桌面端页面统一结构：

```text
DesktopPage
├── DesktopHeader
├── MainContentWideContainer
└── DesktopFooter
```

桌面端规则：

```text
1. 桌面端从移动端展开，不重新设计信息顺序。
2. 首页 Hero 可左右分栏。
3. 图鉴可左筛选右网格。
4. 印刷页可左大图右统计。
5. 规则页可左目录右正文。
6. 游戏层仍为客户端式界面。
```

## 十六、数据读取边界

网站结构允许引用的数据入口：

```text
规则/当前规则.md
规则/V1.2-基础卡表.md
规则/V1.2-技能汇总表.md
规则/V1.2-技能评分标准.md
规则/未来扩展与双人对战计划.md
web/public/assets/print/v1/manifest.json
```

派生展示文件不作为结构设计来源：

```text
规则/游戏手册.md
规则/指南卡.md
卡牌成品/印刷说明.md
```

说明：派生文件只有在明确审核玩家展示文本或生产交付文本时才单独读取。
