# 《夕妖：抢地盘》官网页面结构设计

## 文件定位

本文件只设计网站页面结构、路由层级、页面骨架和模块位置。

本文件不填充具体文案、卡牌内容、规则说明、视觉美术细节或 UI 组件样式。

本文件不修改规则，不新增卡牌，不维护第二份卡表。

最新网站信息架构以以下文件为准：

```text
网站/网站地图.md
网站/Codex实现边界.md
网站/文档位置统一规划.md
```

若本文件与上述文件冲突，以 `网站/网站地图.md` 和 `网站/Codex实现边界.md` 为准。

---

## 一、结构设计原则

```text
1. 先确定页面骨架，再填充内容。
2. 官网层与游戏层分开。
3. 移动端优先，桌面端只横向展开。
4. 首页负责建立第一印象，不承载全部信息。
5. 卡牌、规则、试玩、印刷成果、美术档案、众筹预热、开发记录各自独立。
6. 不新增当前阶段不需要的商业模块。
7. 不在结构文档里写具体规则解释。
8. 不在结构文档里写具体卡牌数据。
9. 不建立 /docs。
10. 不建立 /library。
11. 不建立前端 Markdown 内容文件夹。
```

---

## 二、网站总层级

网站分为两层：

```text
官网层
游戏层
```

### 1. 官网层

用于：

```text
产品展示
卡牌图鉴
规则入口
印刷成果展示
美术档案展示
试玩入口
众筹预热
开发记录
```

### 2. 游戏层

用于：

```text
游戏大厅
规则教学
人机练习
双人对战
4人抢地盘
本地热座
后续联网房间
```

官网层可以像网站。

游戏层必须像卡牌游戏客户端，不能像普通网页。

## 五、全站公共结构

所有官网层页面采用统一外壳：

```text
SiteShell
├── SiteHeader
├── Breadcrumbs，首页除外
├── PageMain
├── RelatedPagesBlock
├── ContinueReadingBlock
└── SiteFooter
```

### 1. SiteHeader

结构：

```text
品牌区
导航区
CTA 区
移动端菜单区
```

### 2. PageMain

结构由不同页面决定。

### 3. RelatedPagesBlock

每个具体页面必须提供相关页面入口。

### 4. ContinueReadingBlock

每个具体页面必须提供继续阅读入口。

### 5. SiteFooter

结构：

```text
品牌信息
项目状态
主要链接
版权与仓库入口
```

游戏层页面不使用完整官网页脚。

## 十五、数据读取边界

网站结构允许引用的数据入口：

```text
规则/当前规则.md
规则/V1.2-基础卡表.md
规则/V1.2-技能汇总表.md
规则/V1.2-技能评分标准.md
规则/未来扩展与双人对战计划.md
web/public/assets/print/v1/manifest.json
```

明确任务才读取：

```text
规则/游戏手册.md
规则/指南卡.md
卡牌成品/印刷说明.md
备选方案/*
规则历史/*
美术历史/*
```

禁止：

```text
在 web/ 下新建 content/docs/。
在 web/ 下新建 markdown 文档库。
把规则、卡表、技能复制成第二份前端内容。
```
