# 《夕妖：抢地盘》游戏界面设计方向

## 文件定位

本文件用于规定《夕妖：抢地盘》数字试玩与联网游戏的界面方向。

本文件只定义数字界面的表现方向，不修改游戏规则，不新增卡牌设定，不替代视觉规范。

关联文件：

```text
网站/完整网站架构规划.md
规则/未来扩展与双人对战计划.md
规则/双人对战V0.1-召唤延迟调整.md
规范流程/视觉总规范.md
规范流程/UI规范.md
```

---

## 一、核心目标

游戏页面必须像一个卡牌游戏客户端，而不是普通网页。

目标体验：

```text
打开后像进入一个妖怪卡牌游戏。
玩家注意力集中在桌面、卡牌、地盘和操作反馈上。
不出现网页长滚动、网页表格、后台系统感。
```

---

## 二、总体视觉关键词

```text
西游妖怪
妖王洞府
抢地盘
厚重卡牌
金边 UI
石质 / 木质 / 铜纹按钮
炉石式桌面布局
卡牌飞行动画
战斗反馈
聚会互动感
```

说明：

```text
可以参考炉石传说的桌面式交互、手牌布局和战斗反馈。
不能复制炉石传说的具体 UI、图标、美术资产或版式细节。
```

---

## 三、明确禁止的界面风格

游戏页面禁止做成：

```text
普通网页
后台管理系统
表格页面
白底说明页
长页面滚动
普通按钮堆叠
H5测试页风格
Word文档风格
```

不应出现：

```text
顶部传统网页导航栏占据主要区域
整页滚动浏览对战桌面
卡牌像普通 div 卡片
规则说明压过游戏桌面
玩家需要频繁滚动才能操作
```

---

## 四、游戏大厅设计

游戏大厅是玩家进入电子版《抢地盘》的主入口。

### 1. 大厅布局

建议结构：

```text
背景：妖怪洞府 / 山门 / 妖市 / 云雾战场
中间：主模式入口
左侧：玩家信息、卡册、测试员身份
右侧：公告、众筹预热、开发日志
底部：卡牌、规则、对战、设置、反馈
```

### 2. 主模式入口

主模式按钮应做成大型游戏入口，而不是普通网页按钮。

入口包括：

```text
4人抢地盘
妖王对战 1v1
人机练习
规则教学
卡牌图鉴
AI验证
```

### 3. 大厅氛围

大厅应有：

```text
背景景深
妖怪剪影
卡牌悬浮
按钮发光
模式卡片翻转或浮动
音效开关
```

## 五、双人对战桌面设计

双人对战用于《妖王对战 V0.1》。

### 1. 屏幕布局

建议布局：

```text
上方：对手头像、生命、妖气、牌组、手牌背面
中间：战场区域
下方：玩家头像、生命、妖气、牌组、手牌
右侧：结束回合大按钮
左侧：对战日志 / 当前提示，可折叠
```

手牌区域：

```text
底部扇形展开
鼠标悬停 / 手机长按时放大
可打出的牌高亮
妖气不足的牌变暗
```

场上区域：

```text
双方妖怪分上下两排站位
可攻击妖怪发光
本回合刚打出且受召唤延迟影响的妖怪半透明或带“休整”标记
已攻击妖怪变暗
```

### 2. 操作流程

操作应遵循：

```text
点击手牌 → 选择打出
点击己方妖怪 → 选择攻击者
点击敌方妖怪 → 攻击目标
敌方无妖怪时点击己方妖怪 → 直攻
点击结束回合 → AI或对手行动
```

不能要求玩家反复点击“开始回合”。

回合开始应自动处理：

```text
抽牌
获得妖气
刷新可攻击状态
提示当前可操作内容
```

### 3. 动画反馈

关键动画：

```text
抽牌：牌库飞入手牌
打出：手牌飞到己方场上
攻击：攻击者向目标冲撞
直攻：攻击者冲向对方头像 / 地盘生命
消灭：卡牌碎裂、烟雾或下沉
吹回：卡牌飞回手牌
回血 / 清伤：回合结束时淡光闪过
```

### 4. 信息密度

默认只展示必要信息：

```text
生命
妖气
牌组剩余
手牌数量
当前回合提示
```

详细日志折叠到侧边，避免占据桌面中心。

## 六、4人抢地盘桌面设计

4人抢地盘是主产品模式，不能套用 1v1 对战桌面。

### 1. 屏幕布局

建议布局：

```text
中间：当前地盘牌
四角：四名玩家区域
底部：当前玩家手牌
顶部：公共牌库 / 弃牌区 / 回合信息
右侧：当前阶段提示
```

玩家区域包括：

```text
头像
昵称
已占地盘数量
当前派出的妖怪
手牌数量
状态提示
```

### 2. 抢地盘表现

抢地盘时：

```text
地盘牌放大到桌面中心
玩家派出的妖怪围绕地盘站位
结算时显示胜出玩家
胜出玩家将地盘收入己方区域
```

### 3. 聚会互动感

4人局应强化：

```text
表情
短语
临时结盟提示
倒计时
当前玩家高亮
抢地盘结算特效
```

## 七、卡牌图鉴界面

图鉴不是表格，而是卡册。

表现方式：

```text
卡牌网格
星级筛选
类型筛选
模式筛选
点击放大
卡牌翻面
收藏册分页
```

单卡详情：

```text
左侧：大卡图
右侧：名称、星级、类型、技能、规则解释
底部：适用模式、实体牌数量、版本说明
```

---

## 八、规则教学界面

规则教学应游戏化，不应只是文字阅读。

章节：

```text
第一关：认识地盘
第二关：派妖怪
第三关：抢地盘
第四关：使用法宝
第五关：完整一局
```

每关结构：

```text
一句目标
小桌面演示
玩家亲自操作一步
即时反馈
进入下一关
```

---

## 九、移动端要求

移动端优先横屏游戏体验。

要求：

```text
提示玩家横屏
按钮够大
手牌可横向滑动
日志默认收起
卡牌长按放大
结束回合按钮固定在右侧或右下角
```

手机竖屏只适合官网、图鉴和规则阅读，不适合作为完整对战默认视图。

---

## 十、阶段目标

### 第一阶段

```text
重做人机页面为全屏固定桌面
去掉网页滚动
建立游戏大厅雏形
卡牌有基本游戏感
```

### 第二阶段

```text
加入手牌扇形
加入打出 / 攻击 / 消灭动画
加入规则教学
```

### 第三阶段

```text
4人抢地盘本地桌面
联网房间桌面
观战与回放
```
