# 《夕妖：抢地盘》官网视觉美术风格设计

## 文件定位

本文件只定义《夕妖：抢地盘》正式官网的视觉美术风格。

本文件不定义首页文案、页面内容、区块顺序、规则说明或卡牌数量展示。

内容设计来源：

```text
网站/正式官网首页内容设计.md
```

UI 组件规格来源：

```text
网站/官网UI组件规范.md
```

本文件不修改规则，不新增卡牌，不维护第二份卡表。

## 一、官网视觉总定义

正式官网视觉风格确定为：

```text
明亮蓝金西游妖怪桌游官网风
```

完整定义：

```text
以明亮西游山寨、妖旗、山门、蓝天、云雾和金边卡牌 UI 建立欢乐聚会氛围；
以真实印刷卡牌、包装盒和资源清单作为产品展示核心；
整体采用深蓝纹理底、金色边框、红旗点缀、暖色高光；
风格偏商品级实体桌游官网，而不是暗黑网游官网。
```

## 三、角色美术风格

官网与宣传图中的妖怪角色采用：

```text
非Q版东方神话动画电影风妖怪角色
```

角色要求：

```text
1. 比例正常，不做Q版大头短身。
2. 有动画电影级表演感和角色性格。
3. 体块清晰，轮廓强，便于识别。
4. 有电影感光影，但不要写实到像真人CG。
5. 有妖怪感、野性、神怪感和势力感。
6. 兼顾商品级、收藏级、高识别度。
```

角色气质：

```text
狡黠
野性
妖气
江湖感
山寨势力感
群妖逐鹿感
欢乐聚会感
```

禁止角色方向：

```text
Q版二头身
幼态萌系
儿童绘本角色
宠物化小妖
泡泡堂式可爱妖怪
真人写实CG
恐怖怪物
过度暗黑血腥
```

## 四、场景美术风格

官网主视觉场景采用：

```text
明亮西游山寨 / 妖王山门 / 山路 / 妖旗 / 蓝天云雾
```

场景应有：

```text
山寨高低层次
红色妖旗
蓝天与白云
山石与木栅栏
金色阳光
轻微云雾
桌游产品展示台
```

场景不应有：

```text
压抑地牢
血腥战场
现代都市
赛博空间
西方哥特城堡
纯黑暗洞穴
```

说明：

```text
官网主视觉可以有妖气和战斗感，但整体仍要保持欢乐聚会卡牌产品气质。
```

## 五、产品展示风格

官网的产品展示必须以真实资源为核心。

真实资源来源：

```text
web/public/assets/print/v1/manifest.json
web/public/assets/print/v1/cards/
web/public/assets/print/v1/box/
web/public/assets/print/v1/docs/
```

展示原则：

```text
1. 真实卡牌和包装是视觉主角。
2. 背景、角色、装饰都服务于真实产品展示。
3. 不用虚构卡面替代真实印刷图。
4. 不重新生成卡牌内容。
5. 不展示不存在的星级、数值、卡名和技能。
```

产品展示应像：

```text
实体桌游开盒
卡牌收藏展示
第一版印刷成果展示
桌面摆放拍摄感
```

不应像：

```text
虚构游戏截图
抽卡池展示
商城商品格
页游充值宣传
```

## 六、色彩方向

官网采用明亮蓝金西游桌游风。

主色：

```text
深蓝底纹：#0B2342
夜蓝暗部：#071624
面板蓝：#12345A
妖火金：#D8A640
亮金高光：#FFD98A
主按钮暗红：#8F241B
红旗朱砂：#B93525
山石暖棕：#7A4A24
木牌深棕：#3A2414
正文米白：#F7EAD0
弱文字褐金：#BCA37A
边线铜色：#5A3D1F
```

色彩原则：

```text
背景以深蓝纹理和山寨氛围为主。
标题、边框、按钮使用金色。
红旗和朱砂作为点缀。
正文保持米白或深色纸面文字。
产品展示图保持真实色彩，不强行整体染色。
```

禁止色彩方向：

```text
大面积纯白
荧光绿
赛博紫
现代科技蓝渐变
灰白玻璃拟态
SaaS 风浅灰卡片
整体黑色暗黑风
```

## 八、UI 美术风格

官网 UI 应像：

```text
桌游包装上的说明牌
妖王山寨里的木牌
金边卡牌面板
实体卡牌产品展板
```

官网 UI 不应像：

```text
后台管理系统
普通网页按钮
企业站白底卡片
SaaS 功能介绍页
页游充值页
抽卡游戏商城
```

按钮美术方向：

```text
主按钮：红色金边，像妖旗或令牌。
次按钮：蓝色金边，像卡牌 UI 面板。
```

面板美术方向：

```text
深蓝底纹
金色边框
中式角花
轻微立体阴影
```

## 九、移动端视觉原则

移动端视觉第一原则：

```text
可读性优先，装饰服务信息。
```

移动端应保留：

```text
蓝金底色
Logo
菜单按钮
主标题
核心 CTA
真实卡牌 / 包装展示
标题条
少量角花
```

移动端应减少：

```text
过多边框
过多纹理
过多角花
过密小图
过长装饰线
复杂背景角色堆叠
```

移动端首屏不能让背景角色压过主标题和真实产品展示。

---

## 十、桌面端视觉原则

桌面端是在移动端基础上展开，不另起一套风格。

桌面端可以增加：

```text
更宽的山寨背景
左右分栏主视觉
更完整的卡牌堆叠
更多留白
更大标题
横向卡片阵列
```

桌面端不得新增：

```text
新世界观区块
新规则说明
新功能入口
新商业模块
```

## 十一、风格边界

官网风格应保持在：

```text
高品质西游妖怪实体卡牌产品官网
```

不要偏向：

```text
暗黑西游网游官网
Q版儿童卡通官网
写实恐怖怪物官网
白底公司官网
抽卡手游官网
页游充值官网
```

一句话判断：

```text
像一个商品级实体桌游官网，不像一个在线游戏充值官网。
```

---

## 十二、视觉验收标准

完成官网首页后，从视觉上检查：

```text
1. 整体是否为明亮蓝金西游桌游风。
2. 是否有西游山寨、妖旗、金边 UI、实体卡牌展示。
3. 妖怪角色是否为非Q版动画电影风。
4. 是否避免了暗黑网游、SaaS 白底、Q版儿童风。
5. 真实卡牌和包装是否是产品展示核心。
6. 背景是否服务产品，而不是压过产品。
7. 移动端是否清楚可读。
8. 装饰是否节制，没有抢正文。
9. 是否没有虚构卡牌、虚构星级或新规则画面。
10. 是否和项目总视觉的商品级、收藏级、厚重感、高识别度一致。
```
