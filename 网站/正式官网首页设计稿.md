# 《夕妖：抢地盘》正式官网首页设计稿

## 文件定位

本文件是《夕妖：抢地盘》正式官网首页第一版的设计总控索引。

从本版本开始，官网设计拆分为三类文件维护：

```text
内容设计
视觉美术风格设计
UI 组件规范
```

本文件不再混合维护完整文案、颜色、角色风格和组件规格，只负责说明各文件职责和执行顺序。

本文件不修改规则，不新增卡牌，不维护第二份卡表，不替代现有规则文件。

## 三、当前首页设计结论

首页内容核心：

```text
产品展示 + 印刷成果 + 玩法说明 + 试玩预热
```

视觉方向：

```text
明亮蓝金西游妖怪桌游官网风
```

角色方向：

```text
非Q版东方神话动画电影风妖怪角色
```

资源原则：

```text
真实印刷资源优先
```

资源来源：

```text
web/public/assets/print/v1/manifest.json
web/public/assets/print/v1/cards/
web/public/assets/print/v1/box/
web/public/assets/print/v1/docs/
```

---

## 五、硬性边界

首页实现不得：

```text
1. 修改规则文件。
2. 修改基础卡表。
3. 新增第二份卡表。
4. 新增卡名、星级、技能或阵营。
5. 新增胜利条件。
6. 使用随机外部图片替代真实印刷资源。
7. 使用 Q版二头身或幼态萌系妖怪作为主视觉。
8. 改成暗黑网游官网、白底 SaaS 官网、后台管理页或页游充值页。
```

## 六、当前结论

官网首页设计已经拆分为：

```text
内容设计：网站/正式官网首页内容设计.md

```

后续首页实现和审核必须分别对照三份文件，不再把内容设计和视觉美术风格混在同一份文档中维护。
