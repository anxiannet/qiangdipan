## 二、官网风格总定义

正式官网首页风格确定为：

```text
明亮蓝金西游妖怪桌游官网风
```

完整定义：

```text
以明亮西游山寨、妖旗、山门、蓝天、云雾和金边卡牌 UI 建立欢乐聚会氛围；
以真实印刷卡牌、包装盒和资源清单作为产品展示核心；
整体采用深蓝纹理底、金色边框、红旗点缀、暖色高光；
风格偏商品级实体桌游官网，而不是暗黑网游官网。
```

关键词：

```text
西游妖怪
妖王山寨
抢地盘
实体卡牌
金边 UI
明亮蓝金
红旗点缀
动画电影风角色
桌游产品官网
轻 TRPG 代入
欢乐聚会感
```

禁止风格：

```text
白底企业官网
普通 SaaS 官网
后台管理系统
Word 文档风格
表格堆叠

恐怖压抑风
```

## 三、角色风格定义

官网与宣传图中的妖怪角色采用：

```text
非Q版的东方神话动画电影风妖怪角色
```

角色要求：

```text
1. 比例正常，不做Q版大头短身。
2. 有动画电影级表演感和角色性格。
3. 体块清晰，轮廓强，便于识别。
4. 有电影感光影，但不要写实到像真人CG。
5. 有妖怪感、野性、神怪感和势力感。
6. 兼顾商品级、收藏级、高识别度。
```

角色气质：

```text
狡黠
野性
妖气
江湖感
山寨势力感
群妖逐鹿感
欢乐聚会感
```

禁止角色方向：

```text
Q版二头身
幼态萌系
儿童绘本角色
宠物化小妖
泡泡堂式可爱妖怪
真人写实CG
恐怖怪物
过度暗黑血腥
```

说明：

```text
角色要有动画电影风的高级感和表演感，但仍服务于“欢乐聚会卡牌游戏”。
不能做成儿童向萌宠，也不能做成严肃恐怖怪物。
```

## 四、视觉基调

### 1. 色彩

官网首页采用明亮蓝金西游桌游风。

主色：

```text
深蓝底纹：#0B2342
夜蓝暗部：#071624
妖火金：#D8A640
亮金高光：#FFD98A
红旗朱砂：#B93525
山石暖棕：#7A4A24
木牌深棕：#3A2414
正文米白：#F7EAD0
弱文字褐金：#BCA37A
边线铜色：#5A3D1F
```

使用原则：

```text
背景以深蓝纹理和山寨氛围为主。
标题、边框、按钮使用金色。
红旗和朱砂作为点缀。
正文保持米白或深色纸面文字。
不要大面积纯白。
不要荧光色。
不要现代科技蓝紫赛博风。
不要整体压成黑色暗黑风。
```

### 2. 质感

```text
卡牌边框：金属压边感
背景：山寨、山门、蓝天、云雾、石纹、木纹、铜纹
按钮：像游戏按钮，不像网页按钮
区块：像卡牌面板、妖王令牌或桌游说明牌
印刷成果：像真实开盒展示，不像虚构游戏截图
```

### 3. 圆角与阴影

```text
大面板圆角：24px
卡片圆角：18px
按钮圆角：999px 或 14px
阴影：深色投影 + 金色内发光
边框：1px 铜色线，重要内容可加金色描边
```

## 五、移动端优先原则

首页第一版以移动端优先设计。

基准屏幕：

```text
390px 宽手机屏幕
```

原则：

```text
1. 先完成移动端纵向信息流，再扩展桌面端。
2. 桌面端是在移动端基础上展开，不是把PC大图压缩成手机页面。
3. 移动端首屏只表达一个核心信息：这是《夕妖：抢地盘》。
4. 每个区块只承担一个任务，不在手机屏幕堆太多装饰。
5. 真实卡牌图必须清楚可见，不能被背景压过。
```

移动端首屏保留：

```text
Logo
菜单按钮
小标签：实体印刷优先 · 2~4人 · 15~30分钟
主标题：妖怪集结，开抢地盘
副标题：西游妖怪题材欢乐聚会卡牌游戏
按钮：查看印刷成果 / 了解怎么玩
主视觉：山寨 + 妖旗 + 真实印刷卡牌或包装展示
```

移动端首屏不要放：

```text
复杂进度条
二维码
大段规则说明
过多小图标
过多卡牌缩略图
完整页脚链接
```

移动端尺寸建议：

```text
左右 padding：16px
Hero 标题：34px ~ 40px
正文：15px ~ 16px
按钮高度：48px
区块间距：56px ~ 72px
主视觉高度：260px ~ 360px
```

正式官网首页第一版以“产品展示 + 印刷成果 + 玩法说明 + 试玩预热”为核心。

视觉定为：

```text
明亮蓝金西游妖怪桌游官网风
```

角色定为：

```text
非Q版东方神话动画电影风妖怪角色
```

正式官网要像“高品质西游妖怪实体卡牌产品官网”，不要像“暗黑西游网游官网”，也不要像“Q版儿童卡通官网”。
