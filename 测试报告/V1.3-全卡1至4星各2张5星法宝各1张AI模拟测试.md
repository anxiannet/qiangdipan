## 一、测试目的

本报告测试一个“全卡均衡复制”方案：

```text
全部当前可测试公共牌中，1星、2星、3星、4星每种2张；
5星每种1张；
法宝每种1张。
```

该方案用于观察：

```text
1. 不额外堆1星复制时，牌库厚度是否足够。
2. 将扩展包3星互动牌纳入后，是否明显改变空库与胜率结构。
3. 该方案是否适合作为标准版、进阶标准版或扩展套装的候选口径。
```

## 七、测试结论

### 1. 48张全卡均衡比40张明显稳

与40张标准版相比，48张全卡均衡方案明显降低空库出现率和结算率。

尤其是4人局：

```text
40张空库出现率：45.30%
48张空库出现率：31.47%
40张结算率：6.10%
48张结算率：2.60%
```

### 2. 48张不如50张低星增强稳定

虽然48张总张数接近50张，但它把新增空间给了3星互动牌、5星牛魔王和芭蕉扇，而不是补足更多低星复制。

因此在空库表现上，48张全卡均衡不如50张低星增强。

```text
48张4人空库出现率：31.47%
50张4人空库出现率：27.83%
```

### 3. 48张互动更强，复杂度更高

48张方案带入：

```text
金鼻白毛老鼠精
玉面狐狸
铁扇公主
牛魔王
芭蕉扇
```

这些牌会增加偷兵、吹回、额外打出、整地盘吹回等进阶互动。

这使48张更像“进阶试验版”，而不是标准版加厚版。

### 4. 5星密度较高

48张方案中有3张5星：

```text
红孩儿
大鹏精
牛魔王
```

相比标准版40张的2张5星，顶级妖王出现率更高，会提升桌面爆点，但也可能提高新手理解负担。

## 八、建议

```text
不建议把48张全卡均衡方案作为标准版正式口径。
```

更合理的定位：

```text
40张标准版：最轻、最干净，适合首盒与新手。
50张低星增强：适合降低空库但不增加太多复杂度。
48张全卡均衡：适合作为进阶试验版，测试扩展牌互动强度。
60张妖王再临：完整扩展套装玩法。
```

当前推荐真人测试优先级：

```text
1. 40张标准版
2. 50张低星增强版
3. 48张全卡均衡进阶版
4. 60张妖王再临套装
```
