## 九、测试结论

### 1. 牛魔王 / 金鼻白毛老鼠精回基础版后，42张基础版比40张更稳

human_like 下：

```text
2人空库率：36.43% → 29.27%
3人空库率：39.53% → 35.20%
4人空库率：45.30% → 37.30%
```

空库结算率也有下降，但 4人局下降幅度有限：

```text
4人结算率：6.10% → 5.87%
```

说明 42张基础版能改善空库，但不如50张低星增强明显。

### 2. 新42+18合并60张仍然很稳

新合并60张的 human_like 空库率约 14%~18%，结算率低于 1%。

这说明把红孩儿放进扩展包、六健将追加放进扩展包后，60张套装仍然可用。

### 3. 新基础版42张的设计味道更强，但标准版复杂度上升

基础版加入：

```text
牛魔王
金鼻白毛老鼠精
```

会让基础版更有西游识别度和偷兵互动。

但同时基础版从 40 张变为 42 张，并引入更强的3星偷兵与5星号令节奏。它比当前40张更“热闹”，但也更不像极简标准版。

### 4. 红孩儿进扩展包后，基础版火云主线变化

当前标准版是：

```text
红孩儿作为火云5星锚点。
```

新方案会变成：

```text
牛魔王作为基础版5星锚点。
红孩儿与六健将追加复制进入扩展包。
```

这会让扩展包主题更像“火云洞增强包”，而基础版则更偏“大妖王 + 偷兵互动”。
