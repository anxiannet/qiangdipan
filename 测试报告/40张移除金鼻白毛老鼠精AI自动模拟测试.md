## 测试方案

在此前 42 张压缩方案基础上，继续移除：

```text
金鼻白毛老鼠精 × 2张
```

形成 40 张测试牌库。

### 42张方案来源

42 张方案为：

```text
1星每种从4张减到2张
2星每种从4张减到2张
其余卡牌数量不变
公共牌库从58张降至42张
```

### 40张方案

在 42 张基础上移除：

```text
金鼻白毛老鼠精：2张 → 0张
```

因此公共牌库：

```text
42张 - 2张 = 40张
```

## 关键发现

### 1. 40张仍能跑通

2人、3人、4人在 human_like 模式下都能正常收束。

```text
2人：2873 / 3000局直接胜利
3人：2811 / 3000局直接胜利
4人：2776 / 3000局直接胜利
```

### 2. 游戏时长几乎没有下降

40张与42张相比，平均玩家回合几乎不变：

```text
2人：26.84 → 26.85
3人：26.19 → 26.27
4人：26.92 → 26.97
```

### 3. 空库结算继续上升

与42张相比，40张公共牌库耗尽结算增加：

```text
2人：98 → 116
3人：149 → 187
4人：165 → 209
```

### 4. 移除金鼻白毛老鼠精会减少关系型互动

金鼻白毛老鼠精当前功能是针对敌方1星守军的移动/夺取类互动。

移除后，牌库更薄，但对节奏收益很小。

风险是减少低星守军互动和盘面干扰手段。

```text
40张方案能跑通，但并不比42张明显更快。
```

```text
V1.3 已采用40张基础公共牌库。
金鼻白毛老鼠精移出基础版，转入扩展包候选。
```

说明：V1.3 采用 40 张是产品取舍，不是测试自动给出的唯一最优结论。

## 结论

本轮测试结论：

```text
40张移除金鼻白毛老鼠精方案可以运行。
它没有明显加快游戏，但作为V1.3基础牌库压缩方案可以成立。
需要在实体试玩中重点观察空库体感与1星互动减少后的乐趣变化。
```
