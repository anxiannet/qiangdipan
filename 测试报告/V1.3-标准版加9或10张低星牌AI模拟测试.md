## 一、测试目的

本报告用于测试两个中间厚度方案：

```text
方案 A：40张标准版 + 9张1、2星追加牌 = 49张公共牌
方案 B：40张标准版 + 10张1、2星追加牌 = 50张公共牌
```

测试重点：

```text
1. 是否明显降低40张标准版的空库压力。
2. 是否比60张扩展套装更轻、更适合标准版或进阶标准版。
3. 是否引入扩展包强互动牌之前，就能改善牌库续航。
```

## 三、加牌方案定义

### 方案 A：+9 张 1、2星牌

由于 1、2 星共有 10 个卡名：

```text
1星6种：小钻风、有来有去、精细鬼、伶俐虫、急如火、快如风
2星4种：云里雾、雾里云、兴烘掀、掀烘兴
```

+9 张无法完全平均，因此本次采用“四个子方案平均”的方式：

```text
每个子方案均追加6种1星各1张；
2星追加其中3种各1张；
每次轮流省略1种2星；
最终取四个子方案平均值。
```

四个子方案：

```text
49A：省略云里雾
49B：省略雾里云
49C：省略兴烘掀
49D：省略掀烘兴
```

### 方案 B：+10 张 1、2星牌

```text
6种1星各追加1张
4种2星各追加1张
合计追加10张
```

该方案最均衡。

## 九、测试结论

### 1. 49 / 50 张都能明显改善空库

与40张标准版相比，49张与50张都能明显降低空库出现率和结算率。

尤其是4人局：

```text
40张空库出现率：45.30%
49张空库出现率：27.92%
50张空库出现率：27.83%
```

空库结算率也从 6.10% 降到约 3.4%。

### 2. 50张略优于49张，但差距不大

50张方案比49张更均衡：

```text
6种1星各+1
4种2星各+1
```

它避免了“省略哪一张2星”的不对称问题。

但从测试数据看，49与50的整体表现很接近。

### 3. 50张没有引入扩展包强互动

与60张妖王再临相比，50张方案只补1、2星，不带回：

```text
金鼻白毛老鼠精
玉面狐狸
铁扇公主
牛魔王
芭蕉扇
```

因此50张更像“标准版加厚包”，不会提高太多复杂度。

### 4. 60张仍然最稳，但复杂度也最高

60张妖王再临空库最低，但它是扩展套装口径，不适合直接替代标准版。

## 十、建议

```text
如果目标是保持标准版轻量：继续用40张。
如果目标是降低4人局空库：优先测试50张低星增强方案。
如果目标是完整进阶体验：使用60张妖王再临套装。
```

当前推荐进入真人测试的顺序：

```text
1. 40张标准版
2. 50张低星增强版
3. 60张妖王再临套装
```

其中 50张低星增强版的定义最清晰：

```text
在40张标准版基础上，6种1星各追加1张，4种2星各追加1张。
```
