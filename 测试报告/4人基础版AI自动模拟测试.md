# 4人基础版 AI 自动模拟测试报告

更新时间：2026-07-05

## 文件定位

本文件记录《夕妖：抢地盘》基础版 4 人规则的 AI 自动模拟测试结果。

本文件只记录测试结论与风险观察，不替代当前基础规则。

规则唯一来源仍为：

```text
规则/当前规则.md
规则/V1.2-基础卡表.md
妖怪志/玉面狐狸/玉面狐狸.md
```

说明：玉面狐狸的单卡详细结算边界以其妖怪志为准。

---

## 测试目标

验证当前 4 人《抢地盘》基础版规则是否能够闭环运行。

重点观察：

1. 是否能正常开局、抽牌、招兵、抢地盘、使用法宝。
2. 是否能通过“控制同一妖域 3 块地盘”正常结束游戏。
3. 是否会出现死循环、无法结算或公共牌库耗尽后无法结束的问题。
4. 4 人局是否存在明显先手优势。
5. 地盘回流、中央地盘补充、洗地盘牌库是否可能造成实体操作负担。

## 模拟设置

模拟局数：

```text
3000局
```

玩家人数：

```text
4人
```

开局流程：

1. 洗混妖怪牌与法宝牌，组成公共牌库。
2. 每名玩家从公共牌库抽 5 张作为起手牌。
3. 洗混 12 张地盘牌，组成地盘牌库。
4. 翻开 3 张地盘，作为中央地盘区。
5. 随机先手。

回合流程：

1. 抽 1 张牌。
2. 执行 1 个主要行动。
3. 结算行动。
4. 结束阶段。

主要行动：

```text
招兵
抢地盘
使用法宝
不行动直接结束
```

---

## AI 行为模型

本次 AI 为规则验证型 AI，不是强竞技 AI。

基础策略：

1. 优先完成同妖域 3 块地盘。
2. 优先阻止其他玩家完成同妖域 3 块地盘。
3. 优先抢能成功的地盘。
4. 优先打出高星妖怪。
5. 优先使用强法宝。
6. 抢地盘时优先选择能清空目标地盘的出兵组合。
7. 无法形成有效行动时结束回合。

## 胜率分布观察

| 玩家顺位 | 胜率观察 |
|---:|---:|
| 1号位 | 约22% |
| 2号位 | 约24%~25% |
| 3号位 | 约26%~27% |
| 4号位 | 约26%~27% |

测试观察：

```text
当前 4 人基础版没有明显先手优势。
```

反而存在轻微后位优势。

可能原因：

1. 中央地盘区只公开 3 块地盘。
2. 前位玩家更容易先占地，但目标更早暴露。
3. 后位玩家更容易观察局势，选择抢关键妖域。

当前偏差不大，暂不建议因此修改规则。

## 闭环判断

当前 4 人基础版规则可以闭环运行。

已经验证：

```text
能开局
能抽牌
能招兵
能抢地盘
能使用法宝
能结算战斗
能触发地盘回流
能补中央地盘
能通过同妖域3块地盘立即获胜
没有模拟死局
```

公共牌库耗尽结算目前更像兜底规则。

在本轮 3000 局模拟中，大多数游戏在公共牌库还剩约 15~16 张时已经结束。

## 主要风险观察

### 1. 地盘回流较频繁

当前规则允许玩家从一个地盘派出全部守军抢地盘。

如果出兵后原地盘没有守军，该地盘会按地盘回流规则放回地盘牌库并重洗。

风险：

```text
地盘经常回库
中央地盘经常补牌
桌面变化频繁
实体试玩时需要反复洗地盘牌库
```

模拟结论：

```text
规则可闭环，但实体操作频率需要试玩验证。
```

实体试玩重点观察：

1. 地盘回流是否让游戏更热闹。
2. 地盘回流是否让玩家觉得操作繁琐。
3. 反复补中央地盘是否影响节奏。
4. 玩家是否能清楚理解“全部出兵后出兵地回流”。

### 2. 玉面狐狸结算边界已确认

当前卡面文案：

```text
让牛魔王驻守你的地盘1回合。
```

结算确认：

```text
牛魔王来源为场上已有的牛魔王守军。
不是从手牌、公共牌库、弃牌堆额外打出。
不是临时生成新的牛魔王。
```

本次模拟修正后，玉面狐狸不再视为“未完整结算”风险。

仍需实体试玩观察：

```text
玩家是否能理解“借场上牛魔王守军”这一关系型技能。
```

### 3. 金刚琢在基础版有存在意义

金刚琢当前基础版规则为反制法宝。

它可以取消其他玩家打出的法宝，且不占用主要行动。

模拟中主要用于反制：

```text
芭蕉扇
幌金绳
紫金红葫芦
```

结论：

```text
金刚琢在4人基础版中有存在意义。
```

它不同于双人对战 V0.1 中的暂不支持状态。

### 4. 芭蕉扇强，但暂不失控

芭蕉扇效果：

```text
吹回1块地盘中的所有守军。
```

基础版中，芭蕉扇很强，但没有在模拟中造成不可闭环或明显失衡。

原因：

```text
基础版有12块地盘
4人混战会互相制衡
地盘回流会重新打开局势
芭蕉扇清空1块地盘不等于清空全部战场
```

结论：

```text
芭蕉扇仍应作为基础版重点测试牌保留。
```

### 5. “答应后”类技能影响不大

对“喊一名玩家；答应后”类技能测试了不同答应概率。

观察：

| 答应概率 | 平均回合观察 |
|---:|---:|
| 100% | 约23.2回合 |
| 50% | 约22.1回合 |
| 0% | 约22.1回合 |

结论：

```text
答应类技能主要提供欢乐互动，不是当前胜负结构核心。
```

## 当前结论

```text
4人基础版规则基本闭环，可进入实体试玩。
```

当前不建议修改核心胜利条件。

当前不建议因为模拟结果调整基础卡牌数量。

当前最需要实体试玩验证的是：

```text
地盘回流频率
中央地盘补充频率
玉面狐狸玩家理解成本
芭蕉扇实际桌面体验
4人局是否符合15~30分钟目标
```

---

## 下一步建议

1. 用实体测试版进行 4 人试玩。
2. 每局记录：
   - 实际耗时
   - 回合数
   - 地盘回流次数
   - 中央地盘补牌次数
   - 是否因同妖域3地盘获胜
   - 是否进入公共牌库耗尽结算
3. 观察玉面狐狸是否会被玩家误解为“额外生成牛魔王”。
4. 若地盘回流造成明显繁琐，再考虑是否调整“全部出兵后原地盘回流”的说明或流程提示。
