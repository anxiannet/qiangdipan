## 测试目的

验证 2 人局是否可以使用更小地盘牌库：

```text
2个妖域
每个妖域3张地盘
共6张地盘
胜利条件不变：控制同一妖域3块地盘立即获胜
```

重点观察：

```text
2人局是否明显缩短
是否仍能通过同妖域3地盘正常获胜
42张牌库是否仍容易空库
中央2张与中央3张哪个更适合2人局
是否因地盘过少导致过快结束
```

## 关键发现

### 1. 2人6地盘可以稳定跑通

四组测试全部几乎通过同妖域3地盘结束：

```text
58张中央2张：3000 / 3000局直接胜利
58张中央3张：3000 / 3000局直接胜利
42张中央2张：2999 / 3000局直接胜利
42张中央3张：3000 / 3000局直接胜利
```

### 2. 游戏明显变短

2人12地盘平均约25~27个玩家回合。

2人6地盘平均约8~10个玩家回合。

这说明 6地盘非常适合做“双人快速局”，但可能太快，不一定适合作为默认2人完整体验。

### 3. 42张空库压力被明显降低

2人12地盘下，42张有 98 / 3000 局进入公共牌库耗尽结算。

2人6地盘下：

```text
中央2张：1 / 3000局进入公共牌库耗尽结算
中央3张：0 / 3000局进入公共牌库耗尽结算
```

说明如果2人局使用6地盘，42张牌库在空库方面基本没有问题。

### 4. 中央3张比中央2张更快

中央3张会让可抢目标更早出现，因此平均回合更短：

```text
58张：中央3张 9.10回合，中央2张 10.21回合
42张：中央3张 8.52回合，中央2张 9.56回合
```

但中央3张等于开局翻出6张地盘的一半，信息过多，目标暴露更早。

## 当前判断

```text
2人双妖域6地盘变体可行。
```

但它更适合作为：

```text
双人快速局
```

不建议直接替代基础版 2~4 人通用规则。

理由：

1. 平均8~10个玩家回合，节奏非常快。
2. 可能适合教学、短局、快速体验。
3. 但作为完整2人体验可能过短。
4. 6地盘变化度低于12地盘。
5. 中央3张会让目标过早暴露。

---

## 推荐方案

若要加入规则文档，建议作为可选变体：

```text
双人快速局
玩家：2人
地盘牌库：随机选2个妖域，共6张地盘
中央地盘：翻开2张
胜利条件：控制同一妖域3块地盘立即获胜
公共牌库：仍使用基础公共牌库
```

推荐中央地盘使用2张，而不是3张。

原因：

```text
中央2张比中央3张略慢一点
目标暴露没那么快
更适合2人对抗节奏
仍然可以稳定收束
```

---

## 结论

本轮测试结论：

```text
2人使用2个妖域6张地盘可以跑通，而且非常快。
中央2张更适合作为双人快速局。
58张与42张在该变体下都能稳定收束。
如果目标是快速教学/短局体验，可以考虑加入“双人快速局”可选规则。
```
