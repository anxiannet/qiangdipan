# 前线干员｜规则变体

## 当前建议

可保留《抢地盘》的区域控制骨架，但不建议完全照搬所有规则表达。

## 术语映射

| 原版 | 前线干员 |
|---|---|
| 妖怪 | 干员 / Operator |
| 法宝 | 战术装备 / Tactical Gear |
| 地盘 | 目标点 / Objective |
| 妖域 | 战区 / Sector |
| 抢地盘 | 控制目标点 |
| 控制同域3地盘 | 完成战区控制 |

## 胜利句

```text
控制同一战区的3个目标点，立即赢得行动胜利。
```

英文：

```text
Control all 3 Objectives in one Sector to win the operation.
```
