# 黑区回声｜规则变体

## 当前建议

可作为半独立规则变体，保留三点控制结构。

## 术语映射

| 原版 | 黑区回声 |
|---|---|
| 妖怪 | 回声猎人 / 同伴 |
| 法宝 | 回声装备 / 稳定装置 |
| 地盘 | 回声节点 |
| 妖域 | 回收区 |
| 抢地盘 | 抢占回声节点 |
| 控制同域3地盘 | 完成回声回收链 |

## 三点结构

```text
Echo Trace 回声痕迹
Echo Core 回声核心
Extract Gate 撤离门
```

## 胜利句

```text
控制同一回收区的痕迹点、核心点与撤离点，完成回声回收并获胜。
```
