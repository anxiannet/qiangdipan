# 裂境灵伴｜视觉设计

## 视觉关键词

```text
东方灵兽
灵械核心
半可爱半酷
信标栖境
符印纹路
青蓝能量
小型守护灵
机械狐 / 灵鹿 / 云鸟 / 龟甲兽 / 麒麟幼体
```

## 避免方向

必须避开：

```text
红白捕捉球
宝可梦式黄电鼠
御三家结构
三段进化视觉
宝可梦图鉴编号表达
机械恐龙式 Horizon 风格
```

## 角色方向

灵伴应体现“伙伴感”，不做纯战斗怪兽。

推荐：

- 小型灵伴：灵狐、灯灵、纸鸢兽、机械猫。
- 中型灵伴：灵鹿、青鸟、龟甲兽、风犬。
- 高星灵伴：麒麟、龙形灵械、守护兽、星核灵伴。

## UI方向

卡框可更明亮，适合亲子、女性玩家和收藏感。
