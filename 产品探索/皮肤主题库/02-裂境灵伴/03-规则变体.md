# 裂境灵伴｜规则变体

## 当前建议

可作为《抢地盘》同规则换皮，也可后续发展为更偏收集感的轻规则版本。

当前先不修改规则，仅做术语映射。

## 术语映射

| 原版 | 裂境灵伴 |
|---|---|
| 妖怪 | 灵伴 / Companion |
| 法宝 | 装具 / Charm Gear |
| 地盘 | 生命信标 / Habitat Beacon |
| 妖域 | 栖境 / Habitat Zone |
| 抢地盘 | 争夺信标 |
| 控制同域3地盘 | 稳定完整栖境 |

## 胜利句

中文：

```text
控制同一栖境的3座生命信标，立即获胜。
```

英文：

```text
Control all 3 Habitat Beacons in one Habitat Zone to win immediately.
```
