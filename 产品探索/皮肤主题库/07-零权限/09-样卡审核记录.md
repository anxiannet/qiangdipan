## 一、主题命名当前口径

当前样卡视觉中，中文产品名建议采用：

```text
归零者
```

英文产品名建议保留：

```text
ZERO ACCESS
```

说明：

```text
“零权限”更像世界观概念与起点状态。
“归零者”更像产品名、阵营名与包装标题。
```

推荐当前口径：

| 用途 | 中文 | 英文 |
|---|---|---|
| 产品名 / 皮肤名 | 归零者 | ZERO ACCESS |
| 世界观状态 | 零权限 | Zero Access |
| 玩家小队 | 归零者小队 / 零权限小队 | Zero Crew |
| 最高目标 | 根权限 | Root Access |

## 二、样卡：蜂鸟巢 / Hummingbird Hive

### 当前状态

```text
样卡类型：权限节点 / 横版地盘牌
当前最佳版本：蜂鸟巢完整卡牌正面 v3
审核状态：方向通过，待人工排版印刷版
```

### 通过点

```text
1. 横版权限节点卡形态成立。
2. 明亮白蓝科技风适合CMYK实体印刷方向。
3. 蜂鸟无人机、蜂巢穹顶、无人机域三者关系清楚。
4. Access Denied → Access Granted 的权限夺取氛围有效。
5. D1-D2-D3 与 Root Access 胜利提示清楚。
```

### 仍需微调

```text
1. 底部规则区可再压缩。
2. 规则文案建议定为：控制此节点：查看节点牌库顶1张，可置顶或置底。
3. 左下品牌角标可再缩小，避免抢规则区。
4. Access Denied / Granted 可降低透明度，作为氛围而不是主信息。
5. AI生成文字不能直接进入印刷终稿，后续必须人工重排。
```

### 建议留档名

```text
蜂鸟巢-完整卡牌正面-v3-方向通过
```

## 三、样卡：跑线侦察员 / Trace Runner

### 当前状态

```text
样卡类型：1星执行者 / 竖版角色牌
当前最佳版本：跑线侦察员执行者卡 v2
审核状态：方向通过，成品未通过
```

### 通过点

```text
1. 竖版执行者卡形态成立。
2. 已删除无人机域、D1-D2-D3、Root Access 等地盘牌信息。
3. 角色主体占比足够，符合执行者卡方向。
4. 明亮未来科技风延续了归零者视觉基调。
5. “入场”触发词正确，图标技能表达方向清楚。
6. 角色有奔跑、侦察、越权接入的动作感。
```

### 主要问题

```text
1. 角色略显过强，像3星或4星主角，不够1星底层执行者。
2. 左上星级信息视觉权重偏高，可缩小。
3. 底部图标区略像教学卡，图标下说明文字偏多。
4. “归零者 / ZERO ACCESS / ZERO CREW / EXECUTOR”的层级需要固定。
```

### v3修改方向

```text
1. 保留明亮白蓝风格、奔跑动作、无人机辅助、高塔路线。
2. 降低角色高级感：装甲减少，装备更轻便，衣服更像拼装外套。
3. 增加临时线路包、便携终端、廉价护目镜、底层工具感。
4. 星级区缩小，把视觉重点留给卡名与人物。
5. 技能区压缩为：入场：查看节点牌库顶1张，可置顶或置底。
6. 图标表达保持：[入场] [节点牌库顶1] → [查看] → [置顶/置底]。
```

### 建议留档名

```text
跑线侦察员-执行者卡-v2-方向通过待降级
```
