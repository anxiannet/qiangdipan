# 零权限｜规则变体

## 当前建议

可作为《抢地盘》规则引擎的强主题换皮，也可后续发展为独立规则版本。

优先先做同规则映射，验证主题吸引力。

## 术语映射

| 原版 | 零权限 |
|---|---|
| 妖怪 | 执行者 / Runner / Operator |
| 法宝 | 越权模块 / Override Gear |
| 地盘 | 权限节点 / Access Node |
| 妖域 | 系统域 / System Domain |
| 抢地盘 | 破解 / 接管权限节点 |
| 控制同域3地盘 | 获得 Root Access |

## 胜利句

中文：

```text
控制同一系统域的3座权限节点，立即获得 Root Access 并获胜。
```

英文：

```text
Control all 3 Access Nodes in one System Domain to gain Root Access and win.
```

## 系统域建议

```text
门禁域 Access Domain

```

玩家不是抢物品，而是抢控制现实的权限。
