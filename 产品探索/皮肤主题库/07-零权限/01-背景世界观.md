# 零权限｜背景世界观

> 主题定位：系统弃民、权限节点、Root Access 夺权。
>
> 当前推荐优先级：第一优先。

## 核心背景

未来城市不再由法律、现金或武力直接统治，而是由“权限系统”统治。

门禁、交通、医疗、货币、无人机、住房、武器、身份档案，全部接入同一套城市权限网络。拥有权限的人可以进入高塔，调用医疗舱，远程控制设备，清除债务，甚至让巡逻无人机为自己开路。

而失去权限的人，连自己的名字都无法证明。

他们无法开门，无法买药，无法搭乘列车，无法进入住所，也无法通过任何身份验证。系统不会逮捕他们，因为系统已经从档案里删除了他们。

他们被称为“零权限者”。

但在城市底层，零权限者并没有消失。他们组建小队，改装设备，偷接废弃线路，驯服蜂鸟无人机，穿上机修装甲，在高塔阴影下争夺一个个权限节点。

每个系统域都由三座关键节点构成。控制同一系统域的三座权限节点，即可获得该系统的 Root Access。

## 玩家身份

玩家扮演一支零权限小队的首领。

## 起点与目标

```text
起点：零权限
目标：根权限 / Root Access
爽点：从系统弃民，变成系统主人
```

## 控制后的幻想

- 控制门禁域：整座城市的门、电梯、封锁线和安全通道都会为你打开。
- 控制医疗域：医疗舱会优先救你的同伴，拒绝敌人的急救请求。
- 控制无人机域：巡逻无人机、蜂鸟侦察机和空中炮塔都会改听你的指令。
- 控制信用域：你可以清除自己的债务，冻结敌人的账户，买下他们曾经站立的街区。
- 控制身份域：你可以恢复被删除的人，也可以封锁敌方权限。

## 核心口号

```text
从零权限，到根权限。
```

英文：

```text
From Zero Access to Root Access.
```
