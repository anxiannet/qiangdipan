# 皮肤主题库

> 文件定位：本目录用于集中管理《抢地盘》规则引擎的皮肤主题探索。
>
> 本目录中的内容均为备选方案，不修改《夕妖：抢地盘》当前规则、标准版卡表、《火云再起》扩展包或正式视觉规范。

---

## 目录结构原则

每个皮肤主题独立一个文件夹，统一包含以下内容：

```text
01-背景世界观.md
02-视觉设计.md
03-规则变体.md
04-卡表.md
05-卡牌插画.md
06-完整卡牌.md
```

说明：

- `背景世界观`：解释玩家身份、争夺理由、胜利后的幻想。
- `视觉设计`：记录美术方向、角色风格、UI与卡框方向。
- `规则变体`：记录是否完全沿用《抢地盘》规则，或仅保留区域控制思想。
- `卡表`：仅维护该皮肤的映射或草案，不替代正式卡表唯一来源。
- `卡牌插画`：记录插画需求、提示词、审核状态或后续图片路径。
- `完整卡牌`：记录成品卡面、排版、导出文件或后续图片路径。

## 当前推荐优先级

```text
第一优先：归零者 / ZERO ACCESS
第二优先：裂境前线 / Riftfront
第三优先：裂境灵伴 / Riftbound
```

原因：

- `归零者`的玩家目标最直接：从零权限夺取 Root Access。
- `裂境前线`视觉气质较强，适合东方未来边境题材。
- `裂境灵伴`更接近宠物收集与家庭市场，但需要严格避开宝可梦表达资产。
