# 归零者｜样卡审核记录

> 文件定位：本文件用于记录 `归零者 / ZERO ACCESS` 第一批样卡的阶段性审核结论。
>
> 本文件只记录皮肤主题探索过程，不替代正式规则、正式卡表、正式技能文案或正式视觉规范。

---

## 一、主题命名当前口径

当前样卡视觉中，中文产品名采用：

```text
归零者
```

英文产品名保留：

```text
ZERO ACCESS
```

说明：

```text
“零权限”更像世界观概念与起点状态。
“归零者”更像产品名、阵营名与包装标题。
```

推荐当前口径：

| 用途 | 中文 | 英文 |
|---|---|---|
| 产品名 / 皮肤名 | 归零者 | ZERO ACCESS |
| 世界观状态 | 零权限 | Zero Access |
| 玩家小队 | 归零者小队 / 零权限小队 | Zero Crew |
| 最高目标 | 根权限 | Root Access |

## 二、当前卡面母设定

当前视觉方向已从“普通科幻插画卡”升级为“二维封存体卡牌”。

核心定义：

```text
《归零者》中的卡牌，不是普通印刷卡，
而是将执行者、越权模块与权限节点压缩封存后的二维权限载体。
调用一张卡，不是“打出一张牌”，
而是“释放一个被封存的战术实体”。
```

卡面应表现为：

```text
高科技封存载体
卡内压缩空间
透明封存层
空间折叠边缘
实体从二维介质中展开 / 释放
```

---

## 三、当前卡面文案原则

正式样卡卡面文字只保留四类信息：

```text
1. 卡名
2. 技能描述
3. 底边附近编号
4. 底边附近Logo
```

不再保留：

```text
职业标签长文
类型说明长文
系统域说明长文
连续图标技能链
右上角归零者品牌图标
过多英文装饰句
说明性副标题
```

图标仍可作为“释义徽章 / 识别徽章”存在，但不能回到教学图标链。

## 四、样卡：蜂鸟巢 / Hummingbird Hive

### 当前状态

```text
样卡类型：权限节点 / 横版地盘牌
当前最佳版本：蜂鸟巢-权限节点卡-封存体新版-v1
审核状态：方向通过，可作为新版权限节点卡基线
本地生成路径：/mnt/data/蜂鸟巢科技卡片设计.png
```

### 通过点

```text
1. 横版结构正确，仍然一眼是权限节点 / 地盘卡。
2. 蜂鸟巢主体足够大，场景中心明确。
3. D1 编号清楚，节点身份成立。
4. D1-D2-D3 进度保留得克制，没有长篇说明。
5. 底部大白区被替换为深色金属技能区，收藏感提升明显。
6. 卡框厚重，有高科技载体感。
7. 中央透明封存层有效，像城市节点被压缩封存在卡里。
8. 归零者 Logo 放在底边中央，识别度较好。
```

### 仍需微调

```text
1. 封存体概念还可以更强：增加二维压缩切片、空间折叠边缘、卡内玻璃封存层。
2. 技能文字建议压缩为：控制此节点：查看节点牌库顶1张，可置顶或置底。
3. 左下蜂鸟释义徽章略大，建议缩小10%–15%。
4. 右下小图标意义不够明确，建议改为无人机域徽章或D1-D2-D3小型进度徽章。
5. AI生成文字不能直接进入印刷终稿，后续必须人工重排。
```

### 建议留档名

```text
蜂鸟巢-权限节点卡-封存体新版-v1-方向通过
```

## 五、样卡：跑线侦察员 / Trace Runner

### 当前状态

```text
样卡类型：1星执行者 / 竖版角色牌
当前最佳版本：跑线侦察员执行者卡 v2
审核状态：早期方向通过，但需按新“二维封存体”母设定重做
```

### 通过点

```text
1. 竖版执行者卡形态成立。
2. 角色主体占比足够，符合执行者卡方向。
3. 明亮未来科技风延续了归零者视觉基调。
4. 角色有奔跑、侦察、越权接入的动作感。
```

### 后续重做方向

```text
1. 降低角色高级感：装甲减少，装备更轻便，衣服更像拼装外套。
2. 增加临时线路包、便携终端、廉价护目镜、底层工具感。
3. 强化人物被二维封存 / 从卡内释放的视觉。
4. 卡面文案只保留：卡名、技能描述、底边编号、底边Logo。
5. 不再使用连续图标技能链。
```

### 建议留档名

```text
跑线侦察员-执行者卡-v2-早期方向参考
```
