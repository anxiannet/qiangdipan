# 归零者｜语言版本策略

> 文件定位：本文件用于记录 `归零者 / ZERO ACCESS` 皮肤主题的语言版本策略。
>
> 本文件不替代正式规则书、正式卡面文案或正式发行策略。

---

## 一、结论

正式销售版不建议采用中英文完整混排一版。

推荐方案：

```text
中文版：中文为主，英文只保留品牌、卡名副标题、类型短词。
英文版：英文为主，不在规则区保留中文。
```

也就是：

```text
中英文各出一版。
不要把完整中英文规则塞进同一张实体卡。
```

---

## 二、当前新增决策：中英文共用边框

中英文各出一版，但必须共用同一套卡框和技能区版式。

```text
同一套卡框
同一套插画区
同一套标题区
同一套技能区高度
同一套品牌角标
只替换语言文本
```

技能区空间标准：

```text
中文版：留够 1 行中文规则。
英文版：留够 2 行英文规则。
```

图标语言不再作为技能区核心方案。

---

## 三、为什么不建议完整双语混排

实体卡尺寸有限，双语混排会带来以下问题：

```text
1. 规则区拥挤，降低可读性。
2. 小字号在CMYK印刷后容易糊。
3. 中文玩家不需要完整英文规则。
4. 英文玩家不需要完整中文规则。
5. 双语规则会让卡牌更像说明卡，而不是商品级卡牌。
6. 后续国际版、众筹页、规则书本地化都会更难管理。
```

---

## 四、中文版卡面语言层级

中文版正式卡面建议：

```text
中文卡名为主
英文卡名为副标题
中文规则为唯一规则文本
英文只作品牌与类型装饰
技能区控制为1行中文
```

### 示例：跑线侦察员

```text
跑线侦察员
TRACE RUNNER

底层执行者

入场：查看节点牌库顶1张，可置顶或置底。
```

可保留英文短词：

```text
ZERO ACCESS
EXECUTOR
TRACE RUNNER
ROOT ACCESS
```

不建议保留英文完整规则：

```text
On Play: Look at the top card of the Node Deck, then put it on top or bottom.
```

---

## 五、英文版卡面语言层级

英文版正式卡面建议：

```text
英文卡名为主
英文规则为唯一规则文本
中文不进入规则区
技能区允许2行英文
```

### Example: Trace Runner

```text
TRACE RUNNER

1st Tier Executor

On Play: Look at the top card of the Node Deck.
Put it on top or bottom.
```

中文名可以不出现。若为了收藏感保留中文名，必须很小，不进入规则区。

---

## 六、允许双语保留的区域

即使分中英文版，也可以保留少量双语元素增强产品识别：

| 区域 | 中文版 | 英文版 |
|---|---|---|
| 产品Logo | 归零者 / ZERO ACCESS | ZERO ACCESS |
| 卡名 | 中文主名 + 英文副名 | 英文主名，可不放中文 |
| 类型 | 执行者 / EXECUTOR | EXECUTOR |
| 核心胜利词 | ROOT ACCESS 可保留 | ROOT ACCESS |
| 规则区 | 中文1行 | 英文2行 |

## 八、图标与语言的关系

当前决策：图标语言不再作为卡面技能表达核心。

```text
文字表达规则
图标表达类型、系统域、状态和氛围
```

原因：

```text
如果图标不能完全替代文字，就不应继续占用技能区。
图标链 + 文字会让卡面像教学说明页，降低收藏感。
```

允许保留的图标用途：

```text
类型图标
系统域图标
状态图标
稀有度 / 星级图标
品牌与编号辅助
```

不再使用：

```text
[入场] [节点牌库顶1] → [查看] → [置顶/置底]
```

这种连续技能解释链。

## 九、发行建议

### 首轮实体测试

建议先做中文版：

```text
中文主版 + 少量英文品牌词
```

原因：

```text
当前项目主文档、规则讨论与卡表均为中文。
中文测试可以更快验证机制与视觉。
```

### 后续英文市场

若 `归零者 / ZERO ACCESS` 单独发展为国际版，再制作独立英文版卡面与英文规则书。

不要直接把中文版小字翻译后塞进同一张卡。

---

## 十、当前决策

```text
语言策略：中英文各出一版。
边框策略：中英文使用同一套边框和技能区尺寸。
当前样卡：先按中文主版制作。
技能区：中文1行，英文2行。
图标策略：不再使用图标技能链，只保留类型/状态/域识别符号。
规则区：不做完整双语。
```
