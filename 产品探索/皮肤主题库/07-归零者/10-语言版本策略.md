# 归零者｜语言版本策略

> 文件定位：本文件用于记录 `归零者 / ZERO ACCESS` 皮肤主题的语言版本策略。
>
> 本文件不替代正式规则书、正式卡面文案或正式发行策略。

---

## 一、结论

正式销售版不建议采用中英文完整混排一版。

推荐方案：

```text
中文版：中文为主。
英文版：英文为主。
中英文各出一版。
```

卡面文案进一步精简，只保留：

```text
1. 卡名
2. 技能描述
3. 底边附近编号
4. 底边附近Logo
```

---

## 二、中英文共用边框

中英文各出一版，但必须共用同一套卡框和技能区版式。

```text
同一套卡框
同一套插画区
同一套标题区
同一套技能区高度
同一套底边编号位置
同一套底边Logo位置
只替换语言文本
```

技能区空间标准：

```text
中文版：留够 1 行中文规则。
英文版：留够 2 行英文规则。
```

图标语言不再作为技能区核心方案。

---

## 三、为什么不建议完整双语混排

实体卡尺寸有限，双语混排会带来以下问题：

```text
1. 规则区拥挤，降低可读性。
2. 小字号在CMYK印刷后容易糊。
3. 中文玩家不需要完整英文规则。
4. 英文玩家不需要完整中文规则。
5. 双语规则会让卡牌更像说明卡，而不是商品级卡牌。
6. 后续国际版、众筹页、规则书本地化都会更难管理。
```

---

## 四、卡面保留信息

正式卡面只保留四类文字信息：

| 信息 | 位置 | 说明 |
|---|---|---|
| 卡名 | 顶部或画面主标题区 | 中文版用中文卡名，英文版用英文卡名 |
| 技能描述 | 底部技能区 | 中文1行，英文2行 |
| 编号 | 底边附近 | 如 TR-01、OM-01、D1 |
| Logo | 底边附近 | 归零者 / ZERO ACCESS |

---

## 五、卡面删除信息

不再在卡面上保留：

```text
职业标签长文
类型说明长文
系统域说明长文
防御型 / 执行者 / 越权模块等重复说明文字
连续图标技能链
右上角归零者品牌图标
过多英文装饰句
说明性副标题
```

说明：

```text
卡牌类型、星级、系统域等信息应主要通过卡框、颜色、编号、符号和视觉结构识别。
卡面文字只服务于“认牌”和“执行规则”。
```

## 六、中文版卡面语言层级

中文版正式卡面建议：

```text
中文卡名为主
中文规则为唯一规则文本
技能区控制为1行中文
底边保留编号与Logo
```

### 示例：跑线侦察员

```text
跑线侦察员

入场：查看节点牌库顶1张，可置顶或置底。

TR-01
归零者 / ZERO ACCESS
```

### 示例：离线地堡

```text
离线地堡

使用：保护你的1个权限节点，持续1回合。

OM-01
归零者 / ZERO ACCESS
```

## 七、英文版卡面语言层级

英文版正式卡面建议：

```text
英文卡名为主
英文规则为唯一规则文本
技能区允许2行英文
底边保留编号与Logo
```

### Example: Trace Runner

```text
TRACE RUNNER

On Play: Look at the top card of the Node Deck.
Put it on top or bottom.

TR-01
ZERO ACCESS
```

### Example: Offline Bunker

```text
OFFLINE BUNKER

Use: Protect 1 of your Access Nodes
for 1 round.

OM-01
ZERO ACCESS
```

## 九、图标与语言的关系

当前决策：图标语言不再作为卡面技能表达核心。

```text
文字表达规则
图标表达类型、系统域、状态和氛围
```

原因：

```text
如果图标不能完全替代文字，就不应继续占用技能区。
图标链 + 文字会让卡面像教学说明页，降低收藏感。
```

允许保留的图标用途：

```text
类型图标
系统域图标
状态图标
稀有度 / 星级图标
品牌与编号辅助
```

不再使用：

```text
[入场] [节点牌库顶1] → [查看] → [置顶/置底]
```

这种连续技能解释链。

## 十、发行建议

### 首轮实体测试

建议先做中文版：

```text
中文主版
```

原因：

```text
当前项目主文档、规则讨论与卡表均为中文。
中文测试可以更快验证机制与视觉。
```

### 后续英文市场

若 `归零者 / ZERO ACCESS` 单独发展为国际版，再制作独立英文版卡面与英文规则书。

不要直接把中文版小字翻译后塞进同一张卡。

---

## 十一、当前决策

```text
语言策略：中英文各出一版。
边框策略：中英文使用同一套边框和技能区尺寸。
当前样卡：先按中文主版制作。
卡面文案：只保留卡名、技能描述、底边附近编号、底边附近Logo。
技能区：中文1行，英文2行。
图标策略：不再使用图标技能链，只保留类型/状态/域识别符号。
规则区：不做完整双语。
```
