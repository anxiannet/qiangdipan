# 零权限｜规则变体

## 当前建议

可作为《抢地盘》规则引擎的强主题换皮，也可后续发展为独立规则版本。

当前优先作为同规则映射，验证主题吸引力。

```text
核心规则不变
胜利条件不变
卡牌数量不变
技能效果不变
仅替换术语、卡名、插画、世界观与包装表达
```

---

## 二、胜利句

中文：

```text
控制同一系统域的3座权限节点，立即获得 Root Access 并获胜。
```

英文：

```text
Control all 3 Access Nodes in one System Domain to gain Root Access and win.
```

## 三、首版系统域

首版固定 4 个系统域，对应原版 4 个妖域。

```text
门禁域 Access Domain
医疗域 Medical Domain
无人机域 Drone Domain
信用域 Credit Domain
```

`身份域 Identity Domain` 暂不进入首版，作为扩展包或独立规则候选。

## 五、玩家对抗理由

每个系统域同一时间只能存在一个 Root Access。

一名玩家完成同一系统域三座权限节点控制后，即获得该系统域的最高权限。其他玩家不只是输掉一个地点，而是被该系统域降权、封锁或排除。

对抗理由：

```text
同一个系统域只承认一个最高权限。
别人先获得 Root Access，你就会被系统踢出去。
```

## 六、可选规则变体候选

以下内容仅作未来独立规则候选，暂不进入同规则换皮首版。

### 权限警报轨

```text
每次使用带有“警报”图标的越权模块，权限警报 +1。
警报达到上限时，系统清场，未获得 Root Access 的玩家进入结算或失败。
```

### 身份域扩展

```text
新增身份域 Identity Domain。
控制身份域后，可恢复被删除的执行者，或封锁敌方执行者的权限。
```

### Root Token

```text
控制完整系统域后，获得 Root Token。
Root Token 可作为实体指示物，表示该系统域已被接管。
```

## 七、核心体验

玩家不是抢物品，而是抢控制现实的权限。

```text
系统不给你权限，你就夺取 Root Access。
```
