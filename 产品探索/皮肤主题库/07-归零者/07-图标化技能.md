# 零权限｜图标化技能

> 文件定位：本文件用于记录 `零权限 / Zero Access` 皮肤主题的图标化技能表达草案。
>
> 本文件不替代正式技能唯一来源。正式技能效果仍以 `规则/V1.3-基础卡表.md` 与 `规则/扩展包一-火云再起卡表.md` 为准。

---

## 一、图标化原则

```text
图标表达规则含义
短文表达确认语义
不新增技能
不改变强度
不改变目标限制
```

每张牌尽量采用：

```text
触发 / 目标 / 效果
```

格式示例：

```text
[入场] [权限节点牌库顶1] → [查看] [置顶/置底]
```

## 五、图标化检查清单

成品卡制作前检查：

```text
1. 同一动作是否始终使用同一图标。
2. [消灭] 与 [吹回] 是否视觉差异明显。
3. [加入手牌] 与 [加入节点] 是否不混淆。
4. [节点牌库] 与 [公共牌库] 是否不混淆。
5. 星级限制是否一眼可读。
6. 触发时机是否统一放在技能最左侧。
7. 极短文案是否仍能独立理解。
```
