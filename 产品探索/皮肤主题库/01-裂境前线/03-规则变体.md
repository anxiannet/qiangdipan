# 裂境前线｜规则变体

## 当前建议

优先作为《抢地盘》同规则换皮方案。

```text
核心规则不变
胜利条件不变
卡牌数量不变
技能效果不变
仅替换术语、卡名、插画与包装表达
```

## 术语映射

| 原版 | 裂境前线 |
|---|---|
| 妖怪 | 巡守者 / Warden |
| 法宝 | 灵械装置 / Relic-Tech Gear |
| 地盘 | 信标 / Beacon |
| 妖域 | 裂境区 / Frontier Zone |
| 抢地盘 | 夺取信标 |
| 控制同域3地盘 | 接管完整裂境区 |

## 胜利句

中文：

```text
控制同一裂境区的3座关键信标，立即获胜。
```

英文：

```text
Control all 3 Beacons in the same Frontier Zone to win immediately.
```
