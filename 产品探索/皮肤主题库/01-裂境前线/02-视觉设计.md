# 裂境前线｜视觉设计

## 视觉关键词

```text
东方未来
轻机甲
灵械装甲
裂境废墟
边境信标
狐灵图腾
青蓝能量
黑白陶瓷装甲
高科技遗迹
巡守者小队
```

## 角色方向

- 巡守者 / Warden
- 引路者 / Wayfinder
- 灵械战员 / Relic-Tech Operator
- 机甲骑士 / Frame Knight
- 边境医生 / Frontier Medic
- 无人机侦察员 / Drone Scout

## 地点方向

地盘视觉不做普通军事据点，改为“信标 / 锚点”。

每张地盘应表现：

```text
能量核心
阵台结构
边境废墟
光柱 / 信号环
可被争夺的控制装置
```

## UI方向

- 卡框：东方符纹 + 科技HUD混合。
- 主色：冷白、黑、青蓝、少量红色警示。
- 星级：可改为作战等级或灵械等级，但仍保留星形直觉。
