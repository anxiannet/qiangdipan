## 二、主题方向

### 游戏名

```text
暗线
ANXIAN
```

### 域名

```text
anxian.net
```

### 一句话定位

```text
部署高科技装备，占领营地，连成暗线。
```

英文口径：

```text
Deploy tech gear, claim camps, and complete a hidden line.
```

### 主题核心

《暗线》不做“妖怪换士兵”，而是做：

```text
妖怪能力 → 高科技装备功能
```

也就是说，原本的妖怪牌在《暗线》中统一映射为：

```text
侦查无人机
战术终端
干扰系统
重型平台
战略级装备
```

这样可以保留原技能逻辑，同时让科幻题材更直观。

### 胜利口径

中文：

```text
控制同一条暗线上的3座营地，立即获胜。
```

英文：

```text
Control all 3 Camps on the same Line to win immediately.
```

### 抢营地的理由

```text
每座营地都是路线节点。
三座营地连成一条完整暗线。
控制整条暗线，就掌握穿越边境的通路、补给与安全权。
```
