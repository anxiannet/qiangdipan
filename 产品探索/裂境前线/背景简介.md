## 二、背景简介

未来东方文明进入“灵械纪元”后，人类不再只依赖钢铁与算法，而是将古老图腾、灵能遗迹与高维科技融合，创造出被称为“灵械”的新型装甲与战术系统。

这本该是一个秩序重建的时代。

直到“裂境”出现。

裂境是一种撕裂现实边界的异常区域。它吞没道路，扭曲通讯，污染能源，也会在废墟中留下无法解释的信号与遗迹。城市之间的连接被切断，边境地带变得危险而混乱。

为了维持通路、补给、防护与通讯，人类在裂境边缘建立了一座座“信标”。

信标不是普通据点。

它们是维系边境秩序的核心节点。

每一个裂境区，都由三座关键信标组成：一座引导道路，一座稳定能源，一座维持防护。只要控制同一区域的三座信标，就能接管整片边境的通行权、补给线与防御系统。

于是，各方巡守者小队开始进入裂境前线。

他们有的是方舟城邦派出的灵械战员，有的是边境遗民组成的游猎小队，有的是掌握旧时代技术的机甲骑士，也有的是与狐灵、兽形无人机、残存 AI 共生的特殊个体。

他们争夺信标，不只是为了胜利。

而是为了决定这片边境由谁守护，由谁通行，由谁重建秩序。

在裂境蔓延的世界里，控制三座信标，就等于掌握一整个区域的命运。

## 六、视觉方向

参考方向：

```text
东方未来
轻机甲
灵械
青蓝能量
黑白装甲
狐灵图腾
边境废墟
圆形阵台
信标残碑
高科技遗迹
巡守者小队
```

本方向不建议做成传统硬核军事战争，也不建议做成纯美少女机甲。

推荐定位为：

```text
东方未来边境巡守者题材
```

它需要同时满足：

```text
男性玩家：机甲、战术、对抗、据点控制、装备感
女性玩家：角色关系、守护者身份、边境旅人感、东方审美、世界神秘感
```

视觉表达重点：

```text
角色好看，但不是花瓶。
机甲酷，但不是纯军武。
世界有末世边境感，但不能过度灰暗。
信标、裂境、狐灵、灵械装置要形成统一识别。
```

## 七、题材吸引力

该方案的吸引力不只是“机甲好看”，而是提供一种明确幻想：

```text
我操控的是东方未来边境中的机甲巡守者。
我在裂境废墟中争夺决定秩序的关键锚点。
我的角色不是普通士兵，而是带图腾、灵火、无人机、轻机甲的守望者。
```

这比普通未来战争更适合《抢地盘》换皮，因为它让“抢地盘”有更充分的世界观理由：

```text
争夺信标 = 争夺道路、补给、防护、通讯与边境秩序。
控制同一区域3座信标 = 完整接管一个裂境区。
```
