# 铁扇公主

## 基础信息

| 项目 | 内容 |
|---|---|
| 世界观档位 | 3 档 |
| 星级 | 2 星 |
| 战力 | 2 |
| 类型 | 洞主 |
| 来源/归属 | 芭蕉洞 |
| 技能状态 | 待审核 |

## 背景

铁扇公主当前按 3 档洞主处理，为 2 星。她的牌面与芭蕉扇关系极强，但法宝芭蕉扇已经单独承担 100 分锚点。

## 小传

铁扇公主应体现“会扇风、能把守军吹回去”，但不能直接复制法宝芭蕉扇的整地盘压制。

## 候选技能详细描述

候选规则效果：

```text
选择 1 块地盘，将其中 1 只守军吹回拥有者手牌。
```

卡面候选文案：

```text
吹回1只守军，回到拥有者手牌。
```

## 设计理由

候选效果把芭蕉扇的“大范围吹回”压缩为单体吹回，既保留代入感，又避免 2 星角色过强。

## 强度分析

| 项目 | 评价 |
|---|---|
| 主要作用对象 | 任意守军 |
| 受影响战力 | 1~3 |
| 牌区去向 | 回到拥有者手牌 |
| 技能强度评分 | 64 |
| 世界观符合度评分 | 84 / 100 |
| 技能评级 | B+ |

评分理由：可处理 3 星守军但不消灭，资源仍回到拥有者手牌。作为 2 星候选技能偏强，需重审。

## 与其他妖怪的关系

- 与牛魔王、红孩儿、玉面狐狸属于火云 / 积雷山关系网。
- 与法宝芭蕉扇强关联，但必须区分角色技能与法宝效果。

## 羁绊

候选羁绊方向：芭蕉洞、火云家族、借扇生风。

## 互动

单体吹回清楚易懂，适合制造“关键守军被吹走”的桌面瞬间。

## 连锁

若吹回最后 1 只守军，可能间接导致地盘无主。

## 视觉形象设计

- 芭蕉洞洞主、扇风姿态、华丽但不压过法宝芭蕉扇。
- 角色手中可出现扇影，但法宝卡应表现更夸张的场景级风暴。
