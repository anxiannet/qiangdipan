# 银角大王

| 世界观档位 | 3 档 |
| 星级 | 2 星 |
| 战力 | 2 |

| 来源/归属 | 平顶山莲花洞 |
| 技能状态 | 待审核 |

## 背景

银角大王与金角大王同属莲花洞知名妖王，当前按 3 档普通妖王处理，为 2 星。

## 小传

银角大王应与金角大王形成组合，但不完全重复。金角负责控地盘牌库，银角负责控公共牌库，形成清晰的兄弟分工。

## 候选技能详细描述

候选规则效果：

```text
查看公共牌库顶 3 张牌，将它们按任意顺序放回公共牌库顶。
```

卡面候选文案：

```text
盘库点将，查看公共牌库顶3张，按任意顺序放回。
```

## 设计理由

优先级 1：代入感来自莲花洞妖王盘点妖怪、法宝与手下资源的感觉。

优先级 2：好玩有趣。玩家可以看到接下来 3 张公共牌，并调整顺序，形成明确选择。

优先级 3：强度可控。它只调整公共牌库顶 3 张，不检索任意牌，也不直接获得牌，因此低于金角大王的地盘牌库任意检索。

## 强度分析

| 项目 | 评价 |
|---|---|
| 主要作用对象 | 公共牌库 |
| 动作 | 查看顶 3 张 + 调整顺序 |
| 受影响战力 | 0 |
| 是否直接改变资源 | 否 |
| 是否影响地盘控制 | 否，间接影响公共牌资源节奏 |
| 是否突破行动节奏 | 否 |
| 技能强度评分 | 42 |
| 世界观符合度评分 | 82 / 100 |
| 技能评级 | A- |

评分理由：查看后调整牌序的标准参考约 38；银角影响公共牌库顶 3 张，信息量与调整空间更高，但不直接获得资源，建议评为 42。

## 与其他妖怪的关系

- 与金角大王形成核心组合：金角控地盘牌库，银角控公共牌库。
- 与精细鬼形成层级：精细鬼只看公共牌库顶 1 张并可顶 / 底，银角看顶 3 张并排序。
- 与莲花洞小妖形成上下级关系。

## 羁绊

候选羁绊方向：金银兄弟、莲花洞盘库、点将排阵、公共牌库操控。

当前羁绊未定稿。

## 互动

- 玩家可以为自己安排后续抽到的公共牌顺序。
- 也可能把短期不想让别人摸到的牌排到后面。
- 多人局中会产生“银角看到了什么牌”的心理博弈。

## 连锁

- 与公共牌库抽牌节奏联动。
- 不直接改变公共牌库数量。
- 不直接触发地盘回流或地盘控制变化。

## 视觉形象设计

- 银色角饰，与金角形成强对比。
- 妖王气质但保持 2 星尺度。
- 可加入莲花洞、令牌、宝册、牌架、宝光元素。
- 画面可以表现他在挑选妖怪牌、法宝牌或安排队伍顺序。
