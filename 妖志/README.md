# 妖志

## 文件定位

本目录用于维护《夕妖：抢地盘》基础版每个妖怪的详细设计资料。

基础卡表只保留索引用信息：

- 卡牌名称
- 数量
- 世界观档位
- 星级
- 战力
- 类型
- 卡面文案
- 技能强度评分
- 世界观符合度评分
- 技能评级
- 审核状态
- 妖志链接

以下详细内容统一维护在本目录对应妖怪文档中：

- 背景
- 小传
- 候选技能详细描述
- 设计理由
- 强度分析
- 与其他妖怪的关系
- 羁绊
- 互动
- 连锁
- 视觉形象设计

## 维护原则

1. 每个妖怪一篇文档。
2. 不在基础卡表写长篇技能解释。
3. 不在视觉文件重复维护规则。
4. 若技能调整，先修改对应妖志，再同步基础卡表中的卡面文案、评分、评级与审核状态。
5. 法宝暂不纳入妖志，后续可另建 `法宝志/`。
