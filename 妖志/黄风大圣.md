# 黄风大圣

## 基础信息

| 项目 | 内容 |
|---|---|
| 世界观档位 | 2 档 |
| 星级 | 3 星 |
| 战力 | 3 |
| 类型 | 强妖王 / 强神通者 |
| 来源/归属 | 黄风岭 |
| 技能状态 | 待审核 |

## 背景

黄风大圣是黄风岭体系的强化风系角色，当前与黄风怪存在重复风险，需要审核是否保留双版本。

## 小传

如果保留黄风大圣，应表现为更强的神风压制，而不是与黄风怪只差一点点的重复技能。

## 候选技能详细描述

候选规则效果：

```text
选择 1 块地盘，将其中 1 只 2 星以下守军吹回拥有者手牌。
```

卡面候选文案：

```text
吹回1只2星以下守军，回到拥有者手牌。
```

## 设计理由

比黄风怪能吹回更高星级目标，但仍不能处理 3 星妖王，形成中阶风系压制。

## 强度分析

| 项目 | 评价 |
|---|---|
| 主要作用对象 | 2 星以下守军 |
| 受影响战力 | 1~2 |
| 牌区去向 | 回到拥有者手牌 |
| 技能强度评分 | 58 |
| 世界观符合度评分 | 100 / 100 |
| 技能评级 | B+ |

评分理由：强于黄风怪，但不能处理 3 星，且回手保留资源。作为 3 星候选技能仍偏保守。

## 与其他妖怪的关系

- 与黄风怪、虎先锋同属黄风岭体系。
- 需要审核是否与黄风怪合并或重做差异。

## 羁绊

候选羁绊方向：黄风岭大圣、神风升级、风沙压阵。

## 互动

可让玩家感到中低星守军会被风吹散，但对 3 星仍有安全边界。

## 连锁

可能吹回关键 2 星守军，间接导致地盘失守。

## 视觉形象设计

- 比黄风怪更强烈的风沙法相。
- 可以更庄重、更大圣感，但仍需区分于大鹏精和芭蕉扇。
