# 大鹏精

## 基础信息

| 项目 | 内容 |
|---|---|
| 世界观档位 | 1 档 |
| 星级 | 3 星 |
| 战力 | 3 |
| 类型 | 顶级妖王 |
| 来源/归属 | 狮驼岭 / 狮驼国 |
| 技能状态 | 待审核 |

## 背景

大鹏精是 1 档顶级妖王，核心是速度、突袭、压迫感和机动性。

## 小传

大鹏精出场应让玩家感到局势突然加速。它适合承担“立即抢地盘”这种强节奏技能。

## 候选技能详细描述

候选规则效果：

```text
立即发动一次攻山。
```

卡面候选文案：

```text
立即发动一次抢地盘。
```

## 设计理由

代入感来自大鹏的速度和突袭。它不是慢慢铺场，而是突然发动攻击，改变地盘争夺节奏。

## 强度分析

| 项目 | 评价 |
|---|---|
| 主要作用对象 | 行动流程 / 地盘 |
| 受影响战力 | 取决于出兵地 |
| 是否突破节奏 | 是，额外抢地盘 |
| 技能强度评分 | 86 |
| 世界观符合度评分 | 100 / 100 |
| 技能评级 | A |

评分理由：额外抢地盘可能直接夺地，节奏爆发强，但仍需要场上已有可出兵地盘，不是空降。

## 与其他妖怪的关系

- 与青狮精同属狮驼岭 / 狮驼国体系。
- 可与小钻风形成“先探地盘，再突然抢地盘”的节奏链。

## 羁绊

候选羁绊方向：狮驼三王、极速突袭、风云压境。

## 互动

大鹏精应制造“他突然又抢一次”的桌面惊讶感。

## 连锁

可能配合高战力地盘产生直接胜利威胁，需要重点测试。

## 视觉形象设计

- 巨翼、俯冲、压迫感、天空阴影。
- 3 星顶级妖王气质，应有强速度感和巨大体型。
