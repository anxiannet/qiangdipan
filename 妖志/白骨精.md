# 白骨精

|---|---|
| 世界观档位 | 3 档 |

| 技能状态 | 待审核 |

## 背景

白骨精是白骨岭代表妖怪，当前按 3 档普通妖王 / 山主处理，为 2 星。

## 小传

白骨精核心不是正面战力，而是变化、伪装、窥探、欺骗。技能应体现“看穿对方”或“让对方误判”。

## 候选技能详细描述

候选规则效果：

```text
查看一名玩家手牌。
```

卡面候选文案：

```text
查看一名玩家手牌。
```

## 设计理由

代入感来自白骨精的变化与欺骗。查看手牌可以表现她识破、设局、窥探人心的一面。

## 强度分析

| 项目 | 评价 |
|---|---|
| 主要作用对象 | 玩家手牌信息 |
| 受影响战力 | 0 |
| 是否直接改变资源 | 否 |
| 技能强度评分 | 30 |
| 世界观符合度评分 | 84 / 100 |
| 技能评级 | B |

评分理由：只获得信息，不改变手牌数量、守军、地盘或行动节奏。降为 2 星后强度更合适，但趣味性需要重审。

## 与其他妖怪的关系

- 与白骨妖域地盘天然绑定。
- 可与信息型小妖形成侦查链。

## 羁绊

候选羁绊方向：白骨设局、三变迷惑、识破手牌。

## 互动

查看手牌会制造心理压力，但桌面爽感偏低，后续可考虑加入轻微“误导”效果增强趣味。

## 连锁

信息可辅助抢地盘与法宝判断，但不直接触发地盘回流。

## 视觉形象设计

- 白骨、幽雾、伪装美人、骷骨轮廓。
- 不应做成顶级大魔神，应是狡黠、阴森、会设局的 2 星妖王。
