## 背景

白骨精是白骨岭代表妖怪，当前按 3 档普通妖王 / 山主处理，为 2 星。

## 小传

白骨精核心不是正面战力，而是变化、伪装、白骨不散、死而复现。相比单纯查看手牌，她更适合通过“被消灭后不进弃牌堆”来表现三打三变、死后又回来的角色记忆点。

## 候选技能详细描述

规则效果：

```text
白骨精被消灭时，不进入弃牌堆，放回公共牌库并重洗。
```

卡面文案：

```text
白骨不散，被消灭时，放回公共牌库并重洗。
```

## 设计理由

优先级 1：代入感极强。白骨精最有记忆点的不是偷看，而是三次变化、被打倒后仍以另一种形式回来。

优先级 2：好玩有趣。玩家消灭白骨精后，她不会进入弃牌堆，而是回到公共牌库，制造“她还会回来”的桌面期待。

优先级 3：强度可控。该技能不立即产生战力收益，也不会直接夺地；只是让白骨精未来可能再次被抽到。

## 强度分析

| 项目 | 评价 |
|---|---|
| 主要作用对象 | 自身 / 公共牌库 |
| 动作 | 被消灭时回公共牌库并重洗 |
| 受影响战力 | 0 |
| 是否直接改变资源 | 否 |
| 是否影响地盘控制 | 间接影响 |
| 是否突破行动节奏 | 否 |
| 技能强度评分 | 34 |
| 世界观符合度评分 | 100 / 100 |
| 技能评级 | A |

评分理由：白骨精被消灭时不会进入弃牌堆，而是回到公共牌库并重洗，增加未来再次出现的概率。它不立即回手、不立即上场、不增加当前资源，强度低于直接回手或复活，但世界观符合度极高。

## 与其他妖怪的关系

- 与白骨妖域地盘天然绑定。
- 与红孩儿、青狮精、紫金红葫芦等消灭 / 收走类效果形成差异：别人被处理后通常离场，白骨精会回到公共牌库。
- 与精细鬼、银角大王等公共牌库技能有弱联动，可能在重洗后再次被看到或抽到。

## 互动

- 对手消灭白骨精时，会产生“她没有真的没了”的桌面反馈。
- 玩家可能在后续回合再次抽到白骨精，形成轻 TRPG 记忆点。
- 该技能不阻止白骨精被吹回手牌、绑走、收走等非消灭效果。

## 连锁

- 被消灭时进入公共牌库并重洗，不进入弃牌堆。
- 若白骨精被吹回手牌、加入手牌、加入地盘等，不触发该效果。
- 不直接触发地盘回流；地盘是否失去全部守军，仍按地盘回流规则独立结算。

## 视觉形象设计

- 白骨、幽雾、伪装美人、骷骨轮廓。
- 重点表现“白骨不散”和“死后复现”，可有碎骨重组、幽雾回卷、白骨影子重新站起的视觉线索。
- 不应做成顶级大魔神，应是狡黠、阴森、会死而复现的 2 星妖王。
