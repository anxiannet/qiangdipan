## 背景

小钻风是狮驼岭有名小妖，适合承担巡山、探路、报信、发现情况的桌面功能。

## 小传

他不是正面压场的大妖，而是跑在山路前面的小妖。玩家看到“小钻风”，应立刻想到“巡山探路”“先去看看前面有什么”。

## 候选技能详细描述

候选规则效果：

```text
当你打出小钻风时，查看地盘牌库顶 1 张牌。你可以将其放回牌库顶，或放到牌库底。
```

卡面候选文案：

```text
巡山探路，查看地盘牌库顶1张，可放回牌库顶或牌库底。
```

## 设计理由

优先级 1：代入感强。巡山小妖最自然的动作就是探路与报信。

优先级 2：好玩有趣。玩家看到地盘牌库顶牌后，可以决定保留还是送到底部，会制造轻微心理博弈。

优先级 3：强度可控。不直接获得地盘，不直接影响守军，不触发地盘回流。

## 强度分析

| 项目 | 评价 |
|---|---|
| 主要作用对象 | 地盘牌库 |
| 动作 | 查看 + 轻微牌序调整 |
| 受影响战力 | 0 |
| 是否影响地盘控制 | 间接影响 |
| 是否突破行动节奏 | 否 |
| 技能强度评分 | 30 |
| 世界观符合度评分 | 95 / 100 |
| 技能评级 | A |

评分理由：查看地盘牌库顶 1 张的基础价值约 22；允许放回牌库顶或牌库底，增加轻微牌序控制与玩家决策，建议评为 30。

## 与其他妖怪的关系

- 与狮驼岭体系关联，可为青狮精、大鹏精提供地盘节奏信息。
- 与伶俐虫、精细鬼同属“侦查型小妖”，但小钻风负责地盘信息。

## 羁绊

候选羁绊方向：

- 狮驼巡山：与狮驼岭妖怪同场时，可强化地盘信息判断。
- 报信小妖：为后续抢地盘制造预判。

当前羁绊未定稿。

## 互动

- 看到想要的妖域地盘，可放回牌库顶。
- 看到不想要的地盘，可放到牌库底。
- 多人局会制造“他到底看见了什么”的桌面猜测。

## 连锁

- 与中央地盘补充机制有弱联动。
- 不直接改变地盘牌库数量。
- 不直接改变地盘控制权。

## 视觉形象设计

- 小体型狮驼岭巡山小妖。
- 可以背小旗、铜锣、哨子或巡山木牌。
- 表情机灵，动作像在山路上探头观察。
- 画面重点是“跑腿报信”，不应画成正面大妖压迫感。
