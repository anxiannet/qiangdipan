# 《夕妖：抢地盘》成品卡牌合成系统

本目录用于将纯插画资产与统一UI卡框合成为完整卡牌正面，并生成统一卡背。

## 目录

- `正面/`：完整卡牌正面 PNG。
- `正面/试玩版/`：历史试玩版成品卡归档。
- `正面/基础版/`：基础版成品卡归档，不覆盖试玩版或旧正面图。
- `背面/`：统一卡背 PNG。
- `模板/`：UI模板规范与模板预览。
- `导出/`：批量导出辅助文件与总览图。
- `card_data.json`：卡牌合成数据。
- `生成完整卡牌.py`：Python + Pillow 合成脚本。
- `基础版成品卡生成流程规范.md`：基础版单卡成品生成与审核流程。

## 使用

在仓库根目录运行：

```bash
python3 卡牌成品/生成完整卡牌.py
```

脚本会读取：

- `卡牌成品/card_data.json`
- `视觉/批量生成/插画资产/`

输出：

- `卡牌成品/正面/`
- `卡牌成品/背面/`
- `卡牌成品/模板/card_front_template_preview.png`
- `卡牌成品/导出/all_cards_contact_sheet.png`

## 规则边界

本系统只做卡牌视觉合成，不修改规则、星级、数量或技能。

基础版成品卡的技能短文案来自：

`规则/V1.2-基础卡表.md`

说明：

- `card_data.json` 是历史批量合成数据，不作为基础版技能文案唯一来源。
- 基础版妖怪插画与审核记录维护在 `妖怪志/卡名/插画/基础版/`。
- 基础版成品卡生成流程见 `卡牌成品/基础版成品卡生成流程规范.md`。
