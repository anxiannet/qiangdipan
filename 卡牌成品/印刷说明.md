# 一、当前基础版印刷内容物

| 类别 | 数量 | 尺寸 | 方向 | 说明 |
|---|---:|---|---|---|
| 妖怪牌 | 48 | 63 × 88 mm | 竖版 | 1星24张，2星18张，3星6张 |
| 法宝牌 | 4 | 63 × 88 mm | 竖版 | 与妖怪牌共用公共牌库 |

- 公共牌库合计 52 张：妖怪牌 48 张 + 法宝牌 4 张。
- 地盘牌库 12 张。
- 全部游戏牌合计 64 张，不含指南卡。
- 若将指南卡一并计入盒内实体卡，共 66 张。
- 游戏手册只作为电子版说明，不进入实体卡牌印刷内容物。

# 三、卡背要求

## 妖怪牌与法宝牌

妖怪牌与法宝牌属于同一公共牌库，必须共用同一张卡背。

统一文件名建议：

```text
xiyao_qiangdipan_deck_back.png
```

禁止分别生成：

```text
xiyao_qiangdipan_monster_back.png
xiyao_qiangdipan_artifact_back.png
```

## 地盘牌

地盘牌使用独立卡背。

统一文件名建议：

```text
xiyao_qiangdipan_land_back.png
```

## 指南卡

指南卡可使用独立说明卡背风格，也可按正反面正文直接印刷。

指南卡不得混入公共牌库背面，以免玩家误以为可以抽到指南卡。

# 四、导出文件要求

每张卡建议导出：

| 文件类型 | 用途 | 是否含辅助线 |
|---|---|---|
| clean PNG | 印刷 / 成品预览 | 不含辅助线 |
| review PNG | 内部审核 | 可含辅助线与标注 |
| 源文件 | 后续修改 | 可含图层与参考线 |

最终交付给印刷厂的文件：

- 必须使用 clean 版本。
- 不得包含安全线、裁切线、红线、黑线、虚线、十字定位线或说明文字。
- 背景、花纹、边框必须铺满出血区。
- 关键文字、星级、名称栏、技能文字必须在安全区内。
- 分辨率按 300 dpi 制作。

# 六、印刷前检查清单

## 规则一致性

- 是否使用 `规则/V1.2-基础卡表.md` 中的当前卡名、数量、星级和卡面文案。
- 是否确认 3星妖怪与法宝均为唯一卡，各1张。
- 是否确认基础版不出现4星、5星。
- 是否确认地盘牌无技能区。
- 是否确认指南卡使用“攻山”作为正式行动名。
- 是否确认游戏手册不作为实体说明书印刷，只作为电子版说明。

## UI 与版式

- 妖怪牌、法宝牌是否为竖版 63 × 88 mm。
- 地盘牌是否为横版 88 × 63 mm。
- 是否包含四边各 3 mm 出血。
- 星级、名称、技能文案是否都在安全区内。
- 法宝牌是否没有星级战力误导。
- 地盘牌是否没有技能区、驻军区、资源区或规则不存在的信息区。

## 插画与安全区

- 角色脸部、主动作、关键道具是否没有被 UI 遮挡。
- 技能结果是否没有落入底部文案栏。
- 台词文字是否没有进入左上星数区、右侧名称栏或底部文案栏。
- 同组角色是否不会撞动作、撞道具、撞场景。

## 卡背

- 妖怪牌与法宝牌是否共用公共牌库卡背。
- 地盘牌是否使用独立卡背。
- 指南卡是否不会被误混入公共牌库。

## 最终交付

- clean 图是否不含任何辅助线与说明文字。
- 文件名是否清楚可批量检查。
- 是否保留源文件和审核图。
- 是否已完成一次实体小样或屏幕缩小预览检查。

# 八、维护原则

1. 本文件只维护印刷与交付要求。
2. 不在本文件维护第二份卡表。
3. 卡牌数量、卡面文案、星级与审核状态以 `规则/V1.2-基础卡表.md` 为准。
4. 视觉安全区、UI坐标和文字规范以 `规范流程/UI规范.md` 为准。
5. 若规则或卡表变化，先更新规则与基础卡表，再同步本文件。
