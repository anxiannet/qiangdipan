# 《夕妖：抢地盘》视觉设计

本目录用于维护《夕妖：抢地盘》的视觉规范、UI规范、插画设计与生成工作流。

本目录只负责视觉设计，不负责修改：

- 世界观设定
- 游戏规则
- 卡牌数值
- 技能效果
- 程序实现

## 核心原则

规范与插画设计分开维护。

规范文件负责：

```text
必须遵守什么
禁止做什么
信息放在哪里
尺寸与边界是什么
```

插画设计文件负责：

```text
画面怎么设计
角色怎么表现
动作和表情怎么做
法宝和地盘的视觉关键词是什么
```

插画设计必须符合规范要求。

插画设计不得反向修改规范。

## UI与插画分离

插画只生成主体画面。

插画不生成：

- 边框
- 名称
- 星级
- 技能区
- 阵营徽章
- 卡背
- UI元素

最终卡牌通过：

```text
插画 + UI + 名称 + 技能
```

合成。
