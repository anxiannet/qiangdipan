# 《夕妖：抢地盘》角色视觉差异矩阵

## 文件定位

本文件用于约束基础版妖怪与法宝插画的视觉差异。

本文件只服务视觉设计，不维护第二份规则与卡表。

规则、数量、星级、卡面文案、技能评分、审核状态唯一来源：

```text

```

妖怪与法宝详细设定来源：

```text
妖怪志/
法宝志/
```

视觉安全区、卡框、UI 规范来源：

```text
视觉/规范/视觉总规范.md
视觉/规范/UI规范.md
```

## 一、通用视觉原则

| 项目 | 要求 |
|---|---|
| 主体识别 | 玩家 1 秒内看出主角是谁，不靠读技能理解 |
| 技能匹配 | 动作、表情、道具、场景必须服务当前已审核技能 |
| 独立轮廓 | 同组角色必须有不同剪影、姿态和主道具 |
| UI 安全 | 脸、手、核心道具、技能动作不得被星数、名称栏、技能栏遮挡 |
| 风味表达 | 台词、动作、场景可增加代入感，但不得改写规则 |
| 禁止重复 | 不能让两张不同卡看起来像同一张卡换色 |

## 二、急如火 / 有来有去 / 快如风

这三张都是 1 星火云 / 速度小妖，最大风险是都被画成“跑腿小妖”。必须通过动作目的区分。

| 卡牌 | 技能核心 | 主体轮廓 | 核心动作 | 表情 | 道具 | 场景 | 必须一眼看出 | 禁止撞点 |
|---|---|---|---|---|---|---|---|---|
| 急如火 | 喊一名玩家；答应后各抽1张 | 身体前倾、嘴部夸张张开、双手拢嘴 | 大声喊名、火急传话、等待回应 | 急、慌、催促、好笑 | 传令牌、小令旗、火把、喊话纸 | 火云洞门口、营寨传令点 | 正在喊人，不是在奔跑 | 不能只画成跑步；不能像紫金红葫芦收妖；不能表现攻击 |
| 有来有去 | 抽1张牌，然后弃1张牌 | 左右往返残影、双手一进一出 | 一手接新信 / 新牌，另一手丢旧信 / 旧牌 | 忙乱、滑稽、来回折腾 | 两封信、小包袱、旧牌影、新牌影 | 两边阵营之间、山路岔口、火云传令路 | 先来后去、换掉旧信息 | 不能像急如火喊话；不能像快如风吹牌；不能像偷手牌 |
| 快如风 | 将地盘牌库顶1张放到牌库底 | 低伏冲刺、风线拉长、身形轻快 | 带风掠过，把地盘牌影吹走 | 机灵、得意、捣乱 | 风带、轻便跑腿装备、被吹起的地盘牌影 | 山头边、中央地盘补充区、火云山道 | 顶牌被风带走 | 不能画成大范围风暴；不能像黄风怪 / 芭蕉扇；不能表现伤害清场 |

### 该组差异关键词

- 急如火：**喊名 / 声波 / 等回应**
- 有来有去：**新旧交换 / 来回残影 / 信息过期**
- 快如风：**风掠过 / 顶牌吹到底 / 轻反制**

这两张都涉及公共牌库，最大风险是都被画成“拿书算账”。必须区分小妖盘库与妖王点将。

| 卡牌 | 技能核心 | 主体轮廓 | 核心动作 | 表情 | 道具 | 场景 | 必须一眼看出 | 禁止撞点 |

## 六、基础版角色独立性检查表

每张图生成或审核时，必须逐项检查：

| 检查项 | 合格标准 |
|---|---|
| 角色名称遮住后是否仍能区分 | 能通过轮廓、动作、道具识别大致角色 |
| 技能文案遮住后是否仍能猜到技能方向 | 能从动作和场景看出查牌、喊名、吹回、消灭、抓走等方向 |
| 同组角色是否撞动作 | 不允许同组角色都只是站立、挥手、奔跑或放风 |
| 同组角色是否撞道具 | 关键道具不能共用为主视觉，例如铁算盘 / 名册 / 三张牌要区分 |
| 同组角色是否撞场景 | 场景可同体系，但必须有不同功能空间：账房、点将台、洞口、战场等 |
| 是否误导规则 | 不能画出卡面没有的效果，例如消灭3星、跨地盘、回血、额外抽牌 |
| 是否符合安全区 | 脸、手、核心道具、技能特效不得被 UI 栏遮挡 |

## 七、给 Codex / 批量做图的使用方式

生成或审核单张图前，先读取：

1. `规则/V1.2-基础卡表.md`
2. 对应 `妖怪志/卡名/卡名.md` 或 `法宝志/卡名.md`
3. 本文件中对应分组
4. `视觉/规范/视觉总规范.md`
5. `视觉/规范/UI规范.md`

每张图审核必须输出：

```text
卡名：
技能一致性：合格 / 不合格
主体轮廓：合格 / 不合格
动作表情：合格 / 不合格
道具场景：合格 / 不合格
同组差异：合格 / 不合格
UI安全区：合格 / 不合格
是否需要重做：是 / 否
问题说明：
```

如不合格，必须保留旧图与迭代记录，不覆盖历史版本。
