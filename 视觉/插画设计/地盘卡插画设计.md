本文件定义地盘卡插画设计方向，以及地盘成品卡预览时的画面气质要求。

## 一、地盘卡插画定位

地盘卡是可被占领、驻守、争夺的领地卡。

地盘卡不是战棋地图，不展示路线、格子或相邻关系。

基础版不使用相邻、距离或路线规则，因此插画上也不得暗示这些规则。

地盘卡应像：

```text
妖怪可以住
妖怪可以守
妖怪可以抢
妖怪可以插旗占山头
```

而不是：

```text
副本地图
地下城关卡
世界地图
战棋地图
纯风景壁纸
```

---

## 二、地盘卡必须表达

地盘插画必须表达：

- 地名气质
- 阵营气质
- 可占领的山头 / 洞府 / 地域感
- 与其它阵营的色彩差异
- 横版场景感

地盘卡应像可以被妖怪抢、守、攻的地方。

由于当前胜利条件是“控制同一阵营全部3块地盘，立即获胜”，所以地盘卡成品视觉中，阵营归属是最高优先级信息。

成品卡阅读优先级：

```text
1. 阵营归属
2. 地盘名称
3. 地盘场景
```

当前基础版地盘卡不显示：

- 占领值
- 地盘等级
- 中级地盘
- 地盘效果
- 地盘特性
- 驻军区
- 资源产出
- 地盘技能

## 四、四阵营统一原则

所有地盘都必须像：

```text
妖怪居住的山头
```

而不是：

```text
地下城
副本
关卡
秘境
Boss房
```

玩家看到地盘卡时，应觉得：

```text
这里能住妖怪
这里能驻军
这里能插旗
这里值得抢
```

不要让玩家觉得：

```text
这里像最终Boss所在地
这里像单机RPG关卡
这里像战棋地图
```

四阵营之间可以有明显色彩差异，但必须共享同一套：

- 横版地盘卡构图
- 统一UI框架
- 统一字体体系
- 统一边框体系
- 西游妖怪动画电影风
- 高识别度桌游卡牌质感

## 五、四阵营风格文案

本节用于统一四大阵营的视觉表达语气，服务地盘卡插画、UI审核、提示词扩写与美术沟通。

本节只描述视觉风格，不新增规则，不绑定妖怪驻守阵营，不替代 `规则/当前规则.md` 与 `规则/V1.2-基础卡表.md`。

### 白骨阵营｜阴森但不恐怖

风格定位：

白骨阵营不是恐怖片，也不是亡灵副本，而是“阴森荒岭里的妖怪山头”。整体以骨白、墨灰、枯木、荒坡为主，点缀少量蓝紫鬼火，让玩家一眼识别为白骨妖域，但不能压成黑暗恐怖风。

画面文案：

白骨岭一带阴风绕坡，枯木斜立，残破山门半掩在灰雾中。骨白山道通向妖寨，几点蓝紫鬼火浮在路边，像在招呼小妖回山守地。气氛阴森、诡异、有妖气，但保持卡牌游戏的热闹识别度，不做恐怖游戏场景。

关键词：

- 骨白
- 墨灰
- 枯木
- 荒坡
- 鬼火
- 白骨妖寨
- 残破山门
- 骨桥
- 阴森但不恐怖

### 火云阵营｜热闹、暴躁、充满力量

风格定位：

火云阵营要像一座正在冒热气的妖怪火山地盘，不是末日火山，也不是熔岩地狱。颜色要更亮、更热、更有冲突感，适合表现抢地盘时的冲锋和爆发。

画面文案：

火云妖域烈焰翻涌，赤红火云压在山头上，熔岩橙的光从洞府缝隙里透出。红色妖旗插在火山山寨前，热浪、烟尘和旱热山路把整块地盘烘得躁动不安。这里像牛魔群妖随时出动的老巢，热闹、暴躁、力量感强，但画面必须明亮可读。

关键词：

- 赤红
- 熔岩橙
- 火云
- 烟尘
- 热浪
- 红色妖旗
- 火山洞府
- 火山山寨
- 暴躁力量感

### 狮驼阵营｜强盛、霸气、占山为王

风格定位：

狮驼阵营要有“妖城”和“山头霸主”的气势。它不是皇宫，不是天庭，也不是西方兽人部落，而是西游妖怪占据山岭后建立起来的强盛妖国。

画面文案：

狮驼妖域立在荒漠山岭之间，土褐石寨层层叠起，巨大的山门上压着狮头妖印。金褐旗帜在风沙里翻动，瞭望塔、石墙和妖城街道组成一座可以驻军、可以抢占、可以称王的妖怪地盘。整体要霸气、厚重、强盛，但不能画成皇宫或修仙宗门。

关键词：

- 狮金
- 土褐
- 妖城
- 巨门
- 荒漠山岭
- 石寨
- 兽纹旗
- 狮头妖印
- 占山为王

### 盘丝阵营｜神秘、诡美、妖艳

风格定位：

盘丝阵营要有毒紫、暗绿、蛛网、湿雾、幽泉与藤蔓的诡美感。它不是恐怖蜘蛛巢，也不是哥特地牢，而是带有妖艳、潮湿、迷离气质的西游妖怪领地。

画面文案：

盘丝妖域藏在湿雾与藤蔓深处，暗绿色山壁缠着紫色蛛网，幽泉从洞边流过，黄花点缀在妖观与石阶之间。紫色灯火映出潮湿雾气，让整块地盘显得神秘、诡美、带一点危险的妖艳感。画面重点仍然是可占领的洞府与山头，不让大蜘蛛或黑暗洞窟压过地盘主体。

关键词：

- 毒紫
- 暗绿
- 蛛网
- 湿雾
- 幽泉
- 花海
- 藤蔓
- 妖观
- 紫色灯火
- 神秘诡美

### 四阵营一句话总控

白骨阴森不恐怖，火云热闹有爆发，狮驼霸气像妖国，盘丝诡美有妖艳；四者都必须是“能驻军、能插旗、值得抢”的西游妖怪地盘。

## 六、四阵营图腾 / 阵营徽章设计方向

本节用于统一四大阵营图腾、阵营徽章、UI小图标的视觉方向。

图腾只负责表现阵营识别，不新增规则，不表示妖怪只能驻守某一阵营地盘。

### 总体要求

四阵营图腾必须是：

- 简约
- 干净
- 整洁
- 清晰
- 明亮
- 小图可读
- 西游妖怪 3D 动画电影风
- 与当前卡牌 UI 同一套产品气质

四阵营图腾不得使用：

- 复杂装饰背景
- 大型盾牌底板
- 旗帜背景
- 场景背景
- 过多链条、吊坠、碎片、卷纹
- 密集纹理与细小裂纹
- 过暗、过脏、过恐怖的处理

图腾应作为独立透明 PNG 资产使用：

```text
只要图腾，不要装饰背景。
```

### 四阵营图腾实体

当前确认的四阵营图腾实体如下：

| 阵营 | 图腾实体 | 主色方向 | 识别重点 |
|---|---|---|---|
| 白骨 | 骷髅头 / 骨面 | 骨白、墨灰、少量紫色 | 骨质轮廓、紫色妖光、阴森但不恐怖 |
| 火云 | 火牛头 / 牛魔头 | 赤红、熔岩橙、金色 | 牛角、火焰鬃毛、暴躁力量感 |
| 狮驼 | 狮头 / 兽王头 | 狮金、土褐、暗石色 | 狮头轮廓、兽王气势、占山为王 |
| 盘丝 | 蜘蛛 / 蛛网宝石 | 毒紫、暗绿、少量金色 | 蜘蛛轮廓、蛛网结构、紫色晶石 |

### 白骨图腾

白骨图腾以骷髅头或骨面作为主体。

设计要求：

- 主体必须是干净清晰的骨白骷髅轮廓
- 可使用少量紫色宝石或紫色妖光加强识别
- 表情可以阴森，但不能恐怖、血腥或恶心
- 骨裂纹、碎骨、吊坠等细节必须减少
- 小尺寸下仍应一眼看出“白骨”

禁止：

- 巨大复杂骨堆
- 过多牙齿细节
- 恐怖片骷髅
- 亡灵副本感
- 大面积黑暗阴影

### 火云图腾

火云图腾必须有代表实体，不能只是一团火焰。

当前方向为火牛头 / 牛魔头，用来与白骨骷髅头、狮驼狮头、盘丝蜘蛛形成同级别实体识别。

设计要求：

- 主体为红橙色火牛头或牛魔头
- 牛角必须清楚，作为第一识别轮廓
- 可使用火焰鬃毛、火云形轮廓和金色额饰
- 整体要明亮、热闹、暴躁、有力量
- 细节要控制，不能被火焰碎片淹没主体

禁止：

- 只有火焰，没有实体
- 画成普通牛头，与火云无关
- 过多火苗导致轮廓混乱
- 黑红地狱恶魔风
- 过暗熔岩怪物风

### 狮驼图腾

狮驼图腾以狮头或兽王头作为主体。

设计要求：

- 主体必须是金色狮头 / 兽王头
- 轮廓要厚重、正面、霸气
- 可保留少量鬃毛卷曲和金属高光
- 表情要强势，但不做恐怖怪物
- 小尺寸下应一眼识别为“狮驼”

禁止：

- 过度复杂的金属雕花
- 西方兽人部落感
- 皇宫徽章感
- 过多獠牙与阴影导致脏乱

### 盘丝图腾

盘丝图腾以蜘蛛或蛛网宝石作为主体。

设计要求：

- 主体必须能识别为蜘蛛 / 蛛网
- 可使用紫色晶石作为视觉中心
- 结构要对称、清楚、优雅
- 保持神秘、诡美、妖艳，不走恐怖蜘蛛巢穴方向
- 小尺寸下蜘蛛轮廓和紫色核心都要清楚

禁止：

- 真实恐怖蜘蛛
- 大量密集蛛丝
- 黑暗洞窟背景
- 哥特地牢感
- 蜘蛛细腿过多导致小图发脏

## 七、当前地盘卡成品预览方向

当前允许为了审核整体效果，生成带 UI、文字和阵营徽章的成品预览图。

成品预览图用于判断：

- 阵营 UI 是否足够醒目
- 地盘名称是否清楚
- 四阵营放在一起是否像同一套牌
- 是否符合“集齐同阵营3块地盘获胜”的规则阅读需求

成品预览图可以包含：

- 横版卡框
- 左侧阵营旗牌
- 阵营徽章
- 阵营名
- 顶部地盘名称
- 地盘插画

成品预览图禁止包含：

- 占领值
- 地盘等级
- 中级地盘
- 地盘效果
- 地盘特性
- 驻军区
- 技能区
- 资源产出
- 未在规则中存在的能力图标

正式生产时仍建议保留可拆分流程：

```text
插画源图 + UI资产 + 名称文字 + 阵营徽章
```

但在视觉审核阶段，可以先生成整卡效果图。

## 八、与妖怪来源的关系

妖怪来源/归属只用于世界观说明。

地盘阵营用于胜利条件。

二者暂不形成规则绑定。

视觉上可以让部分妖怪背景呼应来源地，但不能暗示妖怪只能驻守某个阵营地盘。

## 十、禁止项

禁止：

- 画出格子路线暗示相邻规则
- 画出路线箭头暗示移动规则
- 让地盘看起来像角色牌
- 过度复杂导致地名不可读
- 用妖怪主体压过地盘本身
- 为地盘添加未在规则中存在的能力图标
- 把地盘画成纯风景壁纸
- 把地盘画成副本关卡
- 把地盘画成世界地图
- 把地盘画成战棋地图
- 成品卡出现占领值
- 成品卡出现地盘等级
- 成品卡出现中级地盘
- 成品卡出现地盘效果
- 成品卡出现地盘特性
- 成品卡出现驻军区

## 十一、插画源文件与成品预览的区别

### 插画源文件

插画源文件不得生成：

- 卡牌边框
- 地名文字
- 阵营徽章
- 卡背图案
- 星级
- 技能区
- 规则能力图标

这些由 UI 合成阶段处理。

### 成品预览图

成品预览图可以生成完整卡面，用于快速审核整体效果。

但成品预览图必须遵守当前规则，不得添加当前规则不存在的信息。
