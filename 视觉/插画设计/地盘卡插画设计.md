# 《夕妖：抢地盘》地盘卡插画设计

## 文件定位

本文件定义地盘卡插画设计方向，以及地盘成品卡预览时的画面气质要求。

必须符合：

```text
视觉/规范/视觉总规范.md
视觉/规范/UI规范.md
视觉/插画设计/插画设计总则.md
```

地盘名称、阵营与胜利条件以以下文件为唯一来源：

```text
规则/当前规则.md
规则/V1.0-核心规则重构.md
```

## 一、地盘卡插画定位

地盘卡是可被占领、驻守、争夺的领地卡。

地盘卡不是战棋地图，不展示路线、格子或相邻关系。

基础版不使用相邻、距离或路线规则，因此插画上也不得暗示这些规则。

地盘卡应像：

```text
妖怪可以住
妖怪可以守
妖怪可以抢
妖怪可以插旗占山头
```

而不是：

```text
副本地图
地下城关卡
世界地图
战棋地图
纯风景壁纸
```

---

## 二、地盘卡必须表达

地盘插画必须表达：

- 地名气质
- 阵营气质
- 可占领的山头 / 洞府 / 地域感
- 与其它阵营的色彩差异
- 横版场景感

地盘卡应像可以被妖怪抢、守、攻的地方。

由于当前胜利条件是“控制同一阵营全部3块地盘，立即获胜”，所以地盘卡成品视觉中，阵营归属是最高优先级信息。

成品卡阅读优先级：

```text
1. 阵营归属
2. 地盘名称
3. 地盘场景
```

当前基础版地盘卡不显示：

- 占领值
- 地盘等级
- 中级地盘
- 地盘效果
- 地盘特性
- 驻军区
- 资源产出
- 地盘技能

## 三、四大阵营插画方向

### 白骨阵营

地盘：

- 白骨岭
- 埋骨坡
- 乱葬岗

视觉关键词：

- 骨白
- 枯木
- 荒坡
- 鬼火
- 墨灰阴影
- 白骨妖寨
- 骨桥
- 残破山门

氛围：

```text
阴森，但不恐怖。
```

允许：

- 骨白山坡
- 枯木剪影
- 少量蓝紫鬼火
- 白骨洞府
- 残破山门
- 荒坡小路

禁止：

- 亡灵城堡
- 地狱副本
- 巨大骷髅头作为主体
- 过密墓碑森林
- 大面积尸骸堆叠
- 恐怖游戏氛围

## 四、四阵营统一原则

所有地盘都必须像：

```text
妖怪居住的山头
```

而不是：

```text
地下城
副本
关卡
秘境
Boss房
```

玩家看到地盘卡时，应觉得：

```text
这里能住妖怪
这里能驻军
这里能插旗
这里值得抢
```

不要让玩家觉得：

```text
这里像最终Boss所在地
这里像单机RPG关卡
这里像战棋地图
```

四阵营之间可以有明显色彩差异，但必须共享同一套：

- 横版地盘卡构图
- 统一UI框架
- 统一字体体系
- 统一边框体系
- 西游妖怪动画电影风
- 高识别度桌游卡牌质感

## 五、当前地盘卡成品预览方向

当前允许为了审核整体效果，生成带 UI、文字和阵营徽章的成品预览图。

成品预览图用于判断：

- 阵营 UI 是否足够醒目
- 地盘名称是否清楚
- 四阵营放在一起是否像同一套牌
- 是否符合“集齐同阵营3块地盘获胜”的规则阅读需求

成品预览图可以包含：

- 横版卡框
- 左侧阵营旗牌
- 阵营徽章
- 阵营名
- 顶部地盘名称
- 地盘插画

成品预览图禁止包含：

- 占领值
- 地盘等级
- 中级地盘
- 地盘效果
- 地盘特性
- 驻军区
- 技能区
- 资源产出
- 未在规则中存在的能力图标

正式生产时仍建议保留可拆分流程：

```text
插画源图 + UI资产 + 名称文字 + 阵营徽章
```

但在视觉审核阶段，可以先生成整卡效果图。

## 六、与妖怪来源的关系

妖怪来源/归属只用于世界观说明。

地盘阵营用于胜利条件。

二者暂不形成规则绑定。

视觉上可以让部分妖怪背景呼应来源地，但不能暗示妖怪只能驻守某个阵营地盘。


## 八、禁止项

禁止：

- 画出格子路线暗示相邻规则
- 画出路线箭头暗示移动规则
- 让地盘看起来像角色牌
- 过度复杂导致地名不可读
- 用妖怪主体压过地盘本身
- 为地盘添加未在规则中存在的能力图标
- 把地盘画成纯风景壁纸
- 把地盘画成副本关卡
- 把地盘画成世界地图
- 把地盘画成战棋地图
- 成品卡出现占领值
- 成品卡出现地盘等级
- 成品卡出现中级地盘
- 成品卡出现地盘效果
- 成品卡出现地盘特性
- 成品卡出现驻军区

---

## 九、插画源文件与成品预览的区别

### 插画源文件

插画源文件不得生成：

- 卡牌边框
- 地名文字
- 阵营徽章
- 卡背图案
- 星级
- 技能区
- 规则能力图标

这些由 UI 合成阶段处理。

### 成品预览图

成品预览图可以生成完整卡面，用于快速审核整体效果。

但成品预览图必须遵守当前规则，不得添加当前规则不存在的信息。
