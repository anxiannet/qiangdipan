# 《夕妖：抢地盘》插画设计总则

## 文件定位

本文件是《抢地盘》插画设计的总入口。

插画设计必须符合：

```text
规范流程/视觉总规范.md
规范流程/UI规范.md
```

本文件只负责画面设计方向，不修改规则、卡表、技能文案或 UI 信息层级。

---

## 一、统一插画风格

《抢地盘》插画统一采用：

```text
高品质 3D 妖怪动画电影风
```

核心特征：

- 头部适度偏大
- 表情夸张
- 动作明确
- 轮廓清楚
- 身体比例英雄化但不写实压迫
- 材质有手办质感
- 明快自然光
- 手机端小图可读

插画应有欢乐抢地盘的动态感，而不是静态展示图。

---

## 二、统一视觉路线

融合方向：

```text
炉石传说式英雄识别
黑神话式西游气质
魔兽兵团式小图可读性
收藏级手办质感
```

注意：

这些只是方向锚点，不得直接模仿任何具体商业 IP 的角色、建筑、画面或专有设计。

---

## 三、角色比例

统一采用：

```text
4~5 头身英雄化比例
```

禁止：

- 2头身超级Q版
- 8头身写实仙侠立绘
- 过度写实暗黑 Boss

允许：

- 头部适度放大
- 手部适度放大
- 武器适度放大
- 轮廓强化

---

## 四、角色识别原则

玩家缩略图尺寸下应优先识别角色身份。

例如应先识别：

- 牛魔王
- 白骨精
- 红孩儿
- 铁扇公主
- 金鼻白毛老鼠精

而不是先看到：

- 帅哥
- 美女
- 萝莉
- 肌肉男

角色身份优先级高于颜值。

---

## 五、角色必须正在做事

角色插画必须表现明确动作。

允许动作方向：

- 巡山
- 送信
- 抢旗
- 守洞
- 偷法宝
- 冲锋
- 攻山
- 逃跑
- 指挥
- 吹风
- 吐火
- 搅局

禁止：

- 站着拍照
- 正面证件照
- 只摆造型不参与游戏行为
- 只展示装备不表现性格
- 只靠背景和特效区分角色

---

## 六、女性角色原则

白骨精、铁扇公主、蜘蛛精、玉面狐狸等女性角色可以有美感、优雅、魅惑。

但必须增加：

- 身份特征
- 轮廓特征
- 妖怪特征
- 动作目的

禁止：

- 网红脸
- 二次元老婆风
- 普通仙侠美女立绘

远看必须先认出角色身份。

---

## 七、场景插画原则

背景必须服务“山头争霸”。

优先出现：

- 山寨
- 洞府
- 山门
- 妖旗
- 瞭望塔
- 木栈道
- 山路
- 悬崖
- 石阶
- 营寨
- 火把
- 灯笼
- 烟尘

次要出现：

- 云海
- 仙山
- 神殿
- 纯风景奇观

禁止让背景变成单纯风景壁纸。

背景应让玩家感觉这里是可以被抢、可以驻守、可以出兵的地盘。

---

## 八、插画与UI关系

插画只负责主体画面。

插画不生成：

- 卡牌边框
- 名称文字
- 技能区
- 星级 UI
- 阵营 UI
- 卡背图标
- 规则符号

这些由 `规范流程/UI规范.md` 管理。

最终卡牌通过以下方式合成：

```text
插画 + UI + 名称 + 技能
```
