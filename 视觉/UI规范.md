# 《夕妖：抢地盘》UI规范

## 文件定位

本文件是《抢地盘》当前 UI、卡牌框架、卡背系统与透明资产拆分的唯一入口。

已合并来源：

- `视觉/UI修订说明-地盘横置方案.md`
- `视觉/UI资产规范.md`
- `视觉/卡牌框架规范.md`
- `视觉/占山为王专属卡牌边框设计.md`

上述拆分文件不再作为当前维护入口。

---

## 一、UI边界

UI 只负责视觉呈现，不定义：

- 游戏规则
- 技能效果
- 卡牌数量
- 星级战力
- 世界观人物事实

规则、卡牌数据、技能文案仍以以下文件为准：

```text
规则/V1.2-基础卡表.md
规则/V1.2-卡面技能文案.md
```

---

## 二、卡牌尺寸

| 类型 | 方向 | 尺寸 |
|---|---|---|
| 妖怪卡 | 竖版 | 63 × 88 mm |
| 法宝卡 | 竖版 | 63 × 88 mm |
| 地盘卡 | 横版 | 88 × 63 mm |

印刷要求：

- 300 dpi
- 3 mm 出血
- 圆角
- 关键文字与图标必须放在安全区内
- 背景、花纹、边框必须延伸至出血区

禁止：

- 白边
- 断边
- 关键文字贴近裁切线
- 背景突然结束

---

## 三、卡牌类型识别

玩家应在 1 秒内区分：

1. 妖怪卡
2. 法宝卡
3. 地盘卡

识别原则：

- 妖怪卡：角色收藏卡感
- 法宝卡：传奇装备卡感
- 地盘卡：地图与领地感

---

## 四、卡背系统

### 妖怪卡与法宝卡

妖怪卡与法宝卡共用同一张卡背。

原因：

妖怪与法宝属于同一公共牌库，玩家抽牌前不能通过卡背区分抽到的是妖怪还是法宝。

统一文件名：

```text
xiyao_qiangdipan_deck_back.png
```

禁止分别生成：

```text
xiyao_qiangdipan_monster_back.png
xiyao_qiangdipan_artifact_back.png
```

### 地盘卡

地盘卡使用独立卡背。

原因：

地盘牌属于独立地盘牌库，不与公共妖怪/法宝牌库混洗。

统一文件名：

```text
xiyao_qiangdipan_land_back.png
```

---

## 五、卡面信息层级

卡面必须清晰展示：

1. 星级或卡牌类型标识
2. 卡名
3. 插画主体
4. 简洁技能文本

妖怪卡不展示：

- 攻击力
- 防守力
- 攻 / 守数值区
- 妖怪阵营区
- 技能类型标签

所有首领技能默认为登场触发，卡面不显示“登场技”“主动技”“被动技”等技能名。

---

## 六、妖怪卡UI

妖怪卡采用竖版收藏卡结构。

从上到下：

1. 左上角星级区
2. 大面积插画区
3. 名称区
4. 底部卷轴 / 石碑式技能区
5. 四周立体金属边框与角饰

比例建议：

- 插画区：70%~80%
- 名称区：10%~15%
- 技能区：10%~15%

### 星级

星级固定在左上角。

要求：

- 1星显示1颗星
- 2星显示2颗星
- 3星显示3颗星
- 星级使用金属浮雕大星
- 不得放到底部或名称下方作为装饰

### 1星小妖

展示：

- 1颗星
- 名字
- 插画

不展示：

- 技能栏
- 技能图标
- 技能文案
- “小妖”文字标签

边框语言：

- 青铜 / 蓝铜方向
- 简洁角饰
- 无明显流光
- 不使用大型兽首、火焰、雷电、传奇特效

### 2星精英

展示：

- 2颗星
- 名字
- 插画

不展示：

- 技能栏
- 技能图标
- 技能文案
- “精英”文字标签

边框语言：

- 银铁 / 紫银方向
- 比1星增加少量妖纹
- 允许轻微金属高光
- 不使用3星红金主框
- 不使用首领级技能栏

### 3星首领

展示：

- 3颗星
- 名字
- 插画
- 底部技能文案

不展示：

- 技能图标
- “技能”二字
- “首领”二字
- “妖王”二字
- 技能类型标签

边框语言：

- 红金 / 暗金方向
- 四周连续金属边框
- 圆角名字牌
- 底部短技能栏
- 少量流光
- 不使用龙头、巨大兽首、满屏火焰、雷电、爆闪特效

3星必须靠边框复杂度、颜色、三颗星与技能栏传达首领层级，不靠文字说明“首领”。

---

## 七、名称区

名称是卡面最高优先级文字之一。

必须支持最长首领名：

```text
金鼻白毛老鼠精
```

要求：

- 名字完整可读
- 不裁切
- 不被花纹遮挡
- 不缩成不可读小字
- 不写额外身份标签
- 名字牌可作为透明 UI 资产，文字由合成脚本后置写入

当前3星模板优先采用竖排名字牌方案。

---

## 八、技能区

技能文本来自：

```text
规则/V1.2-卡面技能文案.md
```

要求：

- 一句话
- 不加句号
- 不换行优先
- 玩家应能在3秒内读完
- 只显示效果文本
- 不显示技能名
- 不显示技能图标
- 不显示主动 / 被动 / 登场等类型标签

视觉要求：

- 卷轴 / 石碑 / 古牌匾 / 妖纹铭牌结构
- 不做普通矩形备注栏
- 不做资料卡说明栏
- 与边框形成统一立体材质

---

## 九、法宝卡UI

法宝卡为竖版。

视觉方向：

- 法器
- 神兵
- 紫金
- 法阵
- 宝光
- 与妖怪卡属于同一世界观背景体系

必须生成资产：

```text
ui_artifact_frame.png
ui_artifact_skill_plate.png
ui_artifact_type_badge.png
```

要求：

- 法宝主体占 70%~80%
- 透明 UI 资产不包含名称、技能文字、星级
- 正面要能与妖怪卡区分
- 背面必须与妖怪卡共用卡背

---

## 十、地盘卡UI

地盘卡为横版。

地盘卡采用独立背景体系，直接以场景作为主体。

方向：

```text
88 × 63 mm
```

视觉方向：

- 地图
- 山川
- 洞府
- 领地
- 横向全景
- 场景感

不采用：

- 妖怪卡背景体系
- 法宝卡背景体系
- 技能区

必须生成资产：

```text
ui_land_frame.png
ui_land_title_plate.png
ui_land_faction_badge_baigu.png
ui_land_faction_badge_huoyun.png
ui_land_faction_badge_shituo.png
ui_land_faction_badge_pansi.png
```

阵营徽记方向：

- 白骨：骨纹 / 鬼火
- 火云：火焰 / 云纹
- 狮驼：狮首 / 妖城门
- 盘丝：蛛网 / 毒纹

---

## 十一、透明UI资产原则

UI 与插画分离。

所有 UI 资产必须：

- PNG
- 透明背景
- 无文字
- 无角色主体
- 无技能描述
- 无妖怪名称
- 无地盘名称
- 无攻击力
- 无防守力
- 无编号
- 无水印

最终卡牌通过程序或设计工具合成：

```text
插画 + UI + 名称 + 技能
```

## 十三、禁止风格

禁止：

- 资料卡风格
- Word 表格风格
- 百科卡风格
- 原型测试卡
- 页游低质边框
- 过度复杂到影响阅读

当前基础牌最高只到3星，禁止提前消耗4星、5星视觉空间。
