# 《夕妖：抢地盘》UI规范

## 文件定位

本文件是《抢地盘》UI、卡牌框架、卡背系统、图标系统与透明资产拆分的唯一规范入口。

本文件只写 UI 规范，不写具体插画设计。

插画设计内容放在：

```text
视觉/插画设计/
```

---

## 一、UI边界

UI 只负责视觉呈现和信息组织，不定义：

- 游戏规则
- 技能效果
- 卡牌数量
- 星级战力
- 世界观人物事实
- 插画具体内容

规则、卡牌数据、技能文案仍以以下文件为准：

```text
规则/当前规则.md
规则/V1.2-基础卡表.md
规则/V1.2-卡面技能文案.md
```

---

## 二、卡牌尺寸

| 类型 | 方向 | 尺寸 |
|---|---|---|
| 妖怪卡 | 竖版 | 63 × 88 mm |
| 法宝卡 | 竖版 | 63 × 88 mm |
| 地盘卡 | 横版 | 88 × 63 mm |

印刷要求：

- 300 dpi
- 3 mm 出血
- 圆角
- 关键文字与图标必须放在安全区内
- 背景、花纹、边框必须延伸至出血区

禁止：

- 白边
- 断边
- 关键文字贴近裁切线
- 背景突然结束

---

## 三、卡牌类型识别

玩家应在 1 秒内区分：

1. 妖怪卡
2. 法宝卡
3. 地盘卡

识别原则：

- 妖怪卡：角色卡
- 法宝卡：装备 / 法器卡
- 地盘卡：领地 / 地图卡

---

## 四、卡背系统

### 妖怪卡与法宝卡

妖怪卡与法宝卡共用同一张卡背。

原因：

妖怪与法宝属于同一公共牌库，玩家抽牌前不能通过卡背区分抽到的是妖怪还是法宝。

统一文件名：

```text
xiyao_qiangdipan_deck_back.png
```

禁止分别生成：

```text
xiyao_qiangdipan_monster_back.png
xiyao_qiangdipan_artifact_back.png
```

### 地盘卡

地盘卡使用独立卡背。

统一文件名：

```text
xiyao_qiangdipan_land_back.png
```

---

## 五、卡面信息层级

卡面必须清晰展示：

1. 星级或卡牌类型标识
2. 卡名
3. 插画主体
4. 简洁技能文本或效果文本

妖怪卡不展示：

- 攻击力
- 防守力
- 攻 / 守数值区
- 妖怪阵营区
- 技能类型标签

所有首领技能默认为登场触发，卡面不显示“登场技”“主动技”“被动技”等技能名。

---

## 六、核心图标组

必须建立以下图标组：

| 图标 | 用途 |
|---|---|
| 1星 | 小妖星级，也是基础结算识别 |
| 2星 | 精英星级，也是基础结算识别 |
| 3星 | 首领星级，也是基础结算识别 |
| 妖怪 | 妖怪卡类型 |
| 法宝 | 法宝卡类型 |
| 地盘 | 地盘卡类型 |
| 无主 | 无主地盘状态 |
| 已占领 | 已占领地盘状态 |
| 攻山 | 攻击行动 |
| 招兵 | 出牌驻守行动 |

基础妖怪卡不建立单独战力数字图标。

---

## 七、星级图标

星级图标应保持统一形状，只通过颜色与数量区分：

- 1星：青铜
- 2星：银铁
- 3星：暗金

要求：

- 星级必须比普通装饰更醒目
- 星级位置必须统一
- 星级大小必须支持手机端小图阅读
- 3星卡的三星可以适度放大，用于强化结算识别
- 禁止每张卡使用不同星级图案

---

## 八、妖怪卡UI

妖怪卡采用竖版结构。

从上到下：

1. 左上角星级区
2. 大面积插画区
3. 名称区
4. 底部技能区
5. 四周边框与角饰

比例建议：

- 插画区：70%~80%
- 名称区：10%~15%
- 技能区：10%~15%

### 1星小妖

展示：

- 1颗星
- 名字
- 插画

不展示：

- 技能栏
- 技能图标
- 技能文案
- “小妖”文字标签

### 2星精英

展示：

- 2颗星
- 名字
- 插画

不展示：

- 技能栏
- 技能图标
- 技能文案
- “精英”文字标签

### 3星首领

展示：

- 3颗星
- 名字
- 插画
- 底部技能文案

不展示：

- 技能图标
- “技能”二字
- “首领”二字
- “妖王”二字
- 技能类型标签

---

## 九、名称区

名称是卡面最高优先级文字之一。

必须支持最长首领名：

```text
金鼻白毛老鼠精
```

要求：

- 名字完整可读
- 不裁切
- 不被花纹遮挡
- 不缩成不可读小字
- 不写额外身份标签
- 名字牌可作为透明 UI 资产，文字由合成脚本后置写入

当前 3 星模板优先采用竖排名字牌方案。

---

## 十、技能区

技能文本来自：

```text
规则/V1.2-卡面技能文案.md
```

要求：

- 一句话
- 不加句号
- 不换行优先
- 玩家应能在 3 秒内读完
- 只显示效果文本
- 不显示技能名
- 不显示技能图标
- 不显示主动 / 被动 / 登场等类型标签

---

## 十一、法宝卡UI

法宝卡为竖版。

必须生成资产：

```text
ui_artifact_frame.png
ui_artifact_skill_plate.png
ui_artifact_type_badge.png
```

要求：

- 法宝主体占 70%~80%
- 透明 UI 资产不包含名称、技能文字、星级
- 正面要能与妖怪卡区分
- 背面必须与妖怪卡共用卡背

---

## 十二、地盘卡UI

地盘卡为横版。

方向：

```text
88 × 63 mm
```

不采用：

- 妖怪卡背景体系
- 法宝卡背景体系
- 技能区

必须生成资产：

```text
ui_land_frame.png
ui_land_title_plate.png
ui_land_faction_badge_baigu.png
ui_land_faction_badge_huoyun.png
ui_land_faction_badge_shituo.png
ui_land_faction_badge_pansi.png
```

---

## 十三、透明UI资产原则

UI 与插画分离。

所有 UI 资产必须：

- PNG
- 透明背景
- 无文字
- 无角色主体
- 无技能描述
- 无妖怪名称
- 无地盘名称
- 无攻击力
- 无防守力
- 无编号
- 无水印

最终卡牌通过程序或设计工具合成：

```text
插画 + UI + 名称 + 技能
```

## 十五、禁止项

禁止：

- 资料卡风格
- Word 表格风格
- 百科卡风格
- 原型测试卡
- 页游低质边框
- 过度复杂到影响阅读
- 用插画内容替代 UI 信息层级

当前基础牌最高只到 3 星，禁止提前消耗 4 星、5 星视觉空间。
