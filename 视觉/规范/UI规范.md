# 《夕妖：抢地盘》UI规范

## 文件定位

本文件是《抢地盘》UI、卡牌框架、卡背系统、图标系统与透明资产拆分的唯一规范入口。

本文件只写 UI 规范，不写具体插画设计。

插画设计内容放在：

```text
视觉/插画设计/
```

---

## 一、UI边界

UI 只负责视觉呈现和信息组织，不定义：

- 游戏规则
- 技能效果
- 卡牌数量
- 星级战力
- 世界观人物事实
- 插画具体内容

规则、卡牌数据、技能文案仍以以下文件为准：

```text
规则/当前规则.md
规则/V1.2-基础卡表.md
规则/V1.2-卡面技能文案.md
```

说明：

- UI 可以为 1星、2星、3星妖怪卡统一预留技能描述区。
- 这只代表卡面版式统一，不代表 1星、2星在当前规则中获得技能。
- 当前 1星、2星是否显示 `无技能` 或留空，以 `规则/V1.2-卡面技能文案.md` 为准。
- 若未来规则或技能文案调整，必须先更新规则与技能文案唯一来源，再同步本 UI 规范。

## 二、卡牌尺寸

| 类型 | 方向 | 成品尺寸 |
|---|---|---|
| 妖怪卡 | 竖版 | 63 × 88 mm |
| 法宝卡 | 竖版 | 63 × 88 mm |
| 地盘卡 | 横版 | 88 × 63 mm |

印刷要求：

- 300 dpi
- 四边各 3 mm 出血
- 圆角
- 关键文字与图标必须放在安全区内
- 背景、花纹、边框必须延伸至出血区
- 最终交付图不得画入裁切线、安全线、红线、黑线、虚线、十字定位线或说明文字

### 妖怪卡 / 法宝卡印刷画布

妖怪卡与法宝卡为竖版，成品尺寸：

```text
63 × 88 mm
```

制作印刷文件时，画布必须包含四边各 3 mm 出血：

| 区域 | 毫米尺寸 | 300 dpi 像素尺寸 | 用途 |
|---|---:|---:|---|
| 含出血画布 | 69 × 94 mm | 815 × 1110 px | 最终制作画布，背景与边框必须铺满 |
| 成品裁切区 | 63 × 88 mm | 744 × 1039 px | 裁切后的实际卡牌范围 |
| 安全区 | 57 × 82 mm | 673 × 969 px | 星级、卡名、技能文本、核心角色信息放置区 |

参考线位置以含出血画布 `69 × 94 mm` 为准：

| 参考线 | 像素位置 | 毫米位置 |
|---|---:|---:|
| 左裁切线 | x=36 | 3 mm |
| 右裁切线 | x=780 | 66 mm |
| 上裁切线 | y=36 | 3 mm |
| 下裁切线 | y=1075 | 91 mm |
| 左安全线 | x=71 | 6 mm |
| 右安全线 | x=744 | 63 mm |
| 上安全线 | y=71 | 6 mm |
| 下安全线 | y=1040 | 88 mm |

坐标换算：

```text
含出血画布：x=0, y=0, w=815, h=1110
成品裁切区：x=36, y=36, w=744, h=1039
安全区：x=71, y=71, w=673, h=969
```

出血区审核底色：

```text
#10243D
RGB(16, 36, 61)
```

说明：

- `#10243D` 用于审核合成图的出血区底色，便于检查边框与出血覆盖。
- 最终实体卡交付图可以使用完整背景、边框或插画铺满出血区，不要求保留纯色底。
- 边框、背景纹理、非关键信息可以进入出血区。
- 星级、卡名、技能文字、核心角色脸部与关键信息必须在安全区内。
- 673 × 969 px 是安全内容区，不是最终卡面画布。

### 地盘卡印刷画布

地盘卡为横版，成品尺寸：

```text
88 × 63 mm
```

制作印刷文件时，画布必须包含四边各 3 mm 出血：

| 区域 | 毫米尺寸 | 300 dpi 像素尺寸 | 用途 |
|---|---:|---:|---|
| 含出血画布 | 94 × 69 mm | 1110 × 815 px | 最终制作画布，背景与边框必须铺满 |
| 成品裁切区 | 88 × 63 mm | 1039 × 744 px | 裁切后的实际卡牌范围 |
| 安全区 | 82 × 57 mm | 969 × 673 px | 地盘名称、妖域徽章、妖域名等关键信息放置区 |

参考线位置以含出血画布 `94 × 69 mm` 为准：

| 参考线 | 位置 |
|---|---:|
| 左裁切线 | 3 mm |
| 右裁切线 | 91 mm |
| 上裁切线 | 3 mm |
| 下裁切线 | 66 mm |
| 左安全线 | 6 mm |
| 右安全线 | 88 mm |
| 上安全线 | 6 mm |
| 下安全线 | 63 mm |

交付要求：

- 裁切线、安全线只能作为设计软件中的参考线
- 最终导出的 PNG、JPG、PDF 不得把裁切线或安全线画进卡面
- 最终图中不得出现红线、黑线、虚线、十字定位线、裁切线文字或安全区文字
- 地盘背景、地图纹理、云雾、山脉、边框装饰必须铺满到 `94 × 69 mm` 出血画布
- 地盘名称、妖域徽章、妖域名、重要地图标识必须控制在 `82 × 57 mm` 安全区内

禁止：

- 白边
- 断边
- 关键文字贴近裁切线
- 背景突然结束
- 在最终交付图中显示裁切线或安全线

## 三、妖怪卡合成版式

本节用于妖怪卡 UI 合成、审核图与最终出图。

### 画布与图层

画布：

```text
815 × 1110 px
```

图层顺序从下到上：

1. 出血区底色或完整背景
2. 卡框
3. 插画
4. 技能描述背景
5. 竖排名称栏
6. 星级图标
7. 名称文字
8. 技能文字
9. 审核辅助线与标注，仅审核图使用

最终 clean 图不得包含第 9 层。

### 卡框

卡框放置：

```text
x=0, y=0, w=815, h=1110
```

要求：

- 卡框必须铺满含出血画布。
- 外框装饰可以进入出血区。
- 重要信息不得放在裁切线外。
- 1星、2星、3星可以使用不同等级边框，但元素位置应尽量统一。

### 星级图标

星级是重要结算信息，必须顶部横排展示，且完全位于安全区内。

单颗星尺寸：

```text
60 × 60 px
```

横向间距：

```text
8 px
```

1星：

```text
star1: x=111, y=149, w=60, h=60
```

2星：

```text
star1: x=111, y=149, w=60, h=60
star2: x=179, y=149, w=60, h=60
```

3星：

```text
star1: x=111, y=149, w=60, h=60
star2: x=179, y=149, w=60, h=60
star3: x=247, y=149, w=60, h=60
```

若 3星顶部徽记与星级图标冲突，允许整排星星下移 8 px：

```text
y=157
```

星级图标要求：

- 1星：白银 / 骨石质感，简洁。
- 2星：白银 / 骨石质感，可有少量紫晶点缀。
- 3星：可有金色外边和少量紫晶，但五角星主体必须清楚。
- 单颗星最终占位应统一，不得因装饰导致 2星、3星明显大于 1星。
- 缩小到 60 × 60 px 后仍必须一眼可读。

### 竖排名称栏

名称栏本体：

```text
x=624, y=227, w=96, h=360
```

名称文字安全区：

```text
x=642, y=247, w=60, h=320
```

要求：

- 名称栏必须完全在安全区内。
- 名称栏右侧不得贴到安全区边缘。
- 名称文字必须完全落入名称文字安全区。
- 妖怪卡名称竖排，从上到下。
- 名称栏可作为 1星、2星、3星通用 UI，不应自带骷髅、宝石、紫火等会抬高低星级的强装饰。

### 技能描述背景

技能描述背景用于承载卡面规则文字。

技能条本体：

```text
x=128, y=863, w=560, h=96
```

技能文字安全区：

```text
x=168, y=885, w=480, h=52
```

要求：

- 1星、2星、3星妖怪卡统一预留技能描述背景。
- 技能区位于卡面内部，不在边框外侧，也不覆盖边框主体。
- 技能条必须完全在安全区内。
- 技能文字必须完全在技能文字安全区内。
- 技能条不要压到底部边框外侧。
- 技能条为通用 UI，默认不使用金边、紫火、宝石、骷髅等高星级装饰。
- 当前 1星、2星无技能时，可按技能文案文件留空或显示 `无技能`。

### 主视觉建议区

主视觉建议区用于审核角色插画与 UI 的空间关系，不是最终交付图元素。

```text
x=143, y=241, w=454, h=560
```

要求：

- 角色主体大部分应落入主视觉建议区。
- 角色头部不要压到星级和顶部边框。
- 角色下半身不要压到底部技能条。
- 插画主体仍应占卡面主要视觉空间。
- 原始生成插画必须在主体四周保留可调整留白，不得让脸部、手部主动作、关键道具或技能结果贴边。
- 生成时只向模型描述主体安全区比例与四周留白比例，不把名称栏、星级区、技能栏等 UI 位置写成固定构图要求；后续 UI 位置可能调整，原始插画应保持可复用。
- 生成时应预留后期缩放和平移空间；如果插画本体通过，优先用放大、缩小、移动和裁切适配主视觉建议区、名称栏、星级区和技能栏，而不是直接重新生成。
- 按当前卡牌数据推算，若以卡牌安全区 `673 × 969 px` 为插画有效安全画布，主体安全区建议居中为 `454 × 560 px`，约占安全画布宽度 `67.5%`、高度 `57.8%`。
- 对应主体区四周留白约为：左 `109.5 px`、右 `109.5 px`、上 `204.5 px`、下 `204.5 px`；换算为比例约为左右各 `16.3%`、上下各 `21.1%`。
- 生成提示词可表述为：主体关键元素保持在画面中央约 `68%` 宽、`58%` 高的安全构图框内，四周保留约 `16%` 水平留白与 `21%` 垂直留白；留白只放非关键信息。

## 四、文字规范

### 名称文字

主字体：

```text
Source Han Serif SC Heavy
```

替代字体：

1. `Noto Serif SC Bold`
2. `Songti SC Bold`
3. `STSongti-SC-Bold`

方向：

```text
竖排，从上到下
```

字号：

| 字数 | 字号 |
|---:|---:|
| 1~4字 | 36 px |
| 5~6字 | 34 px |
| 7字 | 32 px |

颜色：

| 星级 | 名称字色 |
|---|---|
| 1星 | `#F7F4EE` |
| 2星 | `#F7F4EE` |
| 3星 | `#F4E3B2` |

描边：

```text
颜色：#2A211D
粗细：2 px
```

阴影：

```text
颜色：rgba(0,0,0,0.35)
偏移：0, 2
模糊：4
```

禁止：

- 强发光
- 复杂渐变
- 金属浮雕字抢过名称本身
- 为了装饰牺牲可读性

### 技能文字

主字体：

```text
Source Han Sans SC Medium
```

替代字体：

1. `Noto Sans CJK SC Medium`
2. `PingFang SC Medium`
3. `Hiragino Sans GB W6`

排版：

```text
单行，不换行，水平垂直居中
```

字号：

| 文本长度 | 字号 |
|---:|---:|
| 12字以内 | 30 px |
| 13~16字 | 28 px |
| 更长文本 | 最低 26 px，优先压缩文案 |

颜色：

```text
#F3EEE4
```

描边：

```text
颜色：#1E1A18
粗细：1.5 px
```

阴影：

```text
颜色：rgba(0,0,0,0.35)
偏移：0, 1
模糊：2
```

要求：

- 规则文字必须优先保证清楚易读。
- 不得为了保留插画面积把技能字压得过小。
- 尽量不超过 16 个中文字符。
- 若超过 16 个中文字符，应优先回到 `规则/V1.2-卡面技能文案.md` 压缩文案，而不是继续缩小字号。

禁止：

- 强发光
- 复杂渐变
- 过小字号
- 文字超出安全区
- 长段规则说明

## 六、卡牌类型识别

玩家应在 1 秒内区分：

1. 妖怪卡
2. 法宝卡
3. 地盘卡

识别原则：

- 妖怪卡：角色卡
- 法宝卡：装备 / 法器卡
- 地盘卡：领地 / 地图卡

## 七、卡背系统

### 妖怪卡与法宝卡

妖怪卡与法宝卡共用同一张卡背。

原因：

妖怪与法宝属于同一公共牌库，玩家抽牌前不能通过卡背区分抽到的是妖怪还是法宝。

统一文件名：

```text
xiyao_qiangdipan_deck_back.png
```

禁止分别生成：

```text
xiyao_qiangdipan_monster_back.png
xiyao_qiangdipan_artifact_back.png
```

### 地盘卡

地盘卡使用独立卡背。

统一文件名：

```text
xiyao_qiangdipan_land_back.png
```

## 八、卡面信息层级

### 妖怪卡与法宝卡

妖怪卡与法宝卡必须清晰展示：

1. 星级或卡牌类型标识
2. 卡名
3. 插画主体
4. 简洁技能文本或效果文本

妖怪卡不展示：

- 攻击力
- 防守力
- 攻 / 守数值区
- 妖域归属区
- 技能类型标签

所有首领技能默认为登场触发，卡面不显示“登场技”“主动技”“被动技”等技能名。

### 地盘卡

地盘卡由于直接服务胜利条件，信息层级不同于妖怪卡与法宝卡。

当前规则中，玩家控制同一妖域全部 3 块地盘时立即获胜。

因此地盘卡最高优先级是：

```text
妖域归属
```

地盘卡成品阅读优先级：

```text
1. 妖域归属：妖域徽章 + 妖域名 + 妖域色
2. 地盘名称：白骨岭 / 火焰山 / 狮驼国等
3. 地盘插画：可被占领的山头、洞府、妖寨、地域
```

地盘卡不展示：

- 占领值
- 地盘等级
- 中级地盘
- 地盘效果
- 地盘特性
- 技能区
- 驻军区
- 资源产出
- 攻击力
- 防守力
- 星级
- 当前规则不存在的能力图标

## 十、透明资产与绿幕资源处理

绿幕资源进入正式合成前必须转为透明 PNG。

处理要求：

1. 去除纯绿色背景。
2. 输出真实透明 PNG。
3. 清理绿色溢边，重点处理骨白边缘、紫晶边缘、紫火边缘、星星外轮廓、卡框尖角和骨刺。
4. 不得损坏高光、裂纹、骨质边缘、金色描边。
5. 抠图后可以做内容裁边，但不得裁掉外扩尖角、骨刺、紫火。
6. 透明资产不得自带说明文字、尺寸标注、示意卡面或多余背景。

建议中间资源命名：

```text
frame_1star_clean.png
frame_2star_clean.png
frame_3star_clean.png
nameplate_vertical_clean.png
skillbar_common_clean.png
star_1_clean.png
star_2_clean.png
star_3_clean.png
```

## 十一、最终检查标准

每张妖怪卡、法宝卡、地盘卡最终出图前必须检查：

1. 是否使用正确含出血画布尺寸。
2. 背景、花纹、边框是否铺满出血区。
3. 成品裁切后是否不会断边、露白。
4. 关键文字、星级、名称栏、技能文字是否完全在安全区内。
5. 技能文字是否实体印刷后清楚易读。
6. 星级是否手机小图与实体牌上都能快速识别。
7. 名称是否不会被边框、角色、特效遮挡。
