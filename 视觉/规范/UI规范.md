# 《夕妖：抢地盘》UI规范

## 文件定位

本文件是《抢地盘》UI、卡牌框架、卡背系统、图标系统与透明资产拆分的唯一规范入口。

本文件只写 UI 规范，不写具体插画设计。

插画设计内容放在：

```text
视觉/插画设计/
```

---

## 一、UI边界

UI 只负责视觉呈现和信息组织，不定义：

- 游戏规则
- 技能效果
- 卡牌数量
- 星级战力
- 世界观人物事实
- 插画具体内容

规则、卡牌数据、技能文案仍以以下文件为准：

```text
规则/当前规则.md
规则/V1.2-基础卡表.md
规则/V1.2-卡面技能文案.md
```

---

## 二、卡牌尺寸

| 类型 | 方向 | 成品尺寸 |
|---|---|---|
| 妖怪卡 | 竖版 | 63 × 88 mm |
| 法宝卡 | 竖版 | 63 × 88 mm |
| 地盘卡 | 横版 | 88 × 63 mm |

印刷要求：

- 300 dpi
- 3 mm 出血
- 圆角
- 关键文字与图标必须放在安全区内
- 背景、花纹、边框必须延伸至出血区

### 地盘卡印刷画布

地盘卡为横版，成品尺寸：

```text
88 × 63 mm
```

制作印刷文件时，画布必须包含四边各 3 mm 出血：

| 区域 | 毫米尺寸 | 300 dpi 像素尺寸 | 用途 |
|---|---:|---:|---|
| 含出血画布 | 94 × 69 mm | 1110 × 815 px | 最终制作画布，背景与边框必须铺满 |
| 成品裁切区 | 88 × 63 mm | 1039 × 744 px | 裁切后的实际卡牌范围 |
| 安全区 | 82 × 57 mm | 969 × 673 px | 地盘名称、阵营徽章、阵营名等关键信息放置区 |

参考线位置以含出血画布 `94 × 69 mm` 为准：

| 参考线 | 位置 |
|---|---:|
| 左裁切线 | 3 mm |
| 右裁切线 | 91 mm |
| 上裁切线 | 3 mm |
| 下裁切线 | 66 mm |
| 左安全线 | 6 mm |
| 右安全线 | 88 mm |
| 上安全线 | 6 mm |
| 下安全线 | 63 mm |

交付要求：

- 裁切线、安全线只能作为设计软件中的参考线
- 最终导出的 PNG、JPG、PDF 不得把裁切线或安全线画进卡面
- 最终图中不得出现红线、黑线、虚线、十字定位线、裁切线文字或安全区文字
- 地盘背景、地图纹理、云雾、山脉、边框装饰必须铺满到 `94 × 69 mm` 出血画布
- 地盘名称、阵营徽章、阵营名、重要地图标识必须控制在 `82 × 57 mm` 安全区内

禁止：

- 白边
- 断边
- 关键文字贴近裁切线
- 背景突然结束
- 在最终交付图中显示裁切线或安全线

## 三、卡牌类型识别

玩家应在 1 秒内区分：

1. 妖怪卡
2. 法宝卡
3. 地盘卡

识别原则：

- 妖怪卡：角色卡
- 法宝卡：装备 / 法器卡
- 地盘卡：领地 / 地图卡

---

## 四、卡背系统

### 妖怪卡与法宝卡

妖怪卡与法宝卡共用同一张卡背。

原因：

妖怪与法宝属于同一公共牌库，玩家抽牌前不能通过卡背区分抽到的是妖怪还是法宝。

统一文件名：

```text
xiyao_qiangdipan_deck_back.png
```

禁止分别生成：

```text
xiyao_qiangdipan_monster_back.png
xiyao_qiangdipan_artifact_back.png
```

### 地盘卡

地盘卡使用独立卡背。

统一文件名：

```text
xiyao_qiangdipan_land_back.png
```

## 五、卡面信息层级

### 妖怪卡与法宝卡

妖怪卡与法宝卡必须清晰展示：

1. 星级或卡牌类型标识
2. 卡名
3. 插画主体
4. 简洁技能文本或效果文本

妖怪卡不展示：

- 攻击力
- 防守力
- 攻 / 守数值区
- 妖怪阵营区
- 技能类型标签

所有首领技能默认为登场触发，卡面不显示“登场技”“主动技”“被动技”等技能名。

### 地盘卡

地盘卡由于直接服务胜利条件，信息层级不同于妖怪卡与法宝卡。

当前规则中，玩家控制同一阵营全部 3 块地盘时立即获胜。

因此地盘卡最高优先级是：

```text
阵营归属
```

地盘卡成品阅读优先级：

```text
1. 阵营归属：阵营徽章 + 阵营名 + 阵营色
2. 地盘名称：白骨岭 / 火焰山 / 狮驼国等
3. 地盘插画：可被占领的山头、洞府、妖寨、地域
```

地盘卡不展示：

- 占领值
- 地盘等级
- 中级地盘
- 地盘效果
- 地盘特性
- 技能区
- 驻军区
- 资源产出
- 攻击力
- 防守力
- 星级
- 当前规则不存在的能力图标

## 六、核心图标组

必须建立以下图标组：

| 图标 | 用途 |
|---|---|
| 1星 | 小妖星级，也是基础结算识别 |
| 2星 | 精英星级，也是基础结算识别 |
| 3星 | 首领星级，也是基础结算识别 |
| 妖怪 | 妖怪卡类型 |
| 法宝 | 法宝卡类型 |
| 地盘 | 地盘卡类型 |
| 白骨 | 白骨阵营地盘识别 |
| 火云 | 火云阵营地盘识别 |
| 狮驼 | 狮驼阵营地盘识别 |
| 盘丝 | 盘丝阵营地盘识别 |
| 无主 | 无主地盘状态 |
| 已占领 | 已占领地盘状态 |
| 攻山 | 攻击行动 |
| 招兵 | 出牌驻守行动 |

基础妖怪卡不建立单独战力数字图标。

地盘卡基础版不建立占领值、地盘等级、地盘技能图标。

---

## 七、星级图标

星级图标应保持统一形状，只通过颜色与数量区分：

- 1星：青铜
- 2星：银铁
- 3星：暗金

要求：

- 星级必须比普通装饰更醒目
- 星级位置必须统一
- 星级大小必须支持手机端小图阅读
- 3星卡的三星可以适度放大，用于强化结算识别
- 禁止每张卡使用不同星级图案

---

## 八、妖怪卡UI

妖怪卡采用竖版结构。

从上到下：

1. 左上角星级区
2. 大面积插画区
3. 名称区
4. 底部技能区
5. 四周边框与角饰

比例建议：

- 插画区：70%~80%
- 名称区：10%~15%
- 技能区：10%~15%

### 1星小妖

展示：

- 1颗星
- 名字
- 插画

不展示：

- 技能栏
- 技能图标
- 技能文案
- “小妖”文字标签

### 2星精英

展示：

- 2颗星
- 名字
- 插画

不展示：

- 技能栏
- 技能图标
- 技能文案
- “精英”文字标签

### 3星首领

展示：

- 3颗星
- 名字
- 插画
- 底部技能文案

不展示：

- 技能图标
- “技能”二字
- “首领”二字
- “妖王”二字
- 技能类型标签

## 九、名称区

名称是卡面最高优先级文字之一。

必须支持最长首领名：

```text
金鼻白毛老鼠精
```

要求：

- 名字完整可读
- 不裁切
- 不被花纹遮挡
- 不缩成不可读小字
- 不写额外身份标签
- 名字牌可作为透明 UI 资产，文字由合成脚本后置写入

当前 3 星模板优先采用竖排名字牌方案。

---

## 十、技能区

技能文本来自：

```text
规则/V1.2-卡面技能文案.md
```

要求：

- 一句话
- 不加句号
- 不换行优先
- 玩家应能在 3 秒内读完
- 只显示效果文本
- 不显示技能名
- 不显示技能图标
- 不显示主动 / 被动 / 登场等类型标签

地盘卡基础版没有技能区。

## 十二、地盘卡UI

地盘卡为横版。

方向：

```text
88 × 63 mm
```

地盘卡是阵营收集目标牌。

因为胜利条件是控制同一阵营全部 3 块地盘，所以阵营归属必须比普通装饰更醒目。

### 地盘卡推荐结构

```text
左侧：阵营旗牌 / 阵营徽章 / 阵营名
上方：地盘名称
中部：大面积地盘插画
四周：统一地盘卡边框
```

### 左侧阵营旗牌

左侧阵营旗牌是地盘卡最重要的 UI 区域之一。

要求：

- 必须显示阵营徽章
- 必须显示阵营名
- 必须使用阵营主色
- 必须在手机小图中可识别
- 不要被插画遮挡

四阵营建议：

| 阵营 | 主色 | 徽章方向 |
|---|---|---|
| 白骨 | 骨白 / 墨灰 / 幽蓝 | 骷髅、骨纹、鬼火 |
| 火云 | 赤红 / 熔岩橙 / 暗金 | 火焰、火云、燃烧纹 |
| 狮驼 | 狮金 / 土褐 / 暗铜 | 狮头妖印、巨门纹、兽纹旗 |
| 盘丝 | 毒紫 / 暗绿 / 紫金 | 蜘蛛、蛛丝、花纹 |

### 顶部名称牌

顶部名称牌显示地盘名称。

要求：

- 地盘名称完整可读
- 字号大于普通说明文字
- 位置稳定，所有地盘卡统一
- 与左侧阵营旗牌不冲突

### 插画区

插画区应占据主体面积。

插画应表现可被占领的山头、洞府、妖寨或地域。

插画可以被 UI 框架压住少量边缘，但不能被文字框大量遮挡。

### 不采用

地盘卡不采用：

- 妖怪卡背景体系
- 法宝卡背景体系
- 技能区
- 占领值区
- 地盘效果区
- 地盘特性区
- 驻军区

驻军是桌面状态，由玩家把妖怪牌放在地盘卡上体现，不在地盘卡上预留固定区域。

## 十三、透明UI资产原则

UI 与插画分离是正式生产推荐流程。

所有 UI 资产必须：

- PNG
- 透明背景
- 无角色主体
- 无技能描述
- 无妖怪名称
- 无地盘名称
- 无攻击力
- 无防守力
- 无编号
- 无水印

最终卡牌通过程序或设计工具合成：

```text
插画 + UI + 名称 + 阵营信息
```

视觉审核阶段可以临时生成整卡效果图，用于确认整体观感。

但整卡效果图也必须遵守当前规则，不得添加当前规则不存在的 UI 信息。

## 十四、成品卡面与同名副本资产原则

成品卡牌目录中，同名、同星级、同效果、同视觉的基础卡只维护一张标准正面图。

重复数量只来自：

```text
规则/V1.2-基础卡表.md
```

成品图不通过复制文件来表达数量。

正确：

```text
卡牌成品/妖怪卡/小钻风.png
卡牌成品/妖怪卡/有来有去.png
卡牌成品/妖怪卡/虎先锋.png
```

错误：

```text
小钻风-1.png
小钻风-2.png
小钻风-3.png
```

印刷拼版时，可以重复放置同一个成品图文件，例如 `小钻风.png` 重复 3 次。

但仓库中的标准成品卡面仍只保留一份。

基础版同名副本禁止：

- 添加 A / B / C 编号
- 使用不同插画
- 使用不同边框
- 使用不同技能文案
- 使用不同名称
- 添加当前规则不存在的收藏、闪卡、异画标识

收藏异画、闪卡、纪念版、扩展包、测试版必须另行建立明确版本，不得混入基础牌库标准成品图。

## 十六、禁止项

禁止：

- 资料卡风格
- Word 表格风格
- 百科卡风格
- 原型测试卡
- 页游低质边框
- 过度复杂到影响阅读
- 用插画内容替代 UI 信息层级
- 在地盘卡上添加占领值
- 在地盘卡上添加地盘等级
- 在地盘卡上添加中级地盘
- 在地盘卡上添加地盘效果
- 在地盘卡上添加地盘特性
- 在地盘卡上添加驻军区
- 在地盘卡上添加规则不存在的资源或能力图标

当前基础牌最高只到 3 星，禁止提前消耗 4 星、5 星视觉空间。
