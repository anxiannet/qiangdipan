# 一、审核基准

## 1. 卡牌结构

当前基础牌库为：

- 1星小妖：24张，无技能
- 2星精英：12张，无技能
- 3星首领：12张，有登场技能
- 法宝：4张
- 地盘：12张

## 2. 尺寸与方向

- 妖怪卡：63 × 88 mm，竖版
- 法宝卡：63 × 88 mm，竖版
- 地盘卡：88 × 63 mm，横版

## 3. 视觉定位

- 地盘卡：地图感、领地感、场景感
- 妖怪卡：角色收藏卡感
- 法宝卡：传奇装备卡感

## 4. 生成原则

插画资产必须是纯插画：

- 不要 UI
- 不要文字
- 不要边框
- 不要技能图标
- 不要星级
- 不要卡名
- 不要阵营徽记

后续由程序执行：

```text
插画 + UI + 名称 + 技能
```
