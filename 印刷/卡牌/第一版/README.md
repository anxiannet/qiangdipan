# 卡牌第一版实际打印文件

本目录存放《夕妖：抢地盘》卡牌第一版实际打印相关文件。

## 目录说明

```text
可打印文件/  第一版实际打印图、单卡出血图、拼版 PDF、工厂确认稿
源文件/      可编辑源文件，如 PSD、AI、Figma、Canva 导出源稿
预览图/      仅在以后需要单独保存展示截图、压缩图、拍照效果图时使用
```

## 当前归档口径

第一版卡牌如果只有一套图片，且这些图片就是实际拿去打印的图，应放入：

```text
印刷/卡牌/第一版/可打印文件/妖怪卡/
印刷/卡牌/第一版/可打印文件/法宝卡/
印刷/卡牌/第一版/可打印文件/地盘卡/
印刷/卡牌/第一版/可打印文件/指南卡/
```

不再把这批文件归为“预览图”。

## 卡牌类型

```text
妖怪卡/
法宝卡/
地盘卡/
指南卡/
```

## 使用原则

- 本目录只保存第一版卡牌实际打印文件。
- 本目录不维护第二份卡表，不维护技能文案。
- 卡牌名称、数量、类型、星级、技能等信息仍以 `规则/` 与 `卡牌成品/印刷说明.md` 中的当前版本为准。
- 实际送印文件必须符合尺寸、出血、安全区、方向和 clean 成品图要求。
