# 包装盒第一版实际打印文件

本目录存放《夕妖：抢地盘》包装盒第一版实际打印相关文件。

## 目录说明

```text
可打印文件/  第一版实际打印图、送印 PDF、出血版高清图、工厂确认稿
源文件/      可编辑源文件，如 PSD、AI、Figma、Canva 导出源稿
预览图/      仅在以后需要单独保存展示截图、压缩图、拍照效果图时使用
```

## 当前归档口径

第一版包装盒如果只有一套图片，且这些图片就是实际拿去打印的图，应放入：

```text
印刷/包装盒/第一版/可打印文件/
```

不再把这批文件归为“预览图”。

## 使用原则

- 本目录只保存第一版包装盒实际打印文件。
- 本目录不维护游戏规则、卡牌数量、卡表或技能文案。
- 包装盒内容物、尺寸和印刷要求应与项目当前唯一来源保持一致。
- 正式送印前，以印刷厂 / 包装厂确认的最终文件为准。

## 建议命名

```text
包装盒-第一版-正面-打印图.png
包装盒-第一版-背面-打印图.png
包装盒-第一版-左侧面-打印图.png
包装盒-第一版-右侧面-打印图.png
包装盒-第一版-送印稿.pdf
包装盒-第一版-源文件.psd
```
