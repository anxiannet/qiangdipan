# 第一版印刷文件网站资源

本目录用于存放《夕妖：抢地盘》第一版印刷文件的网站展示资源副本。

## 来源

原始印刷文件目录：

```text
印刷/
```

印刷说明文档：

```text
卡牌成品/印刷说明.md
```

## 用途

本目录供正式网站读取：

```text
https://qdp.weijie.sg
```

网站运行时资源路径：

```text
/assets/print/v1/
```

## 原则

* 原始印刷文件仍以 `印刷/` 目录为准。
* 本目录只服务网站展示。
* 不在本目录维护第二份规则、卡表或技能文案。
* 文件如需更新，应先更新 `印刷/` 下的原始文件，再同步到本目录。
* `manifest.json` 记录原始路径与网站路径对应关系。

## 目录

```text
cards/  卡牌、指南卡、卡背
box/    包装盒、盒面、刀模
docs/   印刷说明与交付文档
other/  其他第一版印刷资源
```
