## 文件定位

本文件用于维护《夕妖：抢地盘》V1.3 基础版卡牌索引数据。

本文件是当前基础版以下信息的唯一来源：

- 卡牌名称
- 数量
- 世界观档位
- 星级
- 类型
- 卡面文案
- 技能强度评分
- 世界观符合度评分
- 技能评级
- 审核状态
- 妖怪志链接 / 法宝志链接

妖怪详细内容统一维护于：

```text
妖怪志/卡名/卡名.md
```

法宝详细内容统一维护于：

```text
法宝志/法宝名/法宝名.md
```

技能评分标准来源：

```text
规则/V1.2-技能评分标准.md
```

备选、移出基础版、后续扩展与双人对战测试内容，统一维护于：

```text
规则/V1.3-扩展包与移出基础版卡表.md
```

## 十四、维护原则

1. 本文件只维护基础版卡牌索引数据。
2. 妖怪详细资料统一维护于 `妖怪志/卡名/卡名.md`。
3. 法宝详细资料统一维护于 `法宝志/法宝名/法宝名.md`。
4. 基础卡表不得写长篇背景、小传、技能详细描述、设计理由、互动连锁或视觉设计。
5. 若妖怪志或法宝志中的技能调整，本文件只同步卡面文案、评分和审核状态。
6. 金鼻白毛老鼠精不再属于 V1.3 基础公共牌库，后续如进入扩展包，不得在基础卡表内重复维护其扩展包技能。
7. 所有新建或更新的规则、测试、视觉、包装相关文件，应在文件开头标明适用规则版本。
