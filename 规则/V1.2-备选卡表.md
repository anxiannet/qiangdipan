本文件不是当前基础版正式卡表。

当前基础版正式卡表唯一来源：

```text

```

本文件内容不得反向修改正式卡表。

## 五、扩展包候选方向

《抢地盘》未来扩展不依赖4星、5星。

正式边界：

- 基础版星级最高为3星
- 当前基础版不开放4星、5星
- 不修改基础版52张公共牌库，除非明确进入新版本迭代
- 不把双人对战规则混入抢地盘基础规则
- 不引入必须长期记录妖怪剩余生命值的机制

可扩展方向：

| 扩展方向 | 说明 |
|---|---|
| 新1星小妖 | 增加新的基础驻军 |
| 新2星精英 | 增加新的中坚驻军 |
| 新3星首领 | 增加新的妖王、洞主、势力核心角色 |
| 新法宝 | 维持无星级、规则级效果定位 |
| 新地盘 | 增加新山头、新洞府、新场景 |
| 新妖域 | 以3块地盘为一组进行扩展 |
| 新玩法模块 | 可选规则、场景规则、Boss模式等 |
| 收藏扩展 | 异画、闪卡、限定版、金边版等 |

### 对战版战斗模型边界

对战版可以测试以下模型：

- 妖怪没有剩余生命值
- 不在卡上放伤害标记
- 战斗只比较战力
- 低战力一方死亡
- 相同战力双方死亡
- 高战力一方存活
- 存活妖怪不记录伤害

以上模型不得反向修改《抢地盘》V1.2正式规则。

## 九、维护原则

1. 本文件只维护备选、移出、候选、待测与对战版参考。
2. 本文件不得作为当前基础版正式卡表使用。
3. 若某张备选卡进入正式基础版，必须先明确版本迭代，再移动到 `规则/V1.2-基础卡表.md` 或后续新版正式卡表。
4. 同名角色允许在不同产品中拥有不同战力，但必须分开维护。
5. 双人对战测试内容不得反向修改《抢地盘》基础规则。
6. 视觉资产可以复用，但规则数据必须分开维护。
