# 《夕妖：抢地盘》V1.2 基础卡表

## 文件定位

本文件用于维护《夕妖：抢地盘》V1.2 基础版卡牌索引数据。

本文件是当前基础版以下信息的唯一来源：

- 卡牌名称
- 数量
- 世界观档位
- 星级
- 战力
- 类型
- 卡面文案
- 技能强度评分
- 世界观符合度评分
- 技能评级
- 审核状态
- 妖怪志链接 / 法宝志链接

妖怪的以下详细内容不再写入基础卡表，统一维护于根目录：

```text
妖怪志/卡名/卡名.md
```

包括：背景、小传、候选技能详细描述、设计理由、强度分析、与其他妖怪的关系、羁绊、互动、连锁、视觉形象设计。

法宝详细资料可维护于：

```text
法宝志/
```

技能评分标准来源：

```text
规则/V1.2-技能评分标准.md
```

备选、移出基础版、后续扩展与双人对战测试内容，统一维护于：

```text
规则/V1.2-备选卡表.md
```

## 二、技能设计优先级

| 优先级 | 目标 | 说明 |
|---:|---|---|
| 1 | 增加玩家代入感 | 技能应让玩家觉得这张牌像这个西游角色、妖怪、法宝或小妖群体 |
| 2 | 好玩有趣 | 技能应制造轻 TRPG 感、桌面互动、惊喜、笑点或清楚的玩家决策 |
| 3 | 强度与平衡性 | 强度必须可测试、可评分、可调整，但不能压过代入感与趣味性 |

### 新技能默认审核规则

后续任何新加技能，默认审核状态一律为 **已审核**。

- 新技能可以直接进入基础卡表、妖怪志和技能汇总表。
- 新技能默认标记为“已审核”。
- 如后续发现问题，再将该技能改为“待重审”或“待修改”。
- 未形成具体技能的卡牌仍保持“待设计”。

### 量词标准

卡面文案统一使用以下量词：

| 对象 | 标准写法 |
|---|---|
| 手牌 / 牌库 / 弃牌堆里的卡 | 1张妖怪牌 / 1张法宝牌 |
| 场上的妖怪单位 | 1个妖怪 |
| 地盘里的守军单位 | 1个守军 |
| 地盘 | 1块地盘 |

说明：不使用“1只守军”或“1支守军”，避免同音歧义；不使用“1名妖怪”，避免人类感。

## 三、技能评级说明

| 评级 | 含义 |
|---|---|
| S | 当前锚点级或产品记忆点，必须重点测试 |
| A | 方向明确，代入感强，优先进入测试 |
| B | 可保留，但需要重审趣味性、强度或适配星级 |
| C | 风味、趣味或强度存在明显问题，优先重做 |
| 待评 | 尚未形成候选技能 |

说明：审核状态以本表记录为准；评级不代表最终定稿。

## 十一、维护原则

1. 本文件只维护基础版卡牌索引数据。
2. 妖怪详细资料统一维护于 `妖怪志/`。
3. 法宝详细资料维护于 `法宝志/`。
4. 基础卡表不得写长篇背景、小传、技能详细描述、设计理由、互动连锁或视觉设计。
5. 若妖怪志或法宝志中的技能调整，本文件只同步卡面文案、技能强度评分、世界观符合度评分、技能评级、审核状态。
6. 审核状态以本文件表格为准。
7. 后续任何新加技能，默认审核状态一律为“已审核”。
8. 卡面文案量词以本文件“量词标准”为准。
9. 不得在视觉文件、印刷说明或其他规则文件中维护第二份卡表。
