# 《夕妖：抢地盘》未来扩展与双人对战计划

## 文件定位

本文件用于记录《夕妖：抢地盘》的长期扩展方向，以及基于现有卡牌资产尝试开发“双人30卡对战游戏”的计划。

本文件不是当前基础规则。

当前正式规则仍以：

```text
规则/当前规则.md
规则/V1.0-核心规则重构.md
规则/V1.2-基础卡表.md
规则/V1.2-卡面技能文案.md
```

为准。

---

## 一、抢地盘本体扩展方向

### 1. 基础版星级上限

《抢地盘》基础版星级最高为3星。

当前定位：

| 星级 | 定位 | 规则作用 |
|---|---|---|
| 1星 | 小妖 | 基础驻军，无技能 |
| 2星 | 精英 | 中坚驻军，无技能 |
| 3星 | 首领 / 妖王 | 当前最高妖怪单位，有出场技能 |

基础版不增加4星、5星。

原因：

- 牛魔王、大鹏精、红孩儿、九灵元圣等已经作为3星首领进入基础版
- 3星即当前妖怪体系中的最高规则层级
- 继续增加4星、5星会削弱3星首领的牌面感
- 《抢地盘》是欢乐聚会卡牌，星级层级不宜过多
- 当前核心体验应保持为占山、守山、抢地盘，而不是高星单位碾压

---

### 2. 不通过升星扩展

《抢地盘》未来扩展不依赖4星、5星。

扩展方式改为横向扩展：

| 扩展方向 | 说明 |
|---|---|
| 新妖怪 | 继续在1星、2星、3星体系内增加角色 |
| 新3星首领 | 新妖王、新洞主、新势力核心角色 |
| 新法宝 | 维持无星级、规则级效果定位 |
| 新地盘 | 增加新妖域、新山头、新洞府 |
| 新妖域 | 以3块地盘为一组进行扩展 |
| 新玩法模块 | 可选规则、场景规则、Boss模式等 |
| 收藏扩展 | 异画、闪卡、限定版、金边版等 |

星级只表示规则战力，不承担收藏稀有度功能。

收藏价值通过边框、异画、闪卡、限定工艺体现，不通过4星、5星体现。

---

### 3. 抢地盘扩展边界

未来扩展不得直接破坏以下基础版原则：

- 不修改基础版核心胜利条件
- 不修改基础版52张公共牌库，除非明确进入新版本迭代
- 不把4星、5星加入基础公共牌库
- 不把双人对战规则混入抢地盘基础规则
- 不引入必须长期记录妖怪剩余生命值的机制

---

## 二、双人30卡对战游戏计划

### 1. 产品定位

双人30卡对战游戏是基于《抢地盘》现有妖怪、法宝、美术资产衍生的新游戏计划。

它不是《抢地盘》基础版规则。

暂定定位：

- 2人对战
- 每人约30张牌
- 可复用现有妖怪、法宝、插画与技能概念
- 更强调牌组构筑、前中后期节奏、单位交换与终结能力
- 不要求记录妖怪剩余生命值

---

### 2. 对战版星级方向

双人对战版可以测试1星到5星的战力体系。

该体系只作为对战版测试，不改变《抢地盘》基础卡表。

建议定位：

| 星级 | 对战定位 | 使用密度 |
|---|---|---|
| 1星 | 小兵、铺场、交换资源 | 多 |
| 2星 | 基础战斗单位 | 较多 |
| 3星 | 中型主力、有技能角色 | 中等 |
| 4星 | 大妖、压场单位 | 少 |
| 5星 | 王牌、终结者 | 极少 |

对战版可以临时为现有角色设置独立战力。

例如：

| 角色 | 抢地盘版 | 对战版测试方向 |
|---|---:|---:|
| 小钻风 | 1星 | 1星 |
| 虎先锋 | 2星 | 2星 |
| 金角大王 | 2星 | 3星 |
| 银角大王 | 2星 | 3星 |
| 白骨精 | 3星 | 3星 |
| 红孩儿 | 3星 | 4星 |
| 铁扇公主 | 3星 | 4星 |
| 牛魔王 | 3星 | 5星 |
| 大鹏精 | 3星 | 5星 |
| 九灵元圣 | 3星 | 5星 |

以上只是测试方向，不是正式卡表。

---

### 3. 无生命值标记战斗方案

双人对战版优先测试“要么死，要么活”的战斗模型。

核心原则：

- 妖怪没有剩余生命值
- 不在卡上放伤害标记
- 战斗只比较战力
- 低战力一方死亡
- 相同战力双方死亡
- 高战力一方存活
- 存活妖怪不记录伤害

示例：

| 战斗 | 结果 |
|---|---|
| 3星攻击2星 | 2星死亡，3星存活 |
| 2星攻击3星 | 2星死亡，3星存活 |
| 3星攻击3星 | 双方死亡 |
| 5星攻击3星 | 3星死亡，5星存活 |

该机制的目标是解决实体卡牌对战中“记录剩余生命值麻烦”的问题。

---

### 4. 技能复用原则

对战版早期测试可以复用当前技能方向，但不直接改动《抢地盘》卡面技能文案。

测试原则：

- 先只改对战战力，不重写技能
- 技能沿用现有角色身份与功能方向
- 如技能因对战环境失衡，再单独建立对战版技能表
- 对战版技能表不得反向覆盖《抢地盘》基础技能文案

---

### 5. 实体卡复用方案

当前建议先采用测试表复用现有卡牌。

阶段方案：

| 阶段 | 方案 | 说明 |
|---|---|---|
| 内部测试 | 使用现有卡牌 + 对战版临时战力表 | 不改卡面，不重印 |
| 小范围验证 | 形成独立对战规则草案 | 检查节奏与平衡 |
| 成熟后 | 制作独立对战版卡牌 | 同角色可拥有对战版星级与技能 |

现有《抢地盘》卡牌不应因为对战版测试而立即修改星级。

---

## 三、冲突处理原则

当《抢地盘》与双人对战版出现差异时：

- 《抢地盘》基础规则以当前规则文件为准
- 双人对战版以未来独立规则草案为准
- 同名角色允许在不同产品中拥有不同战力
- 同名角色的对战版设定不得反向修改抢地盘基础卡表
- 视觉资产可以复用，但规则数据必须分开维护

---

## 四、后续待测试问题

1. 双人对战版是否需要资源费用，还是每回合固定出牌限制即可
2. 每人30卡中1星到5星的合理比例
3. 5星王牌每副牌应限制为1张还是2张
4. 法宝在双人对战中是否仍作为一次性效果牌
5. 当前3星首领技能直接复用到对战版是否会失衡
6. 是否需要独立胜利条件，例如击破妖王、耗尽牌库、占领战线等
7. 是否保留地盘概念，或改为纯战线对战

---

## 当前结论

《抢地盘》本体继续坚持最高3星，不开放4星、5星。

双人30卡对战版可以作为独立新游戏计划，测试1星到5星战力体系，并采用无剩余生命值标记的战斗模型。
