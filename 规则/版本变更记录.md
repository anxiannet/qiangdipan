| 项目 | 内容 |
|---|---|
| 原定位 | 3星洞主 |
| 原基础版数量 | 2张 |
| 当前处理 | 移出基础版，进入扩展包候选 |
| 当前记录文件 | 规则/V1.3-扩展包与移出基础版卡表.md |
| 原技能 | 选1个1星守军，加入你的地盘。 |

### 测试依据

本次变更依据以下测试报告：

```text
测试报告/40张移除金鼻白毛老鼠精AI自动模拟测试.md
```

测试结论摘要：

```text
40张移除金鼻白毛老鼠精方案可以运行。
但它没有明显加快游戏，只是增加空库风险。
若目标是减少牌数，42张是更合理的下限测试点。
若目标是正式基础版稳定体验，原测试建议仍是58张更稳。
本次根据产品方向决定采用40张基础公共牌库，并将金鼻白毛老鼠精转入扩展包。
```

说明：本次版本变更是产品取舍，不是单纯由 AI 测试自动推荐。

### 调整后的标准版法宝

| 法宝 | 当前归属 | 卡面文案 |
|---|---|---|
| 紫金红葫芦 | V1.3标准版 | 喊一名玩家名字；对方答应后，收走其1个守军到你的手牌。 |
| 金刚琢 | V1.3标准版 | 取消1次法宝效果。 |
| 幌金绳 | V1.3标准版 | 选择1个守军，加入你的手牌。 |
| 辟火罩 | V1.3标准版 | 保护你的地盘1回合。 |

| 法宝 | 当前处理 | 原卡面文案 |
|---|---|---|
| 芭蕉扇 | 转入《妖王再临》扩展包候选 | 吹回1块地盘中的所有守军。 |

### 规则边界

```text
辟火罩可被金刚琢取消。
辟火罩只阻止其他玩家对你的地盘发动“抢地盘”。
辟火罩不阻止妖怪技能或其他法宝效果。
本次调整不改变主要行动、抢地盘、公共牌库耗尽、地盘回流或胜利条件。
```

## 后续要求

1. 后续所有新建或更新文件必须标明规则版本或适用规则版本。

6. 基础卡表有独立卡表版本号；卡表变化应递增卡表版本号并追加记录，不直接覆盖旧记录。
