# 《夕妖：抢地盘》V1.2 技能具体分数标准

## 文件定位

本文件用于把《夕妖：抢地盘》技能强度从“0 到 5 等级”细化为“0.0 到 5.0 具体分数”。

用途：

- 后续 AI 评估新技能时给出更精确数值
- 后续双人对战版设计时复用技能强度参数
- 后续平衡测试时比较同等级技能内部差异
- 后续生成卡表、测试表、数值表时作为评分依据

本文件不是正式规则来源。

正式卡牌数据唯一来源：

```text
规则/V1.2-基础卡表.md
```

技能汇总来源：

```text
规则/V1.2-技能汇总表.md
```

基础评分原则来源：

```text
规则/V1.2-技能评分标准.md
```

本文件不得新增正式技能，不得修改正式卡表，不得创建平行规则体系。

---

## 一、核心原则

以后评估技能时，不只给“等级 1 / 2 / 3 / 4 / 5”，必须给出具体分数。

推荐格式：

```text
规则强度：3.4 / 5.0
世界观符合度：4.5 / 5.0
综合建议：可作为 3 星首领技能，但需要测试是否偏强
```

说明：

- 规则强度用于判断技能在游戏中有多强。
- 世界观符合度用于判断技能是否符合西游原著角色 / 法宝印象。
- 两者必须分开打分。
- 不允许只写“强”“弱”“中等”。
- 不允许只写“等级 3”。

---

## 二、分数刻度

### 1. 总范围

| 分数范围 | 含义 |
|---:|---|
| 0.0 | 完全无用 |
| 0.1 ~ 0.9 | 几乎无用，仅有极微小意义 |
| 1.0 ~ 1.9 | 弱技能，有一点信息或轻微收益 |
| 2.0 ~ 2.9 | 低强度实用技能，可影响局面但限制明显 |
| 3.0 ~ 3.9 | 中等强度技能，有明确场面、资源或节奏收益 |
| 4.0 ~ 4.9 | 高强度技能，能影响关键对象或关键节奏 |
| 5.0 | 极高强度锚点，整地盘、关键控制或强制重置级别 |

### 2. 推荐精度

正式评估建议使用 0.1 分精度。

例如：

```text
3.0、3.1、3.2、3.3、3.4、3.5、3.6、3.7、3.8、3.9
```

如果只是快速草评，可以使用 0.5 分精度。

例如：

```text
2.5、3.0、3.5、4.0
```

不建议使用超过 1 位小数，因为当前游戏仍是欢乐聚会卡牌，不需要过度精算。

## 三、等级锚点与具体分数区间

| 原等级 | 具体分数区间 | 锚点 | 说明 |
|---:|---:|---|---|
| 0 | 0.0 | 查看自己手牌 | 完全没有实际收益 |
| 1 | 1.0 ~ 1.9 | 查看公共牌库顶 1 张后放回 / 查看地盘牌库顶 1 张后放回 | 有极轻微信息收益 |
| 2 | 2.0 ~ 2.9 | 吹回 1 只 1 星守军 | 低星、单体、轻度场面影响 |
| 3 | 3.0 ~ 3.9 | 获得 1 只 1 星守军 / 消灭 1 只 2 星以下守军 / 额外打出 1 张妖怪 | 明确资源差、场面差或节奏收益 |
| 4 | 4.0 ~ 4.9 | 任意守军硬处理 / 额外攻山 / 法宝反制 | 关键对象或关键节奏影响 |
| 5 | 5.0 | 清空一块地盘所有守军并使其变为无主 | 整地盘控制结构重置 |

## 四、具体分数锚点

### 0 分段

| 分数 | 技能模板 | 判断 |
|---:|---|---|
| 0.0 | 查看自己手牌 | 完全无用 |
| 0.3 | 查看自己已知公开信息 | 几乎无用，最多提醒玩家 |
| 0.5 | 查看自己下一步本来必然会看到的信息 | 极弱，只有轻微计划价值 |
| 0.8 | 查看一个低价值公开状态 | 有一点点辅助，但不值得作为正式技能 |

### 1 分段

| 分数 | 技能模板 | 判断 |
|---:|---|---|
| 1.0 | 查看公共牌库顶 1 张牌，然后放回 | 基础信息收益 |
| 1.1 | 查看地盘牌库顶 1 张地盘，然后放回 | 信息略贴近胜利目标，但不改变局面 |
| 1.3 | 查看一名玩家手牌中的 1 张随机牌 | 有信息但不完整 |
| 1.5 | 查看一名玩家全部手牌 | 有博弈价值，但不改资源 |
| 1.8 | 查看后可以选择是否公开给所有玩家 | 有轻微心理博弈价值 |

### 2 分段

| 分数 | 技能模板 | 判断 |
|---:|---|---|
| 2.0 | 吹回 1 只 1 星守军 | 低星单体回手 |
| 2.2 | 消灭 1 只 1 星守军 | 低星单体去除，比回手重 |
| 2.4 | 选择 1 块己方地盘，本回合驻军上限 +1 | 临时防守收益 |
| 2.6 | 吹回 1 只 2 星以下守军，但有明显条件 | 中低星处理但受限 |
| 2.8 | 获得 1 只 1 星守军到手牌，但不能立刻使用 | 有资源差但节奏慢 |

### 3 分段

| 分数 | 技能模板 | 判断 |
|---:|---|---|
| 3.0 | 获得 1 只 1 星守军到手牌 | 明确资源差 |
| 3.1 | 消灭 1 只 2 星以下守军 | 可处理 2 星，不能处理 3 星 |
| 3.2 | 吹回 1 只任意守军 | 可处理 3 星但不消灭 |
| 3.3 | 获得 1 只 1 星守军并放入己方地盘 | 直接形成场面差 |
| 3.4 | 额外打出 1 张妖怪牌 | 突破铺场节奏，但不直接攻山 |
| 3.5 | 查看一名玩家手牌并弃掉其中 1 张低价值牌 | 信息转化为资源破坏 |
| 3.6 | 吹回 1 只 2 星以下守军，无额外条件 | 稳定中低星回手 |
| 3.7 | 选择 1 块地盘，消灭其中所有 1 星守军，常见情况下能清场 | 群体低星处理 |
| 3.8 | 选择 1 块己方地盘，驻军上限 +1，持续到地盘失控 | 持续地盘强化 |

### 4 分段

| 分数 | 技能模板 | 判断 |
|---:|---|---|
| 4.0 | 消灭 1 只任意守军 | 可处理 3 星首领 |
| 4.1 | 收走 1 只任意守军并弃掉 | 法宝式硬去除 |
| 4.2 | 获得 1 只任意守军加入你的手牌 | 高资源差 |
| 4.3 | 立即发动一次攻山 | 可直接夺地，强节奏收益 |
| 4.4 | 取消 1 次法宝效果 | 反制规则级压制物 |
| 4.5 | 获得 1 只任意守军并放入己方地盘 | 对手少，你地盘立刻变强 |
| 4.6 | 清空一块地盘内所有 1 星和 2 星守军 | 大范围处理但不碰 3 星 |

| 4.9 | 清空一块地盘所有守军，但有显著限制或代价 | 接近 5 分，但被条件压制 |

### 5 分锚点

| 分数 | 技能模板 | 判断 |
|---:|---|---|
| 5.0 | 选择 1 块地盘，将其中所有守军吹回拥有者手牌，该地盘立即变为无主地盘 | 整地盘清场 + 改变控制结构 + 触发回流，是 V1.2 极高强度锚点 |

## 五、规则强度基础计算法

### 1. 起始分

先根据作用对象和动作确定起始分。

| 类型 | 起始分 |
|---|---:|
| 无实际收益 | 0.0 |
| 轻微信息 | 1.0 |
| 对手手牌信息 | 1.5 |
| 1 星守军轻处理 | 2.0 |
| 1 星守军资源转移 | 3.0 |
| 2 星以下守军处理 | 3.1 |
| 任意守军回手 | 3.2 |
| 任意守军硬去除 | 4.0 |
| 额外打出妖怪 | 3.4 |
| 额外攻山 | 4.3 |
| 法宝反制 | 4.4 |
| 整地盘清空并变无主 | 5.0 |

### 2. 加分因子

| 因子 | 加分 |
|---|---:|
| 影响目标从 1 个变成 2 个 | +0.5 |
| 影响一块地盘内所有 1 星 | +0.7 |
| 影响一块地盘内所有 2 星以下 | +1.0 |
| 影响一块地盘内所有守军 | +1.5 |
| 能处理 3 星首领 | +0.6 |
| 直接让地盘无主 | +0.8 |
| 可能触发地盘回流 | +0.3 |
| 必定触发地盘回流 | +0.7 |
| 产生双向资源差 | +0.6 |
| 额外行动 | +0.7 |
| 额外主要行动级收益 | +1.2 |
| 持续到你的下回合开始 | +0.4 |
| 持续到地盘失控 | +0.7 |
| 世界观符合度 4 分以上且表达清晰 | +0.1 ~ +0.3 |

### 3. 扣分因子

| 因子 | 扣分 |
|---|---:|
| 只能 1 星 | -0.5 |
| 只能 2 星以下 | -0.2 |
| 只能己方地盘 | -0.3 |
| 只能自己 | -0.6 |
| 需要特定角色在场 | -0.7 |
| 需要特定妖域 / 特定地盘 | -0.7 |
| 占用主要行动 | -0.3 |
| 一次性法宝 | -0.2 |
| 可被金刚琢取消 | -0.2 |
| 目标容易不存在 | -0.3 |
| 效果给对方保留资源，例如回手 | -0.2 |
| 世界观符合度 0~1 且明显违和 | -0.3 ~ -0.8 |

### 4. 封顶规则

最终分数必须在 0.0 到 5.0 之间。

```text
若计算结果 < 0，则记为 0.0
若计算结果 > 5，则记为 5.0
```

对于 V1.2 基础版：

- 普通 3 星首领技能建议大多落在 2.5 ~ 4.2。
- 法宝技能可以落在 4.0 ~ 5.0。
- 5.0 应非常少，通常只给芭蕉扇这种整地盘级效果。
- 低于 1.5 的技能不建议作为 3 星首领正式技能，除非世界观和心理博弈价值非常高。

## 六、世界观符合度具体分数

世界观符合度也必须给具体分数，而不是只给等级。

| 分数范围 | 含义 |
|---:|---|
| 0.0 | 完全违和 |
| 0.1 ~ 0.9 | 几乎无关 |
| 1.0 ~ 1.9 | 弱关联，牵强解释 |
| 2.0 ~ 2.9 | 有关联，但不是核心特征 |
| 3.0 ~ 3.9 | 符合常见印象 |
| 4.0 ~ 4.9 | 高度符合核心能力 |
| 5.0 | 芭蕉扇级，名称、动作、规则结果高度统一 |

### 世界观符合度分数锚点

| 分数 | 示例 | 说明 |
|---:|---|---|
| 0.0 | 芭蕉扇：查看自己手牌 | 完全反向违和 |
| 1.0 | 芭蕉扇：查看公共牌库顶 1 张牌 | 只能说是“神奇法宝”，但不贴核心能力 |
| 2.0 | 芭蕉扇：吹回 1 只 1 星守军 | 有吹风意象，但规模太小 |
| 3.0 | 芭蕉扇：吹回 1 只任意守军 | 符合吹走，但不够法宝牌面 |
| 4.0 | 芭蕉扇：吹回一块地盘所有 1 星守军 | 大范围吹回，方向高度符合 |
| 4.5 | 芭蕉扇：吹回一块地盘所有守军，但地盘不变无主 | 世界观很贴，但规则结果少一层场景压制 |
| 5.0 | 芭蕉扇：吹回一块地盘所有守军，该地盘变无主 | 名称、动作、规则结果高度统一 |

## 七、综合评估建议

后续对战版可能需要综合分，用于排序和数值建模。

建议分开保存三个分数：

| 分数字段 | 用途 |
|---|---|
| 规则强度分 | 判断游戏内强度 |
| 世界观符合度分 | 判断是否贴合西游原著与角色直觉 |
| 综合设计分 | 判断是否值得保留或优先测试 |

推荐综合设计分公式：

```text
综合设计分 = 规则强度分 × 0.75 + 世界观符合度分 × 0.25
```

说明：

- 规则强度权重大，因为最终要服务游戏平衡。
- 世界观符合度不能替代规则强度，但能影响保留优先级。
- 如果是纯视觉、收藏、风味卡，可以提高世界观权重。
- 如果是对战版数值平衡，应主要看规则强度分。

## 十、对战版使用说明

后续若开发双人 30 卡对战版，可以直接复用本文件分数，但必须注意：

1. 对战版不一定有地盘回流，因此涉及地盘无主的加分要重新计算。
2. 对战版如果有 4 星、5 星，能否处理高星单位要重新校准。
3. 对战版如果每回合允许多动作，额外行动的价值会下降。
4. 对战版如果有费用系统，同一技能分数要结合费用重新换算。
5. 对战版如果没有公共地盘牌库，查看地盘牌库顶这类技能应重评。

建议对战版增加字段：

| 字段 | 说明 |
|---|---|
| 抢地盘规则强度分 | 当前 V1.2 评分 |
| 对战版规则强度分 | 在双人对战环境下重新评分 |
| 世界观符合度分 | 可复用 |
| 推荐费用 / 星级 | 根据对战版系统另行计算 |

## 十一、维护原则

1. 后续所有技能评估必须给出具体分数，不得只给等级。
2. 规则强度分和世界观符合度分必须分开记录。
3. 综合设计分可以用于排序，但不得替代规则强度分。
4. V1.2 正式规则仍以 `规则/V1.2-基础卡表.md` 为准。
5. 本文件不得新增正式技能，不得修改正式卡表。
6. 后续若对战版规则成型，应新增对战版专用评分表，不得反向覆盖本文件。
