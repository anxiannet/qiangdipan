# 《夕妖：抢地盘》V1.2 技能评分标准

## 文件定位

本文件用于建立《夕妖：抢地盘》V1.2 技能强度评分标准，供后续 AI、规则整理、平衡测试和扩展设计时参考。

本文件不是正式规则来源。

正式卡牌数据唯一来源：

```text
规则/V1.2-基础卡表.md
```

当前技能统计来源：

```text
规则/V1.2-技能汇总表.md
```

卡面短文案来源：

```text
规则/V1.2-卡面技能文案.md
```

本文件不得新增正式技能，不得修改正式卡表，不得创建平行规则体系。

---

## 一、评分用途

技能评分用于回答以下问题：

1. 一个技能大约有多强。
2. 两个技能是否处于同一强度层级。
3. 新技能是否可能破坏 V1.2 基础版节奏。
4. 法宝与 3 星首领技能是否存在过强或过弱问题。
5. 后续扩展包技能是否需要增加限制条件。
6. 技能是否符合《西游记》原著中的角色、法宝、神通或情节印象。

评分不用于：

- 卡面显示
- 直接决定卡牌星级
- 直接决定是否进入正式卡表
- 替代测试
- 替代正式规则文本

---

## 二、评分总原则

技能强度不是只看动作，也不是只看目标。

必须同时考察：

```text
作用对象 × 动作类型 × 影响数量 × 持续时间 × 牌区去向 × 地盘连锁 × 行动节奏 × 限制条件 × 西游原著世界观符合度
```

简化公式：

```text
技能等级 = 基础对象价值 + 动作强度 + 放大因子 - 限制因子 + 世界观符合度修正
```

更完整的判断公式：

```text
技能等级 =
对象价值
+ 动作强度
+ 数量修正
+ 持续时间修正
+ 地盘连锁修正
+ 行动节奏修正
+ 资源差修正
+ 选择自由度修正
+ 世界观符合度修正
- 星级限制
- 前置条件
- 使用成本
- 反制风险
```

最终评分应落在 0 到 5 之间。

说明：

- “技能等级”主要衡量规则强度。
- “世界观符合度”是独立维度，通常不直接把弱技能变成强技能。
- 当两个技能规则强度接近时，优先选择世界观符合度更高、玩家一看就懂的技能。

## 三、技能等级锚点

### 等级 0：完全无用

| 项目 | 内容 |
|---|---|
| 锚点技能 | 查看自己手牌 |
| 规则效果 | 选择你自己，查看你的手牌 |
| 强度定义 | 没有任何实际收益，只执行玩家原本就能做到的动作 |

判断标准：

- 不提供新信息
- 不改变手牌数量
- 不改变守军
- 不改变地盘
- 不改变行动
- 不改变牌区
- 不产生心理博弈

典型用途：

```text
作为 0 分基准，用来确认某个技能是否真的有实际意义。
```

### 等级 1：有一丁点作用

| 项目 | 内容 |
|---|---|
| 锚点技能 A | 查看公共牌库顶 1 张牌，然后放回 |
| 锚点技能 B | 查看地盘牌库顶 1 张地盘，然后放回 |
| 强度定义 | 有极轻微信息收益，但不改变资源、场面、地盘控制或行动 |

为什么“查看地盘牌库顶 1 张地盘”是 1 分：

- 可以预判未来中央地盘补充
- 可以辅助判断是否清空地盘或等待某妖域地盘出现
- 但不抽取地盘
- 不改变地盘牌库顺序
- 不改变地盘控制
- 不保证该地盘马上出现

### 等级 2：低强度实用技能

| 项目 | 内容 |
|---|---|
| 参考技能 | 吹回 1 只 1 星守军 |
| 强度定义 | 能影响场面，但目标价值低、限制明显 |

典型特征：

- 只处理 1 星
- 只影响单体
- 主要产生轻微节奏干扰
- 通常不能处理 3 星首领
- 通常不能稳定改变地盘控制

### 等级 3：中等强度技能

| 项目 | 内容 |
|---|---|
| 参考技能 | 获得 1 只 1 星守军到手牌 / 消灭 1 只 2 星以下守军 / 额外打出 1 张妖怪 |
| 强度定义 | 能产生明确资源差、场面差或节奏收益，但仍有明显限制 |

典型特征：

- 能稳定影响守军
- 能产生资源差
- 能产生场面差
- 可能间接导致地盘无主
- 但通常不是整地盘效果
- 通常不直接完成胜利条件

### 等级 4：高强度技能

| 项目 | 内容 |
|---|---|
| 参考技能 | 消灭或获得 1 只任意守军 / 额外攻山 / 持续强化地盘 / 取消法宝效果 |
| 强度定义 | 能处理关键对象，或显著改变节奏、资源、地盘防守结构 |

典型特征：

- 能处理 3 星首领
- 能反制关键法宝
- 能突破每回合 1 个主要行动限制
- 能持续强化关键地盘
- 能产生明显胜负相关收益

### 等级 5：极高强度技能

| 项目 | 内容 |
|---|---|
| 参考技能 | 清空一块地盘所有守军并使其变为无主 |
| 强度定义 | 大范围影响关键对象，直接改变地盘控制结构或强制重置关键局面 |

典型特征：

- 影响一整块地盘
- 影响所有守军
- 能直接让地盘变为无主
- 能触发地盘回流
- 能阻断或创造胜利机会
- 通常需要限制、一次性、法宝身份或可反制机制

## 四、西游原著世界观符合度评分

### 1. 文件定位

世界观符合度用于评估技能是否符合《西游记》原著中角色、法宝、神通、情节和玩家直觉。

它是独立评分维度，不替代规则强度评分。

用途：

- 判断技能是否“像这个角色 / 法宝该有的能力”
- 判断玩家是否能通过名称自然理解技能
- 判断技能是否有西游味、代入感和记忆点
- 辅助同强度技能之间的取舍

不用于：

- 直接提高卡牌星级
- 直接改变正式技能
- 强行还原原著全部细节
- 创建复杂世界观系统

### 2. 世界观符合度锚点

| 世界观符合度 | 锚点 | 判断标准 |
|---:|---|---|
| 0 | 完全无关技能 | 技能与角色 / 法宝原著印象没有关系，甚至反向违和 |
| 1 | 弱关联 | 只能牵强解释，玩家不容易自然理解 |
| 2 | 有关联 | 能看出来源，但不是该角色 / 法宝最核心特征 |
| 3 | 符合 | 技能符合角色或法宝常见印象，玩家基本能接受 |
| 4 | 高度符合 | 技能抓住核心能力，名称、效果和玩法有明显对应 |
| 5 | 芭蕉扇级锚点 | 原著意象、玩家直觉、规则效果高度统一 |

### 3. 满分锚点：芭蕉扇

| 项目 | 内容 |
|---|---|
| 锚点法宝 | 芭蕉扇 |
| 当前规则效果 | 选择 1 块地盘，将其中所有守军吹回拥有者手牌。该地盘立即变为无主地盘 |
| 世界观符合度 | 5 |

为什么芭蕉扇是 5 分锚点：

- 原著印象中，芭蕉扇的核心就是“大范围扇动、吹退、压制、改变局面”
- 当前规则中的“吹回所有守军”直接对应“扇飞 / 吹走”的玩家直觉
- “一块地盘变为无主”对应芭蕉扇对场景级局面的强干预
- 法宝名称、动作词“吹回”、规则结果三者高度统一
- 玩家看到芭蕉扇，不需要解释太多，就能理解它应该是大范围地盘压制法宝

因此：

```text
芭蕉扇 = 世界观符合度 5 的标准样本
```

### 4. 世界观符合度 0 到 5 示例

| 分数 | 示例模板 | 说明 |
|---:|---|---|
| 0 | 芭蕉扇：查看自己手牌 | 与法宝核心印象完全无关 |
| 1 | 芭蕉扇：查看公共牌库顶 1 张牌 | 只有“神奇法宝”这种弱关联，不符合核心印象 |
| 2 | 芭蕉扇：吹回 1 只 1 星守军 | 有吹回意象，但规模太小，不能体现芭蕉扇牌面 |
| 3 | 芭蕉扇：吹回 1 只任意守军 | 符合“吹走”，但仍偏单体 |
| 4 | 芭蕉扇：吹回 1 块地盘所有 1 星守军 | 大范围吹回，符合度高，但不够完整 |
| 5 | 芭蕉扇：吹回 1 块地盘所有守军，该地盘变为无主 | 名称、动作、场景级效果高度统一 |

### 5. 世界观符合度评分维度

| 维度 | 问题 | 高分表现 |
|---|---|---|
| 原著核心能力 | 技能是否抓住角色 / 法宝最有代表性的能力？ | 芭蕉扇能吹、红孩儿用火、黄风怪用风 |
| 玩家直觉 | 玩家看到名字后，是否能猜到效果方向？ | 名称和效果自然对应 |
| 动作词贴合 | 技能动词是否贴合角色 / 法宝意象？ | 吹回、烧掉、收走、绑走、偷取 |
| 作用对象贴合 | 技能影响对象是否符合原著表现？ | 法宝作用守军或地盘，首领作用战场或守军 |
| 规模贴合 | 效果规模是否配得上角色 / 法宝牌面？ | 芭蕉扇不应只是单体小效果 |
| 结果贴合 | 结算结果是否符合玩家对原著能力的期待？ | 扇飞后回手，火烧后消灭 |
| 记忆点 | 技能是否容易被玩家用一句话记住？ | “芭蕉扇一扇清一地” |
| 不违和 | 技能是否避免反向设定？ | 芭蕉扇不应主打查看手牌 |

### 6. 世界观符合度修正建议

世界观符合度通常不直接覆盖规则强度，但可以作为修正项。

| 世界观符合度 | 建议修正 | 使用方式 |
|---:|---:|---|
| 0 | -1 | 技能严重违和，应优先重做 |
| 1 | -0.5 | 技能可用但缺少西游味 |
| 2 | 0 | 有一定关联，不加不扣 |
| 3 | +0.25 | 符合角色印象，可保留 |
| 4 | +0.5 | 高度贴合，优先保留 |
| 5 | +0.5 到 +1 | 规则和世界观高度统一，可作为产品记忆点 |

注意：

- 世界观符合度不能让一个完全没用的技能变成强技能。
- 世界观符合度可以帮助决定“同样 3 分技能中哪个更值得保留”。
- 世界观符合度过低时，即使规则强度合理，也应考虑换技能表达。

### 7. 世界观符合度与规则强度的关系

| 情况 | 处理建议 |
|---|---|
| 规则强、世界观也强 | 优先保留，但注意是否过强 |
| 规则强、世界观弱 | 优先重写表现方式或换角色承载 |
| 规则弱、世界观强 | 可以保留为风味技能，但要确认是否有游戏价值 |
| 规则弱、世界观也弱 | 不建议进入正式卡表 |
| 规则过强、世界观满分 | 增加限制，不要直接删除 |

示例：

```text
芭蕉扇规则强度 5，世界观符合度 5。
处理方式不是削弱到失去特色，而是通过法宝一次性、占用主要行动、可被金刚琢反制等方式控制。
```

## 五、作用对象价值表

| 作用对象 | 基础价值 | 说明 |
|---|---:|---|
| 自己手牌 / 自己信息 | 0 | 玩家本来就知道，通常无收益 |
| 公共牌库顶 | 1 | 只有轻微信息收益 |
| 地盘牌库顶 | 1 | 能预判未来地盘，但不改变局面 |
| 对手手牌信息 | 1~2 | 有博弈价值，但不直接改变资源 |
| 玩家手牌中的牌 | 2~4 | 若只是查看偏低，若弃掉或获得偏高 |

| 一块地盘内所有守军 | 5 | 群体作用，容易改变地盘控制 |
| 法宝效果 | 4 | 法宝属于规则级压制物，反制价值高 |
| 行动次数 / 流程 | 4~5 | 影响每回合 1 个主要行动的节奏限制 |
| 地盘控制权 | 5 | 直接关联胜利条件 |

| 动作 | 基础强度 | 说明 |
|---|---:|---|
| 查看自己已知信息 | 0 | 没有实际收益 |
| 查看未知信息 | 1 | 只有信息收益 |

| 额外攻山 | 4 | 可能直接夺地，节奏爆发强 |
| 清空地盘 | 5 | 群体移除，容易改变控制权 |
| 直接改变控制 | 5 | 直接关联胜利条件，基础版慎用 |

## 八、持续时间修正

| 持续时间 | 修正 | 说明 |
|---|---:|---|
| 立即一次性结算 | 0 | 基础值 |
| 持续到本回合结束 | +0.5 | 短期战术价值 |
| 持续到你的下回合开始 | +1 | 覆盖一轮对手行动，防守价值提升 |
| 持续到目标地盘失控 | +1.5 | 地盘是胜利目标，持续收益明显 |
| 永久持续 | +2 | 基础版慎用，可能破坏平衡 |

示例：

- 玉面狐狸：持续到你的下回合开始，因此有一定防守价值
- 九灵元圣：持续到地盘失去控制，因此强度明显高于一次性小效果

## 九、地盘连锁修正

《抢地盘》的关键连锁是：

```text
守军被移走 / 消灭
→ 地盘失去全部守军
→ 地盘变为无主
→ 地盘回流
→ 中央地盘区补充
```

| 连锁能力 | 修正 | 说明 |
|---|---:|---|
| 不可能触发地盘无主 | 0 | 只看信息或只强化 |
| 可能触发地盘无主 | +0.5 | 单体移除最后守军时可能触发 |
| 经常触发地盘无主 | +1 | 常见局面下能打空地盘 |
| 必定触发地盘无主 | +1.5 | 清空一整块地盘 |
| 同时触发回流与中央补充 | +2 | 影响地盘循环节奏 |

判断重点：

- 技能是否直接写“该地盘变为无主”
- 技能是否能清空所有守军
- 技能是否能处理最后 1 只守军
- 目标地盘是否是某妖域胜利关键地盘

## 十、是否影响地盘控制权

| 地盘影响 | 修正 | 说明 |
|---|---:|---|
| 不影响地盘 | 0 | 只看信息或处理手牌 |
| 可能间接影响地盘 | +0.5 | 单体守军位移或消灭 |
| 高概率让地盘无主 | +1 | 群体低星处理或关键守军处理 |
| 直接让地盘无主 | +1.5 | 清空地盘或明确变无主 |
| 直接夺取地盘 | +2 | 基础版慎用 |
| 直接完成胜利条件 | 需要单独测试 | 通常不建议无条件出现 |

地盘控制是《抢地盘》最高价值对象，因为胜利条件是控制同一妖域 3 块地盘。

## 十一、是否能处理 3 星首领

| 星级限制 | 修正 | 说明 |
|---|---:|---|
| 只能 1 星 | -1 | 目标价值低 |
| 只能 2 星以下 | 0 | 可处理精英，但不能处理首领 |
| 任意星级 | +1 | 可处理 3 星首领，强度明显上升 |
| 专门克制 3 星 | +1.5 | 基础版慎用，容易削弱首领牌面 |
| 无视所有保护或条件 | +2 | 通常接近法宝级或禁用级 |

3 星首领是 V1.2 基础版最高妖怪层级。能否处理 3 星首领，是技能从中等进入高强度的重要分界线。

## 十二、牌区去向修正

同样是移走守军，去向不同，强度不同。

| 去向 | 修正 | 说明 |
|---|---:|---|
| 回到拥有者手牌 | 0 | 对手失去场面，但保留资源 |
| 进入弃牌堆 | +1 | 对手失去场面和资源 |
| 加入你的手牌 | +1.5 | 对手失去资源，你获得资源 |
| 加入你的地盘 | +2 | 对手失去资源，你立刻获得场面 |
| 移出游戏 | +3 | 基础版不建议使用 |

强度排序：

```text
回到拥有者手牌
<
进入弃牌堆
≈
加入你的手牌
<
加入你的地盘
```

## 十三、行动节奏修正

每回合最多 1 个主要行动是 V1.2 核心节奏限制。

任何突破该限制的技能都必须加分并重点测试。

| 行动影响 | 修正 | 说明 |
|---|---:|---|
| 不影响行动 | 0 | 普通效果 |
| 额外查看 / 轻微动作 | +0.5 | 轻微节奏收益 |
| 额外打出 1 张妖怪 | +1 | 额外铺场 |
| 额外攻山 | +1.5 | 可能直接夺地 |
| 额外使用 1 张法宝 | +2 | 法宝本身强度高，风险大 |
| 额外执行 1 个完整主要行动 | +2.5 | 容易失控，基础版慎用 |

示例：

- 牛魔王：额外打出 1 张妖怪，属于中等偏强节奏收益
- 大鹏精：额外攻山，可能直接夺地，因此评分更高

## 十四、选择自由度修正

目标越自由，技能越强。

| 选择范围 | 修正 | 说明 |
|---|---:|---|
| 只能自己 | -1 | 通常限制较大 |
| 只能己方地盘 | -0.5 | 多为防守强化 |
| 只能敌方地盘 | 0 | 攻击性明确，但不能自保 |
| 任意玩家 | +0.5 | 信息或手牌互动更灵活 |
| 任意地盘 | +0.5 | 可攻可守，灵活度高 |
| 任意守军 | +1 | 能处理关键 3 星首领 |
| 不需要选择，自动影响最优目标 | +1.5 | 基础版慎用，容易减少博弈 |

说明：

“选择”本身不加分，选择范围才加分。

## 十五、前置条件与使用成本修正

| 条件 / 成本 | 修正 | 说明 |
|---|---:|---|
| 无条件 | 0 | 标准情况 |
| 需要己方有地盘 | -0.5 | 多数地盘互动可接受 |
| 需要目标有指定星级守军 | -0.5 | 例如只能 1 星 |
| 需要特定角色在场 | -1 | 例如玉面狐狸需要牛魔王 |
| 需要特定妖域 / 特定地盘 | -1 | 限制明显，可能卡手 |
| 需要对手即将获胜才可用 | -1.5 | 强救场但触发窄 |
| 占用主要行动 | -0.5 | 法宝通常有此成本 |
| 一次性法宝 | -0.5 | 使用后进入弃牌堆 |
| 可被金刚琢取消 | -0.5 | 法宝效果存在反制风险 |

注意：

3 星首领技能是“招兵出场附带触发”，通常不额外扣主要行动成本。

法宝效果虽然常常更强，但使用法宝占用主要行动，且使用后进入弃牌堆。

## 十六、信息技能专项评分

信息技能通常偏低，除非信息可以转化为行动或资源。

| 信息技能 | 建议等级 | 说明 |
|---|---:|---|
| 查看自己手牌 | 0 | 完全没用 |
| 查看公共牌库顶 1 张牌 | 1 | 轻微信息收益 |
| 查看地盘牌库顶 1 张地盘 | 1 | 能预判地盘补充，但不改变局面 |
| 查看一名玩家手牌 | 1~2 | 有博弈价值，但不改变资源 |
| 查看后调整牌序 | 2 | 信息转化为未来收益 |
| 查看后弃掉其中 1 张 | 3~4 | 信息转化为资源破坏 |
| 查看后获得其中 1 张 | 4 | 信息转化为资源转移 |

信息技能判断问题：

1. 看的是自己已知信息，还是未知信息？
2. 看完之后是否能改变牌序？
3. 看完之后是否能弃掉或获得？
4. 信息是否能影响当前回合决策？
5. 信息是否关联胜利妖域或关键地盘？

## 十八、胜利相关性修正

胜利条件是控制同一妖域 3 块地盘。

因此，同一个技能在不同局面下实际强度会变化。

| 局面 | 临场修正 | 说明 |
|---|---:|---|
| 普通地盘 | 0 | 正常评分 |
| 对手已有同妖域 2 块地盘 | +1 | 阻止对手胜利价值上升 |
| 你已有同妖域 2 块地盘 | +1 | 进攻或补强价值上升 |
| 技能能阻止对手立即胜利 | +1 | 救场价值高 |
| 技能能让你立即胜利 | +2 | 终结价值极高，需要测试 |

注意：

胜利相关性通常作为临场修正，不直接写入卡牌基础评分。

## 十九、资源差修正

资源差是指技能是否让一方亏、另一方赚。

| 资源变化 | 修正 | 说明 |
|---|---:|---|
| 只看信息 | 0 | 不改变牌量 |
| 让对方回手 | 0 | 对方失去场面但保留牌 |
| 让对方弃掉 | +1 | 对方失去资源 |
| 你获得 | +1 | 你增加资源 |
| 对方失去 + 你获得 | +2 | 双向资源差 |
| 对方失去地盘 + 你获得地盘 | +3 | 极高，直接关联胜利 |

示例：

```text
金鼻白毛老鼠精 = 对方少 1 只守军 + 你多 1 只地盘守军
```

因此它比普通吹回强。

## 二十一、评分流程

后续 AI 评估新技能时，按以下流程执行。

### 第一步：确认技能来源

判断技能属于：

- 3 星首领出场技能
- 法宝效果
- 扩展包候选技能
- 双人对战测试技能
- 仅用于讨论的假设技能

如果不是 V1.2 正式卡牌，不得写入正式卡表。

### 第二步：拆解动作

把技能拆成：

```text
选择对象 + 动作 + 数量 + 去向 + 持续时间 + 条件 + 世界观来源
```

示例：

```text
选择 1 块地盘，消灭其中所有 1 星守军
=
对象：地盘内 1 星守军
动作：消灭
数量：所有 1 星
去向：弃牌堆
持续时间：一次性
条件：目标地盘存在 1 星守军
世界观来源：红孩儿三昧真火 / 火烧低星小妖的表现
```

### 第三步：给基础分

根据作用对象和动作类型给初始分。

参考：

| 类型 | 常见基础分 |
|---|---:|
| 无实际收益 | 0 |
| 轻微信息 | 1 |
| 单体低星互动 | 2 |
| 单体资源差 / 2 星以下处理 | 3 |
| 任意守军 / 额外攻山 / 法宝反制 | 4 |
| 整地盘清场 / 直接控制结构变化 | 5 |

### 第四步：加入规则强度修正因子

重点检查：

- 是否群体效果
- 是否持续多回合
- 是否触发地盘无主
- 是否影响地盘控制权
- 是否能处理 3 星首领
- 是否突破主要行动限制
- 是否产生双向资源差
- 是否可自由选择目标

### 第五步：加入世界观符合度判断

必须回答：

1. 这个技能是否抓住角色 / 法宝的原著核心能力？
2. 玩家看到卡名后，是否能自然理解这个技能？
3. 动作词是否贴合原著意象？
4. 作用对象是否贴合原著表现？
5. 效果规模是否配得上角色 / 法宝牌面？
6. 是否达到芭蕉扇这种“名称、动作、规则结果高度统一”的程度？

### 第六步：扣除限制因子

重点检查：

- 是否只能 1 星
- 是否只能己方
- 是否需要特定角色在场
- 是否需要特定妖域或地盘
- 是否占用主要行动
- 是否一次性
- 是否可被金刚琢反制

### 第七步：对齐锚点

最终评分必须和锚点比较：

| 分数 | 必须接近的锚点 |
|---:|---|
| 0 | 查看自己手牌 |
| 1 | 查看牌库顶 1 张后放回 |
| 2 | 吹回 1 只 1 星守军 |
| 3 | 获得 1 只 1 星守军 / 消灭 1 只 2 星以下守军 |
| 4 | 任意守军硬处理 / 额外攻山 / 法宝反制 |
| 5 | 清空一块地盘所有守军并改变地盘状态 |

世界观符合度必须和芭蕉扇锚点比较：

| 世界观分数 | 必须接近的锚点 |
|---:|---|
| 0 | 与角色 / 法宝完全无关 |
| 1 | 牵强解释 |
| 2 | 有弱关联 |
| 3 | 符合常见印象 |
| 4 | 抓住核心能力 |
| 5 | 芭蕉扇级：名称、动作、规则结果高度统一 |

### 第八步：写出评分理由

AI 输出评分时必须写明：

1. 主要作用对象
2. 动作类型
3. 影响数量
4. 星级限制
5. 牌区去向
6. 是否影响地盘控制
7. 是否突破行动节奏
8. 西游原著世界观符合度评分
9. 世界观符合度理由
10. 最终规则强度评分

## 二十四、最关键的强度放大器

对《抢地盘》来说，以下 6 项是最重要的规则强度放大器：

| 放大器 | 为什么重要 |
|---|---|
| 影响地盘控制 | 直接关系胜利条件 |
| 处理 3 星首领 | 影响基础版最高层级单位 |
| 影响整块地盘 | 单体到群体的质变 |
| 产生双向资源差 | 对手少，你变多 |
| 突破主要行动限制 | 改变回合节奏 |
| 触发地盘回流 | 改变中央地盘节奏和妖域机会 |

另有 3 项世界观放大器：

| 世界观放大器 | 为什么重要 |
|---|---|
| 名称和动作高度一致 | 玩家容易理解和记住 |
| 原著核心能力被准确表达 | 技能有角色辨识度 |
| 规则结果能表现故事意象 | 技能不只是数值效果，而有西游味 |

判断经验：

```text
命中 1 个规则放大器：通常至少 3 分
命中 2 个规则放大器：通常 4 分以上
命中 3 个规则放大器：通常 5 分，或必须增加限制条件
世界观符合度 4~5 的技能，优先保留表达方向，再通过限制条件调平衡
```

## 二十五、禁忌与警戒线

以下技能方向需要高度谨慎：

| 技能方向 | 风险 |
|---|---|
| 直接获得 1 块地盘 | 可能绕过攻山核心体验 |
| 无条件直接完成同妖域 3 块控制 | 破坏胜利条件 |
| 全场清空守军 | 过强且结算复杂 |
| 额外执行完整主要行动 | 容易爆发失控 |
| 可重复触发的额外攻山 | 容易连锁夺地 |
| 无条件处理多个 3 星首领 | 削弱首领牌面 |
| 大量检索公共牌库 | 增加洗牌和检索成本 |
| 频繁操作地盘牌库 | 增加实体桌游维护负担 |
| 长期持续全局规则改变 | 容易创建平行系统 |
| 为了世界观强行加入复杂例外 | 破坏欢乐聚会卡牌节奏 |
| 角色技能与原著核心能力反向违和 | 降低玩家代入感和记忆点 |

## 二十六、维护原则

2. 本文件不得替代 `规则/V1.2-基础卡表.md`。
3. 本文件不得新增正式技能。

7. 若后续扩展出现新角色或新法宝，必须同时评估规则强度与西游原著世界观符合度。
8. AI 后续评估技能时，应先读取本文件，再读取正式卡表和技能汇总表。
