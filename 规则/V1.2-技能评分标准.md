# 《夕妖：抢地盘》V1.2 技能评分标准

## 文件定位

本文件用于建立《夕妖：抢地盘》V1.2 技能强度评分标准，供后续 AI、规则整理、平衡测试和扩展设计时参考。

本文件不是正式规则来源。

正式卡牌数据唯一来源：

```text
规则/V1.2-基础卡表.md
```

当前技能统计来源：

```text
规则/V1.2-技能汇总表.md
```

卡面短文案来源：

```text
规则/V1.2-卡面技能文案.md
```

本文件不得新增正式技能，不得修改正式卡表，不得创建平行规则体系。

---

## 一、评分用途

技能评分用于回答以下问题：

1. 一个技能大约有多强。
2. 两个技能是否处于同一强度层级。
3. 新技能是否可能破坏V1.2基础版节奏。
4. 法宝与3星首领技能是否存在过强或过弱问题。
5. 后续扩展包技能是否需要增加限制条件。

评分不用于：

- 卡面显示
- 直接决定卡牌星级
- 直接决定是否进入正式卡表
- 替代测试
- 替代正式规则文本

---

## 二、评分总原则

技能强度不是只看动作，也不是只看目标。

必须同时考察：

```text
作用对象 × 动作类型 × 影响数量 × 持续时间 × 牌区去向 × 地盘连锁 × 行动节奏 × 限制条件
```

简化公式：

```text
技能等级 = 基础对象价值 + 动作强度 + 放大因子 - 限制因子
```

更完整的判断公式：

```text
技能等级 =
对象价值
+ 动作强度
+ 数量修正
+ 持续时间修正
+ 地盘连锁修正
+ 行动节奏修正
+ 资源差修正
+ 选择自由度修正
- 星级限制
- 前置条件
- 使用成本
- 反制风险
```

最终评分应落在0到5之间。

## 三、技能等级锚点

### 等级0：完全无用

| 项目 | 内容 |
|---|---|
| 锚点技能 | 查看自己手牌 |
| 规则效果 | 选择你自己，查看你的手牌 |
| 强度定义 | 没有任何实际收益，只执行玩家原本就能做到的动作 |

判断标准：

- 不提供新信息
- 不改变手牌数量
- 不改变守军
- 不改变地盘
- 不改变行动
- 不改变牌区
- 不产生心理博弈

典型用途：

```text
作为0分基准，用来确认某个技能是否真的有实际意义。
```

### 等级1：有一丁点作用

| 项目 | 内容 |
|---|---|
| 锚点技能A | 查看公共牌库顶1张牌，然后放回 |
| 锚点技能B | 查看地盘牌库顶1张地盘，然后放回 |
| 强度定义 | 有极轻微信息收益，但不改变资源、场面、地盘控制或行动 |

为什么“查看地盘牌库顶1张地盘”是1分：

- 可以预判未来中央地盘补充
- 可以辅助判断是否清空地盘或等待某妖域地盘出现
- 但不抽取地盘
- 不改变地盘牌库顺序
- 不改变地盘控制
- 不保证该地盘马上出现

### 等级2：低强度实用技能

| 项目 | 内容 |
|---|---|
| 参考技能 | 吹回1只1星守军 |
| 强度定义 | 能影响场面，但目标价值低、限制明显 |

典型特征：

- 只处理1星
- 只影响单体
- 主要产生轻微节奏干扰
- 通常不能处理3星首领
- 通常不能稳定改变地盘控制

### 等级3：中等强度技能

| 项目 | 内容 |
|---|---|
| 参考技能 | 获得1只1星守军到手牌 / 消灭1只2星以下守军 / 额外打出1张妖怪 |
| 强度定义 | 能产生明确资源差、场面差或节奏收益，但仍有明显限制 |

典型特征：

- 能稳定影响守军
- 能产生资源差
- 能产生场面差
- 可能间接导致地盘无主
- 但通常不是整地盘效果
- 通常不直接完成胜利条件

### 等级4：高强度技能

| 项目 | 内容 |
|---|---|
| 参考技能 | 消灭或获得1只任意守军 / 额外攻山 / 持续强化地盘 / 取消法宝效果 |
| 强度定义 | 能处理关键对象，或显著改变节奏、资源、地盘防守结构 |

典型特征：

- 能处理3星首领
- 能反制关键法宝
- 能突破每回合1个主要行动限制
- 能持续强化关键地盘
- 能产生明显胜负相关收益

### 等级5：极高强度技能

| 项目 | 内容 |
|---|---|
| 参考技能 | 清空一块地盘所有守军并使其变为无主 |
| 强度定义 | 大范围影响关键对象，直接改变地盘控制结构或强制重置关键局面 |

典型特征：

- 影响一整块地盘
- 影响所有守军
- 能直接让地盘变为无主
- 能触发地盘回流
- 能阻断或创造胜利机会
- 通常需要限制、一次性、法宝身份或可反制机制

| 作用对象 | 基础价值 | 说明 |
|---|---:|---|
| 自己手牌 / 自己信息 | 0 | 玩家本来就知道，通常无收益 |
| 公共牌库顶 | 1 | 只有轻微信息收益 |
| 地盘牌库顶 | 1 | 能预判未来地盘，但不改变局面 |
| 对手手牌信息 | 1~2 | 有博弈价值，但不直接改变资源 |
| 玩家手牌中的牌 | 2~4 | 若只是查看偏低，若弃掉或获得偏高 |
| 1星守军 | 2 | 低价值场面单位 |
| 2星以下守军 | 3 | 覆盖1星和2星，实用性明显增加 |
| 任意守军 | 4 | 可处理3星首领，是重要分界线 |
| 一块己方地盘 | 3 | 多用于防守强化，价值取决于是否接近胜利 |
| 一块任意地盘 | 4 | 可影响敌方关键地盘，价值高 |
| 一块地盘内所有守军 | 5 | 群体作用，容易改变地盘控制 |
| 法宝效果 | 4 | 法宝属于规则级压制物，反制价值高 |
| 行动次数 / 流程 | 4~5 | 影响每回合1个主要行动的节奏限制 |
| 地盘控制权 | 5 | 直接关联胜利条件 |

## 五、动作强度表

| 动作 | 基础强度 | 说明 |
|---|---:|---|
| 查看自己已知信息 | 0 | 没有实际收益 |
| 查看未知信息 | 1 | 只有信息收益 |

| 放回原位 | 0 | 不改变牌区或局面 |

| 获得到手牌 | 3 | 对方失去场面，你获得手牌资源 |
| 获得到地盘 | 4 | 对方失去场面，你立刻获得场面 |
| 消灭 | 3~4 | 目标进入弃牌堆，强于回手 |

| 额外攻山 | 4 | 可能直接夺地，节奏爆发强 |
| 清空地盘 | 5 | 群体移除，容易改变控制权 |
| 直接改变控制 | 5 | 直接关联胜利条件，基础版慎用 |

## 六、影响数量修正

| 影响数量 | 修正 | 说明 |
|---|---:|---|
| 1个目标 | 0 | 基础单体效果 |
| 2个目标 | +1 | 明显强于单体 |
| 所有1星守军 | +1 | 群体低星处理 |
| 所有2星以下守军 | +1.5 | 群体中低星处理，强度高 |
| 一块地盘内所有守军 | +2 | 直接影响地盘控制结构 |
| 全场所有目标 | +3 | 基础版慎用，通常不建议进入基础牌库 |

## 七、持续时间修正

| 持续时间 | 修正 | 说明 |
|---|---:|---|
| 立即一次性结算 | 0 | 基础值 |
| 持续到本回合结束 | +0.5 | 短期战术价值 |
| 持续到你的下回合开始 | +1 | 覆盖一轮对手行动，防守价值提升 |
| 持续到目标地盘失控 | +1.5 | 地盘是胜利目标，持续收益明显 |
| 永久持续 | +2 | 基础版慎用，可能破坏平衡 |

示例：

- 玉面狐狸：持续到你的下回合开始，因此有一定防守价值
- 九灵元圣：持续到地盘失去控制，因此强度明显高于一次性小效果

## 八、地盘连锁修正

《抢地盘》的关键连锁是：

```text
守军被移走 / 消灭
→ 地盘失去全部守军
→ 地盘变为无主
→ 地盘回流
→ 中央地盘区补充
```

| 连锁能力 | 修正 | 说明 |
|---|---:|---|
| 不可能触发地盘无主 | 0 | 只看信息或只强化 |
| 可能触发地盘无主 | +0.5 | 单体移除最后守军时可能触发 |
| 经常触发地盘无主 | +1 | 常见局面下能打空地盘 |
| 必定触发地盘无主 | +1.5 | 清空一整块地盘 |
| 同时触发回流与中央补充 | +2 | 影响地盘循环节奏 |

判断重点：

- 技能是否直接写“该地盘变为无主”
- 技能是否能清空所有守军
- 技能是否能处理最后1只守军
- 目标地盘是否是某妖域胜利关键地盘

## 九、是否影响地盘控制权

| 地盘影响 | 修正 | 说明 |
|---|---:|---|
| 不影响地盘 | 0 | 只看信息或处理手牌 |
| 可能间接影响地盘 | +0.5 | 单体守军位移或消灭 |
| 高概率让地盘无主 | +1 | 群体低星处理或关键守军处理 |
| 直接让地盘无主 | +1.5 | 清空地盘或明确变无主 |
| 直接夺取地盘 | +2 | 基础版慎用 |
| 直接完成胜利条件 | 需要单独测试 | 通常不建议无条件出现 |

地盘控制是《抢地盘》最高价值对象，因为胜利条件是控制同一妖域3块地盘。

## 十、是否能处理3星首领

| 星级限制 | 修正 | 说明 |
|---|---:|---|
| 只能1星 | -1 | 目标价值低 |
| 只能2星以下 | 0 | 可处理精英，但不能处理首领 |
| 任意星级 | +1 | 可处理3星首领，强度明显上升 |
| 专门克制3星 | +1.5 | 基础版慎用，容易削弱首领牌面 |
| 无视所有保护或条件 | +2 | 通常接近法宝级或禁用级 |

3星首领是V1.2基础版最高妖怪层级。能否处理3星首领，是技能从中等进入高强度的重要分界线。

## 十一、牌区去向修正

同样是移走守军，去向不同，强度不同。

| 去向 | 修正 | 说明 |
|---|---:|---|
| 回到拥有者手牌 | 0 | 对手失去场面，但保留资源 |
| 进入弃牌堆 | +1 | 对手失去场面和资源 |
| 加入你的手牌 | +1.5 | 对手失去资源，你获得资源 |
| 加入你的地盘 | +2 | 对手失去资源，你立刻获得场面 |
| 移出游戏 | +3 | 基础版不建议使用 |

强度排序：

```text
回到拥有者手牌
<
进入弃牌堆
≈
加入你的手牌
<
加入你的地盘
```

## 十二、行动节奏修正

每回合最多1个主要行动是V1.2核心节奏限制。

任何突破该限制的技能都必须加分并重点测试。

| 行动影响 | 修正 | 说明 |
|---|---:|---|
| 不影响行动 | 0 | 普通效果 |
| 额外查看 / 轻微动作 | +0.5 | 轻微节奏收益 |
| 额外打出1张妖怪 | +1 | 额外铺场 |
| 额外攻山 | +1.5 | 可能直接夺地 |
| 额外使用1张法宝 | +2 | 法宝本身强度高，风险大 |
| 额外执行1个完整主要行动 | +2.5 | 容易失控，基础版慎用 |

示例：

- 牛魔王：额外打出1张妖怪，属于中等偏强节奏收益
- 大鹏精：额外攻山，可能直接夺地，因此评分更高

## 十三、选择自由度修正

目标越自由，技能越强。

| 选择范围 | 修正 | 说明 |
|---|---:|---|
| 只能自己 | -1 | 通常限制较大 |
| 只能己方地盘 | -0.5 | 多为防守强化 |
| 只能敌方地盘 | 0 | 攻击性明确，但不能自保 |
| 任意玩家 | +0.5 | 信息或手牌互动更灵活 |
| 任意地盘 | +0.5 | 可攻可守，灵活度高 |
| 任意守军 | +1 | 能处理关键3星首领 |
| 不需要选择，自动影响最优目标 | +1.5 | 基础版慎用，容易减少博弈 |

说明：

“选择”本身不加分，选择范围才加分。

## 十四、前置条件与使用成本修正

| 条件 / 成本 | 修正 | 说明 |
|---|---:|---|
| 无条件 | 0 | 标准情况 |
| 需要己方有地盘 | -0.5 | 多数地盘互动可接受 |
| 需要目标有指定星级守军 | -0.5 | 例如只能1星 |
| 需要特定角色在场 | -1 | 例如玉面狐狸需要牛魔王 |
| 需要特定妖域 / 特定地盘 | -1 | 限制明显，可能卡手 |
| 需要对手即将获胜才可用 | -1.5 | 强救场但触发窄 |
| 占用主要行动 | -0.5 | 法宝通常有此成本 |
| 一次性法宝 | -0.5 | 使用后进入弃牌堆 |
| 可被金刚琢取消 | -0.5 | 法宝效果存在反制风险 |

注意：

3星首领技能是“招兵出场附带触发”，通常不额外扣主要行动成本。

法宝效果虽然常常更强，但使用法宝占用主要行动，且使用后进入弃牌堆。

## 十五、信息技能专项评分

信息技能通常偏低，除非信息可以转化为行动或资源。

| 信息技能 | 建议等级 | 说明 |
|---|---:|---|
| 查看自己手牌 | 0 | 完全没用 |
| 查看公共牌库顶1张牌 | 1 | 轻微信息收益 |
| 查看地盘牌库顶1张地盘 | 1 | 能预判地盘补充，但不改变局面 |
| 查看一名玩家手牌 | 1~2 | 有博弈价值，但不改变资源 |
| 查看后调整牌序 | 2 | 信息转化为未来收益 |
| 查看后弃掉其中1张 | 3~4 | 信息转化为资源破坏 |
| 查看后获得其中1张 | 4 | 信息转化为资源转移 |

信息技能判断问题：

1. 看的是自己已知信息，还是未知信息？
2. 看完之后是否能改变牌序？
3. 看完之后是否能弃掉或获得？
4. 信息是否能影响当前回合决策？
5. 信息是否关联胜利妖域或关键地盘？

| 作用对象 / 动作 | 查看 | 获得 | 吹回 | 消灭 | 弃掉 | 强化 | 额外行动 |

| 自己手牌 | 0 | 1~2 | - | - | 0~1 | 1 | 1 |
| 对手手牌 | 1~2 | 3~4 | - | - | 3~4 | - | - |
| 公共牌库顶 | 1 | 2~3 | - | - | 2 | - | - |
| 地盘牌库顶 | 1 | 2~3 | - | - | 2 | - | - |
| 1星守军 | - | 2~3 | 2 | 2 | 2 | 1~2 | - |
| 2星以下守军 | - | 3 | 3 | 3 | 3 | 2~3 | - |
| 任意守军 | - | 4 | 3 | 4 | 4 | 3 | - |
| 一块己方地盘 | 1 | - | - | - | - | 3~4 | 2~3 |

- 若技能可处理3星首领，应额外加分。

## 十七、胜利相关性修正

胜利条件是控制同一妖域3块地盘。

因此，同一个技能在不同局面下实际强度会变化。

| 局面 | 临场修正 | 说明 |
|---|---:|---|
| 普通地盘 | 0 | 正常评分 |
| 对手已有同妖域2块地盘 | +1 | 阻止对手胜利价值上升 |
| 你已有同妖域2块地盘 | +1 | 进攻或补强价值上升 |
| 技能能阻止对手立即胜利 | +1 | 救场价值高 |
| 技能能让你立即胜利 | +2 | 终结价值极高，需要测试 |

注意：

胜利相关性通常作为临场修正，不直接写入卡牌基础评分。

---

## 十八、资源差修正

资源差是指技能是否让一方亏、另一方赚。

| 资源变化 | 修正 | 说明 |
|---|---:|---|
| 只看信息 | 0 | 不改变牌量 |
| 让对方回手 | 0 | 对方失去场面但保留牌 |
| 让对方弃掉 | +1 | 对方失去资源 |
| 你获得 | +1 | 你增加资源 |
| 对方失去 + 你获得 | +2 | 双向资源差 |
| 对方失去地盘 + 你获得地盘 | +3 | 极高，直接关联胜利 |

示例：

```text
金鼻白毛老鼠精 = 对方少1只守军 + 你多1只地盘守军
```

因此它比普通吹回强。

## 十九、反制与规避修正

| 反制 / 规避情况 | 修正 | 说明 |
|---|---:|---|
| 几乎无法反制 | +0.5 | 稳定性高 |
| 可被金刚琢取消 | -0.5 | 法宝存在反制风险 |
| 需要目标存在，可能空发 | -0.5 | 目标环境限制 |
| 需要己方条件，容易卡手 | -1 | 例如特定角色在场 |
| 对手可提前规避 | -0.5 | 例如避免堆1星 |
| 效果公开且可被预判 | -0.5 | 长期效果容易被绕开 |

## 二十、评分流程

后续AI评估新技能时，按以下流程执行。

### 第一步：确认技能来源

判断技能属于：

- 3星首领出场技能
- 法宝效果
- 扩展包候选技能
- 双人对战测试技能
- 仅用于讨论的假设技能

如果不是V1.2正式卡牌，不得写入正式卡表。

### 第二步：拆解动作

把技能拆成：

```text
选择对象 + 动作 + 数量 + 去向 + 持续时间 + 条件
```

示例：

```text
选择1块地盘，消灭其中所有1星守军
=
对象：地盘内1星守军
动作：消灭
数量：所有1星
去向：弃牌堆
持续时间：一次性
条件：目标地盘存在1星守军
```

### 第三步：给基础分

根据作用对象和动作类型给初始分。

参考：

| 类型 | 常见基础分 |
|---|---:|
| 无实际收益 | 0 |
| 轻微信息 | 1 |
| 单体低星互动 | 2 |
| 单体资源差 / 2星以下处理 | 3 |
| 任意守军 / 额外攻山 / 法宝反制 | 4 |
| 整地盘清场 / 直接控制结构变化 | 5 |

### 第四步：加入修正因子

重点检查：

- 是否群体效果
- 是否持续多回合
- 是否触发地盘无主
- 是否影响地盘控制权
- 是否能处理3星首领
- 是否突破主要行动限制
- 是否产生双向资源差
- 是否可自由选择目标

### 第五步：扣除限制因子

重点检查：

- 是否只能1星
- 是否只能己方
- 是否需要特定角色在场
- 是否需要特定妖域或地盘
- 是否占用主要行动
- 是否一次性
- 是否可被金刚琢反制

### 第六步：对齐锚点

最终评分必须和锚点比较：

| 分数 | 必须接近的锚点 |
|---:|---|
| 0 | 查看自己手牌 |
| 1 | 查看牌库顶1张后放回 |
| 2 | 吹回1只1星守军 |
| 3 | 获得1只1星守军 / 消灭1只2星以下守军 |
| 4 | 任意守军硬处理 / 额外攻山 / 法宝反制 |
| 5 | 清空一块地盘所有守军并改变地盘状态 |

### 第七步：写出评分理由

AI输出评分时必须写明：

1. 主要作用对象
2. 动作类型
3. 影响数量
4. 星级限制
5. 牌区去向
6. 是否影响地盘控制
7. 是否突破行动节奏
8. 最终评分

## 二十三、最关键的强度放大器

对《抢地盘》来说，以下6项是最重要的强度放大器：

| 放大器 | 为什么重要 |
|---|---|
| 影响地盘控制 | 直接关系胜利条件 |
| 处理3星首领 | 影响基础版最高层级单位 |
| 影响整块地盘 | 单体到群体的质变 |
| 产生双向资源差 | 对手少，你变多 |
| 突破主要行动限制 | 改变回合节奏 |
| 触发地盘回流 | 改变中央地盘节奏和妖域机会 |

判断经验：

```text
命中1个放大器：通常至少3分
命中2个放大器：通常4分以上
命中3个放大器：通常5分，或必须增加限制条件
```

## 二十四、禁忌与警戒线

以下技能方向需要高度谨慎：

| 技能方向 | 风险 |
|---|---|
| 直接获得1块地盘 | 可能绕过攻山核心体验 |
| 无条件直接完成同妖域3块控制 | 破坏胜利条件 |
| 全场清空守军 | 过强且结算复杂 |
| 额外执行完整主要行动 | 容易爆发失控 |
| 可重复触发的额外攻山 | 容易连锁夺地 |
| 无条件处理多个3星首领 | 削弱首领牌面 |
| 大量检索公共牌库 | 增加洗牌和检索成本 |
| 频繁操作地盘牌库 | 增加实体桌游维护负担 |
| 长期持续全局规则改变 | 容易创建平行系统 |
