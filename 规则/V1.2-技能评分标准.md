# 《夕妖：抢地盘》V1.2 技能评分标准

## 文件定位

本文件用于建立《夕妖：抢地盘》V1.2 技能强度评分标准，供后续 AI、规则整理、平衡测试、扩展设计和对战版数值设计时参考。

本文件不是正式规则来源。

正式卡牌数据唯一来源：

```text
规则/V1.2-基础卡表.md
```

当前技能统计来源：

```text
规则/V1.2-技能汇总表.md
```

本文件是技能评分标准唯一维护文件。

本文件不得新增正式技能，不得修改正式卡表，不得创建平行规则体系。

---

## 一、核心原则

以后评估技能时，必须给出**整数技能强度评分**。

技能强度评分采用：

```text
无上限累计分
```

不再使用：

- 0 到 5 等级
- 0.0 到 5.0 小数分
- 1 到 100 封顶分
- 只写“强 / 弱 / 中等”
- 只写“等级 3”

推荐输出格式：

```text
技能：XXX
技能强度评分：168
评分理由：XXX
```

重要边界：

- **技能强度评分只评价规则强度。**
- **技能强度评分不设置上限。**
- **100 只是芭蕉扇级强技能参照点，不是满分。**
- **西游原著世界观符合度不参与技能强度评分。**
- **世界观符合度只在某个技能被选中、准备进入候选或正式讨论时另行评分。**
- **世界观符合度必须与技能强度评分完全分开记录。**

---

## 二、评分用途

技能强度评分用于回答以下问题：

1. 一个技能在游戏规则中有多强。
2. 两个技能是否处于同一强度层级。
3. 新技能是否可能破坏 V1.2 基础版节奏。
4. 法宝与 3 星首领技能是否存在过强或过弱问题。
5. 后续扩展包技能是否需要增加限制条件。
6. 后续双人对战版是否可以复用某个技能强度参数。

技能强度评分不用于：

- 卡面显示
- 直接决定卡牌星级
- 直接决定是否进入正式卡表
- 替代测试
- 替代正式规则文本
- 评价西游原著贴合度

---

## 三、评分总公式

技能强度不是只看动作，也不是只看对象。

必须同时考察：

```text
作用对象 × 动作类型 × 受影响战力 × 影响数量 × 持续时间 × 牌区去向 × 地盘连锁 × 行动节奏 × 选择自由度 × 限制条件
```

推荐公式：

```text
技能强度评分 = 锚点分 + 超出锚点的放大因子 - 限制因子
```

完整判断项：

```text
技能强度评分 =
锚点基础分
+ 受影响战力修正
+ 数量修正
+ 持续时间修正
+ 地盘连锁修正
+ 行动节奏修正
+ 资源差修正
+ 选择自由度修正
+ 多玩家 / 多地盘修正
- 星级限制
- 前置条件
- 使用成本
- 反制风险
```

最终评分为整数，不设置上限。

特殊说明：

- 完全无用技能可记为 0，用作理论锚点。
- 正式技能、候选技能和对战版技能原则上使用正整数。
- 100 不是满分，而是“芭蕉扇级强技能”参照点。
- 芭蕉扇作为 100 分锚点的原因不是“让 1 块地盘变无主”本身，而是它一张牌按基础地盘上限最多可吹回 9 星战力，打乱对手约 3 个回合的铺场布局，并重置关键地盘控制结构。
- 芭蕉扇 100 分按基础地盘上限 3 只守军计算；若目标地盘因九灵元圣等效果上限提高，实际评分可按额外战力继续加分。
- “影响约 3 个回合布局”是按对手通常需要多次主要行动重新部署关键守军估算，不是硬规则。
- 若技能只是让地盘变无主，不自动等于 100 分；例如 1 星打 1 星也可能让两块地盘变无主，但其消耗与收益结构远低于芭蕉扇。
- 如果一个技能消灭 9 星战力，应高于芭蕉扇。
- 如果一个技能收走对手 9 星战力并加入你的手牌，应高于消灭 9 星战力。
- 如果一个技能同时清空全场守军、获得所有玩家手牌、夺取多个关键资源，应继续向上累计，可能达到 180、240、300 甚至更高。

## 四、锚点优先原则

评分时必须先找最接近的锚点。

如果一个技能已经命中某个锚点，优先使用该锚点分数，不再重复叠加该锚点已经包含的对象、数量、地盘无主、回流、战力总量、回合布局影响等加分。

只能对**超出锚点的新效果**继续加分。

### 示例 1：芭蕉扇

芭蕉扇效果：

```text
吹回 1 块地盘全部守军，该地盘变为无主。
```

评分：

```text
技能强度评分 = 100
```

不能重复算成：

```text
100 + 影响所有守军 + 直接变无主 + 回流 + 影响 3 回合布局
```

因为这些内容已经包含在芭蕉扇 100 分锚点中。

### 示例 2：强化芭蕉扇

若新技能为：

```text
吹回 1 块地盘全部守军，该地盘变为无主，然后查看地盘牌库顶 1 张。
```

可以评为：

```text
100 + 轻微信息收益 5~10 = 105~110
```

因为查看地盘牌库顶是芭蕉扇锚点之外的新效果。

### 示例 3：消灭 9 星战力

若新技能为：

```text
消灭 1 块地盘全部守军，该地盘变为无主。
```

应直接对齐 120 分锚点，而不是先用芭蕉扇 100 再机械加所有弃牌修正。

## 五、累计分数刻度

| 分数范围 | 强度层级 | 含义 |
|---:|---|---|
| 0 | 无效 | 完全没有实际作用，只作为理论锚点 |
| 1 ~ 19 | 极弱 | 几乎无用，只有极轻微信息或提示价值 |
| 20 ~ 39 | 弱 | 有轻微收益，可影响局面但限制明显 |
| 40 ~ 59 | 中 | 有明确场面、资源或节奏收益 |
| 60 ~ 79 | 强 | 能影响关键对象、关键地盘或关键节奏 |
| 80 ~ 99 | 极强 | 大范围影响、强制重置、接近胜负关键 |
| 100 ~ 149 | 超强 | 芭蕉扇级或高于芭蕉扇，能显著改变胜负结构 |
| 150 ~ 219 | 破局级 | 多区域、多牌区或多玩家资源同时被强影响 |
| 220 以上 | 失控级 / Boss级 | 多个核心系统同时被强制重置或夺取，通常不适合普通基础牌库 |

## 六、强度锚点

| 分数 | 锚点技能 | 判断标准 |
|---:|---|---|
| 0 | 查看自己手牌 | 玩家本来就知道，完全没有收益 |
| 20 | 查看公共牌库顶 1 张牌，然后放回 | 有极轻微信息收益，不改变局面 |
| 22 | 查看地盘牌库顶 1 张地盘，然后放回 | 有轻微地盘信息收益，不改变局面 |
| 40 | 吹回 1 只 1 星守军 | 低星、单体、轻度场面影响 |
| 44 | 消灭 1 只 1 星守军 | 低星单体去除，比回手重 |
| 50 | 消灭 1 只 2 星以下守军 | 可处理 2 星，但不能处理 3 星 |
| 60 | 获得 1 只 1 星守军并放入己方地盘 | 产生明确场面差 |
| 68 | 额外打出 1 张妖怪牌 | 突破铺场节奏，但不直接攻山 |
| 74 | 红孩儿式：消灭 1 块地盘内所有 1 星守军 | 可消灭最多 3 星战力，但只限 1 星守军，低于芭蕉扇 |
| 80 | 消灭 1 只任意守军 | 可处理 3 星首领，是高强度分界线 |
| 86 | 立即发动一次攻山 | 可能直接夺地，节奏爆发强 |
| 88 | 取消 1 次法宝效果 | 反制规则级压制物 |
| 92 | 获得 1 只任意守军并加入你的手牌 | 高资源差，可处理 3 星 |
| 100 | 芭蕉扇：吹回 1 块地盘全部守军，该地盘变为无主 | 按基础上限最高吹回 9 星战力，打乱对手约 3 个回合布局，是当前基础版强技能锚点 |
| 120 | 消灭 1 块地盘全部守军，该地盘变为无主 | 同样影响最高 9 星战力，但目标进入弃牌堆，对手不能直接重新部署，强于芭蕉扇回手 |
| 150 | 收走 1 块地盘全部守军并加入你的手牌 | 最高转移 9 星战力到你手牌，形成巨大双向资源差，明显强于消灭 9 星 |
| 180 | 清空全场所有守军，使全部有守军地盘变为无主 | 全场级重置，通常不低于 180，具体按受影响战力、地盘数、玩家数继续累计 |
| 240 | 清空全场所有守军并全部加入你的手牌 | 全场清场 + 所有守军资源转移到自己手牌 |
| 300 | 清空全场守军到自己手牌，并获得其他所有玩家的全部手牌 | 同时夺取场面资源与手牌资源，是失控级锚点 |

## 八、受影响战力总量修正

后续对战版会高度依赖战力总量，因此评估技能时必须记录“最多影响多少星战力”。

| 受影响战力 | 修正判断 | 说明 |
|---:|---|---|
| 0 | 信息或流程技能 | 不直接影响守军战力 |
| 1 | 低星单体影响 | 典型 1 星小妖 |
| 2 ~ 3 | 单体常规影响 | 2 星精英或 3 星首领 |
| 4 ~ 6 | 中等群体影响 | 多只低星或两只中高星 |
| 7 ~ 9 | 芭蕉扇级地盘影响 | 基础上限 3 只守军时，一块地盘最高 9 星 |
| 10 ~ 12 | 超过基础地盘上限 | 通常来自九灵元圣等上限强化，应高于 100 |
| 13 以上 | 全场或异常局面 | 应继续累计，通常进入 150+ 区间 |

### 战力总量评分建议

| 受影响战力 | 建议加分 |
|---:|---:|
| 1 | +0 |
| 2 ~ 3 | +5 |
| 4 ~ 6 | +10 |
| 7 ~ 9 | +20 |
| 10 ~ 12 | +30 |
| 13 ~ 18 | +45 |
| 19 以上 | +60 起，按实际战力继续累计 |

说明：

- 如果锚点已经包含战力总量，例如芭蕉扇 100 已包含基础 9 星战力，不要重复加 7~9 星修正。
- 如果技能超过锚点，例如吹回 12 星战力，可以在芭蕉扇 100 的基础上加 10~12 星的额外战力差额修正。
- 对战版应记录“理论最高影响战力”和“常见局面影响战力”两个字段。

## 十、扣分因子

| 因子 | 扣分 |
|---|---:|
| 只能 1 星 | -10 |
| 只能 2 星以下 | -4 |
| 只能己方地盘 | -6 |
| 只能自己 | -12 |
| 需要特定角色在场 | -14 |
| 需要特定妖域 / 特定地盘 | -14 |
| 需要对手即将获胜才可用 | -20 |
| 占用主要行动 | -6 |
| 一次性法宝 | -4 |
| 可被金刚琢取消 | -4 |

| 效果公开且容易被规避 | -6 |

- 3 星首领技能是“招兵出场附带触发”，通常不额外扣主要行动成本。

- 扣分后若低于 1，正式候选技能记为 1；理论无效锚点可以记为 0。

## 十一、关键修正维度

### 1. 持续时间

| 持续时间 | 修正 |
|---|---:|
| 立即一次性结算 | 0 |
| 持续到本回合结束 | +5 |
| 持续到你的下回合开始 | +7 |
| 持续到目标地盘失控 | +12 |
| 永久持续 | +18，基础版慎用 |

### 2. 地盘连锁

《抢地盘》的关键连锁是：

```text
守军被移走 / 消灭
→ 地盘失去全部守军
→ 地盘变为无主
→ 地盘回流
→ 中央地盘区补充
```

| 连锁能力 | 修正 |
|---|---:|
| 不可能触发地盘无主 | 0 |
| 可能触发地盘无主 | +5 |
| 经常触发地盘无主 | +10 |
| 必定触发 1 块地盘无主 | +14 |
| 必定触发多块地盘无主 | +30 起，按地盘数量继续累计 |
| 同时触发 1 块地盘回流与中央补充 | +20 |
| 同时触发多块地盘回流与中央补充 | +45 起，按地盘数量继续累计 |

### 3. 是否影响地盘控制权

| 地盘影响 | 修正 |
|---|---:|
| 不影响地盘 | 0 |
| 可能间接影响地盘 | +5 |
| 高概率让地盘无主 | +10 |
| 直接让 1 块地盘无主 | +14 |
| 直接让多块地盘无主 | +30 起，按地盘数量继续累计 |
| 直接夺取 1 块地盘 | +20，基础版慎用 |
| 直接夺取多块地盘 | +50 起，基础版慎用 |
| 直接完成胜利条件 | 单独测试，通常不建议无条件出现 |

### 4. 是否能处理 3 星首领

| 星级限制 | 修正 |
|---|---:|
| 只能 1 星 | -10 |
| 只能 2 星以下 | -4 |
| 任意星级 | +12 |
| 专门克制 3 星 | +18，基础版慎用 |
| 无视所有保护或条件 | +25，通常接近禁用级 |

### 5. 牌区去向

同样影响 9 星战力时，牌区去向决定强度阶梯。

| 去向 | 修正 |
|---|---:|
| 回到拥有者手牌 | 0 |
| 进入弃牌堆 | +20 |
| 加入你的手牌 | +50 |
| 加入你的地盘 | +60 |
| 全场守军加入你的手牌 | +120 起，按总战力继续累计 |
| 其他玩家全部手牌加入你的手牌 | +160 起，按玩家数与手牌数量继续累计 |
| 移出游戏 | +60，基础版不建议使用 |

强度排序：

```text
回到拥有者手牌
<
进入弃牌堆
<
加入你的手牌
<
加入你的地盘
<
全场守军加入你的手牌
<
其他玩家全部手牌加入你的手牌
```

## 十六、世界观符合度评分

世界观符合度用于评估技能是否符合《西游记》原著中角色、法宝、神通、情节和玩家直觉。

重要边界：

- 世界观符合度只对已经选中的技能评分。
- 没有选中、没有进入候选、只是随口发散的技能，不必评分。
- 世界观符合度不参与技能强度评分。
- 世界观符合度不参与对战版强度换算。
- 世界观符合度只作为选中技能后的表达质量、保留优先级和风味判断。

### 1. 世界观符合度 1~100 整数评分

| 分数范围 | 含义 |
|---:|---|
| 1 ~ 19 | 几乎无关，甚至违和 |
| 20 ~ 39 | 弱关联，牵强解释 |
| 40 ~ 59 | 有关联，但不是核心特征 |
| 60 ~ 79 | 符合常见印象 |
| 80 ~ 99 | 高度符合核心能力 |
| 100 | 芭蕉扇级，名称、动作、规则结果高度统一 |

### 2. 世界观满分锚点：芭蕉扇

| 项目 | 内容 |
|---|---|
| 锚点法宝 | 芭蕉扇 |
| 当前规则效果 | 选择 1 块地盘，将其中所有守军吹回拥有者手牌。该地盘立即变为无主地盘 |
| 世界观符合度 | 100 |

为什么芭蕉扇是世界观 100 分锚点：

- 原著印象中，芭蕉扇的核心就是“大范围扇动、吹退、压制、改变局面”。
- 当前规则中的“吹回所有守军”直接对应“扇飞 / 吹走”的玩家直觉。
- “一块地盘变为无主”对应芭蕉扇对场景级局面的强干预。
- 法宝名称、动作词“吹回”、规则结果三者高度统一。
- 玩家看到芭蕉扇，不需要解释太多，就能理解它应该是大范围地盘压制法宝。

### 3. 世界观符合度示例

| 分数 | 示例模板 | 说明 |
|---:|---|---|
| 1 | 芭蕉扇：查看自己手牌 | 与法宝核心印象完全无关 |
| 20 | 芭蕉扇：查看公共牌库顶 1 张牌 | 只有“神奇法宝”这种弱关联 |
| 40 | 芭蕉扇：吹回 1 只 1 星守军 | 有吹回意象，但规模太小 |
| 60 | 芭蕉扇：吹回 1 只任意守军 | 符合“吹走”，但不够法宝牌面 |
| 80 | 芭蕉扇：吹回 1 块地盘所有 1 星守军 | 大范围吹回，符合度高，但不够完整 |
| 90 | 芭蕉扇：吹回 1 块地盘所有守军，但地盘不变无主 | 世界观很贴，但少一层场景压制 |
| 100 | 芭蕉扇：吹回 1 块地盘所有守军，该地盘变为无主 | 名称、动作、场景级结果高度统一 |

### 4. 世界观符合度评分维度

| 维度 | 问题 |
|---|---|
| 原著核心能力 | 技能是否抓住角色 / 法宝最有代表性的能力？ |
| 玩家直觉 | 玩家看到名字后，是否能猜到效果方向？ |
| 动作词贴合 | 技能动词是否贴合角色 / 法宝意象？ |
| 作用对象贴合 | 技能影响对象是否符合原著表现？ |
| 规模贴合 | 效果规模是否配得上角色 / 法宝牌面？ |
| 结果贴合 | 结算结果是否符合玩家对原著能力的期待？ |
| 记忆点 | 技能是否容易被玩家用一句话记住？ |
| 不违和 | 技能是否避免反向设定？ |

## 十八、对战版使用说明

后续若开发双人 30 卡对战版，可以复用本文件的评分逻辑，但必须重新评估以下内容：

1. 对战版不一定有地盘回流，因此涉及地盘无主的加分要重新计算。
2. 对战版如果有 4 星、5 星，能否处理高星单位要重新校准。
3. 对战版如果每回合允许多动作，额外行动的价值会下降。
4. 对战版如果有费用系统，同一技能分数要结合费用重新换算。
5. 对战版如果没有公共地盘牌库，查看地盘牌库顶这类技能应重评。
6. 对战版必须记录“理论最高影响战力”和“常见局面影响战力”。

建议对战版增加字段：

| 字段 | 说明 |
|---|---|
| 抢地盘技能强度评分 | 当前 V1.2 环境评分，可超过 100 |
| 对战版技能强度评分 | 在双人对战环境下重新评分，可超过 100 |
| 理论最高影响战力 | 极限情况下最多影响多少星战力 |
| 常见局面影响战力 | 正常对局中最常见的影响战力 |
| 世界观符合度评分 | 只对选中技能另行评分，可复用但不参与强度 |
| 推荐费用 / 星级 | 根据对战版系统另行计算 |

## 十九、禁忌与警戒线

以下技能方向需要高度谨慎：

| 技能方向 | 风险 |
|---|---|
| 直接获得 1 块地盘 | 可能绕过攻山核心体验 |
| 无条件直接完成同妖域 3 块控制 | 破坏胜利条件 |
| 全场清空守军 | 过强且结算复杂 |
| 清空全场守军并全部加入自己手牌 | 超高资源转移，普通基础牌库不建议 |
| 获得其他所有玩家全部手牌 | 破坏手牌系统，普通基础牌库不建议 |
| 清空全场守军到自己手牌，并获得其他玩家全部手牌 | 失控级技能，只适合作为极端锚点或 Boss 事件参考 |
| 额外执行完整主要行动 | 容易爆发失控 |
| 可重复触发的额外攻山 | 容易连锁夺地 |
| 无条件处理多个 3 星首领 | 削弱首领牌面 |
| 大量检索公共牌库 | 增加洗牌和检索成本 |
| 频繁操作地盘牌库 | 增加实体桌游维护负担 |
| 长期持续全局规则改变 | 容易创建平行系统 |
| 为了世界观强行加入复杂例外 | 破坏欢乐聚会卡牌节奏 |
| 角色技能与原著核心能力反向违和 | 降低玩家代入感和记忆点 |

## 二十、维护原则

1. 本文件是技能评分标准唯一维护文件。
2. 后续所有技能强度评估必须给出整数评分。
3. 理论无效锚点可以记为 0。
4. 技能强度评分不设上限，按效果累计。
5. 100 不是满分，是芭蕉扇级强技能参照点。
6. 芭蕉扇 100 分锚点的核心是按基础上限最多吹回 9 星战力、打乱对手约 3 个回合布局、重置关键地盘控制结构。
7. 同样让地盘无主的效果，不能自动等同于 100 分。
8. 评分时优先匹配锚点，不得重复叠加锚点已包含的加分项。
9. 消灭 9 星战力高于芭蕉扇；收走对手 9 星战力到自己手牌高于消灭 9 星战力。
10. 技能强度评分和世界观符合度评分必须完全分开。
11. 世界观符合度只对选中的技能评分，不对所有发散技能逐一评分。
12. 综合设计分不作为默认字段，避免混淆强度与世界观。
13. 本文件不得替代 `规则/V1.2-基础卡表.md`。
14. 本文件不得新增正式技能。
15. 本文件不得修改卡牌数量、星级、胜利条件或核心规则。
16. 若 `规则/V1.2-技能汇总表.md` 的评分发生变化，本文件的参考评分应同步检查。
17. 若后续扩展出现新对象、新动作或新牌区，必须先确认不与当前 V1.2 基础规则冲突，再补充评分标准。
18. 若后续对战版规则成型，应新增对战版专用评分表，不得反向覆盖本文件。
