# 《夕妖：抢地盘》规则版本与文件标记规范

规则版本：V1.3  
更新时间：2026-07-05

## 文件定位

本文件规定《夕妖：抢地盘》项目内文档的规则版本标记方式。

本文件用于避免不同版本文件混用，便于快速识别未更新文件。

---

## 核心要求

自 V1.3 起，所有新建或更新的项目文件，必须在文件开头显式标明：

```text
规则版本：Vx.x
更新时间：YYYY-MM-DD
```

适用范围包括：

```text
规则文件
卡表文件
技能评分文件
测试报告
视觉规范
包装文案
运营计划
流程规范
```

---

## 标准写法

Markdown 文件推荐写法：

```markdown
# 文件标题

规则版本：V1.3  
更新时间：2026-07-05
```

若文件不是规则文件，但受某个规则版本约束，也应写：

```markdown
# 文件标题

适用规则版本：V1.3  
更新时间：2026-07-05
```

---

## 文件状态判断

| 文件标记 | 判断 |
|---|---|
| `规则版本：V1.3` | 当前版本文件 |
| `适用规则版本：V1.3` | 当前版本配套文件 |
| `规则版本：V1.2` 或更早 | 历史文件，除非当前规则入口明确引用，否则不作为当前规则来源 |
| 没有版本标记 | 旧文件或待更新文件，需要检查是否仍适用于当前版本 |

---

## 当前版本入口

当前规则入口为：

```text
规则/当前规则.md
```

当前基础卡表为：

```text
规则/V1.3-基础卡表.md
```

当前核心规则为：

```text
规则/V1.3-核心规则.md
```

扩展包候选与移出基础版卡牌记录为：

```text
规则/V1.3-扩展包与移出基础版卡表.md
```

---

## 维护原则

1. 每次主规则版本升级，必须同步更新 `规则/当前规则.md`。
2. 每次卡牌数量、卡牌归属或基础卡表发生变化，必须新建或更新当前版本基础卡表。
3. 历史版本文件不直接删除，除非明确进入归档整理。
4. 历史文件必须通过文件名、文件头或当前规则入口判断是否仍是当前来源。
5. 没有版本标记的文件，默认视为需要复核的旧文件。
