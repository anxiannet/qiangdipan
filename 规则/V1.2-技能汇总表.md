## 三、强度评分标准

强度评分为1到5分。

| 分值 | 强度等级 | 判断标准 |
|---:|---|---|
| 1 | 很低 | 信息、轻微条件收益、对局面影响小 |
| 2 | 低 | 单体低星处理、条件型防守、低幅度节奏收益 |
| 3 | 中 | 单体抢夺、单体任意处理、额外行动、明显节奏收益 |
| 4 | 高 | 多目标处理、永久性地盘强化、反制关键牌、强地盘压制 |
| 5 | 极高 | 大范围清场、直接改变地盘归属结构、强制重置关键局面 |

评分维度：

- 作用对象是否关键
- 影响数量
- 是否限制星级
- 是否产生资源差
- 是否改变地盘控制权
- 是否占用主要行动
- 是否带有触发条件
- 是否可反制高星首领或法宝

## 十一、关键观察

### 1. 当前技能主要围绕守军互动

16个技能 / 法宝效果中，直接以守军为主要对象的有9个。

这说明V1.2的主要互动集中在：

- 吹回
- 偷取
- 抓走
- 消灭
- 清空地盘

符合“派妖占山、妖怪驻守、驻军攻山”的核心体验。

### 2. 牌库直接互动很少

当前没有直接操作公共牌库或地盘牌库的技能。

这有利于：

- 降低规则复杂度
- 降低洗牌、检索、记忆成本
- 保持实体桌游节奏

后续若设计牌库互动，应谨慎控制数量。

### 3. 3星首领与法宝强度边界清楚

3星首领多数在2到4分之间。

法宝整体偏高，主要因为：

- 可处理任意星级守军
- 能直接反制法宝
- 能清空地盘

这符合“法宝属于规则级压制物”的定位。

### 4. 芭蕉扇是当前最高压制效果

芭蕉扇同时影响：

- 一整块地盘
- 所有守军
- 玩家手牌
- 地盘控制权
- 地盘回流

因此评分为5。

### 5. 需要重点测试的技能组

| 技能组 | 测试问题 |
|---|---|
| 黄风怪 / 黄风大圣 / 铁扇公主 / 芭蕉扇 | 吹回梯度是否足够清楚 |
| 青狮精 / 红孩儿 / 紫金红葫芦 | 消灭类效果是否压制过强 |
| 牛魔王 / 大鹏精 | 额外行动是否造成回合爆发过高 |
| 九灵元圣 / 玉面狐狸 | 防守强化是否足够有存在感 |
| 白骨精 | 信息技能是否偏弱，是否需要靠玩家心理博弈体现价值 |

## 十二、按作用对象归类的基础动作

本节用于把当前规则与技能中的基础动作按作用对象归类。

本节只做动作词整理，不新增规则效果。

|---|---|---|
| 查看 | 查看一名玩家手牌，不改变牌的位置 | 白骨精 |
| 加入手牌 | 将获得的守军加入你的手牌 | 黄袍怪、幌金绳 |

| 基础动作 | 含义 | 当前来源 / 卡牌 |
|---|---|---|
| 选择守军 | 指定地盘中的1只守军作为目标 | 多数守军技能 |

### 3. 地盘

| 基础动作 | 含义 | 当前来源 / 卡牌 |
|---|---|---|

### 6. 弃牌堆

| 基础动作 | 含义 | 当前来源 / 卡牌 |
|---|---|---|
| 进入弃牌堆 | 被消灭、收走或结算后的牌进入弃牌堆 | 青狮精、红孩儿、紫金红葫芦、法宝使用后 |
| 弃掉 | 把目标牌放入弃牌堆 | 紫金红葫芦 |
| 法宝结算后弃掉 | 法宝使用后进入弃牌堆 | 所有法宝 |
| 被取消后弃掉 | 法宝效果被取消，但法宝仍进入弃牌堆 | 金刚琢 |

当前没有从弃牌堆回收、查看、检索的正式技能。

### 7. 法宝效果

| 基础动作 | 含义 | 当前来源 / 卡牌 |
|---|---|---|
| 使用法宝 | 打出法宝并结算效果 | 所有法宝 |
| 取消 | 取消1次法宝效果 | 金刚琢 |
| 反制 | 针对刚打出的法宝进行处理 | 金刚琢 |
| 结算后弃掉 | 法宝效果结束后进入弃牌堆 | 所有法宝 |

### 8. 行动 / 流程

| 基础动作 | 含义 | 当前来源 / 卡牌 |
|---|---|---|
| 招兵 | 打出1张妖怪牌，占山或增援 | 基础行动 |
| 占山 | 将妖怪放到中央无主地盘，获得控制权 | 基础招兵 |
| 增援 | 将妖怪加入己方已有地盘 | 基础招兵 |
| 攻山 | 从己方地盘派守军攻打其他玩家地盘 | 基础行动 |
| 额外攻山 | 技能允许立即发动一次攻山 | 大鹏精 |
| 使用法宝 | 打出并结算法宝 | 基础行动 |
| 额外打出妖怪 | 技能允许立即再打出1张妖怪牌 | 牛魔王 |
| 结束阶段弃牌 | 手牌超过上限时弃至上限 | 基础流程 |
